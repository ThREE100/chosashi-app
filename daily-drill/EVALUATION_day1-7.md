# 毎日ドリル Day1〜7 の評価と、量産・網羅のための指針

予備校講師の立場での評価。過去問の傾向は、リポジトリの年度別記事（`note-articles-Kijyutsu/` の H20〜R8、第21問・第22問）で整理した内容による。配点・出題頻度の公式な公表はないので、「頻度」は記事から数えた目安である。

## 1. 総合評価

| 観点 | 評価 | 一言 |
|---|---|---|
| 正確さ（答え・条文・計算） | A | 条文の原文照合、別の方法での検算、F-789SGのキー列の再現、別エージェントによる独立照合まで行っている。教材として信頼できる |
| 本番の様式への近さ | B＋ | 条件・聞き取り結果・注・座標表・図・回答欄は本番どおり。ただし1問の規模が小さい（点が3〜4個、独立）ので、本番の「連鎖する計算」の負荷は再現できていない |
| 本番に役立つ力がつくか | B | 部品練習（計算の型・条文・欄の書き方）としては有効。合格点（記述式で安定して得点する力）には、統合演習と網羅の追加が必要 |
| 網羅性 | C＋ | 7日分では当然だが、土地の「型」が3つ、建物が新築・増築の2つ。択一は不動産登記法と調査士法のみ（民法なし） |
| 量産の仕組み | B | 生成・検査の流れはある（`calc_exam.py`／`gen_shinsei.py`／`calc_keys.py`／`check_pm.py`）。ただし問題は手書きで、型とパラメータの仕様がまだない |

結論：**「正確な部品練習」としては合格水準。「本番の得点力」に変えるには、①連鎖する計算、②公差・精度区分の判断、③作図（地積測量図・建物図面・各階平面図）、④週1回の統合演習、⑤誤答の型別の記録、の5つを足す必要がある。**

## 2. 朝のドリル（択一1問＋条文の空欄補充）

**良い点**
- 択一は本番の形式（ア〜オの5肢、組合せ選択、「正しい／誤っている」の混在）にそろえてある。
- 択一と空欄補充の条文を分け、ヒントの重なりを避けている。引用は原文と機械照合し、正誤を伏せた独立照合も行っている。
- 空欄補充は「判断のカギになる語」だけを空欄にしており、記述式の穴埋め（令別表・条文の定義語）に直結する。

**弱い点・改善点**
1. **民法が0問**。本番の配分（民法3・不動産登記法16・調査士法1）に対し、7日間は不動産登記法5・調査士法2。週ごとの配分表で、民法は出題履歴のある条文に限って組み込む。
2. **条文の正誤が中心**。本番は、条文の言い換えに加えて、①事例の当てはめ（「Aが…した場合」）、②規則・準則・先例（通達）の知識、③数字・期間・主体のすり替えが多い。ドリルは①が少なく、②は原文確認が必要なため後回しになっている。事例型を週2〜3問は混ぜる。
3. **難度が一定**。やさしい肢だけで構成すると、本番の「迷う肢」への耐性がつかない。1問の中に、定番の肢（確認用）と紛らわしい肢（判断用）を1〜2個ずつ入れる難度指定を作る。
4. **誤答の記録が自己採点だけ**。どの型（数字のすり替え／主体のすり替え／例外の見落とし／事例の当てはめ）で間違えたかを記録する欄（またはタグ）がない。復習日程（土曜小テスト・日曜復習記事）は仕様のみで未作成。

### 3.3 Day1〜7 の出来栄え

**良い点**
- 条件・聞き取り結果・注・座標表・図・回答欄の配置が本番に近い。地積測量図などの参照元を表の題で示している。
- 聞き取り結果に「ひっかけ」（ブロック塀は筆界でない、擁壁の東1.20m、など）があり、判断力を問える。
- 解答に F-789SG の複素数キー列（式・キー・表示の3点セット）があり、確認済みのキーだけを使っている。
- 申請書は、問題文（試験の構成）と白紙の申請書（記入）に分かれ、欄ごとの根拠条文を引用している。

**弱い点・改善点**
1. **計算が短く、独立している**。本番は、点の求め方が連鎖する（Aの座標→Bの放射→C→D…）。どこか1か所の誤りが後ろに伝わる。Day1〜7 は独立した3〜4点で、「検算が効く」実戦の流れ（検算の距離・杭の位置との一致で誤りに気づく）がない。連鎖6〜8点の問題を週1回入れる。
2. **公差・精度区分の判断がない（T8）**。本番は「この場合地積更正が必要か」「分筆後の地積の合計と登記記録の差が公差内か」の判断が申請書の欄（登記の目的・原因）に影響する。計算の後に判断を続ける設問を足す。
3. **作図がない（T9・B7）**。本番の配点の大きい部分（地積測量図・建物図面・各階平面図）を、ドリルでは扱っていない。A4では、解答欄に「枠・縮尺・方位・辺長・境界標の凡例」を自分で描かせる問題が必要。
4. **申請書の「事案の複雑さ」が本番より小さい**。本番は複数の登記を1件にまとめるか分けるか（一の申請情報）、代位・相続人、抵当権者の承諾、複数筆の合筆・分筆の組み合わせが絡む。Day2・3・5・6は1事案1登記。
5. **建物の型が2つ**。本番で頻度の高い「合体・合併・分割・区分」「滅失＋再築」「附属建物の符号」「独立性の判断」が未着手。
6. **時間配分の訓練がない**。夜15分は部品練習としては妥当だが、本番（記述式は1問あたり約90分が目安）の1/6。月に1回は、土地または建物の1問を本番の時間で解く統合演習を置く。
7. **法令改正・出題当時との違い**（会社法人等番号、住所変更登記の義務化など）を問題文に入れる運用が必要（過去問記事の方針と同じ）。

## 4. 量産・網羅のための指針

### 4.1 型 × 難度 × 論点の表で管理する

- 土地は T1〜T11、建物は B1〜B8（上表）を行とし、難度（L1 単独の計算／L2 2〜3点の連鎖／L3 6〜8点の連鎖＋判断）を列とする。1問ごとに「型・難度・論点（条文）・ひっかけの種類」をメタデータとして `problems/*.json` に持たせ、網羅の穴を表で見えるようにする。
- 優先順位（頻度の高い順）：T1・T2・T9・T10・B1・B7 → T3・T4・T8・B2・B3 → T5・T6・T11・B4〜B6。

### 4.2 ひっかけのカタログ（問題を作るときに必ず1つ以上入れる）

- 計算：観測角の向き（時計回り）、後視の読みが0でない、直角に測る（Yだけ足さない）、点の丸めと面積の順、切捨て（宅地）と四捨五入の取り違え、杭と筆界の違い（ブロック塀・擁壁・犬走り）。
- 申請書：申請人（登記名義人か、借地人・建築費負担者か）、添付情報（令別表の項の添付と、一般の添付〈令第7条〉）、登録免許税（分筆後の個数）、原因の日付（完成日か検査済証か引渡か）、原因の欄番号（②③）。
- 建物：床面積の算入しないもの（出窓・屋外階段・特殊階）、増築後の面積を一度に切り捨てる、階数に数えないもの、独立性。

### 4.3 生成と検査の流れ（現状の延長）

1. 型の関数（座標・観測値・パラメータを引数にする）で問題を作る。**手書きの個別問題をやめ、型ごとに乱数ではなく「設計済みの値」を入れる**（四捨五入の境目を避ける）。
2. 方法A（複素数）と方法B（実数・射影・二分法・靴ひも）で答えを検算。
3. F-789SGのキー列を実行して表示を再現（`calc_keys.py`）。
4. 条文引用の原文照合。
5. 別エージェントの独立照合（申請書は必須、計算は文章の曖昧さのチェック）。
6. A4に2枚で収まるか（クリップを外したPDFのページ数）。
