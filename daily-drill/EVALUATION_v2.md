## 2. 択一式の詳しい評価

- **量**：朝の択一は AM-001〜AM-008 の8問。夜は114日分あるのに、朝は第9日以降がない。過去問の一問一答（`tools/drill`）は別にあるが、毎日ドリルの「初見の問題で判断する」練習が続かない。
- **配分**：朝の計画（`schedule.py`）は、7日あたり不動産登記法4・民法2・調査士法1。本番の配点は不動産登記法（規則・準則・先例を含む）16問・民法3問・調査士法1問なので、民法と調査士法に偏っている。規則・準則は計画の単位に入っていない。
- **難度**：SAT01 は20問すべて、法令を見ない段階で正解された（独立に解いた記録）。原因は、正誤が「条文の原文だけで一つに決まる」肢に限ったため、条文の文言をそのまま言い換えた肢が多くなったこと。本番で差がつくのは、事例への当てはめ、複数の条文の組合せ、規則・準則・先例の知識。
- **良い点**：原文と一字一句照合した根拠、正誤を伏せた独立の照合、ひっかけの型（M1〜M10）の記録、誤答を型で記録するログ。

## 3. 記述式の詳しい評価

- **申請書（75書式）**：網羅は十分。ただし、答えを一つに決めるため注で書き方（欄番号の冠記・原因の文言の形）を与えすぎている問がある。本番では書き方そのものが問われるので、頻出の書式は「注を減らした2周目」を作るとよい（次の改善候補）。
- **計算（37問）**：連鎖・検算・公差・キー列まであり、本番水準。答えが一つに決まるかを機械で確かめている。
- **作図（2問）**：少ない。
- **統合（0問）**：本番形式がない。これが記述式の最大の弱点。

## 4. 改善（この評価にもとづいて実施）

1. **朝の配分を本番に合わせる**：`schedule.py` の比率を、不動産登記法（法・令・規則・準則）中心に改め、規則・準則の単位を加える。民法は出題頻度の高い条文だけ、調査士法は3週に1回程度。
2. **朝の択一を2週間分（第9日〜第22日、14問）追加**：条文・事例・規則準則・先例をまぜ、紛らわしい肢を各問2つ以上入れる。先例は、リポジトリの過去問の解説（`note-articles/`）に記載のあるものだけを使い、その記載を根拠として機械照合する。
3. **土曜模擬の第2回（SAT02）を本番水準で作る**：事例の当てはめ・複数条文の組合せ・規則と準則・先例を中心にし、作っていない担当が法令を見ずに解いた正答率が6〜8割になることを目標に確かめる。
4. **本番形式の統合問題（土地1問・建物1問、各60分）を作る**：1つの事案で、計算（座標・地積または床面積）→申請書→図面（地積測量図または建物図面・各階平面図）を通して解く。計算は計算エンジン、申請書は書式ひな形の検査、図面は自己採点の項目で確かめる。

改善の結果は、この文書の末尾に追記する。

### 独立に解いた担当の指摘で直したこと（統合問題）

- **s01**：申請書の表題・作図の指示・解き方の手順に「地積更正」「③錯誤」と書いてあり、第1部の判断の答えが先に分かった。表題を「分筆の登記等の申請書」にし、指示と手順から外した。基準点T1の備考「市道の南側」が座標と合わなかったので、「器械点」「後視点」にした。
- **s02**：問題文に構造（「木造スレートぶき2階建」など）がそのまま書いてあった。また、第3部の条件で2階の壁の中心線の寸法（7.28×5.46）を明かしていた。材料・屋根の事実（事実関係3）と外面の寸法だけを残し、構造の組み立てと寸法の読み替えを受験者にさせる形に直した。

### 残っている課題（次の改善候補）

1. 統合問題は2問しかない。本番の第21問・第22問の頻出の型（例：建物の区分、合体、土地の分合筆、座標の変換をからめた問題）で、月に2問のペースで増やす。
2. 作図の練習量がまだ少ない。地積測量図・建物図面の作図だけを15分で行う夜の問題を加える。
3. 申請書の「注を減らした2周目」を作っていない。頻出の書式から作る。
4. 独立に解いた担当はAIなので、正答率は人の受験者の難度の目安にとどまる。実際に解いた結果を `kiroku.py` で記録し、型別の正答率で難度を調整する。
5. 朝の択一は第22日分まで。計画の230日分に向けて、2週間ごとに14問ずつ追加する（作成と独立照合の手順は確立済み）。
