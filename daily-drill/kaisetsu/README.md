# ドリルの解説記事（note用）

**執筆ルールの正本は `PROMPT_解説記事の作成.md`。記事を作るたびにその末尾の「PDCAの手順」を回し、プロンプトとチェッカーを改良して、「改善記録」に残す。** 記事は `src/dayNNN.py` のデータから `python3 build_kaisetsu.py N` で組み立てる（Day004は手書きの見本）。

毎日ドリルの択一（朝）の解説記事を、初学者向けに具体例つきで書いて保存する場所。記事の構成は、択一の過去問の解説記事（`note-articles/format-template.md`）と同じ型で、図解インフォグラフィックのプロンプトを記事の末尾に備える。

## 置き方

- 記事：`day{NNN}-am-kaisetsu.md`（例：`day004-am-kaisetsu.md`）。
- 出題行は「**出題：毎日ドリル　第N日（朝）　択一**」。ドリルはオリジナル問題なので、年度・午前午後の部は書かない。noteの引用の出典欄は空欄にする。
- 画像の生成はユーザーが行う。ここに置くのはプロンプトまで。

## 記事の構成（この順番）

1. タイトル（`## 【土地家屋調査士受験生向け】毎朝ドリル_Day004_択一解説～キャッチフレーズ～`。Dayは3桁、キャッチフレーズは25字以内、です・ます調か体言止め）
2. 出題行
3. 問題文の引用（`>`ブロック。各行の間に`>　  `、行末に半角スペース2つ。選択肢の行まで含める）→ `---`
4. 導入文（2〜3文）
5. 各肢の解説（`### ア：正しい結論を表すフレーズ`。結論＋条文番号 → 正誤の一言 → 「**たとえば**、」の具体例）
6. `---` → `### まとめ`（`- **ア（正）** …` の箇条書き）→ 結論文 → `**正解：…の組合せ（選択肢N番）**`
7. 補足説明（必要なとき。`### 補足説明（ウ・エ）：…`）→ `---` → 確認事項ブロック
8. `## 見出し画像用フレーズ`（肢の数だけ）
9. `## 見出し画像プロンプト`（女性のMCキャラクター1人だけ）
10. `## インフォグラフィック プロンプト（問題全体）`（②。カードに番号を付けない）
11. `## インフォグラフィック プロンプト（◯肢・間違いノート）`（補足説明をつけたとき。④。枚数は必要なだけ）

## 守ること

- 初学者が用語と場面を結びつけられるよう、具体例（売買・抵当権など）を入れる。条文の読み方の説明はしない。
- 括弧は全角。判例・先例の番号は本文に書かない。法令の条文番号は書いてよい。
- 条文は `note-articles/laws/` の原文で確かめる。確かめられない箇所は、確認事項ブロックに分けて書く。
- 図解プロンプトは `note-articles/infographic-prompt-template.md` の②・④に従う（絵の中の文字は指定した語だけ、背景は不透明、簡体字・繁体字なし、樹形図の意味の「木」「ツリー」を書かない）。
- 個人の演習結果・内部のファイル名・道具の名前は、記事にもプロンプトにも書かない。

## 機械チェック

`python3 daily-drill/kaisetsu/check_kaisetsu.py`（NG 0件にする）。
