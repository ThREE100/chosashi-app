# 毎日ドリル（朝：択一＋書いて説明／夜：記述式）

2027年（令和9年）の試験に向け、**見るだけでなく、自分で書く・解く**ことで定着させるための、1日2回・各15分のA4ドリル。

| 時間帯 | 内容 | 所要 |
|---|---|---|
| 朝 | オリジナル択一1問（5肢・組合せ）＋条文の空欄補充 | 毎朝10分（択一4分＋空欄補充6分） |
| 夜 | 記述式1ページ：①境界点の計算の抜き出し（類題）、②登記申請書の欄を完成させる練習 | 毎晩15分 |

## 使い方
`python3 daily-drill/build.py` で `out/` にA4印刷用のHTMLができる（`out/index.html` から開く）。ブラウザで印刷（A4・余白なし）するか、タブレットに書き込む。
問題と解答は別ファイル。朝の解答には、根拠条文の引用と、書く問題の「原文（音読用）」が付く。

## 作り方と品質の担保
**択一（朝）**：過去問は使わず、`note-articles/laws/` の条文だけから作ったオリジナル。
1. `morning/problems/AM-NNN.json`：問題文・肢・正誤・根拠の引用・解説・書く問題の模範解答と採点ポイント
2. `check_am.py`：根拠の引用が原文に一字一句あるか、正解の選択肢がちょうど1つか、採点ポイントが条文の言葉か、個人の演習結果・過去問の出典が混じっていないか
3. **独立照合**：問題文・肢・条文原文だけを別のエージェントに渡し（正誤・解説は伏せる）、全肢の正誤を判定させて一致を確認（`morning/review/`。問題文を直すと照合が古くなりNGになる）

**記述式（夜）**
- 計算（`evening/calc_exam.py`）：本番レベルの筆界点の計算。条件・聞き取り結果・注の文章と、地積測量図等の座標表・観測値の表、座標から正確に描いた図（`figure.py` の `svg_generic`）で出す。回答欄は問題文の最初に置く。複素数の式（方法A）で答えを出し、`check_pm.py` が三角関数・クラメルの公式・射影・二分法・三角形分割（方法B）で解き直して一致を確認。
- 電卓操作（`evening/calc_keys.py`）：解答ページに、キヤノン F-789SG の複素数モードのキー列（式・キー・表示の3点セット）を載せる。キー列は `note-articles-Kijyutsu/tools/keysim_note_article.py` でそのまま実行して表示を再現し、`check_pm.py` が答えと一致することを確かめる（使うキーは note-articles-Kijyutsu の執筆指示書の「確認済みのキー操作」だけ。負の数は「0 − 数」で入れる）。問題を作り直したら `python3 daily-drill/evening/calc_exam.py` → `calc_keys.py` の順に実行する。
- 申請書（`evening/gen_shinsei.py`）：土地2回・建物2回。登録免許税法・不動産登記令別表・規則・準則の原文を引用し、引用の原文照合に加え、問題文と条文だけを渡した別のエージェントに解かせて答えが一致することを確認。

数値や論点を新しく作ったら `python3 daily-drill/check_all.py` がNG 0件になること。

## 作成ルールと量産の仕組み
- **`RULES.md`**：朝・夜の作成ルールの正本（配分・難度・ひっかけ・作り方・次に作る型の設計）。
- `taxonomy.json`（分類のID）、`registry.json`（各問の型・難度・ひっかけ）、`coverage/coverage.md`（網羅表。自動生成）。
- 新しい問題：`python3 daily-drill/new_problem.py …` で雛形と仮登録 → TODOを埋める → `check_all.py`。
- 評価と背景：`EVALUATION_day1-7.md`。
- **書式ひな形の一覧と出題順**：`forms_catalog.py`（77書式のうちNo.2〜77。出題数の目安と作成状況）、`schedule/forms-order.md`（出題数の多いものが先に出やすい乱数順。自動生成）。75書式すべて作成済み（PM-02〜PM-81）。PM-17以降は `evening/forms/pmNN.py` の1問1ファイルで、作り方は `RULES.md` の3.6。

## 夜の記述式ドリルの形式（毎回A4で2枚）
- **計算の日（第1・4・7日）**：1枚目＝回答欄（先頭）、問題文（条件・聞き取り結果・注）。2枚目＝座標にもとづく図（黒丸＝与えられた点、赤い白抜き＝求める点）と、地積測量図・道路境界確認書・観測値などの表。地積測量図を使う問題は、表の題に作成年を書いて参照元を明示する。解答ページには、求めた点を赤丸で入れた図と、解き方を載せる。電卓のキー操作・計算メモの欄は置かない。
- **申請書の日（土地2回：第2・5日、建物2回：第3・6日）**：1枚目は本番の試験の構成（事実関係・登記記録・測量成果や各階平面図・注）、2枚目は白紙の申請書に記入する。解答ページは記入例と、欄ごとの根拠条文の引用。第2日＝土地分筆、第3日＝建物の新築（表題登記）、第5日＝土地の地目変更、第6日＝建物の増築（表題部の変更）。
- 申請書の問題は、条文の引用に加え、地積・床面積を座標・寸法から別の方法で計算し直して一致を確かめ（`check_pm.py`）、問題文・注と原文だけを渡した別のエージェントに解かせた結果と比べている（`evening/review/README.md`）。
- A4に2枚で収まることは、印刷時のクリップ（`overflow:hidden`）を外したPDFのページ数が2であることで確かめる。

| 2 | 地目・地積の変更、滅失、更正の登記の申請（法37・38・42条） | 調査士の業務（調査士法3条） | 土地分筆の申請書 |

| 5 | 分筆・合筆の申請人と職権、権利の消滅（法39・40条） | 調査士の義務（調査士法22〜25条） | 土地地目変更の申請書 |

空欄補充は、条文を号（項）の順に要約した表の、判断のカギになる語を空欄にした形式（`…` は条文の言葉の省略）。埋めた文が原文に一字一句あることを機械で確かめている。

## 注意
- 個人の演習結果（誤答など）は問題・解説に入れない。
- 現行法令は `note-articles/laws/`（2026-08-04取得）を正とする。法改正があれば原文を更新してから作り直す。
- 申請書の欄は、条文で根拠を示せる範囲に限っている。条文で決まらない書き方（地番の付け方など）は出題しない。

## 週のリズム（土曜・日曜）
- **土曜：択一式の小テスト（20問・20分）**。本番と同じ構成（民法3問、不動産登記法16問、土地家屋調査士法1問）。19問は、アからオの5つの記述から、正しいもの（誤っているもの）2つの組合せを5択から選ぶ形式。1問は、教授と生徒の連続会話形式で、教授の問に対する生徒の回答5つから、2つの組合せを5択から選ぶ形式。問題は新規作成し、条文との照合（引用の原文確認）と独立照合を終えてから保存する。
- **日曜：復習記事**。土曜のテストを自分で解いた結果をもとに、復習問題を解説する記事を作る（個人の演習結果は記事に載せない）。
- 平日の毎日ドリルは、条文の出題スケジュール（優先度順）で進める。

### noteタイトルの設定ルール（固定）
- 朝：`【土地家屋調査士試験】Day001-AM_毎朝10分ドリル ｜択一＋条文の空欄補充`
- 夜：`【土地家屋調査士試験】Day001-PM_毎日これだけ ｜記述式演習`
- 番号は Day001 のように、先頭が大文字のDで3けた（`note_build.py` の `TITLE_AM`・`TITLE_PM`。形が違うと作成時にエラーになる）。「ドリル」「これだけ」と「｜」の間には半角スペースが1つ入る。
- 見出し画像の左上のバッジも同じ番号（Day001-AM / Day001-PM）。
- **誤答の記録**：解いたら `python3 daily-drill/kiroku.py add <問題> <○|△|×> [型…]`（またはスキル `/kiroku`）。集計と解き直しの予定は `log/report.md`、説明は `log/README.md`。
- **土曜の20問模擬**：`saturday/`（問題 `out/sat01.html`、解答 `out/sat01-ans.html`）。作り方は `RULES.md` の5。
- **記述式デイリー（計算）の量産**：`evening/chain_specs/pmNN.py` の SPEC から `evening/gen_chain.py` で作る（Day85〜114 作成済み）。作り方は `RULES.md` の4.4。

## 配布用のPDFを作る（2026-10-25）

`python daily-drill/make_pdf.py`（Chrome か Edge と、`pip install pypdf` が必要）で、`out/` の全ページを `pdf/` にPDFで書き出す。`day001`・`sat01` のように名前の頭を付けると、その分だけ書き出す。
- ヘッダー・フッター（日付・ファイルの場所）は付かない。網掛け・色は付く（ページ側で `print-color-adjust: exact` を指定しているので、ブラウザから手で印刷しても背景は出る）。
- PDFのプロパティ（作成者・作成アプリなど）は `make_pdf.py` の `DOC_INFO` の値だけにし、ブラウザの版・PCのユーザー名・ファイルの場所は残さない（XMPメタデータも消す）。書き出した後、文書情報と本文にユーザー名・ホームフォルダ・`file:///` が入っていないことを確かめる。
- 各ページの右下に「令和8年8月時点の法令による」が出る（`build.py` の `LAW_BASE`。法令データを更新したら直す）。2枚以上になるページでも全ページに出る。
- `pdf/` はリポジトリに入れない（`.gitignore`）。

## noteに貼る画像を作る（2026-10-25）

`python daily-drill/make_images.py`（Chrome か Edge と、`pip install pypdfium2 pillow` が必要）で、朝・夜の**問題ページだけ**をPNGにして `images/` に書き出す（解答・解説は書き出さない）。印刷と同じ見た目（A4、背景あり、ヘッダー・フッターなし）で、横1240ピクセル（`--width 1600` で変更）。1枚のページは `day001-am.png`、2枚のページは `day001-pm-1.png`・`-2.png`。PNGに文書情報は入れない。`images/` はリポジトリに入れない（`.gitignore`）。
