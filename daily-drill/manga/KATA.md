# 毎日ドリル 学習まんが版の型（朝の択一・夜の記述式）

ひっかけ診断ノートで検証済みの学習まんがの型（`note-unei/hikkake-shindan/kaiwa/02-gakushu-manga-no-kata.md`）を、毎日ドリルの解説に使うための型。
共通部品は `tools/gakushu_manga/`。1ページ＝1枚（1024×1536）、文字は全部プロンプトに一字一句書く、名前・役割名は出さない（話し手は吹き出しのしっぽ）、
生徒＝左・先生＝右、個人の演習結果は入れない、は同じ。

## 朝（択一）：`am/`

5つの肢を、罠の肢から先に見せて、条文の地図で全体をつかませる。

| 段 | ページ | 中身 |
|---|---|---|
| 1 | 扉 | 問いの柱を1枚の絵で。生徒は「全部○かも」と罠に向かう |
| 2 | つまずき | 罠の肢（誤りの肢、または誤りに見える正しい肢）で生徒が引っかかり、先生が止める |
| 3 | 図解の大ゴマ | 根拠の条文（項・号）の地図を1ページで |
| 4〜 | 肢ごと | 1ページに肢2つまで。肢の記号と○×のはんこ、決め手の語をナレーションで |
| 末の前 | 確かめクイズ | 3問 |
| 末 | まとめ | 見出し「答え：選択肢N（…）」、5肢を「ア ○ …」の形で全部並べる |

- 作り方：`src/dayNNN.py`（台本。`problem='AM-NNN'`）→ `python3 daily-drill/manga/am/src/build_manga_am.py` → `python3 daily-drill/manga/am/src/check_manga_am.py`（NG 0件）。
- 生成物：`dayNNN-am-manga.md`（note記事。問題の引用は問題データから自動）、`_prompts.md`、`-codex-instructions.md`、`-chatgpt-github-instructions.md`。手で直さない。
- 機械チェック（朝）：まとめの5肢の○×が問題データの truth と同じ、答えの選択肢が mode・choices から出した正解と同じ、コマの中の「肢の記号＋○×」も truth と同じ、漫画の「第N条」が問題の根拠（basis）の条だけ、数が問題データにある、生成物が最新。
- 解説の中身は、同じ日の択一解説（`daily-drill/kaisetsu/dayNNN-am-kaisetsu.md`）の結論の範囲で描き、正誤・内容を変えない。
- タイトル：`【土地家屋調査士試験】DayNNN-AM_漫画で解説～キャッチ～`（ドリルのnoteタイトルの番号の形に合わせた）。

## 夜（記述式）：`pm/`

計算の手順を、**Claude が作った正確な図**を漫画の中に置いて追わせる。

| 段 | ページ | 中身 |
|---|---|---|
| 1 | 扉 | 求めるもの（点・地積）を問いのカードに |
| 2 | 図で見る | 問題の図（正確な図）を大ゴマに。与えられた点と求める点を見分ける |
| 3 | つまずき | 問題文の罠（観測角の向き、塀の位置、端数など）。【条件】【注】の番号を名指しする |
| 4〜 | 手順ごと | 式とその答えをホワイトボードの文字で。交点などは図（一部を描いた図）を大ゴマに |
| 末の前 | 答えの図 | 求めた点を赤丸と座標で描いた正確な図 |
| 末 | まとめ | 「この問題のポイント」 |

### 図の作り方（夜）
- 描くのは `src/figs.py`。問題データ（`evening/problems/PM-NN.json` の `fig`）から、ドリルの問題・解答ページと同じ作図（`daily-drill/figure.py` の `svg_generic`）で SVG を作り、Chromium で PNG に書き出す。手で描かない。
- 種類（台本の `fig` の `kind`）：`mondai`＝問題の図、`kotae`＝答えの図（求めた点を赤丸、座標を `coord_pos` の位置に書き足す）、`sub`＝問題の図の一部（`points`・`lines` で絞り、太い赤線で見せたい線を強調）。
- 寸法：図の viewBox は 1000×700。漫画の枠は 944×661（同じ縦横比）。PNG は枠の2倍（1888×1322）で書き出す。
- 命名と置き場所：`daily-drill/manga/pm/fig/<問題ID>_<種類>.svg`・`.png`（例 `PM-01_mondai.png`、`PM-01_kouten.png`、`PM-01_kotae.png`）。SVG も残す（照合用）。
- 呼び出し：プロンプトの該当コマに「FIGURE SLOT」として、ファイル名・`https://raw.githubusercontent.com/ThREE100/chosashi-app/main/daily-drill/manga/pm/fig/<名前>.png`・枠の位置（x, y）と大きさを書き、「そのまま置き、描き直さない。枠に人物・吹き出し・ナレーションを重ねない」と指示する。ナレーションの枠は図の枠の上（パネルの左上）に入るよう、図の枠の上に40px以上あける。
- ChatGPT：図のあるページは、6枚のキャラクターシートと一緒にその図のPNGを添付する（貼り付け文の見出し一覧に印）。崩れたら `tools/gakushu_manga/paste_fig.py` で枠に貼り直す。
- 図を作ったら、PNGを開いて、ラベル・座標が重なっていないかを目で確かめる（`coord_pos` で位置を直す）。

### 作り方（夜）
`src/dayNNN.py`（台本。`problem='PM-NN'`）→ `python3 daily-drill/manga/pm/src/build_manga_pm.py`（図も作る）→ `python3 daily-drill/manga/pm/src/check_manga_pm.py`（NG 0件）。

機械チェック（夜）：答え（answers）の値が全部漫画にある、漫画の数が問題データにある（わざと見せる誤りは `wrong_values` に書き、答えと同じ数は不可）、`refs` で名指しした【条件】【注】の番号の文にその語がある、図の求める点の座標が答えと同じ、図の SVG が問題データから作り直したものと同じ、PNGの縦横比が枠と同じ、プロンプトに図のURLがある、生成物が最新。

タイトル：`【土地家屋調査士試験】DayNNN-PM_漫画で解説～キャッチ～`。
