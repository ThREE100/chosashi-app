# 条文穴埋め（単独アプリ）

不動産登記法・不動産登記令・不動産登記規則・不動産登記事務取扱手続準則・区分所有法の
条文の空欄（全19セット・239問）に語句を入力し、正誤を判定する学習アプリ。
既存の「土地家屋調査士 トレーニング」とは別のアプリ（ログイン不要）。

- 公開URL: https://three100.github.io/chosashi-app/anaume/ （`main` に push すると GitHub Actions で自動公開）
- iPhone は Safari で開いて「ホーム画面に追加」するとアプリとして使える（オフラインでも動く）

## 使い方

- **演習**: 法令ごとのセット（レジュメの1ページ＝1セット）を選び、空欄に入力して「採点する」。
  Enter で次の空欄へ。「ヒント（語群）」でレジュメの語群（順不同）を表示できる。
- **表記ゆれ**: 全角半角・空白・漢数字（「二週間」と「2週間」）・カタカナ／ひらがなの違いは自動で正解にする。
  それ以外で意味が同じなら、採点後に「正解扱いにする」を押す（履歴に「正解扱い」と残る）。
- **復習（1日2回）**: 朝の回（0〜12時）と夜の回（12〜24時）に、期限が来た問題を「今日の復習」から解く。
  - 間違えた問題は次の回に出る（朝に間違えたらその日の夜、夜なら翌朝）。
  - 間違えた回数と同じ回数だけ正解すると復習リストから消える（3回間違えた問題は3回正解が必要）。
    復習中にまた間違えると、必要な正解数は通算の間違い回数に戻る。
  - 復習の回で正解するたびに、次の出題までの間隔を忘却曲線に合わせて延ばす
    （次の回 → 1日後 → 2日後 → 4日後 → 7日後）。
  - 正解の数は、出題予定の回（期限が来た回）に答えたものだけ数える（同じ回に何度も解いて一気に消すことはできない）。
    復習をさぼった回の問題は、次に開いた回にまとめて出る。
- **正誤の履歴**: 「正誤の履歴・復習リストを見る」で、復習リスト（残りの正解数・次回）、解答履歴（日時・入力・○×）、日別の集計を見られる。

## データの保管

- **問題データ**: `src/data/anaume.json`（このリポジトリで管理）。GitHub 上でこのファイルを編集して `main` に
  コミットすれば、自動でアプリに反映される。
  - 空欄は本文中の `{番号}`、正解は `blanks` の `answer`、別の正しい表記は `alt` に足す。
  - セットの `id`（例 `fudosanho-p1`）と空欄の番号は解答履歴と結びついているので、後から変えない。
- **解答履歴**: 端末のブラウザ（localStorage）に保存する。復習リストは履歴から毎回計算する。
  別の端末へ引き継ぐ・バックアップするときは、履歴画面の「履歴を書き出す」で JSON を保存し、
  もう一方の端末で「読み込む」（両方の履歴を足し合わせる）。書き出した JSON をこのリポジトリに
  コミットしておけば、履歴も GitHub に保管できる。

## 開発

リポジトリ直下で（依存パッケージは直下の `node_modules` を共用）:

```
npm run dev:anaume     # 開発サーバ
npm run build:anaume   # 型チェック＋ビルド → dist/anaume
```

- `src/anaume.ts`: 履歴の保存、復習スケジュールの計算、採点（表記ゆれの吸収）
- `src/Anaume.tsx`: 画面（メニュー・演習／復習・履歴）
