# note運営の戦略（note-unei）

土地家屋調査士試験のnoteの読者を増やし、購読につなげるための運営方針を置く場所。
記事そのもの（`note-articles/`・`note-articles-Kijyutsu/`・`daily-drill/kaisetsu/` など）とは分けて、
「どう届けるか・どう買ってもらうか」の判断と、その根拠になった数字だけをここに残す。

## ファイル

| ファイル | 中身 | 更新のタイミング |
|---|---|---|
| `senryaku.md` | **今の戦略**（版番号つき）。現状の数字、課題、打ち手、プロフィール・説明文の方針、未決定のこと | 戦略を変えるとき |
| `kaitei-rireki.md` | 戦略の改訂履歴。版ごとに「何を変えたか・なぜか・そのときの数字」 | 戦略を変えるとき（`senryaku.md` と同じコミット） |
| `kpi-log.csv` | noteのダッシュボードの数字の記録（累計と流入元） | 週に1回（目安：月曜） |
| `x/` | Xの運用（プロフィール・固定の投稿・毎日の投稿文） | Xの形を変えるとき |
| `instagram/` | Instagramの運用（計画・予定表・画像の仕様・本文の型） | Instagramの形を変えるとき |
| `archive/` | 改訂前の `senryaku.md` の写し（`senryaku-v1-2026-10-30.md` の形） | 戦略を変えるとき |

## 戦略を変えるときの手順

1. `kpi-log.csv` に、変える時点の数字を1行足す（ダッシュボードの「全期間」と「記事の流入元」）。
2. 今の `senryaku.md` を `archive/senryaku-v<今の版>-<今日の日付>.md` に写す（`git mv` ではなくコピー）。
3. `senryaku.md` を書き換え、冒頭の版番号を1つ上げ、改訂日を今日にする。
   - やめた打ち手は消さずに「やめたこと」の節へ移し、やめた理由を1行書く。
4. `kaitei-rireki.md` の先頭に、新しい版の記録を足す（変えたこと／理由／そのときの数字／次に見る数字）。
5. 打ち手を変えると、ほかのファイルに書いた方針（マガジン説明文 `note-articles/magazine-descriptions.md`、
   見出し画像・タイトルの定型など）も変わることがある。`senryaku.md` の「方針を反映しているファイル」の表を見て、合わせて直す。
6. 4つのファイルを同じコミットで `main` に入れる。

## 週ごとの記録の手順（戦略を変えないとき）

1. `kpi-log.csv` に1行足す。
2. `senryaku.md` の「見る数字」に照らして、目安から外れていたら、その週の行の `memo` に一言残す。
   3週続けて外れたら、戦略の見直し（上の手順）を検討する。

## 守ること

- 個人の演習結果（誤答の回数など）を記事に出すかどうかは、`senryaku.md` の「未決定のこと」に従う。決まるまでは、既存のルール（記事に載せない）のまま。
- 予備校の教材（問題文・解説文）はSNSにも載せない。法務省の試験問題を引用するときも、記事と同じ引用の形を守る。
- 数字は、ダッシュボードの表示をそのまま写す（推計で埋めない。読めない値は空欄）。
