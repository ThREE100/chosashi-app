# Codexに貼る指示文（第1回 学習まんが版の試作：1ページ目と4ページ目）

使い方：「ここから」〜「ここまで」をそのまま OpenAI Codex に貼り、キャラクターシート_トリ先生_01〜03 と キャラクターシート_I-01〜03 の6枚を添付する（シートはリポジトリにない）。試作なので、コマ割りの違う2ページ（扉と図解の大ゴマ）だけを作る。

---ここから---

GitHub のリポジトリ ThREE100/chosashi-app（https://github.com/ThREE100/chosashi-app 、ブランチ main）にある学習まんがのプロンプトで、2ページだけ試作してください。

## 対象（ここから読む）
- プロンプト：https://github.com/ThREE100/chosashi-app/blob/main/note-unei/hikkake-shindan/kaiwa/01-jikou-shutoku-moto-shoyuusha_prompts.md
- 構成の型（確認用）：https://github.com/ThREE100/chosashi-app/blob/main/note-unei/hikkake-shindan/kaiwa/02-gakushu-manga-no-kata.md

## 手順
1. リポジトリを clone する（手元にあれば git pull origin main）。
   git clone https://github.com/ThREE100/chosashi-app.git && cd chosashi-app
2. プロンプトのファイルの「## 1ページ目：…」と「## 4ページ目：…」の見出しの下にある ``` で囲まれたプロンプトを読む。コードブロックの中身を1文字も変えずに使う（要約・翻訳・言い換えをしない）。
3. 添付した6枚を参照画像として渡し、2つのプロンプトで1枚ずつ生成する。「キャラクターシート_トリ先生_01, _02, _03」は鳥の3枚、「キャラクターシート_I-01, I-02, I-03」は女性の3枚。鳥が先生、女性が生徒。
4. 画像を「ひっかけ診断ノート_01_p01.png」「ひっかけ診断ノート_01_p04.png」の名前で note-unei/hikkake-shindan/kaiwa/ に PNG で保存する。1024×1536 でなければ、縦横比を保って拡大・縮小し全体を覆ってから中央で切り取る（歪ませない。余白を足さない。透明の部分を残さず RGB）。
5. 各ページを確かめ、問題があればそのページだけ同じプロンプトで1回作り直す（2回目も直らなければ、そのまま渡して何が直らなかったかを報告する）。
   - コマの数と配置がプロンプトのとおり（1ページ目：大ゴマ＋下の帯、4ページ目：図が8割の大ゴマ＋下の帯）
   - 文字がプロンプトの文字列と一字一句同じで、ほかの文字がない。漢字が中国の字体になっていない
   - 名前・役割名（トリ先生・先生・生徒など）がどこにもない。吹き出しのしっぽが話し手を指している
   - 生徒は I-01〜03 の顔・髪型・服装のままで、鳥の先生と同じ画風
   - 生徒の腕は左右1本ずつ、手は2つで指は5本ずつ。Ａ・Ｂ・Ｃは顔のないピクトグラム
   - 既存の漫画作品に似た画風・キャラクターになっていない。背景が端まで塗られている
6. 2枚の画像と、手順5の確認結果（できた点・崩れた点を具体的に）を報告する。

## してはいけないこと
- 既存のファイルを書き換えない。画像2枚のほかにファイルを作らない。git の commit・push はしない。
- ほかのページ・見出し画像は作らない。
