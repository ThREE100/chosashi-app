# Codexに貼る指示文（第1回 漫画1ページ目の試作）

使い方：下の「ここから」〜「ここまで」をそのまま OpenAI Codex に貼り、キャラクターシート_トリ先生_01〜03 と キャラクターシート_I-01〜03 の6枚をチャットに添付する（シートはリポジトリに入っていない）。試作なので、作るのは漫画1の1枚だけ。

---ここから---

GitHub のリポジトリ ThREE100/chosashi-app（https://github.com/ThREE100/chosashi-app 、ブランチ main）にある学習漫画のプロンプトで、漫画を1枚だけ試作してください。

## 対象（GitHub上のファイル。ここから読む）

- プロンプト：https://github.com/ThREE100/chosashi-app/blob/main/note-unei/hikkake-shindan/kaiwa/01-jikou-shutoku-moto-shoyuusha_prompts.md
- 記事（確認用）：https://github.com/ThREE100/chosashi-app/blob/main/note-unei/hikkake-shindan/kaiwa/01-jikou-shutoku-moto-shoyuusha.md

## 手順

1. リポジトリを clone する（手元にあれば `git pull origin main`）。
   `git clone https://github.com/ThREE100/chosashi-app.git && cd chosashi-app`
2. プロンプトのファイルの見出し「## 漫画1：「登記がないと主張できない」と答えてしまう」の下にある、``` で囲まれたプロンプトを読む。コードブロックの中身を**1文字も変えずに**使う（要約・翻訳・言い換えをしない。ほかの見出しのプロンプトは使わない）。
3. 添付した6枚を参照画像として渡して、画像を1枚生成する。プロンプトの「キャラクターシート_トリ先生_01, _02, _03」は鳥の3枚、「キャラクターシート_I-01, I-02, I-03」は女性の3枚のこと。鳥が先生、女性が生徒。
4. 生成した画像を `ひっかけ診断ノート_01_漫画1.png` という名前で `note-unei/hikkake-shindan/kaiwa/` に PNG で保存する。1080×1920 でなければ、縦横比を保って拡大・縮小し全体を覆ってから中央で切り取る（歪ませない。余白を足さない。透明の部分を残さず RGB で保存）。
5. 次を確かめ、問題があれば同じプロンプトで1回だけ作り直す（2回目も直らなければ、そのまま渡して何が直らなかったかを報告する）。
   - 縦に3コマ、1080×1920
   - 吹き出しと図の文字が、プロンプトで指定した文字列と一字一句同じ。ほかの文字がない。漢字が中国の字体になっていない
   - 画像のどこにも名前・役割名（トリ先生・先生・生徒など）がない
   - 生徒（女性）は全コマで左、先生（鳥）は全コマで右。吹き出しのしっぽが話し手を指している
   - 生徒は I-01〜03 の顔・髪型・服装のままで、鳥の先生と同じ画風（線の太さ・塗り・頭身）になっている
   - 生徒の腕は左右1本ずつ、手は2つで指は5本ずつ
   - 背景が端まで塗られていて、透明の部分がない
6. 画像と、手順5の確認結果（できた点・崩れた点を具体的に。とくに生徒の画風と吹き出しの文字）を報告する。

## してはいけないこと

- リポジトリの既存のファイルを書き換えない。画像1枚のほかにファイルを作らない。git の commit・push はしない。
- 漫画2・漫画3・見出し画像は作らない（試作の結果を見てから作る）。
