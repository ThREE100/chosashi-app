# ひっかけ診断ノート（会話編の漫画記事）

2026-11-28 ユーザー依頼。一問一答ドリルで間違えた回数が3回以上の肢を、多い順に1本ずつ、先生（鳥）と生徒の会話の漫画記事にする。

- 順位：`00-junni-list.md`（個人用・公開しない。回数は並び順にだけ使い、記事・画像に出さない）
- 道具の調査：`01-tool-chousa.md`、試作の比較：`shisaku/README.md`
- **学習まんが版の構成の型：`02-gakushu-manga-no-kata.md`（2026-11-28〜。4コマ風の3ページ×3コマから切り替え）**
- 記事：`NN-<slug>.md`、画像プロンプト：`NN-<slug>_prompts.md`（漫画は必要なページ数、1ページ＝1枚 1024×1536＋見出し画像 note用1280×670・Instagram用1080×1440）、貼り付け文：`NN-codex-instructions.md`（Codex用）・`NN-chatgpt-github-instructions.md`（GitHub接続のChatGPT用）
- 作り方：`src/gNN.py`（台本。定番ページは `src/kata.py`）を書く → `python3 src/build_g.py` → `python3 src/check_g.py`（NG 0件）。生成物は手で直さない。
- 監査（各回）：肢の文・正誤がバンクと一致／解説・条文が年度別記事の結論と一致（`note-articles/` の該当肢と条文の原文 `note-articles/laws/` で確かめる）／名前・役割名・個人の結果の語がない／文字数の上限／まとめの○×と型が一致／絵の指示に出てくる札・ラベルの語がそのコマの文字の指定に入っている（`build_g.py` が自動で足し、`check_g.py` が確かめる）。

## 決まり

- ベースは記述式の会話形式の執筆プロンプト（`note-articles-Kijyutsu/prompt_note-kijutsu_tatemono_kyoutsu.md` のキャラクター設定・会話の組み方：生徒が罠にそのまま引っかかる→先生が辛辣だが愛をもって正す→生徒が自分の言葉で言い直す）。
- **会話の中で名前・役割名を出さない**。漫画は話し手の位置（生徒＝左、先生＝右）と吹き出しの向きで見分ける。記事の本文にも「トリ先生」「藍子」「先生」「生徒」は書かない（`check.py` が確かめる）。
- キャラクター：先生＝キャラクターシート_トリ先生_01〜03、生徒＝キャラクターシート_I-01〜03 の女性を、トリ先生と同じ画風で描く。シートはリポジトリにないので、ChatGPTに6枚を添付する。
- 肢の文と正誤は一問一答バンク（現行法令）から取り、書き写さない。解説は年度別記事の結論に従い、正誤・解説の中身は変えない。
- ひっかけの型は、診断記事（`../src/data.py`）の5つ（A〜E）から選ぶ。
- 1本の形：本試験の肢 → 紙に○×？を書かせる → 学習まんが（扉・事例・つまずき・図解の大ゴマ・なぜ・似た場面・確かめクイズ・まとめ。型は `02-gakushu-manga-no-kata.md`、2026-11-28 検証済み）→ 答えと型・覚えること・根拠。
- タイトル：`【土地家屋調査士試験】ひっかけ診断ノート_NN～キャッチ～`（キャッチ25字以内）。
- 画像の生成・目視確認はユーザー。noteへの投稿もユーザー。
