# ひっかけの型の診断（紙版・10問）

過去の本試験の10肢で、点数ではなく**どの型のひっかけに引っかかりやすいか**を見るnoteの無料記事。型は `daily-drill/taxonomy.json` の traps_morning を読者向けに5つ（数字・期間／主語／ないルールを足す／範囲／似た手続）にまとめ、各型2問。

- 採用：2026-11-25（`bunseki/2026-11-25_kuuhaku-to-atarashii-kirikuchi.md` の提案3。まず紙版の記事で反応を見て、よければ道具にする）
- 状態：**草案**（noteへの投稿はユーザー）
- 記事 `article.md`、見出し画像のプロンプト `header-prompts.md`（note用1280×670・Instagram用3:4、MC1人）、選んだ肢と正誤 `questions.json`

## 作り方（手で直さない）

```
python3 note-unei/jobun-gyakubiki/src/extract.py   # 肢の見出し・条文を使うので先に
python3 note-unei/hikkake-shindan/src/build.py
python3 note-unei/hikkake-shindan/src/check.py      # NG 0件にする
```

- 問題の選び方は `src/data.py`（どの肢をどの型で出すかだけ）。肢の文・正誤は一問一答バンク（確認済みの肢だけ）、一行の解説は年度別記事の肢の見出し。文や正誤を `data.py` に書き写さない。
- チェックで確かめること：10問・各型2問・同じ型が続かない・○が3〜7問・同じ記号が4つ続かない・答えより前に○×が出ない・個人の結果や体験の語がない。
- 投稿前に、`article.md` の「条文の逆引き図鑑：【公開後に…URLを入れる】」を、図鑑を公開したらURLに直す（公開しないなら、その段落を削る）。

## 4週間見る数字（道具にするかの判断）

| 数字 | どこで | 目安 |
|---|---|---|
| スキ | 記事 | 最初の1週間で10スキ以上（ほかの記事の最近のスキは0〜3） |
| コメント・Xでの言及（「Bの型だった」など結果の報告） | 記事のコメント、X | 1件以上 |
| PV | noteのダッシュボード | 自分の記事の平均の2倍以上 |
| この記事から年度別マガジン・メンバーへ | 記事ごとの売上、メンバーシップの加入日 | 1件でも出れば続ける |
