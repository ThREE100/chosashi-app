# 条文の逆引き図鑑（無料のWebページ）

択一式（平成17年度〜令和8年度）の全肢解説から、**条文ごとに「いつ・どの肢で出たか」を引ける**静的なWebページ。条文1つにつき1ページ（検索で「不動産登記法 第58条 過去問」と探す人の入口）と、検索・並べ替えのできる一覧ページからなる。各肢から noteの全肢解説へリンクする。

- 採用：2026-11-25（`bunseki/2026-11-25_kuuhaku-to-atarashii-kirikuchi.md` の提案1）
- 状態：**作成済み・未公開**（公開はユーザーが決める。下の「公開のしかた」）

## 作り方（手で直さない）

```
python3 note-unei/jobun-gyakubiki/src/extract.py   # 記事を肢ごとに分けて条文を拾う → data/shi.json・data/jobun.json
python3 note-unei/jobun-gyakubiki/src/build.py     # site/ を作る（site/index.html と site/j/*.html）
python3 note-unei/jobun-gyakubiki/src/check.py     # 機械チェック。NG 0件にする
```

- 肢の文・正誤は一問一答バンク（`tools/drill/data/items.json`。現行法令で確かめた正誤）から取る。バンクにない令和8年度は、記事の問題文の引用から文を取り、正誤は「？（記事で確認）」と出す。
- 「ポイント」は年度別記事の肢の見出し（自分の記事の結論）。
- 条文の原文は `note-articles/laws/` から `daily-drill/lawtext.py` で取り出す（手で打たない）。
- 拾う条文は、**肢の解説の中で法令名つきで引いている条文だけ**（「条文ベスト10」の `hitogara/src/count_articles.py` と同じ数え方）。法令名のない「法第○条」は拾わないので、実際より少なめ。2026-11-25 時点で 2,188肢のうち 1,475肢（67％）・455条文。問全体の前書きは数えないので、「条文ベスト10」（問ごとに数える）より年度の数が少ない条文がある。
- 年度別記事・バンクを直したら、上の3つを実行し直す。

## noteのURL

`note-urls.csv` に、記事のパスとタイトルの一覧がある（`build.py` が作る）。**`url` の列は空欄**で、空欄の記事は「noteで記事を探す」（記事名でnote内を検索するリンク）になる。noteの記事のURLを入れて `build.py` を実行し直すと、「解説を読む（note）」の直接のリンクに変わる。URLには流入を数える目印を付けてよい（例：`https://note.com/…/n/xxxx?from=jobun`）。

## 公開のしかた（ユーザーが決めてから）

1. 下の「公開前の確認」をする。
2. `site/` の中身を `public/jobun/` に写して `main` に push する（`deploy.yml` で GitHub Pages に出る。URLは `https://three100.github.io/chosashi-app/jobun/` になる見込み）。
3. 公開後、学習アプリ（PWA）を入れている端末で `/jobun/` が開けるか確かめる（PWAのキャッシュがアプリの画面に置き換えないか）。
4. Google Search Console に GitHub Pages のURLを登録し、サイトマップ（必要なら `build.py` に出力を足す）を送る。
5. 記事の末尾・「はじめての方へ」・プロフィールからリンクする。ひっかけの型の診断（`../hikkake-shindan/`）の「次にやること」のURL欄も埋める。

## 4週間見る数字

| 数字 | どこで | 目安 |
|---|---|---|
| 図鑑からnoteへの流入 | noteのダッシュボードの流入元（`three100.github.io`、または `?from=jobun` の目印） | 4週目に週20件 |
| 条文名での検索の表示回数・クリック | Google Search Console（クエリに「第○条」「過去問」） | 4週間で表示1,000回・クリック30回 |
| 図鑑から入った記事の購入・メンバー加入 | noteのダッシュボード（記事ごとの売上）とメンバーシップの加入日 | 1件でも出れば続ける |

判断：4週目に流入が週20件に届けば、規則・準則の法令名のない引用も拾えるように広げる（拾える肢を67％から上げる）。届かなければ、各ページのタイトルを検索される言葉（論点の言葉＋「過去問」）に直して、もう4週間見る。毎週の数字は `../kpi-log.csv` に列を足して記録する。

## note記事シリーズ

図鑑を題材にしたnote記事（第0回〜第13回、目次・記事・図解・間違いノート・見出し画像のプロンプト）は `note-series/` にある（入口は `note-series/README.md`、目次は `note-series/00-mokuji.md`）。図鑑のデータ（`data/`）を作り直したら、`note-series/src/build.py` と `check.py` も実行する。
