# 第5回「建物かどうか・何個か・床面積はどこまでか」見出し画像のプロンプト

MC1人（キャラクターシート MC-01〜MC-04 を添付）。このシリーズは、ほかのシリーズの水彩の空とは雰囲気を変え、世界の有名な本屋をオマージュした店内を背景にする（店名・ロゴ・看板の文字は描かせない）。ポーズと表情は回ごとに変える（`00-mokuji.md` の一覧）。画像に数字は入れない（条文番号は漢数字）。

- オマージュ元：ヴェネツィアの「リブレリア・アクア・アルタ」（水があふれても大丈夫なように、本をゴンドラや浴槽に入れて積んだ店内、運河に面した扉、古い本で作った階段）
- ポーズ：本を積んだ階段の途中に立ち、片手を腰に、もう片手で家の模型を目の高さに掲げて下からのぞく
- 表情：「この家、何階建て？」と口をすぼめて数える、考え込んだ顔
