# 条文の逆引き図鑑 note記事シリーズ（第0回〜第13回）

条文の逆引き図鑑（`../site/`）を題材に、本試験でくり返し出る条文を2〜8条ずつ取り上げるnote記事のシリーズ。目次は `00-mokuji.md`。

## 各回にそろえるもの

- `NN-*/article.md`：記事（先頭の「投稿メモ」はnoteに貼らない）
- `NN-*/zukai-prompts.md`：総論の図解1枚、条文ごとの各論の図解、間違いノートの図解（note用・Instagram用〈3:4、1080×1440〉の2種類）
- `NN-*/header-prompts.md`：見出し画像（note用 1280×670・Instagram用 3:4）。女性のMCキャラクター1人で、ポーズと表情は回ごとに変え、背景は世界の有名な書店のオマージュ（店名・ロゴ・看板の文字は描かない）

## 作り方（生成物は手で直さない）

1. `src/dNN.py`（回ごとのデータ）を直す。肢は図鑑の `../data/shi.json` のID（例 `H29-Q12-ア`）で指定し、正誤は一問一答バンクから自動で入る。肢の説明（→ の後ろ）は、一問一答の見出しをそのまま使わず、問題文を読んで書く（見出しに誤り・言い足りないものがあるため）。
2. `python3 src/build.py` で記事・プロンプト・目次を作り直す。
3. `python3 src/check.py` で NG 0件にする。主な確認：
   - 条文の引用が `note-articles/laws/` の原文と一致する（`…` で分けた部分ごと）
   - 肢がその条文を引いている（図鑑の `cites`）・正誤がバンクにある（令和8年度は使わない）
   - 本文の「法令名第N条」が `laws/` にある
   - 画像に入れる文字に図番・英字・禁止語（木・ツリーなど）がない、見出し画像の文字に算用数字がない
   - 画像挿入マーカーとプロンプトの数が一致、本文に表・半角かっこがない
   - 個人の演習結果の語（誤答・回間違え など）がない

## 個人の演習結果の扱い

一問一答の記録（`drill-log` ブランチの `log.jsonl`）は、取り上げる論点と間違いノートの題材を選ぶことにだけ使った。記事・画像には、回数・正答率・「何度も間違えた」などを書かない（既存のルール。`note-unei/senryaku.md` の 6-1 は未決定のまま）。

- 画像は未生成。生成したら、絵の中の文字の誤字を目視で確かめる。
- noteへの投稿はユーザーが行う。
