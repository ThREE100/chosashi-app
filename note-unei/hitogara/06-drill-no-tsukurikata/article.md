## 本文

明けましておめでとうございます。みもっさんです。今年もよろしくお願いします。

前回は、条文ベスト10から年末年始に読み返す10本を選びました（★前回の記事）。

今回は、毎朝出している択一のドリル（★毎朝ドリル）の話です。過去問をそのまま使うのではなく、**条文から新しく問題を作る**というやり方で、朝の択一を120日分作りました。作ってみて、出題する側の目線で分かったことがあったので、まとめます。

【要確認】最初は「条文から問題を作るなんて、ただの言い換えになって簡単すぎるのでは」と思っていました。実際に作ると逆で、もっともらしい誤りの肢を作るほうがずっと難しい。そこで初めて、本試験の誤りの肢がどれだけよくできているかに気づきました。

### 作るときのルール

朝の択一は、本試験と同じ形の5肢（ア〜オ）の組合せ問題です。作るときに守っているルールのうち、大事なものを挙げます。

1. **条文は原文で確認する。** 根拠に引く条文は、原文に一字一句あることを確かめます。条文で決まらない書き方は出題しません。
2. **誤り肢は、条文の言葉を1か所だけ変える。** まったく別の話にはしません。本試験の誤りの肢にも、この形がよくあります。
3. **ひっかけの型を決めて作る。** どこをどう変えたかを、あとで数えられるように、型の名前で記録しておきます。
4. **作った問題は、正誤を伏せて解き直して確かめる。** 問題文と条文だけを見て全肢の正誤を判定し、作ったときの答えと一致するかを確かめます。
5. **過去問の出典や年度は、問題にも解説にも入れない。**

### ひっかけの型は9つ

使っている型は次の9つです（番号のM9は欠番）。

- M1 数字のすり替え（期間・割合）
- M2 主体のすり替え（誰が申請・誰の義務）
- M3 例外・但書の見落とし
- M4 事例の当てはめ
- M5 手続の期間・起算日・順序
- M6 範囲のすり替え（全部／一部、直接／間接）
- M7 規則・準則・先例の知識
- M8 似た制度・用語の取り違え
- M10 義務と努力義務

### 120問で、どの型を何回使ったか

（図：`zu01_hikkake_note.png`）

朝の択一120問の登録簿から、1問ごとに使った型を数えました（1問で同じ型を2つの肢に使っても1と数えています）。

| 型 | 使った問の数 |
|---|---|
| M7 規則・準則・先例の知識 | 72問 |
| M4 事例の当てはめ | 71問 |
| M8 似た制度・用語の取り違え | 67問 |
| M3 例外・但書の見落とし | 65問 |
| M6 範囲のすり替え（全部／一部、直接／間接） | 64問 |
| M2 主体のすり替え（誰が申請・誰の義務） | 37問 |
| M5 手続の期間・起算日・順序 | 33問 |
| M1 数字のすり替え（期間・割合） | 23問 |
| M10 義務と努力義務 | 3問 |

1問に使った型の数は、4つが66問、3つが39問で、2つの問が7問、5つの問が8問でした。

### 作ってみてわかったこと

**① 「数字」のひっかけは、思ったより少ない。**

ひっかけと聞くと「一月を二月に変える」ような数字のすり替えを思い浮かべますが、120問で使ったのは23問でした。数字を変える誤りは、条文を覚えていれば一目で分かるので、1問に1つ入れれば十分だからです。

**② 多いのは「当てはめ」と「似たものとの取り違え」。**

上位の M7（規則・準則・先例）、M4（事例の当てはめ）、M8（似た制度・用語）は、どれも**条文の言葉を覚えているだけでは解けない**型です。条文を事例に当てはめる、規則や準則まで降りる、似た手続と区別する。作るときのルールでも、本番で「迷う肢」にあたるいちばん難しい段階を「事例の当てはめ、規則・準則、複数条文の組み合わせ」と決めていて、120問のうち62問がこの段階です。

**③ 例外とただし書は、作る側からすると一番作りやすい。**

M3（例外・但書の見落とし）は65問。条文の本文だけを書いて、ただし書を落とすと、それだけで誤りの肢ができてしまいます。逆に言うと、**条文を読むときは、ただし書と「〜を除く」を必ず拾う**のが、いちばん効率のいい対策だと思います。

【要確認】私自身、ドリルを作る前は M3 の肢でよく引っかかっていました。作る側に回ってから、条文のただし書の所で目が止まるようになったのは、思わぬ効果でした。

### どの分野から作ったか

120問の分野は、不動産登記法（令・規則・準則・先例を含む）が97問、民法が17問、土地家屋調査士法が6問です。本試験の20問の割合（不動産登記法が16問前後、民法3問、調査士法1問）に合わせています。根拠に使った条文は、全部で247か所（法令名と条の組み合わせの数）になりました。

### 私の使い方

【要確認】過去問を解いて間違えた肢は、「どの型で引っかかったか」を9つの型の名前でメモするようにしています。数字なのか、主体なのか、ただし書なのか。名前を付けるだけで、次に同じ形の肢を見たときに「これはM3だ」と身構えられるようになりました。

【要確認】このやり方の延長で、本試験の10肢で間違え方の型（数字・主体・ないルール・範囲・似た手続の5つ）を見る「ひっかけの型の診断」（★ひっかけの型の診断）も作りました。点数ではなく、自分がどの型に弱いかを見るためのものです。

- 毎朝の択一ドリル：★毎朝ドリル
- 間違え方の型を見るなら：★ひっかけの型の診断

次回は、**法改正で、昔の過去問の正誤が変わった肢**を並べます。古い年度の過去問を解くときに、答えをそのまま覚えると危ない肢です。
