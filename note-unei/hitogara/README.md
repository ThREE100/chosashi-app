## 書き方の約束

1. **書き手が見える**：一人称は「私」。なぜその記事を書いたか、どう使うか、読者への問いかけ（コメントのお願い）を入れる。
2. **作り話の体験を書かない**：ユーザーの感想・気持ち・やり方として書く文は、**頭に【要確認】を付ける**。ユーザーが投稿前に自分の言葉に直して消す（`check.py` が数を知らせる）。
3. **個人の演習結果は出さない**（`senryaku.md` 6-1 が決まるまで）：誤答の数・正答率・自己採点の点数・「何回間違えた」は書かない。数字は、記事・条文・問題など**誰が数えても同じになるもの**だけを使う（数え方は `src/` のスクリプトに残す）。
4. `senryaku.md` 3. の「書かないこと」を守る（「合格するまで更新」「予備校の解答例と照合」など）。予備校の教材の文章は使わない。
5. 条文の中身を書くときは `note-articles/laws/` の原文で確かめる（`check.py` が「（法令名） 第N条」の存在を確かめる）。
6. 末尾に、関連マガジン（`★` で示しユーザーがリンクを設定）、次回の予告、コメントのお願い、フォローの案内を入れる。
7. 図は文字の図なら HTML→Chromium（`src/make_bar_chart.py` など）で作る。note用と Instagram用3:4（1080×1440）の2種類。見出し画像のプロンプトもnote用・Instagram用の2種類（人物1人〈キャラクターシート_I-01〜03〉、数字は画像に入れない。ユーザーが指定した語〈例：第1回の「Best 10発表」〉だけは例外）。2026-11-27から、見出し画像の背景はトリニティ・カレッジ図書館のロングルームを思わせる重厚な歴史的図書館の内装にし（水彩の空は使わない。胸像・彫像など参照画像の人物以外の人型は入れず、書架・回廊・天井の装飾だけで重厚さを出す）、人物の腕は左右1本ずつと明示する。新しい回は `01-joubun-best10/header-prompts.md` を型にする。
8. タイトルの先頭は【土地家屋調査士試験】。中身が先に伝わる言葉にする。
