# まだ誰もやっていない切り口の提案（競合の提供形態と空白の分析）

- 作成：2026-11-25（日本時間）
- 位置づけ：`2026-11-24_member-11-to-30.md`（以下「前回レポート」）の続き。前回は「note内でどう見つけてもらい、メンバーにするか」（人柄の見える週1記事・交流・タイトル）を扱った。今回は **note の外も含めて、受験生向けの対策の「形式・対象・手法」でまだ空いているところ** を探し、手元の資産で埋める案を出す。前回の打ち手（A1〜C4、Z1〜Z9）と重なるものは書かない。
- 採用するかはユーザーが決める。採用したら `senryaku.md` に移して版を上げる（`note-unei/README.md` の手順）。
- 調べ方：Web検索と公開ページ（2026-11-24〜25 時点）、リポジトリの資産の数え上げ。X・Instagram・YouTube は検索で上位に出るものの傾向だけを見た（クラウドからは各SNSの中を直接見られない）。**「誰もやっていない」は「今回の調べ方では見つからなかった」という意味**で、確定ではない。採用の前に、下の各案の「検証方法」の最初の1つ（公開前の確認）をやってほしい。

## 0. 結論

競合を「何を・どんな形で・誰に」で並べると、空いているのは次の4つ。

1. **条文から過去問を引く（逆引き）しくみ**：過去問は「年度順」「分野順」で並べたもの（予備校の本・アプリ・過去問サイト）ばかりで、**「この条文は、いつ・どの肢で・どうひっかけて出たか」を条文の側から引けるもの**が見つからなかった。
2. **記述式の電卓のキー操作を、文字で検索できる形**：アガルートは動画講座（複素数計算 27,280円、記述式実演 65,780円）で売っていて、しかも2026年版は販売終了。**全年度のキー列を文字で並べ、再現の確認までしたもの**は見つからなかった。
3. **「ひっかけの型」で弱点を診断するもの**：アプリの分析は「分野別の正答率」と「間違えた問題の解き直し」まで。**「なぜ間違えたか（型）」で診断し、型ごとの対策に案内するもの**は見つからなかった。
4. **「法改正で正誤が変わった過去問」の一覧**：古い過去問集・アプリは出題当時の正解のまま。**現行法で答えが変わる肢をまとめた一覧**は見つからなかった。

4つとも、すでに手元にあるデータ（一問一答バンク2,100肢、条文の原文、キー列389か所、ひっかけの分類、「出題当時」の注のある記事76本）を集計・並べ替えるだけで作れる。**新しく書く量は少なく、量と確かめ方という自分の強みがそのまま出る**。

一番のおすすめは **①条文の逆引き（無料のWebページ）×noteの全肢解説へのリンク**。検索（Google・Yahooで流入の約33％）から入ってきた人を、noteの有料記事・メンバーシップに流す「入口の道具」になる。

## 3. 提案（優先順）

工数は、今の作り方（データ→生成器→機械チェック）でClaudeが作る前提の目安。ユーザーの作業は「確認と投稿」の時間。

### 提案1（最優先）：条文の逆引き図鑑「この条文、ここで出た」

**何をするか**
条文1つにつき1ページ（または1枚の表）を作り、「条文の原文」「出題された年度・問・肢の一覧」「その肢の正誤と、どうひっかけたか（一言）」「noteの全肢解説へのリンク」を並べる。不動産登記法の出題の多い条文から始める（`ranking.json` の上位）。

**どこに出すか（2段構え）**
- **無料のWebページ**（既存のGitHub Pagesに足す）：条文と年度・肢の一覧と正誤まで。検索で入ってきた人の入口。
- **note**：「解説」はnoteの有料記事・メンバーシップ側に置き、Webページから1肢ずつリンクする。note側は「条文別」マガジン（今のマガジンは年度別）を1冊足す。

**なぜ空いているか**：過去問集・アプリ・予備校は「年度順」か「分野順」。条文の側から引けるものは見つからなかった。調査士の択一は同じ条文が何年も出る（第58条は22年度のうち18年度）ので、条文から引けると「どこを覚えればよいか」が一目でわかる。

**資産の使い方**：バンクの `sources`（年度・問・肢・記事のパス）と、条文の出題回数の集計を突き合わせるだけで、ほぼ自動で作れる。原文は `laws/` から転記（手で打たない）。

**工数**：仕組みの作成 2〜3日（Claude）。1条文あたりの確認 5分（ユーザー）。最初は上位20条文で公開。

**検証方法**
1. 公開前：Googleで「不動産登記法 第58条 過去問」などを検索し、同じ形のページがないことを確かめる（あれば差を書く）。
2. 公開後4週間：Webページからnoteへのクリック数（リンクに `?from=jobun` のような目印を付け、noteのダッシュボードの流入元で見る）と、条文名での検索の表示回数（Google Search Console を GitHub Pages に設定）。
3. 判断の目安：4週間でnoteへの流入が週20件を超えたら、全条文（規則・準則まで）に広げる。届かなければ、ページのタイトルを検索される言葉（「第58条 過去問」「共用部分である旨の登記 過去問」）に直して、もう4週間見る。

### 提案2：記述式の「キー列図鑑」（文字で引ける電卓の操作）

**何をするか**
記述式の全年度の計算（交点・面積・放射・座標変換など）を「計算の型」ごとに並べ、F-789SG のキー列・途中の表示・最後の表示を文字で載せる。「型 → 年度の例 → キー列 → 再現済み」の順。

**どこに出すか**：noteの有料マガジン（1つの型を無料の見本にする）。Instagramには「1型1枚」の図。

**なぜ空いているか**：電卓の操作を教えるものは予備校の動画講座（2万〜6万円台）で、しかも毎年秋に販売終了になる。**文字で検索でき、見返せて、答えまで機械で確かめたもの**は見つからなかった。動画は「どのキーを何回押したか」を見返すのが大変で、文字の一覧は動画の弱点を埋める。

**資産の使い方**：記事の中にキー列389か所とその再現の仕組みがすでにある。型の分類（`daily-drill/taxonomy.json` の夜の型）で並べ替えるだけ。

**工数**：型の分類と並べ替え 2日、型ごとの見本図 1日（Claude）。確認 2〜3時間（ユーザー）。

**検証方法**
1. 公開前：X・YouTubeで「F-789SG キー操作 土地家屋調査士」を検索し、同じ一覧がないことを確かめる。
2. 無料の見本1本（いちばん出る「2直線の交点」）を出し、2週間のスキ・PV・有料マガジンの購入数を見る。
3. 判断の目安：見本のPVが自分の記事の平均の2倍以上、または購入が1件以上で、全型に広げる。
4. 注意：予備校の講座の「中山式」の手順をまねしない（自分の記事のキー列だけを使う）。

### 提案3：「ひっかけの型」診断（無料の道具）

**何をするか**
20〜30肢の短い診断（〇×）を解くと、「主語のすり替え」「原則と例外の取り違え」「期限・数字」「表示と権利の取り違え」など**間違え方の型ごと**に結果が出て、型ごとの対策記事（noteの4コマ・苦手克服シリーズ・一枚まとめ）に案内する。点数ではなく「型」を返すのが新しい点。

**どこに出すか**：既存のPWAに1ページ足す（登録なし、結果は端末の中だけ）。結果の画面に、型ごとのnoteの記事のリンクと、メンバーシップの案内。

**なぜ空いているか**：アプリの分析は「分野別の正答率」と「間違えた問題の出し直し」まで。**「なぜ間違えるか」を型で返すもの**は見つからなかった。

**資産の使い方**：ひっかけの分類（`taxonomy.json`）と、苦手分析シリーズ・4コマ（誤解の多い肢を型で整理済み）。バンクの肢に型のラベルを付ける作業が要る（下の注意）。

**工数**：診断の肢の選定と型のラベル付け 2〜3日、ページ作成 1〜2日（Claude）。確認 半日（ユーザー）。

**検証方法**
1. 先にnoteの無料記事として「あなたのひっかけの型は？10問チェック」（紙でできる版）を出し、スキとコメントの反応を見る（1週間で10スキ以上なら道具にする）。
2. 道具にしたら、結果画面からnoteへのクリック率（目印付きリンク）を見る。目安は診断を終えた人の1割。
3. 注意：個人の演習結果は使わない（ルールどおり）。型のラベルは「肢の作り」で付け、自分の誤答の記録では付けない。

### 提案4：「法改正で答えが変わった過去問」一覧

**何をするか**
古い過去問集・アプリでは正解が出題当時のまま。現行法で正誤が変わった肢（法定相続情報、住所変更の登記の義務化、区分所有法の改正、会社法人等番号の制度など）を、**「どの改正で」「何が変わったか」「今の答え」** の一覧にする。

**どこに出すか**：note の無料記事（入口）＋一覧はメンバー限定で更新し続ける。法改正の時期（施行日の前後）に毎回追記する。

**なぜ空いているか**：予備校の新しい年度版の本には反映されるが、**改正ごとに「過去問のどの肢が変わったか」を横に並べたもの**は見つからなかった。古い本やアプリで勉強している独学の人ほど困る。「法改正があれば追記します」という今の約束（`senryaku.md` 3.）と一致する。

**資産の使い方**：「出題当時は〜」の注のある記事76本と、ドリルのバンクの「現行法令を正」とする判断。

**工数**：一覧の抽出 1日、文章の整理 1日（Claude）。確認 2時間（ユーザー）。

**検証方法**
1. 公開前：「土地家屋調査士 過去問 法改正 答えが変わる」で検索し、同じ一覧がないことを確かめる。
2. 無料記事として公開し、検索からの流入（noteの流入元のGoogle）を4週間見る。
3. 判断の目安：検索からの流入が出れば、施行日の近い改正（令和9年の施行分）ごとに追記の記事を出す。

### 提案5：答案用紙の実寸「重ねて答え合わせ」シート

**何をするか**
記述式の作図（地積測量図・建物図面・各階平面図）の完成形を、答案用紙と同じ実寸のPDFで出す。受験生が自分で描いた答案に**重ねて透かして**（またはスマホで並べて）答え合わせができる。

**どこに出すか**：noteの有料記事の添付（年度ごと）、またはメンバー特典。

**なぜ空いているか**：アガルートの作図答練は紙の本（21,780円、販売終了）。**実寸で、全年度そろって、印刷して重ねられるもの**は見つからなかった。

**資産の使い方**：全年度の答案用紙の原本から測った寸法、1/250・1/500の実寸の図（すでに作成済み）。PDFに書き出すだけ。

**工数**：書き出しと確認の仕組み 1日（Claude）。確認 年度ごとに5分（ユーザー）。

**検証方法**
1. 1年度（R8の第21問）だけをメンバー特典にして、掲示板で使った感想を聞く。
2. 注意：答案用紙そのものの再配布になる部分（印刷の様式）は、法務省の試験問題の扱いを確かめてから出す。迷うなら、図面の部分だけを実寸で出す。

## 4. やらないほうがよいもの（調べてわかったこと）

| 案 | やらない理由 |
|---|---|
| 一問一答のスマホアプリを新しく作る | すでに2〜3本あり、値段の競争になる。自分のPWAで足りる。差は「型」と「条文」で出す（提案1・3） |
| 動画の講座 | 予備校の主戦場で、時間がかかる。文字と図で検索できる、という強みが消える |
| 予備校の解答例との比較・照合を前に出す | `senryaku.md` 3. で書かないと決めている |
| SNSでの自動投稿・自動フォロー | 前回レポートの6.と同じ理由 |

## 5. 組み合わせ方（流れ）

```
Google・Yahoo で「第58条 過去問」「交点 キー操作」と検索
   ↓
無料の道具・ページ（提案1 逆引き／提案3 診断／提案4 改正一覧）
   ↓ 1肢ずつ・1型ずつのリンク
noteの全肢解説・キー列図鑑（有料記事・マガジン）
   ↓ 「全部まとめて見るなら」
メンバーシップ（逆引きの全条文・改正一覧の更新・実寸シート）
```

前回レポートの「週1の人柄が見える記事」は、この流れの**作り手の顔**として並べて使える（例：「全440問を条文から引けるようにしてみた」という作る過程の記事）。
