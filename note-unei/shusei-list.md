# noteへの反映が必要な修正の一覧

リポジトリの記事（`note-articles/` など）を直したときに、**noteに投稿済みの記事を貼り直す**ための一覧。noteの記事はClaudeからは直せないので、ユーザーが貼り直したら「noteへの反映」を「反映済み（日付）」に変える。

- 新しい修正は表の先頭に足す（1記事1行。同じ記事を何度か直したら、行を分ける）。
- 「正誤」は、肢の正誤・正解番号が変わったかどうか。変わる修正は、ユーザーの指示があったときだけ行う。
- 「noteのタイトル」は、noteに今出ているはずの（直す前の）タイトル。タイトルを変えた行は、noteのタイトルも直す。
- 呼び出し方：Claudeに「修正リストを見せて」「noteに反映していない修正は？」と頼む。
