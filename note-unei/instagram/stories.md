# ストーリーの使い方

ストーリーは、**すでに作成済みの縦長の図解インフォグラフィック**（1080×1920、9:16）をそのまま使う。フィード用に3:4で作り直す必要はない。

## ストーリーを3:4にしないわけ（2026-10-30 決定）

ストーリーは画面いっぱいの縦長（9:16）で表示される。3:4（1080×1440）の画像を出すと、上下に帯（余白）ができて、画像が小さく見える。
そのため、**ストーリーは9:16（1080×1920）のままにする**。作成済みの縦長図解を、3:4に合わせて作り直さない。

3:4の画像（フィード用）をストーリーにも出したいときだけ、1080×1920の無地の背景の中央に置く。
1440pxの高さを中央に置くと、上下に240pxずつ余白ができて、上の約250px・下の約250〜340pxの余白の目安とほぼ重なる。
この形なら、返信欄や名前の表示が重なっても、図解が隠れない。

## 使う素材

| 素材 | 中身 | 出し方 |
|---|---|---|
| 年度別の記事の「②総論インフォグラフィック」 | 各年度・各問の、問題全体の図解（1080×1920） | その日のフィードの3問（左・中・右）と同じ問の図解を、同じ日に出す |
| 4コマ解説図解 | 誤解の多い肢のトリ先生・藍子の4コマ（1080×1920） | つなぎの日（8日目）に、F3と同じ4コマを出す |
| 見るだけ復習の図解 | 論点別の図解 | 余った日の穴埋め、またはハイライト用 |

## 毎日の流れ

1. その日のフィード3枚を投稿する。
2. その日の3問の既存の縦長図解を、ストーリーに順に出す（3枚）。
3. ストーリーの最後に、「プロフィールのリンクからnoteへ」の1枚か、投稿へのリンクのスタンプを足してもよい。

## 余白

上は約250px、下は約250〜340pxに、文字や大事な図を置かない。既存の図解の端に文字がある場合は、背景の色の帯を足して少し縮小し、余白を作る。

## ハイライト

ストーリーは24時間で消えるが、ハイライトにまとめると、プロフィールの自己紹介の下に丸いアイコンで残り、プロフィールを見に来た人がいつでも見られる。
プロフィールを開いた人が最初に見る場所なので、**「ここは何のアカウントか」と「どこから見ればいいか」が分かる並び**にする。

### 作るハイライト（6〜7個まで）

| 名前（4文字ほどに短く） | 中身 | 作る時期 |
|---|---|---|
| はじめに | 自己紹介（何のアカウントか・毎日3枚・順番の見方）、noteへの案内 | 最初（ストーリーに数枚出して作る） |
| 令和 | 令和元年度〜令和8年度の問の図解（ストーリー） | 令和8年度から投稿が進むたびに足す |
| 平成後期 | 平成26〜30年度 | 該当の年度に入ってから |
| 平成中期 | 平成21〜25年度 | 同上 |
| 平成前期 | 平成17〜20年度 | 同上 |
| 4コマ | つなぎの日（F3）の4コマ | F3を出したら足す |
| 記述式 | 記述式の図解・解説 | 記述式を出したら足す |

「ドリル」（毎朝ドリル・記述式ドリル）は、Xで毎日出しているので、Instagramに出す場合だけ足す。

### 「はじめに」の中身（4枚。1080×1920）

プロフィールを開いた人が、30秒で「何のアカウントか」「どう見ればいいか」「くわしくはどこか」を分かるようにする。文字は少なく、大きく。上下の余白（上約250px・下約250〜340px）には文字を置かない。

| 枚 | 見出し（大きく） | 添える文（小さく） |
|---|---|---|
| 1 | 土地家屋調査士試験　過去問を図解で毎日3枚 | 令和8年度の問1から、さかのぼっていきます |
| 2 | いつでもどこでも、隙間時間で復習 | 電車の中・お昼休み・CMの間にスマホで見返すトリ先生の3場面（キャラクターシート添付） |
| 3 | 1枚で「まず何を確認するか」が分かる | 問題文を読まなくても、どこが狙われるかが分かる図解です。保存して、隙間時間に見返してください |
| 4 | くわしい解説はnoteで | プロフィールのリンクから。各肢の正誤は現行の法令で確かめ、根拠の条文は原文と照合しています |

- 4枚目は、プロフィールのリンクを指す案内（ストーリーのリンクスタンプも使える）。
- 画像のプロンプトは `stories-hajimeni-prompts.md`（ChatGPT用。1・4枚目はトリ先生が出る）。文字が崩れるときは、文字なしの背景を作らせて、文字はCanvaなどで入れる。
- 「予備校の解答例との照合」「合格するまで更新」は書かない（`note-unei/senryaku.md` の3.）。

### 作り方

1. ストーリーを投稿する。
2. 投稿したストーリーを開き、右下の「ハイライト」を押して、新規作成か既存のハイライトへの追加を選ぶ。
3. 表紙（丸いアイコン）は、トリ先生のアイコンか、年代を表す1文字の画像にして、色をそろえる。名前は短く（長いと省略される）。
4. 消えたストーリーも、プロフィールの「アーカイブ」に残っていれば、あとからハイライトに足せる。**ストーリーを自動でアーカイブに保存する設定**になっているかを、設定で確かめておく。

### 運用のコツ

- 最初に作るのは「はじめに」だけでよい。年代別のハイライトは、その年代の投稿が始まってから作る（中身がない丸は作らない）。
- 順番や名前は、あとから編集できる。画面と仕様は変わるので、アプリで確かめる。

### 「はじめに」の音楽（2026-10-30 決定）

- 採用：**グリーグ「朝」（『ペール・ギュント』第1組曲）の1曲を、4枚に通して付ける**。毎朝ドリルのコンセプトと合い、音の切れ目が目立たない。
- 区切り：**1枚あたり23秒ずつ**で区切る（ユーザーが指定）。
  - 続きを流す想定の開始位置：1枚目 0:00、2枚目 0:23、3枚目 0:46、4枚目 1:09（想定。録音ごとに違うので、アプリで確定した位置が分かったら、ここを書き直す）。
- 使う録音と、音量・開始位置は、アプリで確認した結果を追記する。ライブラリに出なければ（プロアカウントでは録音が限られる）、次点の候補を使う。
- 次点の候補（検討済み）：ヴィヴァルディ「春」、ジムノペディ第1番、ホルスト「ジュピター」中間部、ローファイ系のインスト。
- 音楽を付けても、画像の文字を読み終えるまで盛り上がらないかを確かめる。

### ハイライトの上限（2026-10-30 ユーザーが調べた内容。公式ヘルプに明記なし）

- **1つのハイライトに入れられるストーリー：最大100個**。101個目は追加できないか、最も古いものが自動で消える報告がある。
- **ハイライトの個数：公式の上限なし**（実質無制限）。「100個まで」とする英語記事は、上の1ハイライトあたりの上限との混同の可能性が高い。
- プロフィールで、スクロールせずに見えるハイライトは5〜6個ほど。多すぎると見てもらいにくいので、**5〜8個ほど**が目安。

### 年度の区切り（2026-10-30 決定）

令和8年度だけ独立させ、残りは3年度ずつ。「はじめに」と合わせて**9個**（目安の5〜8個より1つ多いが、年度ごとの探しやすさを優先する）。1年度＝約20〜24枚なので、3年度でも約60〜72枚で、上限の100個に収まる。

| ハイライト名 | 含む年度 |
|---|---|
| はじめに | （案内の4枚） |
| R8 | 令和8年度 |
| R7-R5 | 令和7・6・5年度 |
| R4-R2 | 令和4・3・2年度 |
| R1-H29 | 令和元・平成30・29年度 |
| H28-H26 | 平成28・27・26年度 |
| H25-H23 | 平成25・24・23年度 |
| H22-H20 | 平成22・21・20年度 |
| H19-H17 | 平成19・18・17年度 |

- 新しい年度の最初のストーリーを投稿したときにハイライトを作り、3年度分がそろうまで同じハイライトに足す（R8だけは令和8年度の分で完結）。
- 自動アーカイブがオンか、設定で確かめる。
- 名前は省略されないよう短くする（上の表の形）。令和元年度の表記は「R1」。

## 注意

- ストーリーはグリッドにも出ないので、投稿の枚数（1日3枚）には数えない。
- 画像の中の文字・結論は、フィードの図解や記事と一致していること。
