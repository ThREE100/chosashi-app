# 3:4（1080×1440）のインフォグラフィック プロンプト（Instagram用）

令和8年度から平成17年度まで、各年度の問1〜問20（22年度×20問＝440問）。年度ごとに1ファイル（`R08.md` 〜 `H17.md`）。

## できかた

記事（`note-articles/{r8,r7,…,h17}-mondai/qNN-*.md`）の「インフォグラフィック プロンプト（問題全体）」を `make_ig_prompts.py` が読み取り、次の3つだけ変えて書き出す。記事は編集しない。

1. 大きさの指定を `3:4 aspect ratio, 1080x1440 pixels` にする。
2. Instagram用の指示（`INSTAGRAM FEED FORMAT`）を差し込む。
   - 余白（左右54px・上下72px）の内側に大事な要素を置く。
   - カードを2列に配置する（グループが3つのときは、3つ目を下の全幅の行にする）。カードは小さくし、文字は小さくしない。
   - スマホで読める文字の大きさ（タイトル72px以上、見出し36px以上、結論タグ32px以上、絵の中の語32px以上）。
   - 画像の中に、フッター・アカウント名・URL・ハッシュタグ・案内の文字を入れない。
   - 番号つきバッジは描かない（古い記事のプロンプトにある `Badge` の行は無視する）。
3. 最後の確認に、大きさ・余白・案内の文字がないことの確認を足す。

カードの見出し・イラストの説明・許可する語・結論タグは、**記事のまま**（結論は記事を正とする）。
各問に、カードの見出しから作った**キャプション案**も付けてある（`caption-template.md` の型）。

## 使い方

1. 該当の年度のファイルを開き、問のところの「3:4画像プロンプト」のコードブロックをChatGPTなどに貼る。
2. 仕上がりを確かめる：1080×1440か／余白の内側に収まっているか／文字が崩れていないか（1字ずつ）／カードの数が記事と同じか／記事の結論と食い違わないか。
3. 画像を `schedule.csv` の `feed_image` の名前で保存し、`status` を直す。
4. キャプション案を下書きにして、投稿する。

## 要手作業の6問

「状態」が「要手作業」の問は、そのままでは3:4に収まりにくいか、配置を確かめる必要がある。**絞り方を決めてから使う。**

| 年度・問 | 元のカード数 | 理由 |
|---|---|---|
| 平成30年度 第11問 | 9 | カードが多い（区分建物の語句6＋敷地権の語句3）。6枚以内に絞る |
| 平成19年度 第19問 | 10 | カードが多い（建物として扱えるもの7＋扱えないもの3）。6枚以内に絞るか、2列×5行の小さなカードにする |
| 平成18年度 第7問 | 10 | カードが多い（宅地になるもの5＋ほか5）。同上 |
| 令和3年度 第8問・第14問・第19問 | 5 | グループが3つ。3つ目を下の全幅の行に置く指示は入れてあるので、仕上がりの配置を確かめる |

一覧は `index.csv`（年・問・タイトル・カード数・状態・メモ・出典）。

## 作り直し

記事のプロンプトを直したら、`python3 note-unei/instagram/make_ig_prompts.py` で作り直す（このフォルダのファイルは手で直さない）。
`schedule.csv` の `prompt_status` 列は、`make_schedule.py` で作り直すと反映される（状態の列を書き込んでいたら、作り直さず手で直す）。
