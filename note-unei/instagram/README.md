戦略上の位置づけは `note-unei/senryaku.md` の「5. 入り口を増やす（SNS）」の③。
2026-10-30 に、画像がそろってからではなく、図解を作り直しながら始める計画に決めた。

## 1. 全体の形

- **順番**：令和8年度の問1から始めて、令和7年度、令和6年度…と平成17年度まで**さかのぼる**（22年度）。
- **1つの年度のかたまり（ブロック）は24枚**：問1〜問20（20枚）＋つなぎの4枚（F1〜F4）。
  20は3の倍数でないので、そのまま次の年度に進むとグリッド（3列）の行が年度の途中でずれる。つなぎを4枚はさむと24＝3×8で、**年度の切れ目が行の切れ目にそろう**。
- **1日3枚**。1日＝グリッドの1行。1ブロックは8日、全体は22ブロック×8日＝**176日**（開始日 2026-11-09 の場合は 2027-05-03 まで）。
- **ストーリーは、作成済みの縦長の図解**（1080×1920）をそのまま使う（`stories.md`）。
- **フィードに載せる画像は、インスタに合う比率（3:4、1080×1440）で作り直す**（`image-spec.md`）。

### つなぎの4枚（F1〜F4）

| 枠 | 中身 | 素材 |
|---|---|---|
| F1 | その年度のまとめ（20問の狙われどころ一覧）と、次の年度の予告 | 新しく作る（20問の記事から） |
| F2 | 個別テーマ解説 | `filler-pool.csv`（テーマ別解説43・苦手分析26・論点別の復習図解10） |
| F3 | 4コマ解説 | `filler-pool.csv`（4コマ86本） |
| F4 | 案内（メンバーシップ・毎朝ドリル・Xのどれか。年度ごとに入れ替える） | 新しく作る |

必要数は各22枚。F2・F3は素材が足りている。F1・F4は新しく作る。
各ブロックの8日目は F2・F3・F4 の3枚で、**ブロックが完成したときにプロフィールの一番上に見える行**になる。見せたい素材をここに置く。

## 2. グリッドの並びと投稿する順番

グリッドは新しい投稿が左上に来て、1行の中は左ほど新しい。そのまま順に投稿すると、1行が「Q3・Q2・Q1」と右から左に並んでしまう。
そこで、**その日の3枚は右から先に投稿する**（Q3 → Q2 → Q1）。すると行が左から **Q1・Q2・Q3** と並ぶ。
`schedule.csv` の `slot` が投稿する順番（1→2→3）、`grid_col` がグリッドの列（左・中・右）。

| 日 | 左 | 中 | 右 | 投稿する順番 |
|---|---|---|---|---|
| 1日目 | Q01 | Q02 | Q03 | Q03 → Q02 → Q01 |
| … | … | … | … | … |
| 6日目 | Q16 | Q17 | Q18 | Q18 → Q17 → Q16 |
| 7日目 | Q19 | Q20 | F1 | F1 → Q20 → Q19 |
| 8日目 | F2 | F3 | F4 | F4 → F3 → F2 |

行の順番（上下）は、新しい日ほど上になる。つまりブロックの中では、問1〜3の行が一番下、F2〜F4の行が一番上になる。
上から下へ見ていくと各ブロックは「つなぎ→問19〜20→…→問1〜3」の順で、行の中は左から右へ問の順に読める。

### 守らないとグリッドがずれること

- **1日3枚を守る**。投稿できない日があったら、翌日に6枚（2行分）で取り戻す。1枚や2枚だけ足りない状態を残さない。
- **投稿をピン留めしない**（する場合は3枚ちょうど）。ピン留めはグリッドの最初に出て、行をずらす。
- **リール（動画）はグリッドに出る**。使うなら3枚の中の1枚に数える。
- **投稿の削除・アーカイブをしない**（するなら3枚ずつ）。
- 複数枚をめくる投稿（カルーセル）は、グリッドでは1枚分。表紙の1枚目がグリッドに出る。

## 3. 毎日のやること

1. `schedule.csv` で、その日の3行（`slot` 1〜3）を見る。
2. `feed_image` の名前の画像（1080×1440）を、`slot` の順に3枚投稿する。本文は `caption-template.md` の型で作る。
3. ストーリーに、その日のQの既存の縦長図解を出す（`stories.md`）。
4. `schedule.csv` の `status` を「投稿済み」に直す。

画像は容量が大きい（528枚）ので、リポジトリには入れず、手元（OneDriveなど）に `feed_image` の名前で置く。リポジトリには予定表と状態だけを残す。
画像づくりは、1日3枚の投稿に対して**1日3枚以上のペース**で進める必要がある。先に1ブロック（24枚）を作ってから開始日を決めるのがよい。

## 4. 守ること

- 画像の中に、個人の演習結果（誤答の回数など）、予備校の教材、問題の本文の丸写しを入れない（記事・X と同じ）。出題の年度と問の番号は、出題の識別として入れてよい。
- 図の中の文字は、指定した語だけにする（`note-articles/infographic-prompt-template.md` の「絵の中の文字は、指定した語だけ」）。生成後に1字ずつ確かめる。
- 「合格するまで更新を続けます」「予備校の解答例と照合」は書かない（`senryaku.md` の3.）。更新の約束は「法改正があれば追記します」。
- ストーリーとフィードの図解が、同じ記事の結論と一致していること。結論は `note-articles/` の記事を正とする。
