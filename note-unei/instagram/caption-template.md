# Instagramの本文（キャプション）とプロフィール欄

Instagramは、本文の中のリンクを押せない。noteへは、**プロフィールのリンク**（`https://note.com/cool_lilac6617`）に誘導する。

## 過去問の図解（Q01〜Q20）の本文の型

```
【令和8年度 問1】（その問題の「まず確認すること」を1行で）
例）時効取得できるのは、土地だけ？賃借権も？

この問題で狙われるのは、（狙われどころを1〜2行で）。
各肢の正誤は現行の法令で確かめ、根拠の条文は原文と照合した解説を、noteにまとめています。
くわしくはプロフィールのリンクから。

#土地家屋調査士 #調査士試験 #令和8年度 #過去問
```

- 1行目は、`schedule.csv` の `title`（記事のタイトルの「〜〜」の部分）をそのまま使える。
- 問題の本文は丸写ししない。
- 2200字以内。ハッシュタグは少なめ（3〜5個）にして、本文の最後にまとめる。

## つなぎの本文の型

| 枠 | 本文 |
|---|---|
| F1（年度のまとめ） | 「令和8年度の20問、これで一周。次は令和7年度（明日から）。」＋その年度の狙われどころの一言 |
| F2（個別テーマ） | テーマの名前＋「年度をまたいで繰り返し出るテーマです」＋ noteへの案内 |
| F3（4コマ） | 「藍子がはまった罠を、トリ先生が1コマずつほどきます」＋ noteへの案内 |
| F4（案内） | メンバーシップ・毎朝ドリル・Xのいずれか。押し売りにならないよう、読者の得を1行で書く |

## プロフィール欄

決めた文面と、画面の各欄に入れるものは `profile.md`（自己紹介は91文字。「隙間時間でみられる図解を毎日3枚投稿していきます」「くわしい解説はnoteで↓」）。
