# Instagramの画像の仕様

## フィード（毎日3枚・過去問の図解とつなぎ）

| 項目 | 値 |
|---|---|
| 大きさ | **1080×1350px（縦4:5）。Instagramの画像はすべて4:5に固定する**（2026-11-05 ユーザー指示。フィード・表紙・見出し画像・カルーセルの全スライド） |
| 形式 | PNG（容量が大きければ高画質のJPEG） |
| 枠 | 1投稿＝1枚（カルーセルにするときも、全部同じ4:5） |

### 4:5に固定する理由

- フィード投稿の縦長の上限は4:5（1080×1350）。縦長を使うなかで画面を最も広く使える。
- プロフィールのグリッドは3:4の縦長サムネイルなので、4:5の画像は左右がわずかに（約34pxずつ）切り取られて表示される。**左右の端に文字や主要な絵を置かない**（下の「構図の決まり」）。
- 以前は3:4（1080×1440）で作っていたが、比率をそろえるため、すべて4:5に統一した。カルーセルは、全部のスライドの比率をそろえる。

Metaの公式の仕様の文書は確認できていない（制作系のブログの情報）。アカウントを作ったら、最初の1枚をアップして、グリッドで切れないかを自分の画面で確かめる。

### 構図の決まり

- **大事な要素（年度・問の番号・タイトル・結論）は、上下左右5%（左右54px・上下68px）の内側**に置く。端に置くと、表示によって切れる。
- 文字の大きさは、スマホの小さな画面で読める大きさにする。目安は、タイトル 72px以上、本文 40px以上、細かい注 32px以上（1080幅のとき）。
- 1枚で読める量にする。note の総論インフォグラフィック（1080×1920）をそのまま縮めない。4:5に合わせて、カードの数を減らすか、要点を絞る。
- 識別の表示（年度・問）：左上に「令和8年度　問1」の形で入れる。
- **画像の中には、アカウント名・URL・ハッシュタグ・「noteへ」などの案内の文字を入れない**（画像生成で文字が崩れやすく、指定した語以外を描かせない決まりと合わない）。案内は本文（キャプション）に書く。

### 過去問の図解（Q01〜Q20）の作り方

1. 記事の「インフォグラフィック プロンプト（問題全体）」を元に、4:5用のプロンプトを `prompts/{年度コード}.md`（`make_ig_prompts.py` で作る）に作ってある。ChatGPTにそのまま貼る。
2. 記事のプロンプトからの変更は、大きさ（1080x1350）、Instagram用の指示（余白・文字の大きさ・2列の配置・画像内に案内を入れない）、最後の確認の追加だけ。カードの中身は記事のまま。カードは4〜6枚に収まる（収まらない問は「要手作業」）。
   **カードの下端はそろえる**：2列の下端を同じ高さの1本の線（下の余白の線）にそろえ、余った高さはカードの中（イラスト領域・上下の余白）で吸収する。カードとカードのすき間はそろえる（プロンプトの `BOTTOM ALIGNMENT` の指示）。
3. 「その問題で、どこが狙われるか／まず何を確認するか」が、問題文を読まなくても分かる内容にする。
4. 1字ずつ文字を確かめ、記事の結論と食い違わないか確かめる。

## ストーリー

| 項目 | 値 |
|---|---|
| 大きさ | **1080×1920px（縦9:16）** |
| 使うもの | **すでに作成済みの縦長の図解**（下の「stories.md」） |
| 余白 | 上は約250px、下は約250〜340pxに、文字や大事な図を置かない（返信欄や名前の表示が重なる）。既存の図解で端に文字がある場合は、背景の色の帯を足して縮小し、余白を作る |

ストーリーを4:5にしない理由と、4:5の画像をストーリーに出すときの置き方は `stories.md`。

## 年度・問の表記と、見出し画像のプロンプト（2026-11-05追加）

- 画像の中の年度・問は**算用数字**（「令和8年度　問1」「第3問」）。漢数字にしない。
- 見出し画像のInstagram用（4:5・1080×1350）は、令和8年度の各問が `prompts/header-R08.md`、年度の表紙（4:5）が `prompts/cover-R08.md`・`prompts/Instagram_{年度}_00.md`。note用の見出し画像（1280×670）は各記事にある。
