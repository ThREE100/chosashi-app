# Instagramの画像の仕様

## フィード（毎日3枚・過去問の図解とつなぎ）

| 項目 | 値 |
|---|---|
| 大きさ | **1080×1440px（縦3:4）** |
| 形式 | PNG（容量が大きければ高画質のJPEG） |
| 枚数 | 1投稿＝1枚（カルーセルにするときも、全部同じ3:4） |

### 3:4にする理由

- プロフィールのグリッドは、縦長（3:4）のサムネイルで表示される（2025年1月に全ユーザーへ展開）。3:4で作ると、グリッドで切り取られない。
- フィードの投稿は 4:5（1080×1350）も使えるが、グリッドでは上下がわずかに切れる。
- カルーセルは、全部のスライドの比率をそろえる。

Metaの公式の仕様の文書は確認できていない（制作系のブログの情報）。アカウントを作ったら、最初の1枚をアップして、グリッドで切れないかを自分の画面で確かめる。

### 構図の決まり

- **大事な要素（年度・問の番号・タイトル・結論）は、上下左右5%（54px・72px）の内側**に置く。端に置くと、表示によって切れる。
- 文字の大きさは、スマホの小さな画面で読める大きさにする。目安は、タイトル 72px以上、本文 40px以上、細かい注 32px以上（1080幅のとき）。
- 1枚で読める量にする。note の総論インフォグラフィック（1080×1920）をそのまま縮めない。3:4に合わせて、カードの数を減らすか、要点を絞る。
- 識別の表示（年度・問）：左上に「令和8年度　問1」の形で入れる。
- **画像の中には、アカウント名・URL・ハッシュタグ・「noteへ」などの案内の文字を入れない**（画像生成で文字が崩れやすく、指定した語以外を描かせない決まりと合わない）。案内は本文（キャプション）に書く。

### 過去問の図解（Q01〜Q20）の作り方

1. 記事の「インフォグラフィック プロンプト（問題全体）」を元に、3:4用のプロンプトを `prompts/{年度コード}.md`（`make_ig_prompts.py` で作る）に作ってある。ChatGPTにそのまま貼る。
2. 記事のプロンプトからの変更は、大きさ（1080x1440）、Instagram用の指示（余白・文字の大きさ・2列の配置・画像内に案内を入れない）、最後の確認の追加だけ。カードの中身は記事のまま。カードは4〜6枚に収まる（収まらない6問は「要手作業」）。
3. 「その問題で、どこが狙われるか／まず何を確認するか」が、問題文を読まなくても分かる内容にする。
4. 1字ずつ文字を確かめ、記事の結論と食い違わないか確かめる。

## ストーリー

| 項目 | 値 |
|---|---|
| 大きさ | **1080×1920px（縦9:16）** |
| 使うもの | **すでに作成済みの縦長の図解**（下の「stories.md」） |
| 余白 | 上は約250px、下は約250〜340pxに、文字や大事な図を置かない（返信欄や名前の表示が重なる）。既存の図解で端に文字がある場合は、背景の色の帯を足して縮小し、余白を作る |

ストーリーを3:4にしない理由と、3:4の画像をストーリーに出すときの置き方は `stories.md`。
