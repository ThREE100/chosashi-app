# 令和7年度 第21問（土地）座標データ・図面一式

`traverse_tool.py`（リポジトリ直下）を使って、令和7年度 第21問（土地・記述式）の
座標を実際に描画した最初の実例。学習漫画のコマに使う「技術的に正確な図」を
どうやって用意するかの具体例として、このフォルダごと参照できる。

## データの出所と検算

- 座標・境界標・問題文は `src/data/kijutsu.json` の `chosashi_R07_q21`
  （問題文・自作模範解答）と、法務省公表の問題冊子
  （`public/kijutsu/R07-tochi/q1.png`〜`q4.png`：〔調査図素図〕〔合成図〕
  〔遺産分割協議書添付図〕）を突き合わせて確認した。
- Ｄ点（トラバース計算）とＫ点（Ｄ－Ｋ線による等積分割）は、このセッションで
  Pythonで独立に再計算し、`kijutsu.json`収録の模範解答と一致することを確認済み
  （Ｄ＝(201.71, 114.41)、Ｋ＝(199.98, 131.88)）。
- 交換対象のＩ・Ｊ・Ｍ・Ｌ点、および206番（甲地・畑）559㎡、乙地（10番・宅地）
  561.19㎡という模範解答中の地積も、`traverse_tool.py`の座標法・不動産登記規則
  第100条の端数処理ロジックで機械的に再計算し、模範解答と一致することを確認した
  （206番は畑のため1㎡未満切り捨てで**559.00㎡**＝登記記録の559㎡と完全一致）。
- Ｍ－Ｌ（丙→甲交換分の切り分け線）はＤ－Ｋと厳密に平行ではなく、座標を
  小数第2位までに丸める設問の指示（注3）に起因するごく小さな誤差が残っている。
  等積であること（両交換分とも62.72㎡）は確認済みなので実用上問題ない。

## ファイル構成

- `build_specs.py` — 座標・境界標・筆の定義から`spec_*.json`を組み立てるスクリプト。
  座標を修正する場合はこのファイルの`POINTS`辞書を直接編集して再実行する。
- `spec_00_overview.json` → `00_overview.svg` — 〔調査図素図〕相当。206番（甲地・畑）
  と10番（乙地・宅地・分筆前全体）、基準点Ｔ1・Ｔ2からの観測線を表示。
- `spec_01_bunkatsu.json` → `01_bunkatsu.svg` — 問1〜3：乙地の地積更正
  （556.00→561.19㎡）＋Ｄ－Ｋ線による等積分筆（10番1・10番2、各280.59㎡）。
  令和7年8月15日申請分。
- `spec_02_koukan.json` → `02_koukan.svg` — 問4：甲地・丙地（10番1）の等積交換
  （Ｂ－Ｃ－Ｊ－Ｉ ⇔ Ｍ－Ｌ－Ｋ－Ｄ、各62.72㎡）。平行線による等積分割の考え方を
  可視化する、この問題で最も座標計算が絡む場面。
- `spec_03_final.json` → `03_final.svg` — 問5：丙地（10番1）の分筆登記
  （令和7年10月30日申請、残地10番1＝217.90㎡・新設10番3＝62.72㎡）。

## 再生成コマンド

```
python3 build_specs.py
for f in spec_00_overview spec_01_bunkatsu spec_02_koukan spec_03_final; do
  python3 ../../traverse_tool.py "$f.json" -o "${f#spec_}.svg"
done
```
