# 【土地家屋調査士試験】令和6年度 第21問（土地）を複素数で解く｜キヤノンF-789SG完全手順

令和6年度の土地の記述式（第21問）を、キヤノンの関数電卓 F-789SG の複素数モードで最初から最後まで解いていきます。

この問題の山場は「どの資料で筆界を判断するか」と「ずれている部分をどう登記で直すか」の判断です。計算そのものは、放射2点と交点1点、面積が数個だけで、令和7年度より軽めです。判断さえ正しければ、確実に得点できる問題です。

※本記事の数値は、アガルートアカデミーの解答例と照合済みです。

---

## この問題の全体像

まず時系列を押さえます。

- **平成27年**：山田太郎が費用を出して、甲土地の南側にブロック塀を設置。測量はせず、山田と野原の合意した位置に設置した（それ以前は同じ位置に生垣）
- **令和6年7月1日**：野原花子が乙土地を売ろうとして地図に準ずる図面を閲覧し、自宅の敷地の形と違うことに気づく
- **その後**：山田太郎も甲土地の図面を閲覧し、同じく形が違うことを確認
- **合意**：調査の結果、利用状況と筆界が違う場合は、利用状況に筆界を合わせる。手続が必要な土地の所有者が手続をし、もう一方が協力する
- **令和6年10月18日**：土地家屋調査士法務一郎が登記を申請（問3）

登場する土地は次のとおりです。

- **甲土地**：A市B町一丁目2番1（宅地、97.00㎡）。所有者は山田太郎
- **乙土地**：A市B町一丁目3番1（宅地、45.88㎡）。所有者は野原花子

利用状況は次のとおりです。

- **山田太郎（甲土地）**：A→B→C→D→E→F→G→A で囲まれた範囲を使っている
- **野原花子（乙土地）**：B→H→I→C→B で囲まれた範囲を使っている

## 複素数の約束事と電卓の準備

### 座標の置き方

座標は **Z ＝ X ＋ Yi**（X＝北、Y＝東）で扱います。

この置き方だと、複素平面の反時計回りが、地図上の時計回り（方向角の向き）と一致します。つまり、時計回りで与えられた観測角を、そのまま「∠θ」で掛ければ回転できます。

### F-789SGのキー操作

- **複素数モード**：[MODE] [2]（画面に CPLX と表示）
- **角度単位**：Deg（初期設定のまま）
- **i（虚数単位）**：[i]（ENGキー）
- **∠**：[∠]
- **絶対値（距離）**：[Abs]
- **偏角（方向角）**：[Apps] [3]（arg）
- **共役複素数**：[Apps] [4]（Conjg）
- **度分秒の入力と変換**：[°′″]
- **記憶**：[SHIFT] [STO] [文字]
- **呼び出し**：[ALPHA] [文字]

※[∠]・[i]・[°′″] が SHIFT 側（黄色文字）に印字されている場合は、先に [SHIFT] を押してください。

### 変数の割り当て

問題の点名と電卓の変数名がぶつかるので、次のように決めておきます。

- **X**：T1（B点・D点を出した後は P点に入れ替え）
- **Y**：T2
- **B**：B点
- **C**：C点
- **D**：D点
- **A**：J点
- **E**：H点
- **F**：I点

入力例（C点）はこうなります。

```
27.49 [+] 60.92 [i] [SHIFT] [STO] [C]
```

同じように、J点を [A]、H点を [E]、I点を [F] に記憶しておきます。

```
19.83 [+] 60.93 [i] [SHIFT] [STO] [A]
21.83 [+] 54.17 [i] [SHIFT] [STO] [E]
21.83 [+] 60.90 [i] [SHIFT] [STO] [F]
```

### 計算過程の書き方

ここからの計算は、すべて次の3点セットで示します。

- **式（点名）**：問題の点名で書いた計算式。何を計算しているかを理解するためのもの
- **電卓操作**：F-789SGで実際に押すキー。点名は電卓の変数名に置き換わる
- **表示**：電卓に表示される値

式の中の「Conjg( )」は共役複素数、「Abs( )」は絶対値（距離）、「arg( )」は偏角（方向角）です。

## 問1 筆界の判断と、必要な登記手続

答えを先に並べます。

- **ア**：2（地図に準ずる図面に記録された本件各土地の形状）
- **イ**：9（野原花子）
- **ウ**：5（乙土地）
- **エ**：6（分筆の登記の申請）

### ア：どの資料で筆界を判断するか

候補の3つを、1つずつ検討します。

- **1 現地の境界標・構造物**：ブロック塀も金属標も、測量によらず当事者の合意で置いたもの。筆界の根拠にはなりません
- **3 乙土地を残地とする地積測量図**：昭和50年に3番を分筆したときの図です。ただし「残地」とは、測量して面積を出さなかった側の土地のこと。この図で求積されているのは3番2だけで、三斜求積表も3番2の分しかありません
- **2 地図に準ずる図面**：精度は低いものの、甲土地と乙土地の境の形を表している、残された資料です

ポイントは選択肢3の「残地」という言葉です。

乙土地（3番1）は残地なので、昭和50年当時、3番1の周りは測量されていません。この図で信用できるのは、測量された3番2の筆界点（A・B・H・I・J・K）までです。甲乙の境であるB→Dは3番1だけの境なので、測量の裏付けがありません。

甲土地には地積測量図がなく、乙土地の図も甲乙の境は測っていない。そうなると、甲乙の筆界の形を示す資料は地図に準ずる図面しか残りません。したがって、筆界は主に「2」の地図に準ずる図面の形状で判断します。

### 地図に準ずる図面から読み取れる筆界

地図に準ずる図面では、2番1の南側の境は、西のA点付近から東のD点まで **一直線** に描かれています。

この形状に、座標で位置を押さえられる点を当てはめます。

- **B点**：3番2の角として、地積測量図で測量されている点
- **D点**：道路境界確認図のK1と一致する点

B点とD点を結ぶ直線（A点からの一直線の一部）が、甲乙の筆界です。問2でB点・D点の座標を求めると、A・B・Dが一直線に並ぶことを確かめられます。

- **乙土地（3番1）の筆界**：B→D→I→H→B
- **野原花子の利用範囲**：B→H→I→C→B

つまり、三角形B・C・Dの部分は、**筆界上は乙土地なのに、山田太郎（甲土地）が使っている** ことになります。ブロック塀B→Cが、筆界より南にずれているのです。

### イ〜エ：必要な登記手続

合意は「利用状況に筆界を合わせる」ことです。筆界そのものは動かせないので、次の流れになります。

1. 乙土地から、三角形部分を分筆する
2. 分筆した土地を、野原花子から山田太郎に移す（権利の登記）

手続が必要なのは乙土地で、その所有者は野原花子です。したがって「野原花子（イ）が乙土地（ウ）について分筆の登記の申請（エ）をする」となります。

### 選択肢7（地積更正と地図訂正）がひっかけである理由

- **地図訂正は不要**：地図に準ずる図面の形状は、まさに判断の根拠にした筆界そのものです。ずれているのは「筆界と利用状況」であって、「図面と筆界」ではありません
- **地積更正も求められていない**：問題文には地積測定の公差の表がなく、面積の差を問う作りになっていません。参考までに、市街地地域（甲2）の公差の式で計算すると、乙土地は筆界どおり45.86㎡（登記記録45.88㎡、公差約0.51㎡）、甲土地は96.29㎡（登記記録97.00㎡、公差約0.80㎡）で、どちらも公差の範囲内です

## 問2 B点・D点・P点の座標

### B点とD点（放射計算）

T2に器械を据え、T1を後視して、B点とD点を観測しています。

- **B点**：観測角 78°58′08″、水平距離 10.03m
- **D点**：観測角 118°24′27″、水平距離 4.60m

**① 基準点を記憶する**

式（点名）

```
T1 ＝ 16.63 ＋ 61.67i
T2 ＝ 26.91 ＋ 64.19i
```

電卓操作（X＝T1、Y＝T2）

```
16.63 [+] 61.67 [i] [SHIFT] [STO] [X]
26.91 [+] 64.19 [i] [SHIFT] [STO] [Y]
```

**② T2→T1の方向角を確認する（任意）**

式（点名）

```
T2→T1の方向角 ＝ arg(T1 − T2)
```

電卓操作（X＝T1、Y＝T2）

```
[Apps] [3] [ALPHA] [X] [−] [ALPHA] [Y] [)] [=] [°′″]
```

表示：−166°13′34.82″

負の値で出るので、360°を足して 193°46′25.18″ と読みます。次の計算では、負のまま使っても結果は同じです。

**③ B点を計算する**

「T2→T1の方向」に「観測角78°58′08″」を足した方向へ、10.03m進みます。

式（点名）

```
B ＝ T2 ＋ 10.03∠( arg(T1 − T2) ＋ 78°58′08″ )
```

電卓操作（X＝T1、Y＝T2）

```
[ALPHA] [Y] [+] 10.03 [∠] [(] [Apps] [3] [ALPHA] [X] [−] [ALPHA] [Y] [)]
[+] 78 [°′″] 58 [°′″] 8 [°′″] [)] [=]
```

表示：27.3899… ＋ 54.1714…i

注3により、小数第3位を四捨五入して記憶し直します。

```
27.39 [+] 54.17 [i] [SHIFT] [STO] [B]
```

**▶ B点（27.39, 54.17）**

**④ D点を計算する**

式（点名）

```
D ＝ T2 ＋ 4.60∠( arg(T1 − T2) ＋ 118°24′27″ )
```

電卓操作（X＝T1、Y＝T2）

```
[ALPHA] [Y] [+] 4.60 [∠] [(] [Apps] [3] [ALPHA] [X] [−] [ALPHA] [Y] [)]
[+] 118 [°′″] 24 [°′″] 27 [°′″] [)] [=]
```

表示：29.9987… ＋ 60.7812…i

```
30.00 [+] 60.78 [i] [SHIFT] [STO] [D]
```

**▶ D点（30.00, 60.78）**

**⑤ 既存資料と照合する（検算）**

求めたB点・D点が正しいかを、既存資料の辺長で確かめます。

式（点名）

```
BH ＝ Abs(H − B)
DJ ＝ Abs(J − D)
```

電卓操作（E＝H、A＝J）

```
[Abs] [ALPHA] [E] [−] [ALPHA] [B] [)] [=]
[Abs] [ALPHA] [A] [−] [ALPHA] [D] [)] [=]
```

表示：5.56（1行目）、10.1711…（2行目）

- BH 5.56 は、昭和50年の地積測量図の「5.56」と一致
- DJ 10.17 は、道路境界確認図の K1K2「10.17」と一致（D＝K1、J＝K2）

同様に、A点（25.09, 48.35）とB点の距離を出すと 6.258 → 6.26 となり、地積測量図の「6.26」と一致します。

**気づいておきたいこと**

B点とH点はY座標が同じ（54.17）です。つまり、BHは真北方向の直線です。地積測量図の「5.56」は、X座標の差（27.39 − 21.83）そのものです。

### 乙土地の面積（筆界どおり）

問1で使う、地積更正の要否の判断材料です。4点 B→D→I→H で計算します。

式（点名）

```
倍面積 ＝ B・Conjg(D) ＋ D・Conjg(I) ＋ I・Conjg(H) ＋ H・Conjg(B)
```

電卓操作（F＝I、E＝H）

```
[ALPHA] [B] [Apps] [4] [ALPHA] [D] [)]
[+] [ALPHA] [D] [Apps] [4] [ALPHA] [F] [)]
[+] [ALPHA] [F] [Apps] [4] [ALPHA] [E] [)]
[+] [ALPHA] [E] [Apps] [4] [ALPHA] [B] [)] [=]
```

表示：15778.3691 − 91.7357i

- **iの係数** を読みます。実部は使いません
- 91.7357 ÷ 2 ＝ 45.86785
- 宅地なので小数第2位未満を切り捨てて 45.86㎡

登記記録の45.88㎡との差は0.02㎡です。問題文に公差の表はありませんが、市街地地域（甲2）の公差の式で計算すると約0.51㎡で、差はその範囲内です。**地積更正の登記は不要** です。

### P点（ブロック塀の線と道路境界の交点）

C点の金属標は、道路との境界線上にありませんでした（調査結果2(3)ウ）。そこで、ブロック塀の線（B→C）が道路境界（D→J）と交わる点に移設し、これをP点とします。

**考え方**

P点は「直線BC上」かつ「直線DJ上」の点です。

直線BC上の点は、B ＋ (C − B) × t と表せます。このtを求めるには、Conjgの積のiの係数（平行四辺形の面積）の比を使います。

- 「DからBへ向かう線」と「DJ」が作る平行四辺形の面積
- 「BからCへ向かう線」と「DJ」が作る平行四辺形の面積

この2つの比が、BからPまでの長さとBからCまでの長さの比 t になります。

**① 1つ目のiの係数を求める**

式（点名）

```
Conjg(D − B) × (J − D)
```

電卓操作（A＝J）

```
[Apps] [4] [ALPHA] [D] [−] [ALPHA] [B] [)] [×] [(] [ALPHA] [A] [−] [ALPHA] [D] [)] [=]
```

表示：−25.5522 ＋ 67.6152i

**② 2つ目のiの係数を求める**

式（点名）

```
Conjg(C − B) × (J − D)
```

電卓操作（A＝J）

```
[Apps] [4] [ALPHA] [C] [−] [ALPHA] [B] [)] [×] [(] [ALPHA] [A] [−] [ALPHA] [D] [)] [=]
```

表示：−0.0045 ＋ 68.6625i

**③ P点を計算する**

```
t ＝ 67.6152 ÷ 68.6625 ＝ 0.984747
```

式（点名）

```
P ＝ B ＋ (C − B) × t
```

電卓操作

```
[ALPHA] [B] [+] [(] [ALPHA] [C] [−] [ALPHA] [B] [)] [×] 67.6152 [÷] 68.6625 [=]
```

表示：27.4884… ＋ 60.8170…i

T1はもう使わないので、変数Xを使い回してP点を記憶します。

```
27.49 [+] 60.82 [i] [SHIFT] [STO] [X]
```

**▶ P点（27.49, 60.82）**

**検算**

- C点（27.49, 60.92）とP点の距離は0.10mです。金属標は、道路側に10cmはみ出していたことになります
- C点から直線DJに垂線を下ろした足を計算しても、丸めると同じ（27.49, 60.82）になります。BCとDJがほぼ直角に交わっているためです

## 問3 登記申請書（10月18日申請分）

### 分筆後の各土地の面積

乙土地（3番1）を、直線BPで2つに分けます。

- 北側の三角形 B・D・P：山田太郎に移す部分
- 南側の四角形 B・P・I・H：野原花子に残る部分

**① 三角形BDPの面積**

式（点名）

```
△BDPの倍面積 ＝ Conjg(D − B) × (P − B)
```

電卓操作（X＝P）

```
[Apps] [4] [ALPHA] [D] [−] [ALPHA] [B] [)] [×] [(] [ALPHA] [X] [−] [ALPHA] [B] [)] [=]
```

表示：44.2175 ＋ 16.6955i

16.6955 ÷ 2 ＝ 8.34775 → 地積 8.34㎡

**② 四角形BPIHの面積**

式（点名）

```
倍面積 ＝ B・Conjg(P) ＋ P・Conjg(I) ＋ I・Conjg(H) ＋ H・Conjg(B)
```

電卓操作（X＝P、F＝I、E＝H）

```
[ALPHA] [B] [Apps] [4] [ALPHA] [X] [)]
[+] [ALPHA] [X] [Apps] [4] [ALPHA] [F] [)]
[+] [ALPHA] [F] [Apps] [4] [ALPHA] [E] [)]
[+] [ALPHA] [E] [Apps] [4] [ALPHA] [B] [)] [=]
```

表示：15659.4297 − 75.0658i

75.0658 ÷ 2 ＝ 37.5329 → 地積 37.53㎡

**③ 地番を決める**

注8により、分筆後の土地のうち **面積の小さい方を3番3** とします。

- 三角形BDP（8.34㎡）：（ロ）3番3
- 四角形BPIH（37.53㎡）：（イ）3番1（元の地番のまま）

**検算**

切り捨て前の値を足すと、8.34775 ＋ 37.5329 ＝ 45.88065 となり、登記記録の45.88㎡とよく合います。

### ひっかけポイント

**申請人は野原花子**

分筆の登記を申請できるのは、その土地の所有者だけです。三角形部分を最終的に取得するのは山田太郎ですが、分筆の時点ではまだ野原花子の土地です。山田太郎は「協力する側」です。

**申請人の住所**

登記記録の住所は「A市B町一丁目3番地1」です。「3番1号」ではなく「3番地1」と書きます。

**地積更正は申請しない**

この問題で必要なのは、利用状況に筆界を合わせるための分筆だけです。面積の差も公差の範囲内なので、地積更正まで申請すると不要な申請になります。

**地図訂正の申出書も不要**

問3の本文に「申出書を作成する必要がある場合であったとしても、記載する必要はない」とありますが、これはひっかけです。地図に準ずる図面の形状は筆界どおりなので、申出は必要ありません。

## 問4 地積測量図（10月18日申請分）

### 何を描くか

分筆後の2筆を表示した地積測量図を作成します。

- **地番欄**：3番1、3番3
- **土地の所在**：A市B町一丁目
- **縮尺**：1/250（印刷済み）
- **申請人・作成者・作成日**：答案用紙に（略）と印刷済みなので記入不要

## 問5 地図に準ずる図面の訂正

答えを先に並べます。

- **①（申出権者）**：当該土地の表題部所有者若しくは所有権の登記名義人又はこれらの相続人その他の一般承継人
- **②ア**：地番
- **②イ**：職権
- **②ウ**：土地所在図又は地積測量図

### 考え方

**①とア（不動産登記規則16条1項）**

地図の場合は「土地の区画又は地番」、地図に準ずる図面の場合は「土地の位置、形状又は地番」に誤りがあるとき、訂正の申出ができます。申出できるのは、表題部所有者・所有権の登記名義人と、その相続人その他の一般承継人です。

**イ**

申出権のない人からの申出は、却下するか、登記官の職権の発動を促すものとして扱います。登記官は、職権で地図等を訂正できるからです。

**ウ（不動産登記規則16条5項）**

位置や形状の誤りを直すには、正しい形を示す図面が必要です。そのため、土地所在図又は地積測量図を提供します。なお、これとは別に「誤りがあることを証する情報」も必要です。

## まとめ：この問題で差がつくところ

- **「残地」の地積測量図を過信しない。** 乙土地は残地なので、甲乙の境は測量されていません。筆界の形は地図に準ずる図面で判断し、B点・D点は測量済みの資料で押さえます
- **ずれているのは「筆界と利用状況」。** 図面と筆界は合っているので、地図訂正も地積更正も不要。必要なのは乙土地の分筆です
- **申請人は分筆する土地の所有者。** 最終的に土地を取得する山田太郎ではなく、野原花子です
- **P点は「ブロック塀の線」と「道路境界」の交点。** Conjgの積のiの係数の比で、交点を一発で出せます
- **作図ではC点を描かない。** 移設後のP点（金属標）で描きます

計算量が少ない分、問1・問5の判断と、申請書の細部（住所の「番地」、地番の付け方）で差がつきます。
