# 依頼文：新しい年度の第22問（建物）記事を別チャットで作成するとき

新しい年度の第22問（建物）の会話形式note記事を、別のチャット（Claude Code のセッション）で作らせるときに貼り付ける依頼文です。

## 使い方

- 下のコードブロックの中身をそのままチャットに貼る
- 書き換えるのは冒頭の【対象年度】の1行だけ（年度と、フォルダ名）
- 問題PDF・答案用紙PDF・予備校の解答例PDFの3つを一緒に添付する
- 平成の年度のフォルダ名は `H30` のように書く（令和は `R1`〜`R7`、平成は `H28`・`H29`・`H30` を使用済み）

## 保守のルール

- 執筆プロンプト（`prompt_note-kijutsu_tatemono_kyoutsu.md`）やダブルチェック指示書（`qa-checklist-kijutsu.md`）に、依頼文にも関わる新しいルールが加わったら、この依頼文も合わせて更新する
- 参考例（年度ごとの問題の型）の一覧は、新しい年度の記事ができるたびに追記する

---

```
【対象年度】平成30年度（フォルダ名：H30）

GitHubリポジトリ ThREE100/chosashi-app の main ブランチで、上記年度の土地家屋調査士試験 第22問（建物）について、トリ先生と藍子の会話形式のnote解説記事と付属ファイル一式を作ってください。完成したら main に直接コミット・pushしてください。

■ 添付資料
- 問題PDF（全ページ）
- 答案用紙PDF
- 予備校の解答例PDF（照合専用。解説文は流用しない）

添付PDFのファイル名と中身が一致しないことや、1つのPDFに問題と解答例がまとめて入っていることがあります。欠けている資料があると判断する前に、すべてのPDFを全ページ確認してください。それでも欠けていれば、作業を始める前に私に確認してください。
予備校の過去問集に再掲された問題文は、日付が試験問題の本文と違うことがあります。答案用紙に印刷された申請日と前後関係が合わないときは、試験問題の本文がそろうまで作業を始めずに私に確認してください。
PDFが撮影画像でテキストを読み取れない場合や pdftoppm がない場合は、pymupdf でページを画像にして読んでください。
予備校の過去問集は、問題文の日付や記述を書き換えていることがあります。記事の日付・事実は、試験問題本文と答案用紙の印刷に合わせてください。

■ 最初に読むファイル（この順番で）
1. CLAUDE.md
   ブランチ運用ルールと、第22問の各年度の完了状況が書いてある。セッションで別ブランチを指定されていても、note-articles-Kijyutsu 配下の変更は main に直接コミットする
2. note-articles-Kijyutsu/README.md
   フォルダ構成
3. note-articles-Kijyutsu/prompt_note-kijutsu_tatemono_kyoutsu.md
   執筆プロンプト。作業手順、建物固有の必須チェック論点、note向けの体裁ルール、タイトル形式、記事の構成テンプレート、書き方の注意が書いてある
4. note-articles-Kijyutsu/qa-checklist-kijutsu.md
   ダブルチェック指示書。3-2「建物固有」と、末尾の改善記録も読む
5. 完成した参考例：note-articles-Kijyutsu/H28/Q22/・H29/Q22/・H30/Q22/・R1/Q22/〜R7/Q22/ の各フォルダ
   問題の型が近い年度を優先して読む
   - 渡り廊下でつながった新館の増築（区分建物の要件・傾斜地の階数・渡廊下付き）：H28
   - 建物分割登記・主である建物の種類変更と附属建物の新築（1室の一部の天井が低い建物）：H29
   - 所有権の登記がある建物の合体・存続登記（同一人でないとみなす持分）：H30
   - 区分建物の表題登記・敷地権：R1
   - 滅失登記・表題登記：R2
   - 建物区分登記：R3
   - 附属建物の接続・新築：R4
   - 区分建物の合併：R5
   - 共有建物の表題登記：R6
   - 主である建物の取壊し・附属建物の再築：R7

■ 画像プロンプトの共通フォーム
- 解説図：note-articles-Kijyutsu/prompt_kaisetsuzu-gazou_kihon-form_tatemono.md
  （頂点座標からPythonで作図する方式。参考例の prompt_R?_dai22mon_kaisetsuzu.md と同じ作り）
- 登記申請書：note-articles-Kijyutsu/prompt_toukishinseisho-gazou_kihon-form_tatemono.md
  （欄の名前・順序・「（略）」の印刷は、予備校の再現ではなく試験の答案用紙に合わせる）
- note見出し画像：note-articles-Kijyutsu/R7/Q22/prompt_R7_dai22mon_miidashi_gazou.md の構成を踏襲する

■ 検算・体裁チェックの道具
- note-articles-Kijyutsu/tools/calc_helpers.py
- note-articles-Kijyutsu/tools/lint_note_article.py

■ 作成するファイル（保存先：note-articles-Kijyutsu/{フォルダ名}/Q22/）
- note_{フォルダ名}_dai22mon_tatemono_kaisetsu.md（note記事本文）
- prompt_{フォルダ名}_dai22mon_kaisetsuzu.md（解説図。標準セットは次のとおり。年度により増減してよい）
  - 敷地の辺長確認図（作図チェック用）
  - 建物図面の完成形
  - 誤り比較図
  - 各階の求積図
- prompt_{フォルダ名}_dai22mon_toukishinseisho_gazou.md（登記申請書の完成形。欄が複数あれば全部）
- prompt_{フォルダ名}_dai22mon_toukishinseisho_machigai.md（誤答→添削→正解の3コマ）
- prompt_{フォルダ名}_dai22mon_miidashi_gazou.md（note見出し画像）
- verify_{フォルダ名}_dai22mon.py（照合スクリプト）

■ 特に守ること
- タイトルは「【土地家屋調査士受験生向け】{年度}問題22（建物）〜見出し〜」の形にする
  - 見出しは25文字以内
  - 年度は「平成30年度」「令和元年度」のように問題文どおりに書く
  - 見出し画像の文字もタイトルと同じ文言にそろえる
- 設問一覧表を作り、問1〜問Nのすべてに会話の中で答える
  - 添付書類・登録免許税・申請人・一棟の建物の表示なども、画像任せにしない
- 藍子の誤答やトリ先生の「AじゃなくてB」の対比には、正解と対になる概念を使う
  - 例：報告的登記⇔形成的登記、合併⇔合体、壁心⇔内法
  - 受験生なら選ばない明らかな誤りは使わない。対比側の用語が正しい用語かも確認する
- 数値が解答例と合っていても安心しない。数値に至る説明（どこを除くか・なぜか・どの寸法線から拾うか）を平面詳細図と1文ずつ突き合わせる
- 図形の位置は「右上・奥側」ではなく、配置図の方位で確かめて東西南北で書く
- 解説図の頂点座標は、面積を計算して求積表と一致させる
- 敷地の辺長は作図チェック用で、建物図面には書かない
- 床面積は1平方メートルの100分の1未満を切り捨てる（小数第3位がちょうど5のときに注意）
- 原因及びその日付の頭に、変更した欄の番号（②③など）を付ける
- 記号「✕」「✓」と実務の略語（「名変」など）は本文に使わない
- 条文を示すときは原典で確認したものだけにする。確認していない先例は書かない

■ 完了前に行うこと
1. verify_{フォルダ名}_dai22mon.py で NG 0件を確認する。照合の対象は次のとおり
   - 記事の数値・求積
   - 付属プロンプト（登記申請書・添削・見出し画像・解説図の頂点座標）
   - タイトル形式と note向けの体裁
2. lint_note_article.py で表記ルール違反がないことを確認する
3. qa-checklist-kijutsu.md に従ってダブルチェックする
   - 改善記録の先頭に、今回の年度の記録（照合結果・自分で直した誤り・新しい気づき）を追加する
   - 新しい論点があれば、執筆プロンプトの「建物固有の必須チェック論点」と、チェックリストの3-2にも追加する
4. CLAUDE.md の第22問の項に、この年度の完了状況と主な論点を1段落で追記する
5. note-articles-Kijyutsu/README.md のフォルダ構成に、今回のフォルダを追加する
6. note-articles-Kijyutsu/irai-bun_tatemono_shinki-nendo.md の参考例の一覧に、今回の年度と問題の型を追記する
7. git pull origin main で最新化してから main にコミット・pushする

■ 最後に報告すること
- 解答例と一致した項目
- 食い違った項目と、どちらを採用したか
- 照合できなかった項目と理由
- 作成中に自分で見つけて直した誤り
- 問1〜問Nのそれぞれを、記事のどの章で答えたかの一覧
```
