# 依頼文：新しい年度の第22問（建物）記事を別チャットで作成するとき

新しい年度の第22問（建物）の会話形式note記事を、別のチャット（Claude Code のセッション）で作らせるときに貼り付ける依頼文です。

## 使い方

- 下のコードブロックの中身をそのままチャットに貼る
- 書き換えるのは冒頭の【対象年度】の1行だけ（年度と、フォルダ名）
- 問題PDF・答案用紙PDF・予備校の解答例PDFの3つを一緒に添付する
- 平成の年度のフォルダ名は `H30` のように書く（令和は `R1`〜`R7`、平成は `H20`・`H21`・`H22`・`H23`・`H24`・`H25`・`H26`・`H27`・`H28`・`H29`・`H30` を使用済み）

## 保守のルール

- 執筆プロンプト（`prompt_note-kijutsu_tatemono_kyoutsu.md`）やダブルチェック指示書（`qa-checklist-kijutsu.md`）に、依頼文にも関わる新しいルールが加わったら、この依頼文も合わせて更新する
- 参考例（年度ごとの問題の型）の一覧は、新しい年度の記事ができるたびに追記する

---

```
【対象年度】平成30年度（フォルダ名：H30）

GitHubリポジトリ ThREE100/chosashi-app の main ブランチで、上記年度の土地家屋調査士試験 第22問（建物）について、トリ先生と藍子の会話形式のnote解説記事と付属ファイル一式を作ってください。完成したら main に直接コミット・pushしてください。

■ 添付資料
- 問題PDF（全ページ）
- 答案用紙PDF
- 予備校の解答例PDF（照合専用。解説文は流用しない）
- 予備校の解説（解説文・動画の書き起こし）があれば一緒に貼る。答えの照合に加え、解く順番・時間配分・つまずく点を記事と見比べ、足りない観点を自分の言葉で足す

添付PDFのファイル名と中身が一致しないことや、1つのPDFに問題と解答例がまとめて入っていることがあります。欠けている資料があると判断する前に、すべてのPDFを全ページ確認してください。それでも欠けていれば、作業を始める前に私に確認してください。
予備校の過去問集に再掲された問題文は、日付が試験問題の本文と違うことがあります。答案用紙に印刷された申請日と前後関係が合わないときは、試験問題の本文がそろうまで作業を始めずに私に確認してください。
PDFが撮影画像でテキストを読み取れない場合や pdftoppm がない場合は、pymupdf でページを画像にして読んでください。
予備校の過去問集は、問題文の日付や記述を書き換えていることがあります。記事の日付・事実は、試験問題本文と答案用紙の印刷に合わせてください。

■ 特に守ること
- セリフの1段落はnoteの本文で5行（全角換算220字。半角は0.5字。多くても260字）までにする。超えるときは、「。」の後ろで段落を分ける（空行。最初の段落だけ「で始め最後の段落だけ」で閉じる）・相手の短い受け答えをはさんで分ける・3つ以上の列挙は箇条書きに出す、のどれかで直す。1つのセリフは3段落まで（執筆プロンプトの「セリフの長さ」）
- タイトルは「【土地家屋調査士受験生向け】{年度}問題22（建物）〜見出し〜」の形にする
  - 見出しは25文字以内
  - 年度は「平成30年度」「令和元年度」のように問題文どおりに書く
  - 見出し画像の文字もタイトルと同じ文言にそろえる
- 設問一覧表を作り、問1〜問Nのすべてに会話の中で答える
  - 添付書類・登録免許税・申請人・一棟の建物の表示なども、画像任せにしない
- 藍子の誤答やトリ先生の「AじゃなくてB」の対比には、正解と対になる概念を使う
  - 例：報告的登記⇔形成的登記、合併⇔合体、壁心⇔内法
  - 受験生なら選ばない明らかな誤りは使わない。対比側の用語が正しい用語かも確認する
- 数値が解答例と合っていても安心しない。数値に至る説明（どこを除くか・なぜか・どの寸法線から拾うか）を平面詳細図と1文ずつ突き合わせる
- 図形の位置は「右上・奥側」ではなく、配置図の方位で確かめて東西南北で書く
- 問題文の注と〔調査・測量〕などの図の注は、同じ番号でも「問題文の注4」「〔調査・測量〕の図の（注）3」のように書き分ける
- 標準セットの図を作らない年度（座標・辺長がない、建物図面を求めない等）は、作らない理由を解説図プロンプトに書く
- 解説図の頂点座標は、面積を計算して求積表と一致させる
- 敷地の辺長は作図チェック用で、建物図面には書かない
- 床面積は1平方メートルの100分の1未満を切り捨てる（小数第3位がちょうど5のときに注意）
- 原因及びその日付の頭に、変更した欄の番号（②③など）を付ける
  - ただし、種類・構造・床面積を全部書き起こす行には付けない（主である建物の滅失で附属建物を主である建物に変更した行〈不動産登記事務取扱手続準則第102条。R7・H25〉、合体後の建物の表題登記〈H30〉）
- 所在は概略図の見た目で決めず、座標と筆界からの距離で建物の位置を出して、どの筆にかかるかを確かめる
- 同じ話者のセリフを続けない。画像挿入マーカー・求積表・箇条書きをはさんでも、間に相手の短い受け答えを入れるか1つにまとめる（`lint_note_article.py` と照合スクリプトで確かめる）
- 穴埋め（ア〜オ、①〜⑤）は、理由の筋を説明するだけで終えず、答えの語そのものを会話で言わせる
- 答案用紙の形は、予備校の再現ではなく試験の答案用紙で決める（欄名の「添付情報」は「〜情報」、「主たる／主である」、登録免許税・一棟の建物の表示の欄がない年度は描き足さない、申請の日付・提出先の行の位置、「（略）」が印刷されていない代理人・職印・作成者・申請人の欄は書く）。答案用紙が手元にないときは前後の年度にならって「仮」と明記し、作業報告で確認を求める
- 解く順番（問を先に読む→時系列メモ→計算なしで先に書ける欄→いちばん時間を食う作業）と具体的な時間配分を、まとめの章の会話と図で示す。附属建物が多い年度は、建物ごとの時系列メモを第1章の終わりに入れる。予備校の解説があれば見比べて自分の言葉で足す
- 作図・書き出しの環境（`fonts-noto-cjk`、matplotlib、pillow、playwright、pymupdf）は入っていないことが多い。作業の最初に確かめて入れる
- アプリの問題画像（`public/kijutsu/`・`src/data/kijutsu.json`）の追加・保存は、記事の作成の依頼には含めない（読むだけ。ユーザーの指示があったときだけ行う）
- 記号「✕」「✓」と実務の略語（「名変」など）は本文に使わない
- 条文を示すときは原典で確認したものだけにする。確認していない先例は書かない
- 画像（解説図・申請書・添削）の中には「図1」「画像2」などの通し番号を書かない。タイトルは内容だけにする（番号はPNG名・画像挿入マーカー・図の一覧の管理用。今後作る記事から適用し、作成済みの記事・図は変えない）
- 図は、画像挿入マーカーとPNGの数が合うだけでなく、本文で説明しているのに図がない箇所がないかを章ごとに確かめる（藍子の誤答と訂正の組、申請書の欄ごとの誤答の添削〈欄ごとに1枚〉、その年度の最大のわなの理由、条文の各号の当てはめ、本文で計算した確認の数値、注の仕分け、時系列メモ、解く順番）。足したら該当する会話の直後に置き、図の番号を挿入順に振り直して、ファイル名・作図スクリプト・プロンプト・照合スクリプトの番号をそろえる（H22〜H26で同じ指摘が続いた）
- 予備校の解答例と答えが食い違ったら、答えを決める前に択一式の記事（`note-articles/`）を論点の語で検索する。択一式で出題され、根拠の先例まで解説済みのことがある（H21/Q22：床面積に算入する部分の屋根面積の30％未満の屋根は構造に表示しない。昭和63年3月24日民三第1826号、択一式の平成25年度第12問・平成29年度第16問）
- 予備校の解答例が改題版（日付の置き換え・人名や問題文の注の書き換え・会社法人等番号や答案用紙の欄の追加など）のことがある。改題で加えられた要素はアガルート独自の教材なので、照合にも記事本文・図解にも使わず、「改題」の説明も書かない。日付・問題文・答案用紙の欄は試験問題本文と試験の答案用紙だけで決める（照合で日付の対応表を使うのは作業の中だけ）
- 法改正で答えが変わる項目（会社法人等番号など）は、今の法令で答え、「（出題当時は〜）」の注を添える（H26/Q22：添付情報は会社法人等番号〈出題当時は会社法人等番号の制度がなく、資格証明書〉）。登記申請書の画像も今の法令で記入する
- 法改正で答えや理由が変わる論点の一覧（択一式の解説で見つかったもの）は `qa-checklist-kijutsu.md` の3-0にある。法人の申請人・相続人による申請・共有者の一部による申請・区分所有の規約などが出てきたら、その一覧で今の扱いを確かめる
```
