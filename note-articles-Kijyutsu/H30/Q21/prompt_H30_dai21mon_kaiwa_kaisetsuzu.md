## 図の必須セット（出題で求められる解答ごとに1枚）

年度によって設問は変わるが、次の対応を基準にして、**設問の答え1つにつき少なくとも1枚**を用意する。1枚に2つの答えを詰め込まない（例：J点とL点は別の図にする）。

- **全体像**（第1章用）：問題の調査図素図を、座標どおり北を上にして描き直した図。問題の図は傾いて描かれていることが多く、軸に平行な辺（X座標またはY座標が同じ2点）が見えにくい
- **座標を求める問（点ごとに1枚）**：その点を出すための作図の考え方を示す
  - 放射：器械点・後視点・求点、北の方向、後視の方向角の弧、観測角の弧（時計回りの向きの矢印付き）、距離。観測角の向きを逆にした誤りの点を薄く添えると、わなが伝わる。**同じ器械点・同じ後視から2点以上を放射で出す年度でも、点ごとに1枚にする**（R6/Q21のB点・D点。1枚にまとめると弧と吹き出しが重なり、答えごとの図にならない）
  - 面積分割：分割線、面積を計算する三角形の塗り分け、高さ（垂線と直角の記号）、求めた辺の長さ
  - 平行線・等積交換：平行の記号（辺の中央に「＞」を同じ向きで。組ごとに本数を変える）、補助線（X＝一定、Y＝一定の破線）、交換する区画の塗り分け
  - 延長線の交点・相似：交点が遠くにある場合は、全体（交点まで入れた縮小図）と拡大図の2パネルにする
  - 延長線の上の交点（H30/Q21：H→Eの延長線とA→Bの交点I）：元の2点の間（t＝0〜1）と延長した部分（t＝1〜）を色と線種で分け、tの範囲を吹き出しで書く。「ほぼ軸に平行」と見て誤った点が別の点とほぼ重なる場合（真南に下ろした誤りのIがJと0.01m）は、拡大パネルで両方を描き、差を書く
  - 座標変換（道路境界確認図などの任意座標から測量の座標へ）：任意座標と測量の座標の2パネルに、共通点と求める点の折れ線を同じ形で並べ、差のベクトル（B − A など）を添えて、回転・縮尺の有無を示す（R2/Q21）
  - 境界標の移設・わずかなずれ（R6/Q21：金属標Cが道路境界から0.10mはみ出し、交点Pへ移設）：全体の縮尺ではずれが見えないので、全体図と、その点のまわり（数十cm四方）の拡大図の2パネルにし、拡大図にずれの長さを書く。求めた点と誤りの点・杭がごく近い場合も同じ（R3/Q21：E点の杭とH点は0.02m、平行四辺形と思い込んだ誤りのL点は筆界から0.15m）
- **筆界の判断**（筆界点の認定が問われる年度）：誤った筆界（関係者の当初の説明など）と正しい筆界の2パネル比較。それぞれの区画の面積を書き、登記記録の地積と一致するのはどちらかを示す。隣の土地の地積測量図（辺長・三斜の底辺と高さ）で裏付ける年度は、その辺長・高さを図に書き、誤った点（発見された杭など）の値と並べる（R3/Q21）
- **穴埋め・判断の問**（公差・地積更正の要否など）：数直線の判定図。登記記録の地積、公差の範囲（塗り）、実測の面積、差の矢印と判定。筆が2つあれば数直線を2本にする。（R2/Q21）
- **法令の穴埋めの問**（地図訂正の申出など、座標を使わない問）：条文の構造（申出権者、対象、却下と職権、併せて提供する情報など）を角丸の枠で上から並べた整理図（横1600px × 縦1200px、固定配置）。答えの語句を赤にし、取り違えやすい対（地図の「区画」⇔地図に準ずる図面の「位置、形状」など）を同じ枠に並べる。申請人の関係（R3/Q21：相続人の1人が他の相続人に代位する関係図）も、同じく箱と矢印の固定配置で描いてよい。固定配置の図は自動の重なり検査の対象外なので、PNGを開いて文字と矢印が重なっていないかを必ず目で確かめる
- **地積測量図の問**：答案用紙に描く地積測量図の完成見本（下の「地積測量図の見本のルール」）
- **申請書の問**：分筆・合筆後の区画と地番（（イ）（ロ）、新しい地番）を示す図。分合筆は「申請前（登記記録）」と「分合筆の後」の2パネルにし、申請書に書く地積（分筆後の各土地は座標の求積値、合筆後は登記記録の地積＋合併する部分）を区画の中に書く（R2/Q21）。登記申請書の画像そのものは、別のフォーム（`prompt_toukishinseisho-gazou_kihon-form.md`）で作る
- **筆界特定の対象土地・関係土地**（R1/Q21）：座標のない周りの土地（地図に準ずる図面の写しにしかない土地）は、座標のある本件土地に合わせて形と大きさを模式的に置き、説明文に「模式図（座標ではない）」と書く。対象の筆界を赤の太線、その両端の点（関係土地を決める筆界上の点）を赤の点にし、対象土地・関係土地・どちらでもない土地を塗り分ける。関係人のように人を答える問は、条文の号ごとに固定配置の整理図にし、申請人など外れる人を灰色で並べる
- **法令の穴埋めの問の補足**（R4/Q21）：号ごとに書く事項が分かれる条文（本人確認情報の面識の有無など）は、分かれ道の矢印で見せる。座標のある図にできる場合（筆界特定の「位置」と「位置の範囲」など）は、座標どおりの図に答えの語を書き込む。固定配置の図は重なりの自動検査の対象外なので、目視で必ず確認する（R4/Q21の図6・図10）
- **筆界の判断の裏付けが面積でできない年度**：関係者の認識の線と筆界で囲んだ面積がどちらも登記記録に近いとき（交換する2つの部分がほぼ同じ面積のとき）は、面積の比較図に加えて、備付けの地積測量図の辺長（対角線など）を座標から再現して一致を示す図を作る（R4/Q21の図3）

## 全図に共通するルール

### 座標の扱い（最重要）

- 測量の座標系では **X＝北（上）、Y＝東（右）**。数学のグラフとは軸が逆なので注意する
- 作図では、**横軸にY座標、縦軸にX座標** をとる
- 縦横の縮尺を必ず同じにする。matplotlib なら `ax.set_aspect('equal', adjustable='datalim')`。`adjustable='box'`（既定）だと、図形の縦横比に合わせてパネルが細くなり、文字を置く余白がなくなる
- 座標軸・目盛り・グリッドは表示しない

### サイズ・フォント・色

- **サイズ**：横1600px × 縦1200px（数直線の判定図は横1600px × 縦900px でよい）。背景は白
- **フォント**：日本語が表示できるもの（Noto Sans CJK JP、IPAゴシックなど）。□や豆腐文字が1つでも出たら、フォントを見直す。記号「≒」は、Noto Sans CJK JP で描いても豆腐（□）になった（H27/Q21の説明文）。「≒」は使わず、「＝」と言葉（「表の○○の行」など）で書く
- **タイトル**：図の上部に「図N　問M　○○の求め方」
- **説明文**：図の下部に1〜3行。長い計算式・経緯はパネルの中に書かず、ここに書く
- **色**：黒（筆界）、灰色（補助線・参考）、赤（求めた点・新しい筆界・誤りの指摘）、青・橙・緑・紫（区画の塗り分け。透明度0.2〜0.3）。1枚で使う塗りの色は4色まで
- **地積測量図の見本だけは、すべて黒で描き、塗りを入れない**

### 線と点

- **筆界**：黒の実線
- **補助線（高さ・延長線・X＝一定の線など）**：灰色の破線
- **分割線・新しい筆界・求めた線**：赤の実線（地積測量図の見本では黒）
- **町界**：一点鎖線
- **点の記号**：境界標の種類を問題文どおりに描き分ける。コンクリート杭＝白抜きの丸に中黒、金属標＝黒丸、基準点＝三角形（△）、石杭＝白抜きの四角に中黒（`tools/zu_helpers.py` の `point(p, 'stone')`。R1/Q21）。解説図の中では、求めた点を赤の黒丸にしてよい
- **平行の記号**：辺の中央に「＞」を同じ向きで描く。斜め（45°前後）の辺では、文字の「>」を回転させると字形が崩れて「⊥」のように見えるので、折れ線で描く（`tools/zu_helpers.py` の `parallel_chevron`。R2/Q21）

### 方位記号

- 真上（X軸の正の方向）を向いた矢印と、その上に「N」
- **区画の中や線の上に置かない**。右上→左上→右下→左下の順に空いている隅を探し、なければ余白を上から探す。他の文字より先に置き、以降の文字の重なり検査の対象に含める
- 2パネルの図では、パネルごとに1つずつ置く

### 細い帯・わずかな差の見せ方

- 幅1m程度の帯（全体図で幅30px以下）の区画名・面積・辺長は、帯の中に置かず、吹き出しで帯の外へ出す
- 丸めの差（0.01mなど）や、少しだけずれた2点（筆界点と、そこから0.15〜0.50mずれた塀の角の境界標など）は、全体図では見分けられない。0.1m〜数m四方の拡大パネルを別に作り、拡大パネルでは丸める前の点を描いて、吹き出しに丸めた座標を書く（上の「図の必須セット」の「境界標の移設・わずかなずれ」と同じ考え方。R5/Q21：ACに沿って1.00m測った誤りの点とB点の差は0.007mで、約0.07m四方の拡大で初めて見える）
- 南北または東西に細長い範囲だけを描くと、パネルの上下（または左右）に大きな余白ができる（`fit(..., pad_aspect=True)` で範囲をパネルの縦横比に合わせて広げるため）。その余白を、座標の吹き出しや説明の文字の置き場にする

## 文字の配置ルール（座標値や辺の長さを図形に重ねない）

文字は、候補の位置を順に試して、下の「重なりの自動検査」に引っかからない最初の位置を採用する。**置く順番は、重要なものから**：方位記号 → 座標値の吹き出し → 辺長 → 点名 → 隣接地の地番・道路・町名 → 区画名・面積。

1. **辺長**
   - 辺の中点から、**図形の外側**（外向きの法線の方向）へ離して置く。辺と平行に回転させ、上下逆さまにしない（角度は −90°〜90° に直す）
   - 候補：辺の中点（割合0.5）→ 0.38 → 0.62 → 0.28 → 0.72 の位置 × 離す距離 9pt → 15pt → 22pt
   - 分割線（区画の内側の線）の辺長は、どちらか一方の区画の内側に置く
   - 1m前後の短い辺（R4/Q21の EA 1.22）は、辺の横に置くと両端の点名・隣接地との境の線と必ずぶつかる。辺と平行に置くのをやめ、辺の中点から斜め外側（30pt前後）に水平の文字で置く
   - 凹んだ区画（くの字・L字）では、区画の重心が辺の外側に来ることがある。重心を基準に「外側」を決めると、辺長が区画の内側に入ってしまう（H27/Q21の乙土地のL→K・N→M）。その辺だけは、区画の内側の点を個別に指定する（`tools/zu_helpers.py` の `edge_label` の `inside_ref`）
   - 単位（m）は付けない
2. **点名**
   - 図形の重心から点へ向かう方向（＝外角の二等分線に近い方向）を第一候補にし、±35°・±70°・±110°・180° の順に8方向を試す。離す距離は 13pt → 19pt → 26pt
3. **座標値**
   - 「K（199.98, 131.88）」のように、**点名と座標を1つの吹き出し（枠付き）にまとめ、引き出し線でその点と結ぶ**。座標付きの点には、別に点名を置かない（点名と吹き出しが必ずぶつかるため）
   - 吹き出しは、図形の外の余白へ出す。候補の方向（例：東・南東・北東）と距離（55pt → 75pt → 95pt → 120pt）を指定して試す
   - 吹き出しの箱は、引き出し線の反対側に寄せる（東へ出すなら箱の左端を線の先に合わせる）。箱の中心を線の先に置くと、箱が点や線にかぶって引き出し線が隠れる
4. **隣接地の地番・道路・町名**
   - 回転させず水平に書く。辺長よりも外側（離す距離 30〜45pt）に置く
   - 角で接するだけの地番（例：205・207）は、その角の斜め外側に置く
   - 町名は町界線の両側に、図形から十分離して置く
5. **区画名・面積**
   - 区画の重心に置く。区画が細長くて入らない場合は、吹き出しにして外へ出す
6. **パネルの外に出た文字は描画されないことがある**。matplotlib の `annotate` は、基準点がパネルの外にあると文字を描かない（`annotation_clip=False` を付ける）。基準点は必ずパネルの内側に置くか、図形の点を基準にして offset で外へずらす

## 重なりの自動検査（描画後に必ず行う）

全部の文字について、次の4つを機械的に調べ、1件でもあれば位置を直す。

- **文字どうし**：文字の範囲（周りに4pxの余白を足した長方形）どうしが重なっていないか
- **文字と線**：文字の範囲を、図形の線分（筆界・分割線・補助線・方位記号の矢印・**方向角や観測角の弧**）が横切っていないか。**回転した文字は、外接する長方形ではなく、回転した長方形そのもので判定する**（外接長方形だと斜めの辺長ラベルで誤検出が出る）
- **文字と点**：文字の範囲に、点の記号が入っていないか
- **はみ出し**：文字がパネルの外（タイトル・説明文・隣のパネルの領域）に出ていないか

実装上の注意

- 引き出し線付きの吹き出し（`annotate`）の範囲は、引き出し線まで含んで計算されてしまう。文字の部分だけの範囲（`matplotlib.text.Text.get_window_extent`）で判定する
- 「線に触れているだけ」も重なりとみなす（余白4px）。線から数pxしか離れていない文字は、見た目では線に乗って見える
- 表示範囲は、パネルの縦横比に合わせて広げてから設定する（`tools/zu_helpers.py` の `fit(..., pad_aspect=True)`）。縦横の縮尺をそろえる `adjustable='datalim'` は、範囲を縮めて合わせることがあり、図形の端や基準点がパネルの外に切れる（R2/Q21の地積測量図の見本で、B点と基準点1が切れた）
- 角度の弧（`Arc`）は線分ではないので、そのままでは検査の対象にならない。弧を細かい線分に分けて検査の対象に登録する（`tools/zu_helpers.py` の `angle_arc` は2026-09-29から自動で登録する。R6/Q21で、器械点の座標値の吹き出しが方向角の弧の上に置かれても検査で見つからなかった）
- 図を追加・分割して番号を振り直すときは、文字列の一括置換で新しく入れた図のタイトルまで置き換わることがある（R6/Q21で「図3」が「図4」になった）。書き出した後に、全図のタイトルの番号が1から順に並んでいるかを確かめる
- 線（隣接地の境の短い線なども含む）は、すべて文字より先に描く。文字を置いた後に描いた線は、配置のときの重なり判定に入らず、最後の検査で初めて見つかる（H29/Q21で、B点の点名がBから北へ延びる110番1・110番2の境の線に重なった）
- 太字（点名・タイトル）が細字で描かれたら、日本語フォントに太字がない（IPAゴシックだけの環境）。`fonts-noto-cjk` を入れて Noto Sans CJK JP で描き直す（H29/Q21）

## 数値の検算と丸めのルール

- 座標：小数第3位を四捨五入（問題文の注の指示を優先）。**丸めた座標で**以降の計算・作図をする
- 座標が大きな値（世界測地系の −5万台など。H30/Q21）でも、作図はそのままの座標でよい（matplotlibの倍精度で足りる）。吹き出しの座標には全角の「−」を付け、記事の書き方とそろえる
- 辺長：小数第3位を四捨五入（例：9.3646 → 9.36。四捨五入の境目の値は説明文で注意喚起する）
- 面積：座標法で計算する。**丸め方は数値の種類で使い分ける**
  - **地積（登記する面積）**：宅地は小数第2位未満を切り捨て、それ以外は1㎡未満を切り捨て（問題文の指示を優先）。四捨五入しない
  - **計算途中の三角形などの面積**：小数第4位を四捨五入して小数第3位まで
