# 画像作成プロンプト：平成30年度 第21問（土地）登記申請書 解答記入済み

これは共通テンプレート（`../../prompt_toukishinseisho-gazou_kihon-form.md`）の「基本フォーム」に、平成30年度 第21問（問3・第3欄）の解答を埋め込んだ、そのまま実行できる版です。

**基本フォームとの違い（試験の答案用紙に合わせた）**：平成30年度の答案用紙は、項目の順序が「登記の目的 → 添付書類 → 登録免許税 → 申請人 → 代理人 → 申請の日付と提出先 → 土地の表示」で、土地の表示の記入行は4行。地積の欄に「（略）」の印刷はない。

※画像生成AI（Midjourney、DALL·E など）は日本語の文字が崩れやすく、申請書のような文字中心の画像には向きません。このプロンプトは「HTMLで申請書を組み立て、PNG画像に書き出す」方式で作っています。Claude（ファイル作成とコード実行ができる環境）で使ってください。

※2026-09-29、このプロンプトどおりに生成済み：`zu/H30_dai21mon_toukishinseisho_kansei.png`（横1200px、縦長）と元のHTML。生成スクリプトは `zu/make_H30_dai21mon_shinseisho_gazou.py`（印刷文字は明朝体、記入はゴシック体。Noto CJKがなければIPAフォント）。

---

あなたは土地家屋調査士試験の教材デザイナーです。平成30年度土地家屋調査士試験 第21問 答案用紙の登記申請書（第3欄）を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1650px 程度（A4縦の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない
- 画像の最下部に小さく「平成30年度 土地家屋調査士試験 第21問 登記申請書 解答例」とキャプションを入れる

## フォーム（上から順に。この順序を必ず守る。試験の答案用紙の順序）

各項目は「左に項目名（印刷・黒）、右に横長の記入枠（四角い枠線）」の形です。項目名は枠の左上の高さにそろえます。

**① 表題**
- 中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**
- 項目名「登記の目的」（印刷）
- 記入枠（高さは1行分）に「土地一部地目変更・分筆登記」（記入・青）

**③ 添付書類**
- 項目名「添　付　書　類」（印刷）
- 記入枠（高さは3〜4行分の大きな枠）に「地積測量図　代理権限証書」（記入・青）。枠の上寄せで1行目に書く

**④ 登録免許税**
- 項目名「登録免許税」（印刷）
- 記入枠（高さは1行分）に「金2,000円」（記入・青）

**⑤ 申請人**
- 項目名「申　　請　　人」（印刷）
- 記入枠（高さは2行分）に「Ａ市Ｂ町三丁目13番１号　丙山次郎」（記入・青）

**⑥ 代理人（枠なしの1行）**
- 項目名「代　　理　　人」（印刷）
- 行の中央あたりに「（略）」（印刷・黒）

**⑦ 申請の日付と提出先（枠なしの1行）**
- 「平成30年10月19日　申請　Ａ地方法務局」（印刷・黒）

**⑧ 土地の表示の欄（大きな表）**

表全体を太めの外枠で囲みます。

1行目（所在の行）
- 左セル：「所　在」（印刷）
- 右セル：「Ａ市Ｂ町三丁目」（記入・青）

2行目以降の左端に、縦書きで「土　地　の　表　示」（印刷）と書いた細い列を置きます。この列は、見出し行から最終行までを縦に結合します。

見出し行（印刷）
- 「①地　　番」「②地　　目」「③地　積　（m²）」「登記原因及びその日付」の4列

記入行は4行（答案用紙どおり）。③地積の列は、4行とも縦の点線で整数部と小数部に分けます（「（略）」の印刷はない）。各行の内容は次のとおりです。

- **記入行1**
  - ①地番：「11番」（記入・青）
  - ②地目：「雑種地」（記入・青）
  - ③地積：「253｜」（記入・青）※整数部だけ。小数部は空欄
  - 登記原因及びその日付：空欄
- **記入行2**
  - ①地番：「（イ）11番１」（記入・青）
  - ②地目：空欄
  - ③地積：「244｜」（記入・青）※整数部だけ。小数部は空欄
  - 登記原因及びその日付：2行に分けて「平成30年10月１日一部地目変更」「①③11番１、11番２に分筆」（記入・青）
- **記入行3**
  - ①地番：「（ロ）11番２」（記入・青）
  - ②地目：「宅地」（記入・青）
  - ③地積：「9｜03」（記入・青）
  - 登記原因及びその日付：「11番から分筆」（記入・青）
- **記入行4**：すべて空欄

列幅の目安（表全体を100とした場合）

- 縦書き「土地の表示」の列：6
- ①地番：20（「（イ）11番１」が折り返さない幅）
- ②地目：12
- ③地積：20（整数部13、小数部7）
- 登記原因及びその日付：42

## 記入時の注意

- 地番・地積の数字の書き方は上記のとおり（「11番１」「11番２」のように、番のあとの数字は全角）
- 地積は、整数部を点線の左に右寄せ、小数部を点線の右に左寄せで書く（小数点は書かない）。記入行1・2は雑種地で1㎡未満を切り捨てるので、小数部は空欄
- 記入行2の地番は「（イ）11番１」と書く。支号のない本番の11番を分筆したので、元の土地の地番も11番１に変わる（原因に①を付ける理由）
- 記入内容は各枠・各セルの左寄せ（地目だけ中央寄せ）
- 押印・字数の記載は不要（注7）なので入れない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「表題 → 登記の目的 → 添付書類 → 登録免許税 → 申請人 → 代理人 → 申請日・法務局 → 土地の表示」（答案用紙どおり）になっているか
- 登記の目的が「土地一部地目変更・分筆登記」、登録免許税が「金2,000円」になっているか
- 記入行2の登記原因に「平成30年10月１日一部地目変更」と「①③11番１、11番２に分筆」の2つが入っているか（記入行1の登記原因は空欄）
- 記入行3の地目が「宅地」、地積が「9｜03」になっているか
- 記入行1・2の地積が「253」「244」（小数部なし）になっているか
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
