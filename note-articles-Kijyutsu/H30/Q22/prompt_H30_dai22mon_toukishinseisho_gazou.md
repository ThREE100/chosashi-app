# 画像作成プロンプト：平成30年度 第22問（建物）登記申請書 解答記入済み

これは共通テンプレート（`../../prompt_toukishinseisho-gazou_kihon-form_tatemono.md`）をもとに、本問が**所有権の登記がある2個の建物の合体による登記等（合体後の建物の表題登記及び合体前の建物の表題部の登記の抹消）、存続登記あり**であることに合わせて、次の点を共通テンプレートから変えた版です。欄の名前・順序・「（略）」の印刷は、予備校の再現ではなく平成30年度の試験の答案用紙（第22問答案用紙 第1欄（その1））に合わせています。

- 答案用紙は**横長**で、左半分が登記申請書、右半分に「1　合体前の建物の所有権登記の表示」「2　抵当権等の登記で合体後の建物につき存続すべきものの表示」の2つの表がある
- 項目の順序は「登記の目的 → 添付書類 → 申請人 → 代理人（略）→ 申請日・提出先 → 建物の表示」（代理人の行が申請日の行より上）
- 表示に関する登記のため**登録免許税の欄が存在しない**（共通テンプレートの⑦を省略する）
- 「建物の表示」欄の見出し行は「地番」「家屋番号」「①種類」「②構造」「③床面積　m²」「登記原因及びその日付」の6列。所在の行は1段だけ。記入行は4行（3行目まで記入し、4行目は空欄）
- 合体後の建物の家屋番号は空欄（登記官が付けるため、申請情報に書かない）

note記事「【土地家屋調査士受験生向け】平成30年度問題22（建物）〜増築じゃなく合体、同じ人を別人とみなす〜」第4章の末尾（トリ先生が「申請の期限も守れているわ」と言った直後）に挿入する、**完成形（正解）**の画像。

あなたは土地家屋調査士試験の教材デザイナーです。平成30年度土地家屋調査士試験 第22問 答案用紙の登記申請書（第1欄（その1））を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：横長。横2000px × 縦1400px 程度（A3横の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない
- 画像の最下部に小さく「平成30年度 土地家屋調査士試験 第22問 登記申請書 解答例」とキャプションを入れる

## フォーム（左半分：上から順に。この順序を必ず守る。登録免許税の項目はない）

**① 表題**：左半分の上部中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**：項目名「登記の目的」（印刷）＋記入枠（2行分）

**③ 添付書類**：項目名「添　付　書　類」（印刷）＋記入枠（3〜4行分）

**④ 申請人**：項目名「申　請　人」（印刷）＋記入枠（3行分）

**⑤ 代理人（枠なしの1行）**：「代　理　人」（印刷）、行の中央あたりに「（略）」（印刷・黒）

**⑥ 申請の日付と提出先（枠なしの1行）**：「平成30年10月19日　申請　Ｄ地方法務局Ｅ出張所」（印刷・黒）

**⑦ 建物の表示（大きな表。⑥の少し下）**

太めの外枠で囲んだ表。

- 左端に、縦書きで「建　物　の　表　示」（印刷）と書いた細い列を置く（所在の行から最終の記入行までを縦に結合）
- 所在の行：左セル「所　在」（印刷）／右セル（横いっぱい）に所在を記入（青）。1段だけ
- 見出し行（印刷）：「地　番」「家屋番号」「①種類」「②構造」「③床面積　m²」「登記原因及びその日付」の6列
- 記入行：4行（1〜3行目に記入し、4行目は空欄）

**③床面積の列**：すべての記入行で、縦の点線で整数部と小数部に分けたセルにする（小数点は書かない）。整数部は点線の左に右寄せ、小数部は点線の右に左寄せ。

## フォーム（右半分：上から順に）

**⑧ 「1　合体前の建物の所有権登記の表示」**（印刷の見出し）＋表

- 見出し行（印刷）：「家屋番号」「順位番号」「受付年月日及び受付番号」「登記名義人の氏名」の4列
- 記入行：2行

**⑨ 「2　抵当権等の登記で合体後の建物につき存続すべきものの表示」**（印刷の見出し）＋表

- 見出し行（印刷）：「家屋番号」「順位番号」「登記の目的」「受付年月日及び受付番号」「登記名義人の氏名」「目的となる権利」の6列
- 記入行：2行（1行目に記入し、2行目は空欄）

（答案用紙の右下にある「第1欄（その2）」のア〜エと「第2欄」は、この画像には入れない）

## 記入時の共通ルール

- 記入内容は各枠・各セルの左寄せ（種類・構造・表の中の短い語は中央寄せでよい）
- 空欄と指定された箇所には何も書かない
- 押印・字数の記載は不要なので入れない
- 記入データにない文言を、推測で補わない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 左半分の項目の順序が「表題 → 登記の目的 → 添付書類 → 申請人 → 代理人（略）→ 申請日・法務局 → 建物の表示」になっているか（登録免許税の項目がないことを確認する）
- 登記の目的が「合体後の建物の表題登記及び合体前の建物の表題部の登記の抹消」で、「建物合併登記」「建物表題部変更登記」になっていないか
- 添付書類が8点そろっているか（特に登記識別情報・印鑑証明書・承諾書）
- 申請人が（あ）持分10分の２と（い）10分の８の2行になっていて、持分が入れ替わっていないか
- 記入行3の地番が「302番地」「301番地」の順になっているか。家屋番号が空欄か
- 床面積が「57｜63」「78｜49」「190｜53」になっていて、四捨五入の「57｜64」「78｜50」「190｜54」になっていないか。小数点を書いていないか
- 登記原因及びその日付の頭に、②③などの欄番号を付けていないか（表題登記のため付けない）
- 右半分の2つの表で、登記名義人の氏名に（あ）（い）が付いているか。存続登記の目的となる権利が「甲山太郎（あ）持分」になっているか
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
