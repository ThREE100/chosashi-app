# 図の作成プロンプト：令和7年度 第22問（建物）解説用の図3枚

以下をそのまま貼り付けて使ってください。note記事「【土地家屋調査士受験生向け】令和7年度問題22（建物）〜「主」が消えても滅失登記じゃない〜」に入れる、計算過程を理解するための図を3枚作ります。

※画像生成AI（Midjourney、DALL·E など）では座標・辺長どおりの正確な図は描けません。このプロンプトは「座標値・辺長からプログラムで作図し、PNGに書き出す」方式です。Claude（ファイル作成とコード実行ができる環境）、またはChatGPT／Google AIのコード実行機能（Python・matplotlibを実行できるモード）で使ってください。単なる画像生成（プロンプトだけで絵を描かせる機能）には投げないこと。

- 図1：符号2（1階）の一部取壊し読み取り図（第2章用）

## 作り方

1. Python（matplotlib）で、座標値・辺長から作図する。手で位置を調整してはいけない
2. 各図をPNGで書き出す
3. 書き出したPNGを自分で開いて確認する（下の「確認項目」）
4. 問題があれば直して再出力し、最後に3枚のPNGと作図に使ったPythonファイルを渡す

## 全図に共通するルール

- **サイズ**：横1600px × 縦1200px 程度、背景は白
- **フォント**：日本語が表示できるもの（Noto Sans CJK JP など）。なければインストールする。□や豆腐文字が1つでも出たら、フォントを見直す
- 縦横の縮尺を必ず同じにする（matplotlib なら `ax.set_aspect('equal')`）。形がゆがむと図の意味がなくなる
- 座標軸・目盛り・グリッドは表示しない（図面らしく見せるため）
- 辺の長さの数値ラベルは、対応する辺のすぐそばに大きめのフォントで配置する（記事の数値と一字一句一致させる）
- 数値ラベル以外の文字（部屋名など）は入れない。シンプルな図面線＋寸法線＋強調色だけにする
- 強調したい面積は、半透明の色（赤系またはオレンジ系）で塗る。塗り分けた2つ以上の領域は、はっきり違う色にする
- 「本記事の数値と一字一句一致しているか」を作成後に必ず自分で確認する（下の確認項目）

## 図1：符号2（1階）の一部取壊し読み取り図

第2章、藍子が「符号2の1階の床面積は、138.50から張り出し部分の15.00を引いて……123.50平方メートル！」と答える直前に挿入する図。左右2枚を1枚の画像に並べる。

### 左：「【工事前】符号2 1階（138.50㎡）」

頂点を順に結んだ多角形（原点は図の左上、右方向をY、下方向をXとする。単位はメートル）

```
(Y, X) = (0, 0) → (19.00, 0) → (19.00, 6.50) → (5.00, 6.50) → (5.00, 9.50) → (0, 9.50) → (0, 0)
```

- 本体（Y：0〜19.00、X：0〜6.50。面積19.00×6.50＝123.50）を薄い青で塗る
- 左下の張り出し部分（Y：0〜5.00、X：6.50〜9.50。面積5.00×3.00＝15.00）を目立つ半透明の赤で塗り、赤い矢印と「この部分を取り壊す」というラベルを添える
- 数値ラベル：「19.00m」（上辺）、「6.50m」（本体の縦）、「5.00m」（張り出しの横）、「3.00m」（張り出しの縦）
- 図の下に小さく「工事前 1階：138.50㎡」と入れる

### 右：「【工事後】符号2 1階（123.50㎡）」

- 頂点を順に結んだ単純な長方形
  ```
  (Y, X) = (0, 0) → (19.00, 0) → (19.00, 6.50) → (0, 6.50) → (0, 0)
  ```
- 全体を薄い青で塗る（左の図の本体と同じ範囲であることが一目でわかるように）
- 張り出し部分があった場所には、点線の輪郭だけを薄いグレーで残し、「撤去済み」と小さく添える
- 数値ラベル：「19.00m」「6.50m」
- 図の下に小さく「工事後 1階：123.50㎡（2階と同じ）」と入れる

**中央**：左右を区別する縦の仕切り線を1本入れる。矢印で「取壊し」と示し、L字形から単純な長方形に変わったことが一目でわかるようにする。

## 図2：新築倉庫（符号5）1階の床面積求積図

第4章、藍子が「求積表を作ります！ 10.00×9.00＝90.0000、15.50×6.50＝100.7500、合計190.7500。1階の床面積は190.75平方メートルです！」と答えた直後に挿入する図。

### 形状（原点は図の左上＝北西の角、右方向をY（東）、下方向をX（南）とする。単位はメートル。寸法はすべて壁の中心線（壁心）で、柱芯寸法の両端に0.30ずつ足した値）

1階の外形は、北側が東西いっぱい（25.50m）に広がり、東側10.00mの部分だけが南へ2.50m深く張り出したL字形。

```
(Y, X) = (0, 0) → (25.50, 0) → (25.50, 9.00) → (15.50, 9.00) → (15.50, 6.50) → (0, 6.50) → (0, 0)
```

- 西側の長方形（Y：0〜15.50、X：0〜6.50。面積15.50×6.50）を1色（例：薄い青）で塗る
- 東側の長方形（Y：15.50〜25.50、X：0〜9.00。面積10.00×9.00）を別の色（例：半透明のオレンジ）で塗る
- 右上に方位マーク（真上を向いた矢印＋「N」）を小さく入れる

### 数値ラベル（記事の数値と一字一句一致させる）

- 上辺全体：「25.50m」
- 西側の長方形：横「15.50m」、縦「6.50m」
- 東側の長方形：横「10.00m」、縦「9.00m」
- 図の下に小さく「新築倉庫 1階 床面積：190.75㎡」と入れる

## 図3：新築倉庫（符号5）2階の床面積求積図

第4章、トリ先生が「190.75−34.00＝156.75」と検算してみせた直後に挿入する図。

### 形状（原点・軸の向きは図2と同じ）

2階の床（床面積に入る部分）の外形は、次の頂点を順に結んだ多角形。

```
(Y, X) = (0, 0) → (25.50, 0) → (25.50, 9.00) → (23.50, 9.00) → (23.50, 6.50) → (7.00, 6.50) → (7.00, 4.50) → (0, 4.50) → (0, 0)
```

これを次の3つの長方形に分けて塗り分ける。

- 長方形A（東端の廊下の列）：Y：23.50〜25.50、X：0〜9.00（横2.00m×縦9.00m、面積18.00）
- 長方形B（本体）：Y：7.00〜23.50、X：0〜6.50（横16.50m×縦6.50m、面積107.25）
- 長方形C（西端）：Y：0〜7.00、X：0〜4.50（横7.00m×縦4.50m、面積31.50）

床面積に入らない部分（2か所）

- 南西の吹き抜け：Y：0〜7.00、X：4.50〜6.50（横7.00m×縦2.00m、面積14.00）。北側と東側は腰高壁（その中心線が境界）
- 南東の吹き抜け＋階段：Y：15.50〜23.50、X：6.50〜9.00（横8.00m×縦2.50m、面積20.00）。階段は片面が格子手すりで階段室とはいえないため、吹き抜けと一体で床面積に入らない

### 塗り分け・強調

- 長方形A・B・Cを、それぞれ違う色（薄い青・薄い緑・薄いオレンジなど）で塗る
- 床面積に入らない2か所は、1階の外形の一部として点線の輪郭で描き、中を斜線（グレーのハッチング）で示す
- 南西の斜線部分に「吹き抜け（腰高壁で区切る）」、南東の斜線部分に「吹き抜け＋階段（格子手すり＝壁ではない）」と小さく添える

### 数値ラベル（記事の数値と一字一句一致させる）

- 長方形A：「2.00m」「9.00m」
- 長方形B：「16.50m」「6.50m」
- 長方形C：「7.00m」「4.50m」
- 南西の斜線部分：「7.00m」「2.00m」
- 南東の斜線部分：「8.00m」「2.50m」
- 図の下に小さく「新築倉庫 2階 床面積：156.75㎡（1階190.75㎡−吹き抜け等34.00㎡）」と入れる

## 確認項目（3枚共通）

PNGを渡す前に、次の点を自分で確認してください。

- 記事本文に書かれている数値（辺長・床面積）と、図中のラベルが一字一句一致しているか
- 図1の工事前・工事後の面積（138.50㎡／123.50㎡）が本文と一致しているか
- 図2の1階の分割（西側15.50×6.50＋東側10.00×9.00＝190.75㎡）が本文の求積表と矛盾していないか。東側が南へ2.50m深いL字形になっているか（向きが逆になっていないか）
- 図3の2階の分割（2.00×9.00＋16.50×6.50＋7.00×4.50＝156.75㎡）が本文の求積表と矛盾していないか。床面積に入らない2か所（南西7.00×2.00＝14.00㎡、南東8.00×2.50＝20.00㎡、計34.00㎡）が斜線で示されているか
- 日本語ラベルが正しく表示されているか（文字化けがないか）
