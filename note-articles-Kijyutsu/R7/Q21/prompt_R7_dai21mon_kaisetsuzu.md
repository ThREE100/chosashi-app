# 図の作成プロンプト：令和7年度 第21問（土地）解説用の図3枚

以下をそのまま貼り付けて使ってください。note記事「令和7年度 第21問を複素数で解く」に入れる、計算過程を理解するための図を3枚作ります。

※画像生成AI（Midjourney、DALL·E など）では座標どおりの正確な図は描けません。このプロンプトは「座標値からプログラムで作図し、PNGに書き出す」方式です。Claude（ファイル作成とコード実行ができる環境）で使ってください。

- 図2：問3 地積測量図（8月15日申請分）

## 作り方

1. Python（matplotlib）で、座標値から作図する。手で位置を調整してはいけない
2. 各図をPNGで書き出す
3. 書き出したPNGを自分で開いて確認する（下の「確認項目」）
4. 問題があれば直して再出力し、最後に3枚のPNGと作図に使ったPythonファイルを渡す

## 全図に共通するルール

### 座標の扱い（最重要）

- 測量の座標系では **X＝北（上）、Y＝東（右）** です。数学のグラフとは軸が逆なので注意する
- 作図では、**横軸にY座標、縦軸にX座標** をとる
- 縦横の縮尺を必ず同じにする（matplotlib なら `ax.set_aspect('equal')`）。形がゆがむと図の意味がなくなる
- 座標軸・目盛り・グリッドは表示しない（図面らしく見せるため）

### 方位マーク

- 各図の右上に方位マークを入れる
- 真上（X軸の正の方向）を向いた矢印と、その上に「N」の文字
- 矢印は図の大きさに対して目立ちすぎない大きさ（図の高さの1/8程度）

### 見た目

- **サイズ**：横1600px × 縦1200px 程度、背景は白
- **フォント**：日本語が表示できるもの（Noto Sans CJK JP など）。なければインストールする。□や豆腐文字が1つでも出たら、フォントを見直す
- **筆界線**：黒の実線
- **補助線（高さ・平行線の説明など）**：灰色の破線
- **分割線・新しい筆界**：赤の実線
- **点**：小さな黒丸。点名は点のすぐ外側に、線や他の文字と重ならないように置く
- **辺長の数値**：辺の中央付近、辺と平行に置き、辺の外側に少し離す。数値の単位（m）は付けない
- **面積の数値**：その区画の中央に「○○.○○㎡」
- 色分けは多くても4色まで。塗りは薄い色（透明度0.2〜0.3）
- 各図の上部に図のタイトル、下部に短い説明文（1〜2行）を入れる

### 数値の検算

描く前に、図に書き込む辺長と面積をすべて座標から計算し直し、下に示す値と一致することを確認してください。一致しない場合は作図を止めて報告すること。

- 辺長は小数第3位を四捨五入
- 面積は座標法で計算する。**丸め方は数値の種類で使い分ける**
  - **地積（登記する面積）**：10番1・10番2・四角形BCJI・四角形MLKDなど。宅地なので **小数第2位未満を切り捨て**（四捨五入しない）
  - **計算途中の三角形の面積**：△DCH・△DHK。**小数第4位を四捨五入して小数第3位まで** 表示する
- 参考：座標から計算した値（切り捨て・丸めの前）
  - 10番1（C→H→K→D）：280.59505 → 地積 280.59
  - 10番2（D→K→G→F→E）：280.59545 → 地積 280.59
  - △DCH：131.92535 → 131.925
  - △DHK：148.6697 → 148.670
  - 四角形BCJI：62.72 → 地積 62.72
  - 四角形MLKD：62.7208 → 地積 62.72

四捨五入で比べると 280.60 になりますが、それは誤りです。宅地の地積は切り捨てです。

## 図1：K点の求め方（面積2等分）

**タイトル**：図1　K点の求め方（乙土地を面積2等分）

**描く範囲**：乙土地（C・H・G・F・E・D）と、その周辺。甲土地は描かない

**描くもの**

- 乙土地の外周（黒の実線）
- 分割線DK（赤の実線）
- 三角形DCH を薄い青で塗り、中央に「△DCH 131.925㎡」
- 三角形DHK を薄いオレンジで塗り、中央に「△DHK 148.670㎡」
- 南側の区画DKGFE は塗らず、中央に「10番2 280.59㎡」
- 北側の10番1（CHKD）の面積は、区画の外側（Cの北側など、何とも重ならない位置）に2行で書く
  - 1行目：「10番1 ＝ △DCH ＋ △DHK ＝ 280.595㎡」
  - 2行目：「→ 地積 280.59㎡（宅地は小数第2位未満切捨て）」
- D点から直線HG（Y＝131.88）へ下ろした垂線を灰色の破線で描き、「高さ 17.47」と書く。垂線の足には直角の記号を付ける
- 辺HKに「17.02」と書き、その横に小さく「＝ 148.670 × 2 ÷ 17.47」と添える
- H・K・G が一直線上（Y＝131.88）にあることが分かるよう、HGの延長を灰色の破線で少し伸ばし「Y＝131.88」と書く
- 点名：C、H、K、G、F、E、D

**説明文**

「HGは真北方向の直線（Y＝131.88）。△DHK の高さは Y座標の差 17.47 なので、HK ＝ 148.670 × 2 ÷ 17.47 ＝ 17.02」

## 確認項目

PNGを渡す前に、3枚すべてについて次の点を自分で確認してください。

- 縦横の縮尺が同じか（直角に見えるはずの角が直角に見えるか。例：図2のEとFはX座標が同じなので、FEは真横の線になる）
- 北が上か（X座標が大きい点ほど上にあるか。CとBが一番上、EとFとAが一番下）
- 方位マークが入っているか
- 図に書いた辺長・面積が、座標から計算した値と一致しているか
- 点名・数値が線や他の文字と重なっていないか
- 日本語がすべて正しく表示されているか
