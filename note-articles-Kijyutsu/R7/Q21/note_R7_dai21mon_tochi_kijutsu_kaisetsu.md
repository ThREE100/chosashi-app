## 複素数の約束事と電卓の準備

### 座標の置き方

座標は **Z ＝ X ＋ Yi**（X＝北、Y＝東）で扱います。

この置き方だと、複素平面の反時計回りが、地図上の時計回り（方向角の向き）と一致します。つまり、時計回りで与えられた観測角を、そのまま「∠θ」で掛ければ回転できます。

### F-789SGのキー操作

- **複素数モード**：[MODE] [2]（画面に CPLX と表示）
- **角度単位**：Deg（初期設定のまま）
- **i（虚数単位）**：[i]（ENGキー）
- **∠**：[∠]
- **絶対値（距離）**：[Abs]
- **偏角（方向角）**：[Apps] [3]（arg）
- **共役複素数**：[Apps] [4]（Conjg）
- **度分秒の入力と変換**：[°′″]
- **記憶**：[SHIFT] [STO] [文字]
- **呼び出し**：[ALPHA] [文字]

※[∠]・[i]・[°′″] が SHIFT 側（黄色文字）に印字されている場合は、先に [SHIFT] を押してください。

### 変数の割り当て

問題の点名（A〜M）と電卓の変数名がぶつかるので、次のように決めておきます。

- **X**：T1（D点を出した後は K点に入れ替え）
- **Y**：T2
- **A**：G点
- **B**：H点
- **C**：C点
- **D**：D点
- **E**：E点
- **F**：F点

入力例（C点）はこうなります。

```
219.57 [+] 117.56 [i] [SHIFT] [STO] [C]
```

### 乙土地の面積

式（点名）

```
倍面積 ＝ C・Conjg(H) ＋ H・Conjg(G) ＋ G・Conjg(F)
　　　 ＋ F・Conjg(E) ＋ E・Conjg(D) ＋ D・Conjg(C)
```

電卓操作（B＝H、A＝G）

```
[ALPHA] [C] [Apps] [4] [ALPHA] [B] [)]
[+] [ALPHA] [B] [Apps] [4] [ALPHA] [A] [)]
[+] [ALPHA] [A] [Apps] [4] [ALPHA] [F] [)]
[+] [ALPHA] [F] [Apps] [4] [ALPHA] [E] [)]

[+] [ALPHA] [D] [Apps] [4] [ALPHA] [C] [)] [=]

表示：（実部）− 1122.381i

- **iの係数** を読みます。実部は使いません。
- 符号は回る向きで変わるので、絶対値をとって2で割ります。

**▶ 乙土地の実測面積 561.1905㎡**

面積2等分なので、1筆あたり 280.59525㎡ になります。

### K点（面積2等分）

ここがこの問題の最大のポイントです。

**H点とG点はY座標が同じ（131.88）** です。つまり直線HGは真北方向の直線です。これに気づけば、K点は比例計算だけで出せます。

北側の土地CHKDを、三角形2つに分けて考えます。

- 北側CHKD ＝ △DCH ＋ △DHK
- 必要な面積は 280.59525㎡

**① △DCHの面積を求める**

式（点名）

```
△DCHの倍面積 ＝ Conjg(C − D) × (H − D)
```

電卓操作（B＝H）

```
[Apps] [4] [ALPHA] [C] [−] [ALPHA] [D] [)] [×] [(] [ALPHA] [B] [−] [ALPHA] [D] [)] [=]
```

表示：328.1099 ＋ 263.8507i

iの係数 263.8507 を2で割って、△DCH ＝ 131.92535㎡ です。

**② △DHKに必要な面積を求める**

```
△DHK ＝ 乙土地 ÷ 2 − △DCH
　　　＝ 280.59525 − 131.92535 ＝ 148.6699㎡
```

**③ HKの長さを求める**

△DHKの底辺はHK、高さはD点から直線HGまでの距離です。HGは真北方向なので、高さはY座標の差でそのまま出ます。

式（点名）

```
高さ ＝ Hの Y座標 − Dの Y座標 ＝ 131.88 − 114.41 ＝ 17.47
HK ＝ △DHK × 2 ÷ 高さ
```

電卓操作

```
[(] 561.1905 [÷] 2 [−] 131.92535 [)] [×] 2 [÷] 17.47 [=]
```

表示：17.0200…

**④ K点を求めて記憶する**

式（点名）

```
K ＝ H ＋ (G − H) ÷ Abs(G − H) × HK
```

HからGは真南方向なので、(G − H) ÷ Abs(G − H) ＝ −1 です。したがって式は次のように簡単になります。

```
K ＝ H − 17.02
```

電卓操作（B＝H）

```
[ALPHA] [B] [−] 17.02 [=]
```

表示：199.98 ＋ 131.88i

T1はもう使わないので、変数Xを使い回してKを記憶します。

```
[SHIFT] [STO] [X]
```

**▶ K点（199.98, 131.88）**

**検算：10番1の面積**

式（点名）

```
倍面積 ＝ C・Conjg(H) ＋ H・Conjg(K) ＋ K・Conjg(D) ＋ D・Conjg(C)
```

電卓操作（B＝H、X＝K）

```
[ALPHA] [C] [Apps] [4] [ALPHA] [B] [)]
[+] [ALPHA] [B] [Apps] [4] [ALPHA] [X] [)]
[+] [ALPHA] [X] [Apps] [4] [ALPHA] [D] [)]
[+] [ALPHA] [D] [Apps] [4] [ALPHA] [C] [)] [=]

表示：（実部）− 561.1901i

561.1901 ÷ 2 ＝ 280.59505㎡。10番2も同様に 280.59545㎡ です。

宅地の地積は小数第2位未満を切り捨てるので、どちらも **280.59㎡** で一致します。

## 問4 J点とL点の座標

ここからは10月30日の申請に向けた計算です。花子と一郎が、面積の等しい土地を交換します。

- **花子→一郎**：甲土地のうち B・C・J・I で囲まれた部分
- **一郎→花子**：丙土地のうち M・L・K・D で囲まれた部分

### J点

**① I点を求める**

B点とA点はY座標が同じ（99.33）なので、直線BAは真南方向です。I点はBから南へ3.5mの点になります。

```
I ＝ B − 3.5 ＝（216.07, 99.33）
```

**② J点を求める**

直線BCはX座標が同じなので、真東方向です。BCと平行なIJ上の点は、すべて X＝216.07 になります。つまりJ点は「直線CD上で X＝216.07 の点」です。

CからDへ向かう比率は、X座標の差の比で出ます。

```
比率 ＝ (Cの X − Jの X) ÷ (Cの X − Dの X)
　　 ＝ (219.57 − 216.07) ÷ (219.57 − 201.71) ＝ 3.5 ÷ 17.86
```

式（点名）

```
J ＝ C ＋ (D − C) × 3.5 ÷ 17.86
```

電卓操作

```
[ALPHA] [C] [+] [(] [ALPHA] [D] [−] [ALPHA] [C] [)] [×] 3.5 [÷] 17.86 [=]
```

表示：216.07 ＋ 116.9426…i

**▶ J点（216.07, 116.94）**

**③ 交換する面積を求める**

四角形BCJIは台形です。

```
BC ＝ 117.56 − 99.33 ＝ 18.23
IJ ＝ 116.94 − 99.33 ＝ 17.61
高さ BI ＝ 3.5
面積 ＝ (BC ＋ IJ) ÷ 2 × BI ＝ (18.23 ＋ 17.61) ÷ 2 × 3.5 ＝ 62.72
```

**▶ 交換する面積 62.72㎡**

### L点（平行線による等積分割）

面積62.72㎡の台形MLKDを作ります。ML∥DK です。

この問題で複素数の回転が必要なのはここだけです。DKが実軸に重なるように座標を回転させ、台形の高さを求めます。

以下、電卓の変数は B＝H、C＝C、D＝D、X＝K です。

**① DKの長さaを求める**

式（点名）

```
a ＝ Abs(K − D)
```

電卓操作（X＝K）

```
[Abs] [ALPHA] [X] [−] [ALPHA] [D] [)] [=]
```

表示：17.5554…

**② C点を回転した座標系で表す**

Dを原点に移し、DKの向きが実軸（真北）に重なるように回します。

式（点名）

```
C′ ＝ (C − D) × Conjg(K − D) ÷ Abs(K − D)
```

電卓操作（X＝K）

```
[(] [ALPHA] [C] [−] [ALPHA] [D] [)] [Apps] [4] [ALPHA] [X] [−] [ALPHA] [D] [)]
[÷] [Abs] [ALPHA] [X] [−] [ALPHA] [D] [)] [=]
```

表示：1.3746… − 18.0834…i

ここから、D点の内角のcotを出します。表示された値を、小数第6位まで打ち込んで割り算します。

```
cot(D) ＝ 1.374655… ÷ 18.083484… ＝ 0.076017
```

**③ K→Hの向きを回転した座標系で表す**

式（点名）

```
(K→H)′ ＝ (H − K) × Conjg(K − D) ÷ Abs(K − D)
```

電卓操作（B＝H、X＝K）

```
[(] [ALPHA] [B] [−] [ALPHA] [X] [)] [Apps] [4] [ALPHA] [X] [−] [ALPHA] [D] [)]
[÷] [Abs] [ALPHA] [X] [−] [ALPHA] [D] [)] [=]
```

表示：−1.6772… − 16.9371…i

```
cot(K) ＝ 1.677234… ÷ 16.937156… ＝ 0.099027
```

D・Kの内角はどちらも90°未満です。つまり、台形は上（北側）へ行くほど狭くなります。

**④ 台形の高さsを求める**

台形の高さをsとすると、面積は次の式で表せます。

```
面積 ＝ a × s − s² × (cot D ＋ cot K) ÷ 2 ＝ 62.72
```

数値を入れると、2次方程式になります。

```
0.087522 × s² − 17.5554 × s ＋ 62.72 ＝ 0
```

解の公式で小さい方の解をとります（0.175044 は cot D ＋ cot K）。

式

```
s ＝ ( a − √( a² − 2 × (cot D ＋ cot K) × 面積 ) ) ÷ (cot D ＋ cot K)
```

電卓操作

```
[(] 17.5554 [−] [√] [(] 17.5554 [x²] [−] 2 [×] 0.175044 [×] 62.72 [)] [)]
[÷] 0.175044 [=]
```

表示：3.6386…

以下の計算では、s を小数第4位に四捨五入した 3.6387 として打ち込みます（座標は小数第2位で答えるので、結果に影響はありません）。

ちなみに、√の部分の値（約16.918）は、上底MLの長さそのものです。

**⑤ L点を求める**

KからHへ向かって、「s ÷ （回転後のK→Hの縦成分 16.937156…）」の比率だけ進みます。打ち込むときは、小数第4位に四捨五入した 16.9372 を使います。

式（点名）

```
L ＝ K ＋ (H − K) × s ÷ 16.9372
```

電卓操作（B＝H、X＝K）

```
[ALPHA] [X] [+] [(] [ALPHA] [B] [−] [ALPHA] [X] [)] [×] 3.6387 [÷] 16.9372 [=]
```

表示：203.6364… ＋ 131.88i

**▶ L点（203.64, 131.88）**

参考までに、M点も同じ考え方で出せます。

式（点名）

```
M ＝ D ＋ (C − D) × s ÷ 18.0835
```

電卓操作

```
[ALPHA] [D] [+] [(] [ALPHA] [C] [−] [ALPHA] [D] [)] [×] 3.6387 [÷] 18.0835 [=]
```

表示：205.3037… ＋ 115.0438…i → M（205.30, 115.04）

**検算**

丸めた座標で台形MLKDを計算すると 62.7208㎡ になり、地積（小数第2位未満切捨て）は 62.72㎡ で一致します。

## まとめ：この問題で差がつくところ

- **座標軸に平行な辺を見抜く。** HG・BA・BC が軸に平行と気づけば、K点とJ点は比例計算だけで出せます。
- **回転が必要なのはL点だけ。** DKを実軸に重ねて、台形の高さを2次方程式で解きます。
- **丸めのルールを使い分ける。** 座標と距離は四捨五入、宅地の地積は切り捨てです。
- **時系列で申請内容を分ける。** 8月は地積更正＋分筆、10月は分筆のみ。住所変更の完了日にも注意します。
- **作図ではGFの桁に注意。** 9.3646は9.36です。

時間配分としては、問1・問2を最速で片付け、作図に十分な時間を残すのが理想です。
