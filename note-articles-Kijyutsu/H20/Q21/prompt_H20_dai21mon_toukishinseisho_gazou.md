これは共通テンプレート（`../../prompt_toukishinseisho-gazou_kihon-form.md`）の「基本フォーム」に、平成20年度 第21問の解答をあらかじめ埋め込んだ、そのまま実行できる版です。note記事「【土地家屋調査士受験生向け】平成20年度問題21（土地）〜買主が相続人3人に代位して分筆〜」の第8章に入れる完成形です。

**基本フォームとの違い（試験の答案用紙に合わせた）**：平成20年度の答案用紙は、項目の順序が「登記の目的 → 添付書類 → 申請の日付と提出先 → 申請人などを書く大きな枠 → 代理人 → 土地の表示 → 土地家屋調査士（職印）」で、大きな枠には項目名が印刷されていない（代位の申請のため、被代位者・申請人（代位者）・代位原因を書く大きな枠になっている）。登録免許税の欄はないので、大きな枠の最後の行に書く。土地の表示は、所在が2段、記入行が3行（その下に細い空行）。地積の欄に「（略）」の印刷はない。

このプロンプトどおりに組んだHTMLと書き出したPNGは `zu/H20_dai21mon_toukishinseisho_kansei.html`・`.png`、生成スクリプトは `zu/make_H20_dai21mon_shinseisho_gazou.py`（2026-09-30作成。印刷文字はIPA明朝、記入はNoto Sans CJK JP）。

あなたは土地家屋調査士試験の教材デザイナーです。平成20年度土地家屋調査士試験 第21問 答案用紙の登記申請書（問3）を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP、IPA明朝など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1700px 程度（A4縦の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「問3」という問の番号は画像に入れない
- 画像の最下部に小さく「平成20年度 土地家屋調査士試験 第21問 登記申請書 解答例」とキャプションを入れる

## フォーム（上から順に。この順序を必ず守る。試験の答案用紙の順序）

**① 表題**
- 中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**
- 項目名「登記の目的」（印刷）
- 記入枠（高さは1行分）に「土地分筆登記」（記入・青）

**③ 添付書類**
- 項目名「添　付　書　類」（印刷）
- 記入枠（高さは2行分）に「地積測量図　相続証明書　代位原因証書　代理権限証書」（記入・青。枠の上寄せ）

**④ 申請の日付と提出先（枠なしの1行）**
- 「平成20年８月24日　　申請　　Ｋ地方法務局」（印刷・黒）

**⑤ 大きな枠（項目名なし）**
- 左に項目名を置かず、申請書の幅いっぱいの大きな枠（高さは7行分）だけを描く（答案用紙に項目名の印刷はない）
- 枠の中に、次の7行を記入（記入・青）。住所・氏名の頭をそろえる
  - 1行目：「被代位者（被相続人　西川四郎）」
  - 2行目：「　　　　　　　　相続人　Ｃ市Ａ町二丁目５番２号　西川和子」
  - 3行目：「　　　　　　　　　　　　Ｂ市Ｄ町三丁目１番７号　西川二郎」（住所の頭を2行目の住所にそろえる）
  - 4行目：「　　　　　　　　　　　　Ｂ市Ｄ町四丁目６番１号　西川八郎」（同上）
  - 5行目：「申請人（代位者）　　　　Ｂ市Ｃ町二丁目３番４号　南野二郎」（同上）
  - 6行目：「代位原因　平成19年５月１日売買の所有権移転登記請求権」
  - 7行目：「登録免許税　金2,000円」

**⑥ 代理人（枠なしの2行）**
- 「代　　理　　人　　Ａ市Ｂ町一丁目２番３号　　東田太郎　㊞」（印刷・黒）
- 「（連絡先　＊＊－＊＊＊＊－＊＊＊＊）」（印刷・黒）

**⑦ 土地の表示の欄（大きな表）**

表全体を太めの外枠で囲みます。左端に、縦書きで「土　地　の　表　示」（印刷）と書いた細い列を置き、表の全部の行を縦に結合します。

- 所在の行（2段）：左セル「所　在」（印刷。2段を縦に結合）、右セルの上の段に「Ｋ市Ｂ町一丁目」（記入・青）、下の段は空欄
- 見出し行（印刷）：「①地　　番」「②地　　目」「③地　　積　m²」「登記原因及びその日付」の4列
- 記入行は3行。③地積の列は、縦の点線で整数部と小数部に分ける（「（略）」の印刷はない）。最後に細い空行を1行置く
  - **記入行1**：①「５番」、②「宅地」、③「512｜66」、登記原因及びその日付は空欄
  - **記入行2**：①「（イ）５番１」、②空欄、③「300｜79」、登記原因及びその日付「①③５番１、５番２に分筆」
  - **記入行3**：①「（ロ）５番２」、②「宅地」、③「212｜58」、登記原因及びその日付「５番から分筆」

列幅の目安（表全体を100とした場合）

- 縦書き「土地の表示」の列：6
- ①地番：24
- ②地目：13
- ③地積：23（整数部14、小数部9）
- 登記原因及びその日付：34

**⑧ 表の下の右寄せの1行**
- 「土地家屋調査士　東田太郎　職印」（印刷・黒。「職印」は四角で囲む）

## 記入時の注意

- 地番・地積の数字の書き方は上記のとおり（「５番１」のように、番の前後の数字は全角）
- 地積は、整数部を点線の左に右寄せ、小数部を点線の右に左寄せで書く（小数点は書かない）
- 記入内容は各枠・各セルの左寄せ（地目だけ中央寄せ）
- 押印・字数の記載は不要（問題文の注2）なので入れない
- 記入データにない文言を、推測で補わない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「表題 → 登記の目的 → 添付書類 → 申請日・法務局 → 大きな枠 → 代理人 → 土地の表示 → 土地家屋調査士（職印）」（答案用紙どおり）になっているか
- 添付書類に「地積測量図　相続証明書　代位原因証書　代理権限証書」の4つが入っているか
- 大きな枠に、被代位者（被相続人・相続人3人）・申請人（代位者）・代位原因・登録免許税の7行が入っているか（相続を放棄した西川七郎、欠格の西川六郎、再代襲しない西川九郎が入っていないか）
- 記入行2の登記原因に「①③５番１、５番２に分筆」、記入行3に「５番から分筆」が入っているか（記入行1の登記原因は空欄）
- 記入行1の地積が登記記録の「512｜66」になっているか（計算値の513.37ではない）
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
