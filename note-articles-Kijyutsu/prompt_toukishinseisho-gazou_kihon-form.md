# 画像作成プロンプト：土地家屋調査士試験 土地（記述式）登記申請書 解答記入済み【共通・基本フォーム】

以下をそのまま貼り付けて使ってください。問題ごとに変えるのは、末尾の「記入データ」の部分だけです。

新しい年度・問題を作るときは、このファイルをコピーして年度・問題のフォルダに置き、末尾の記入データを差し替えてください（このファイル自体は汎用のまま保つこと）。

※画像生成AI（Midjourney、DALL·E など）は日本語の文字が崩れやすく、申請書のような文字中心の画像には向きません。このプロンプトは「HTMLで申請書を組み立て、PNG画像に書き出す」方式で作っています。Claude（ファイル作成とコード実行ができる環境）で使ってください。

---

あなたは土地家屋調査士試験の教材デザイナーです。土地家屋調査士試験 土地（記述式）の登記申請書を、解答をすべて記入した状態で、画像（PNG）として作成してください。

様式は下の「基本フォーム」、記入する内容は末尾の「記入データ」に従います。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1650px 程度（A4縦の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない。ただし、申請書でない解答欄（座標・穴埋め・記述）の画像は、見出しを印刷どおり「第1欄」などの欄の名前だけにし、問の内容はキャプションに書く（R2/Q21の照らし直しで、見出しに問の内容が入っていたのを直した。2026-10-08）
- 画像の最下部に小さくキャプションを入れる（文言は記入データで指定）

## 基本フォーム（上から順に。この順序を必ず守る）

※項目の順序・項目名・「（略）」の印刷は、その年度の試験の答案用紙が優先する。答案用紙の順序が下と違う年度は、年度フォルダの記入済みプロンプトで順序を書き換える（R3/Q21：「登記の目的 → 添付書類 → 登録免許税 → 申請人の枠〈項目名の印刷なし〉 → 代理人 → 申請の日付と提出先 → 土地の表示」）。H28/Q21は「登記の目的 → 添付書類 → 登録免許税 → 申請の日付と提出先 → 申請人 → 代理人 → 土地の表示」で、土地の表示は6行、見出しは「①地番」「②地目」「③地積　m²」と印刷されていた（見出しの文言も答案用紙どおりにする）。

各項目は「左に項目名（印刷・黒）、右に横長の記入枠（四角い枠線）」の形です。項目名は枠の左上の高さにそろえます。

**① 表題**
- 中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**
- 項目名「登記の目的」（印刷）
- 記入枠（高さは1行分）

**③ 添付書類**
- 項目名「添　付　書　類」（印刷）
- 記入枠（高さは3〜4行分の大きな枠）。記入は枠の上寄せ。書類が多い場合は折り返してよい

**④ 申請の日付と提出先（枠なしの1行）**
- 「令和○年○月○日　申請　○地方法務局」（印刷・黒）

**⑤ 申請人**
- 項目名「申　　請　　人」（印刷）
- 記入枠（高さは1行分。申請人が複数いる場合は行数に合わせて広げる）

**⑥ 代理人（枠なしの1行）**
- 項目名「代　　理　　人」（印刷）
- 行の中央あたりに「（略）」（印刷・黒）

**⑦ 登録免許税**
- 項目名「登録免許税」（印刷）
- 記入枠（高さは1行分）。登録免許税がかからない登記の場合は、記入データの指示に従う

**⑧ 土地の表示の欄（大きな表）**

表全体を太めの外枠で囲みます。

1行目（所在の行）
- 左セル：「所　在」（印刷）
- 右セル：所在を記入（青）

2行目以降の左端に、縦書きで「土　地　の　表　示」（印刷）と書いた細い列を置きます。この列は、見出し行から最終行までを縦に結合します。

見出し行（印刷）
- 「①地　　番」「②地　　目」「③地　積　（m²）」「登記原因及びその日付」の4列

記入行は5行（標準）。記入データの行数が5行を超える場合は、行を追加する。

**③地積の列（基本形）**
- すべての記入行で、縦の点線で整数部と小数部に分けたセルにする
- 整数部は点線の左に右寄せ、小数部は点線の右に左寄せで書く（小数点は書かない）
- 宅地・鉱泉地以外で小数部がない地積（例：559㎡）は、整数部だけ書いて小数部は空欄にする

**列幅の目安**（表全体を100とした場合。年度の記入済みプロンプトでは、試験の答案用紙の画像〈`{年度}/Q21/touan_youshi/*_p1.png` など〉の縦の罫線の位置を測った比に置き換える。R2/Q21は縦書きの列6・地番18・地目15・地積25〈整数部15・小数部10〉・原因36で、下の目安のままだと地積の欄が狭く原因の欄が広すぎた。2026-10-08）

- 縦書き「土地の表示」の列：6
- ①地番：16
- ②地目：15
- ③地積：20（整数部13、小数部7）
- 登記原因及びその日付：43

「（イ）40番２」のように符号付きの地番が長い年度は、①地番の列を広げて地目の列を狭める（H28/Q21：地番20・地目11。広げないと地番が2行に折り返す）。PNGを目で見て、地番・見出しが折り返していないか確かめる。

## 特例：地積欄を「（略）」にする場合

記入データで「地積の略：あり」と指示された場合だけ、次のようにします。指示がなければ基本形のままです。

- 指示された行（例：記入行2〜5）の③地積の列を、縦に結合した1つのセルにする
- その結合セルの中央に「（略）」（印刷・黒）と入れる
- 指示されていない行（例：記入行1）の③地積は、基本形（点線で整数部と小数部に分けたセル）のまま

## 記入時の共通ルール

- 記入内容は各枠・各セルの左寄せ（地目だけ中央寄せ）
- 地番は「10番１」のように、番のあとの数字を全角で書く
- 分筆後の土地に付ける符号（（イ）（ロ）など）は、地番の前に書く
- 空欄と指定された箇所には何も書かない
- 押印・字数の記載は不要なので入れない
- 記入データにない文言を、推測で補わない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「表題 → 登記の目的 → 添付書類 → 申請日・法務局 → 申請人 → 代理人 → 登録免許税 → 土地の表示」になっているか
- 記入データのすべての項目が、指定の位置に青で記入されているか
- 地積が整数部と小数部に正しく分かれているか（小数点を書いていないか）
- 「（略）」の指示がある場合、指定の行だけが結合セルになっているか
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
- 枠（申請人・添付書類など）の高さを固定せず、中の文字に合わせて伸びるようにしているか（HTMLは `height` ではなく `min-height`）。H27/Q21の添削画像は枠の高さを固定していたため、フォントが Noto Serif CJK に変わったときに最後の行「代表取締役　山川一郎」が枠の下の罫線にかかった
- 地番の欄（「（イ）5番１」など）が2行に折れ返っていないか。記入のフォントを Noto Sans CJK JP にすると IPAゴシックより横に広く、列幅16%では折れ返った（R1/Q21。地番の列を19%に広げ、セルを折り返さない設定にした）

## 代位の申請の申請人欄（R3/Q21で追加）

相続人の1人がほかの相続人に代位して申請する年度は、申請人の欄（枠）に「（被相続人　氏名）」「被代位者　相続人　住所　氏名」（被代位者の人数分）「申請人兼代位者　住所　氏名」「代位原因　日付と原因」を書く。HTMLでは、見出し（被代位者・申請人兼代位者）・「相続人」・住所氏名の3列の表にして住所の頭をそろえ、被相続人の行は中央寄せ、代位原因の行は1行空けて左から書くと崩れない（見本は `R3/Q21/zu/make_R3_dai21mon_shinseisho_gazou.py`）。
