あなたは土地家屋調査士試験の教材デザイナーです。令和3年度土地家屋調査士試験 第22問 答案用紙の登記申請書（第1欄）を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：横長。横1800px × 縦1250px 程度（A3横の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第1欄」という欄の名前は画像に入れない
- 画像の最下部に小さく「令和3年度 土地家屋調査士試験 第22問 登記申請書 解答例」とキャプションを入れる

## フォーム

画像を左右2つの列に分ける。

### 左の列（上から順に。この順序を必ず守る）

**① 表題**：中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**：項目名「登記の目的」（印刷）＋記入枠（1行分）

**③ 添付書類**：項目名「添　付　書　類」（印刷）＋記入枠（2行分）

**④ 登録免許税**：項目名「登録免許税」（印刷）＋記入枠（1行分）

**⑤ 申請人**：項目名「申　請　人」（印刷）＋記入枠（2行分）

**⑥ 代理人（枠なしの1行）**：「代　理　人」（印刷）、行の中央あたりに「（略）」（印刷・黒）

**⑦ 申請の日付と提出先（枠なしの1行）**：「令和３年10月17日　申請　Ｅ地方法務局」（印刷・黒）

**⑧ 一棟の建物の表示（表）**

太めの外枠で囲んだ表。左端に縦書きで「一　棟　の　建　物　の　表　示」（印刷）の細い列を置く。

- 1行目：左セル「所　在」（印刷）／右セル（横いっぱい）に記入（青）
- 2行目：左セル「建物の名称」（印刷）／右セル：記入欄（本問は空欄）
- 見出し行（印刷）：「①構　造」「②床　面　積（m²）」（2つのセルに分かれ、それぞれ縦の点線で整数部と小数部に分ける）「原因及びその日付」
- 記入行：1行

**⑨ 敷地権の目的である土地の表示（表）**

⑧のすぐ下に続ける。左端に縦書きで「敷地権の目的である土地の表示」（印刷）の細い列を置く。

- 見出し行（印刷）：「①土地の符号」「②所在及び地番」「③地目」「④地　積（m²）」（縦の点線で整数部と小数部に分ける）「原因及びその日付」
- 記入行：2行（1行目に記入し、2行目は空欄）

### 右の列（上から順に）

**⑩ 区分した建物の表示欄（イ）（表）**

表の上に「区分した建物の表示欄（イ）」（印刷）。左端に縦書きで「区　分　し　た　建　物　の　表　示」（印刷）の細い列を置く。

- 見出し行（印刷）：「家屋番号」「建物の名称」「主である建物又は附属建物」「①種類」「②構　造」「③床　面　積（m²）」「原因及びその日付」
- 記入行：2行
- ③床面積の列は、縦の点線で整数部と小数部に分ける（小数点は書かない）

**⑪ 敷地権の表示（表）**

⑩の少し下に置く。左端に縦書きで「敷　地　権　の　表　示」（印刷）の細い列を置く。

- 見出し行（印刷）：「①土地の符号」「②敷地権の種類」「③敷地権の割合」「原因及びその日付」
- 記入行：2行（1行目に記入し、2行目は空欄）

## 記入時の共通ルール

- 記入内容は各枠・各セルの左寄せ（符号・種類・地目・割合は中央寄せ）
- 床面積・地積は整数部を点線の左に右寄せ、小数部を点線の右に左寄せ（小数点は書かない）
- 空欄と指定された箇所には何も書かない
- 押印・字数の記載は不要なので入れない
- 記入データにない文言を、推測で補わない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 左の列の項目の順序が「表題 → 登記の目的 → 添付書類 → 登録免許税 → 申請人 → 代理人 → 申請日・法務局 → 一棟の建物の表示 → 敷地権の目的である土地の表示」になっているか
- 登記の目的が「建物区分登記」で、「建物分割登記」「区分建物区分登記」になっていないか
- 添付書類が3点（建物図面・各階平面図・代理権限証書）で、規約証明書・所有権証明書が紛れ込んでいないか
- 登録免許税が「金2,000円」（1,000円ではない）か
- 申請人が「田宮栄一」（栄太ではない）で、住所が「５番１号」、所在が「５番地２」になっていて、取り違えていないか
- 一棟の建物の床面積が「173｜00」「176｜00」（壁心、登記記録どおり）で、区分した建物の表示の記入行2の床面積が「82｜74」「84｜24」（内法）になっているか。記入行2が「86｜50」「88｜00」になっていないか
- 記入行2の種類が「居宅」（共同住宅ではない）、構造が「鉄骨造スレートぶき２階建」（屋根の種類を省いていない）か
- 区分した建物の表示の原因（記入行1・2）に日付が付いていないか。敷地権の表示の原因にだけ「令和３年10月17日」が付いているか
- 床面積・地積が整数部と小数部に正しく分かれているか（小数点を書いていないか）
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
