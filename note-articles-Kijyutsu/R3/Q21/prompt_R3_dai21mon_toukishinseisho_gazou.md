**基本フォームとの違い（試験の答案用紙に合わせた）**：令和3年度の答案用紙（A3横。試験の答案用紙の実物〈`touan_youshi/R3_dai21mon_touan_youshi.pdf`〉で確かめた〈2026-10-02〉）は、1ページ目の左の列に第1欄・第2欄と第3欄の「登記申請書」の表題・登記の目的・添付書類・登録免許税、右の列に申請人の枠・代理人・申請の日付と提出先・所在と土地の表示が並ぶ。左の列の下に右の列を積むと、項目の順序が「登記の目的 → 添付書類 → 登録免許税 → 申請人の枠 → 代理人 → 申請の日付と提出先 → 土地の表示」で、申請人の枠には項目名が印刷されていない（代位の申請のため、被相続人・被代位者・申請人兼代位者・代位原因を書く大きな枠になっている）。地積の欄に「（略）」の印刷はなく、整数部と小数部は点線で分かれている。土地の表示の記入行は5行。添付の欄の名前は「添付書類」（「添付情報」ではない）、登録免許税の欄はある。

あなたは土地家屋調査士試験の教材デザイナーです。令和3年度土地家屋調査士試験 第21問 答案用紙の登記申請書（第3欄）を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1750px 程度（A4縦の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない
- 画像の最下部に小さく「令和3年度 土地家屋調査士試験 第21問 登記申請書 解答例」とキャプションを入れる

## フォーム（上から順に。この順序を必ず守る。試験の答案用紙の順序）

**④ 登録免許税**

- 枠の中に、次の5行を記入（記入・青）。見出しの語（「被代位者」「申請人兼代位者」「代位原因」）は枠の左寄り、住所・氏名はその右にそろえる
  - 1行目（中央寄り）：「（被相続人　山田太郎）」

## 記入時の注意

- 地番・地積の数字の書き方は上記のとおり（「10番１」「10番８」のように、番のあとの数字は全角）
- 地積は、整数部を点線の左に右寄せ、小数部を点線の右に左寄せで書く（小数点は書かない）
- 記入内容は各枠・各セルの左寄せ（地目だけ中央寄せ）
- 押印・字数の記載は不要（問題文の注7）なので入れない
- 表の下に、小さな字（グレー）で次の注を入れる（記事の本文の注と同じ内容。2026-10-02追加）：「※相続証明書は、今は法定相続情報一覧図の写しか法定相続情報番号の提供で代えることもできる（不動産登記規則第37条の3第1項）。出題当時は法定相続情報番号の制度がなかった」
- 記入データにない文言を、推測で補わない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「第3欄・表題 → 登記の目的 → 添付書類 → 登録免許税 → 申請人の枠 → 代理人 → 申請日・法務局 → 土地の表示」（答案用紙どおり）になっているか
- 添付書類に「地積測量図　相続証明書　代位原因証書　代理権限証書」の4つが入っているか
- 申請人の枠に、被相続人・被代位者（2名）・申請人兼代位者・代位原因の5行が入っているか
- 記入行2の登記原因に「③10番１、10番８、10番９に分筆」、記入行3・4に「10番１から分筆」が入っているか（記入行1の登記原因は空欄）
- 記入行1の地積が登記記録の「386｜30」になっているか（計算値の385.89ではない）
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
