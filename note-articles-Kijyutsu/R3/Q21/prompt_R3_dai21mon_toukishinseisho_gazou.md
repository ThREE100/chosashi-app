# 画像作成プロンプト：令和3年度 第21問（土地）登記申請書 解答記入済み

これは共通テンプレート（`../../prompt_toukishinseisho-gazou_kihon-form.md`）の「基本フォーム」に、令和3年度 第21問の解答をあらかじめ埋め込んだ、そのまま実行できる版です。

**基本フォームとの違い（試験の答案用紙に合わせた）**：令和3年度の答案用紙は、項目の順序が「登記の目的 → 添付書類 → 登録免許税 → 申請人の枠 → 代理人 → 申請の日付と提出先 → 土地の表示」で、申請人の枠には項目名が印刷されていない（代位の申請のため、被相続人・被代位者・申請人兼代位者・代位原因を書く大きな枠になっている）。地積の欄に「（略）」の印刷はない。

このプロンプトどおりに組んだHTMLと書き出したPNGは `zu/R3_dai21mon_toukishinseisho_kansei.html`・`.png`、生成スクリプトは `zu/make_R3_dai21mon_shinseisho_gazou.py`（2026-09-29作成。印刷文字はIPA明朝、記入はNoto Sans CJK JP）。

あなたは土地家屋調査士試験の教材デザイナーです。令和3年度土地家屋調査士試験 第21問 答案用紙の登記申請書（第3欄）を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1750px 程度（A4縦の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない
- 画像の最下部に小さく「令和3年度 土地家屋調査士試験 第21問 登記申請書 解答例」とキャプションを入れる

## フォーム（上から順に。この順序を必ず守る。試験の答案用紙の順序）

**① 表題**
- 中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**
- 項目名「登記の目的」（印刷）
- 記入枠（高さは1行分）に「土地分筆登記」（記入・青）

**③ 添付書類**
- 項目名「添　付　書　類」（印刷）
- 記入枠（高さは4行分の大きな枠）に、2行で記入（記入・青。枠の上寄せ）
  - 1行目：「地積測量図　相続証明書」
  - 2行目：「代位原因証書　代理権限証書」

**④ 登録免許税**
- 項目名「登録免許税」（印刷）
- 記入枠（高さは1行分）に「金3,000円」（記入・青）

**⑤ 申請人の枠（項目名なし）**
- 左に項目名を置かず、申請書の幅いっぱいの大きな枠（高さは6行分）だけを描く（答案用紙に項目名の印刷はない）
- 枠の中に、次の5行を記入（記入・青）。見出しの語（「被代位者」「申請人兼代位者」「代位原因」）は枠の左寄り、住所・氏名はその右にそろえる
  - 1行目（中央寄り）：「（被相続人　山田太郎）」
  - 2行目：「被代位者　　　相続人　Ｍ市Ｄ町五丁目２番２号　山田一郎」
  - 3行目：「　　　　　　　　　　　Ｓ市Ｄ町一丁目３番５号　山田三郎」（住所の頭を2行目の住所にそろえる）
  - 4行目：「申請人兼代位者　　　　Ｋ市Ｄ町二丁目10番１号　山田二郎」（住所の頭を2行目の住所にそろえる）
  - 5行目（1行空けて）：「代位原因　令和３年８月１日遺産分割の所有権移転登記請求権」

**⑥ 代理人（枠なしの1行）**
- 項目名「代　　理　　人」（印刷）
- 行の右寄りに「（略）」（印刷・黒）

**⑦ 申請の日付と提出先（枠なしの1行）**
- 「令和３年10月17日　申請　Ａ地方法務局」（印刷・黒）

**⑧ 土地の表示の欄（大きな表）**

表全体を太めの外枠で囲みます。

1行目（所在の行）
- 左セル：「所　在」（印刷）
- 右セル：「Ｋ市Ｄ町二丁目」（記入・青）

2行目以降の左端に、縦書きで「土　地　の　表　示」（印刷）と書いた細い列を置きます。この列は、見出し行から最終行までを縦に結合します。

見出し行（印刷）
- 「①地　　番」「②地　　目」「③地　積　（m²）」「登記原因及びその日付」の4列

記入行は5行。③地積の列は、5行すべてを縦の点線で整数部と小数部に分けたセルにする（「（略）」の印刷はない）。

  - ②地目：「宅地」（記入・青）
  - ③地積：「386｜30」（記入・青）
  - 登記原因及びその日付：空欄

  - 登記原因及びその日付：「③10番１、10番８、10番９に分筆」（記入・青。セルの中で2行に折り返してよい）
- **記入行3**

  - ②地目：「宅地」（記入・青）

  - ②地目：「宅地」（記入・青）

  - 登記原因及びその日付：「10番１から分筆」（記入・青）

列幅の目安（表全体を100とした場合）

- ①地番：16
- ②地目：15

## 記入時の注意

- 地番・地積の数字の書き方は上記のとおり（「10番１」「10番８」のように、番のあとの数字は全角）
- 地積は、整数部を点線の左に右寄せ、小数部を点線の右に左寄せで書く（小数点は書かない）
- 記入内容は各枠・各セルの左寄せ（地目だけ中央寄せ）
- 押印・字数の記載は不要（注7）なので入れない
- 記入データにない文言を、推測で補わない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「表題 → 登記の目的 → 添付書類 → 登録免許税 → 申請人の枠 → 代理人 → 申請日・法務局 → 土地の表示」（答案用紙どおり）になっているか
- 添付書類に「地積測量図　相続証明書　代位原因証書　代理権限証書」の4つが入っているか
- 申請人の枠に、被相続人・被代位者（2名）・申請人兼代位者・代位原因の5行が入っているか
- 記入行2の登記原因に「③10番１、10番８、10番９に分筆」、記入行3・4に「10番１から分筆」が入っているか（記入行1の登記原因は空欄）
- 記入行1の地積が登記記録の「386｜30」になっているか（計算値の385.89ではない）
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
