## 作り方

1. Python（matplotlib）で、座標値・辺長から作図する。手で位置を調整してはいけない
2. 各図をPNGで書き出す
3. 書き出したPNGを自分で開いて確認する（下の「確認項目」）
4. 問題があれば直して再出力し、最後に6枚のPNGと作図に使ったPythonファイルを渡す

## 全図に共通するルール

- **サイズ**：横1600px × 縦1200px 程度、背景は白
- **フォント**：日本語が表示できるもの（Noto Sans CJK JP など）。なければインストールする。□や豆腐文字が1つでも出たら、フォントを見直す
- 縦横の縮尺を必ず同じにする（matplotlib なら `ax.set_aspect('equal')`）。形がゆがむと図の意味がなくなる
- 座標軸・目盛り・グリッドは表示しない（図面らしく見せるため）
- 辺の長さの数値ラベルは、対応する辺のすぐそばに大きめのフォントで配置する（記事の数値と一字一句一致させる）
- 数値ラベル以外の文字は、各図で指定したものだけにする。シンプルな図面線＋寸法線＋強調色にする
- 強調したい面積は、半透明の色で塗る。塗り分けた2つ以上の領域は、はっきり違う色にする
- 「本記事の数値と一字一句一致しているか」を作成後に必ず自分で確認する（下の確認項目）

## 建物の座標の取り方（図1・図4・図5で共通）

- 図の上を北とする（問題の注3「北は、X軸の正方向に一致する」と、図1〔建物概略図〕の方位記号で確認済み。図1・図2〔各階平面見取図1〕とも上が北）

- 右（東）方向をY、下（南）方向をXとし、頂点は `(Y, X)` の順に書く。単位はメートル。寸法はすべて柱（壁）の中心線（問題文の注7。木造で柱の両面が被覆されているので、柱の中心＝壁の中心）

## 図3：建物図面の完成形（筆界からの距離）

第2章、トリ先生が「……方位を書けば完成よ」と言った直後に挿入する図。アガルートの解答例（第4欄 建物図面）と同じ記載事項にする。

### 作図内容

- 図2と同じA〜D（座標は図2参照）を結んだ敷地の外形を、座標どおりに描く（東側の辺BCだけ斜め）

- 車庫（符号2）の外形を実線で描く
  ```
  (Y, X) = (72.5, 69) → (77.5, 69) → (77.5, 65) → (72.5, 65) → (72.5, 69)
  ```

- 主である建物の外形の中に丸囲みの「主」、車庫の中に丸囲みの「附」と「2」を入れる

- 強調色は使わなくてよい

### 位置の決め方（作図の根拠。図には書かない）

- 主である建物の南の外壁：辺AB（X＝50）から3.0 → X＝53
- 主である建物の南東の角：X＝53の高さで辺BCはY＝78＋（53−50）×0.1＝78.3、そこから2.0西 → Y＝76.3

## 確認項目（6枚共通）

PNGを渡す前に、次の点を自分で確認してください。

- 記事本文に書かれている数値（辺長・距離・床面積）と、図中のラベルが一字一句一致しているか
- 図1で、工事前・工事後とも「家屋番号5番3」の1つの枠に収まっているか。増築部分が元の附属建物（西）と元の主である建物（東）の間にあり、車庫が北側にあるか

- 図4の分割（5.00×5.00＋4.00×4.00＋9.00×8.00＝113.00㎡）が本文の求積表と矛盾していないか。南側の外壁が一直線で、北側は増築部分だけが元の附属建物より1.00m南へ引っ込み、元の主である建物が一番北まで出ている形になっているか（東西・南北の向きが逆になっていないか）

- 図6で、誤りが5.10×4.10＝20.91、正解が5.00×4.00＝20.00になっているか。拡大図の「胴縁の中心から柱の外面まで0.05」が読み取れるか

- 日本語ラベルが正しく表示されているか（文字化けがないか）
