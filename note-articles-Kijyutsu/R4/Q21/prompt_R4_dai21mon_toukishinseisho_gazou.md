あなたは土地家屋調査士試験の教材デザイナーです。令和4年度土地家屋調査士試験 第21問 答案用紙の登記申請書（第3欄）を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1650px 程度（A4縦の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない
- 画像の最下部に小さく「令和4年度 土地家屋調査士試験 第21問 登記申請書 解答例」とキャプションを入れる

## フォーム（上から順に。この順序を必ず守る）

各項目は「左に項目名（印刷・黒）、右に横長の記入枠（四角い枠線）」の形です。項目名は枠の左上の高さにそろえます。

**① 表題**
- 中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**
- 項目名「登記の目的」（印刷）
- 記入枠（高さは1行分）に「土地一部地目変更・分筆登記」（記入・青）

**③ 添付書類**
- 項目名「添　付　書　類」（印刷）
- 記入枠（高さは3〜4行分の大きな枠）に「地積測量図　代理権限証書」（記入・青）。枠の上寄せで1行目に書く

**④ 申請の日付と提出先（枠なしの1行）**
- 「令和４年10月14日　申請　Ａ地方法務局」（印刷・黒）

**⑤ 申請人**
- 項目名「申　　請　　人」（印刷）
- 記入枠（高さは2行分）に「Ａ市Ｃ台206番地３　春野朝子」（記入・青）

**⑥ 代理人（枠なしの1行）**
- 項目名「代　　理　　人」（印刷）
- 行の中央あたりに「（略）」（印刷・黒）

**⑦ 登録免許税**
- 項目名「登録免許税」（印刷）
- 記入枠（高さは1行分）に「金3,000円」（記入・青）

**⑧ 土地の表示の欄（大きな表）**

表全体を太めの外枠で囲みます。

1行目（所在の行）
- 左セル：「所　在」（印刷）
- 右セル：「Ａ市Ｂ字八幡」（記入・青）

2行目以降の左端に、縦書きで「土　地　の　表　示」（印刷）と書いた細い列を置きます。この列は、見出し行から最終行までを縦に結合します。

見出し行（印刷）
- 「①地　　番」「②地　　目」「③地　　積　m²」「登記原因及びその日付」の4列（答案用紙の印刷どおり。単位はかっこなしの「m²」）

記入行は5行。③地積の列は、5行とも縦の点線で整数部と小数部に分けます（答案用紙どおり。「（略）」の印刷はない）。各行の内容は次のとおりです。

- **記入行1**
  - ①地番：「184番１」（記入・青）
  - ②地目：「宅地」（記入・青）
  - ③地積：「584｜75」（記入・青）
  - 登記原因及びその日付：空欄
- **記入行2**
  - ①地番：「（イ）」（記入・青）※地番は書かない
  - ②地目：空欄
  - ③地積：「212｜23」（記入・青）
  - 登記原因及びその日付：2行に分けて「令和４年10月５日一部地目変更」「③184番１、184番３、184番４に分筆」（記入・青）
- **記入行3**
  - ①地番：「（ロ）184番３」（記入・青）
  - ②地目：「雑種地」（記入・青）
  - ③地積：「357｜」（記入・青）※整数部だけ。小数部は空欄
  - 登記原因及びその日付：「184番１から分筆」（記入・青）
- **記入行4**
  - ①地番：「（ハ）184番４」（記入・青）
  - ②地目：「宅地」（記入・青）
  - ③地積：「15｜06」（記入・青）
  - 登記原因及びその日付：「184番１から分筆」（記入・青）
- **記入行5**：すべて空欄

列幅の目安（表全体を100とした場合）

- 縦書き「土地の表示」の列：6
- ①地番：19（「（ロ）184番３」が罫線に触れない幅）
- ②地目：12
- ③地積：19（整数部12、小数部7）
- 登記原因及びその日付：44

## 記入時の注意

- 地番・地積の数字の書き方は上記のとおり（「184番１」「184番３」のように、番のあとの数字は全角）
- 地積は、整数部を点線の左に右寄せ、小数部を点線の右に左寄せで書く（小数点は書かない）。記入行3の雑種地は1㎡未満を切り捨てるので、小数部は空欄
- 記入内容は各枠・各セルの左寄せ（地目だけ中央寄せ）。登記原因の欄は折り返してよい（はみ出さない）。縦書きの「土地の表示」は折り返さない
- 押印・字数の記載は不要（問題文の注8）なので入れない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「表題 → 登記の目的 → 添付書類 → 申請日・法務局 → 申請人 → 代理人 → 登録免許税 → 土地の表示」になっているか
- 登記の目的が「土地一部地目変更・分筆登記」、登録免許税が「金3,000円」になっているか
- 記入行2の登記原因に「令和４年10月５日一部地目変更」と「③184番１、184番３、184番４に分筆」の2つが入っているか（記入行1の登記原因は空欄）
- 記入行3の地目が「雑種地」、地積が「357」（小数部なし）になっているか
- 記入行3・4の登記原因が「184番１から分筆」になっているか
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
