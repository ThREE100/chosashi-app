あなたは土地家屋調査士試験の教材デザイナーです。土地家屋調査士試験 土地（記述式）の登記申請書を、解答をすべて記入した状態で、画像（PNG）として作成してください。

様式は下の「基本フォーム」、記入する内容は末尾の「記入データ」に従います。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1650px 程度（A4縦の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない
- 画像の最下部に小さくキャプションを入れる（文言は記入データで指定）

## 基本フォーム（上から順に。この順序を必ず守る）

※項目の順序・項目名・「（略）」の印刷は、その年度の試験の答案用紙が優先する。**平成26年度の答案用紙は「登記の目的 → 添付情報（略） → 申請の日付と提出先 → 申請人 → 代理人（略） → 登録免許税 → 土地の表示」の順なので、下の①〜⑧はこの順に書き換えてある。**項目名は答案用紙の印刷どおり「添付情報」（「添付書類」ではない）。

各項目は「左に項目名（印刷・黒）、右に横長の記入枠（四角い枠線）」の形です。項目名は枠の左上の高さにそろえます。

**① 表題**
- 中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**
- 項目名「登記の目的」（印刷）
- 記入枠（高さは1行分）

**③ 添付情報（枠なしの1行）**
- 項目名「添　付　情　報」（印刷）
- 行の中央あたりに「（略）」（印刷・黒。答案用紙に印刷済みなので何も記入しない）

**④ 申請の日付と提出先（枠なしの1行）**
- 「平成26年8月22日　申請　Ａ地方法務局」（印刷・黒。答案用紙に印刷済み）

**⑤ 申請人**
- 項目名「申　　請　　人」（印刷）
- 記入枠（高さは3行分。申請人3人を1行ずつ書く）

**⑥ 代理人（枠なしの1行）**
- 項目名「代　　理　　人」（印刷）
- 行の中央あたりに「（略）」（印刷・黒）

**⑦ 登録免許税**
- 項目名「登録免許税」（印刷）
- 記入枠（高さは1行分）

**⑧ 土地の表示の欄（大きな表）**

表全体を太めの外枠で囲みます。

1行目（所在の行）
- 左セル：「所　在」（印刷）
- 右セル：「Ａ市Ｂ町字Ｃ」（印刷・黒。答案用紙に印刷済み。その下に空いた1行）

2行目以降の左端に、縦書きで「土　地　の　表　示」（印刷）と書いた細い列を置きます。この列は、見出し行から最下欄までを縦に結合します。

見出し行（印刷）
- 「①地番」「②地目」「③地積」「登記原因及びその日付」の4列（平成26年度の答案用紙の印刷どおり）

記入行は5行（平成26年度の答案用紙どおり）。1行目の「100番1」「雑種地」「380」は答案用紙に印刷済み（黒）。その下に、4列を結合した横に長い最下欄が1行ある（地役権設定の範囲を書く欄）。

**③地積の列（基本形）**
- すべての記入行で、縦の点線で整数部と小数部に分けたセルにする
- 整数部は点線の左に右寄せ、小数部は点線の右に左寄せで書く（小数点は書かない）
- 雑種地の地積（1㎡未満切捨て）は、整数部だけ書いて小数部は空欄にする

**列幅の目安**（表全体を100とした場合）

- 縦書き「土地の表示」の列：6
- ①地番：20（「（イ）100番１」が折り返さない幅）
- ②地目：11
- ③地積：20（整数部13、小数部7）
- 登記原因及びその日付：43

## 記入時の共通ルール

- 記入内容は各枠・各セルの左寄せ（地目だけ中央寄せ）
- 地番は「100番１」のように、番のあとの数字を全角で書く
- 分筆後の土地に付ける符号（（イ）（ロ）など）は、地番の前に書く
- 空欄と指定された箇所には何も書かない
- 押印・字数の記載は不要なので入れない
- 記入データにない文言を、推測で補わない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「表題 → 登記の目的 → 添付情報（略） → 申請日・法務局 → 申請人 → 代理人（略） → 登録免許税 → 土地の表示」（平成26年度の答案用紙の順）になっているか
- 記入データのすべての項目が、指定の位置に青で記入されているか。印刷済みの「Ａ市Ｂ町字Ｃ」「100番１」「雑種地」「380」が黒になっているか
- 地積が整数部と小数部に正しく分かれているか（小数点を書いていないか）
- 最下欄に地役権設定の範囲が1行で書かれているか
- 土地の表示の表の下に、申請人についての注（今の法令と出題当時の扱い）が小さく入っているか
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
