# 画像作成プロンプト：平成24年度 第22問（建物）登記申請書 解答記入済み

これは共通テンプレート（`../../prompt_toukishinseisho-gazou_kihon-form_tatemono.md`）の考え方をもとに、本問が**一棟の建物の新築による区分建物表題登記（代位による申請・敷地権なし）**であることに合わせて、「建物の表示」欄を「一棟の建物の表示」「敷地権の目的である土地の表示（斜線が印刷済み）」「区分した建物の表示」の3つの表に分けた版です（R3/Q22の区分建物の4つの表から「敷地権の表示」がなくなった形）。共通テンプレートから次の点を変えています。

- 答案用紙は**横長（A3横）**で、左半分に登記申請書の上部・一棟の建物の表示・敷地権の目的である土地の表示、右半分に区分した建物の表示・第2欄が並ぶ。画像は横1200pxの縦長にそろえるため、**左の列の欄 → 右の列の欄の順に縦に積む**（欄の形・欄の名前・項目の順序は答案用紙どおり）。第1欄の画像とは別に、第2欄の完成形も1枚作る（下の「第2欄の画像」）
- 項目の順序は「登記の目的 → 添付書類 → 申請日・法務局（『平成何年何月何日申請　Ａ地方法務局』と印刷） → 所有者（被代位者） → 申請人（代位者） → 代位原因 → 代理人（略）」（答案用紙の印刷どおり。**登録免許税の欄はない**）
- 一棟の建物の表示の「所在」は2段、「建物の名称」は記入欄が2つのセル、「②床面積」は整数部｜小数部に分けたセルが左右に2つ並ぶ（本問は解答例どおり、左のセルに1階・2階の2行を書き、右のセルは空欄）
- 「敷地権の目的である土地の表示」は、答案用紙に**最初から対角線（斜線）が印刷されている**。記入はしない（斜線も印刷の黒で描く）
- 区分した建物の表示の見出し行は「家屋番号」「建物の名称」「主である建物又は附属建物」「①種類」「②構造」「③床面積（m²）」「原因及びその日付」の7列、記入行は3行（1行目だけ記入）

あなたは土地家屋調査士試験の教材デザイナーです。平成24年度土地家屋調査士試験 第22問 答案用紙の登記申請書（第1欄）を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px（縦は内容に合わせる。生成済みの画像は1200×2061px）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第1欄」という欄の名前は画像に入れない
- 画像の最下部に小さく「平成24年度 土地家屋調査士試験 第22問 問1 登記申請書（第1欄）解答例」とキャプションを入れる

## フォーム

答案用紙の左の列の欄を上から順に描き、その下に右の列の欄を続ける（1列に縦に積む）。

### 答案用紙の左の列（上から順に。この順序を必ず守る）

**① 表題**：中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**：項目名「登記の目的」（印刷）＋記入枠（1行分）

**③ 添付書類**：項目名「添　付　書　類」（印刷）＋記入枠（2行分）

**④ 申請の日付と提出先（枠なしの1行）**：「平成何年何月何日申請　Ａ地方法務局」（印刷・黒。答案用紙の印刷どおり、日付は「何年何月何日」のまま）

**⑤ 所有者（被代位者）**：項目名「所　有　者」「（被代位者）」の2行（印刷）＋記入枠（1行分）

**⑥ 申請人（代位者）**：項目名「申　請　人」「（代　位　者）」の2行（印刷）＋記入枠（1行分）

**⑦ 代位原因**：項目名「代　位　原　因」（印刷）＋記入枠（1行分）

**⑧ 代理人（枠なしの1行）**：「代　理　人」（印刷）、少し右に「（略）」（印刷・黒）

**⑨ 一棟の建物の表示（表）**

太めの外枠で囲んだ表。左端に縦書きで「一　棟　の　建　物　の　表　示」（印刷）の細い列を置く。

- 1〜2行目：左セル「所　在」（印刷。2行分を結合）／右セル（横いっぱい、2段）。1段目に記入（青）、2段目は空欄
- 3行目：左セル「建物の名称」（印刷）／記入欄が2つのセル（本問はどちらも空欄）
- 見出し行（印刷）：「①構　造」「②床　面　積（m²）」（左右2つのセルに分かれ、それぞれ縦の点線で整数部と小数部に分ける）「原因及びその日付」
- 記入行：1行

**⑩ 敷地権の目的である土地の表示（表）**

⑨のすぐ下に続ける。左端に縦書きで「敷地権の目的である土地の表示」（印刷）の細い列を置き、その右は区切りのない1つの大きな枠。**枠の左上の角から右下の角へ、対角線（斜線）を1本印刷する**（答案用紙どおり。記入はしない）

### 答案用紙の右の列（左の列の下に続けて）

**⑪ 区分した建物の表示（表）**

左端に縦書きで「区　分　し　た　建　物　の　表　示」（印刷）の細い列を置く。

- 見出し行（印刷）：「家屋番号」「建物の名称」「主である建物又は附属建物」「①種類」「②構　造」「③床　面　積（m²）」「原因及びその日付」
- 記入行：3行（1行目だけ記入し、2行目・3行目は空欄）
- ③床面積の列は、縦の点線で整数部と小数部に分ける（小数点は書かない）

## 記入データ

**登記の目的**：区分建物表題登記

**添付書類**：建物図面　各階平面図　所有権証明書　住所証明書　代位原因証書　代理権限証書（1行目に前の4つ、2行目に後の2つ）

**登録免許税**：欄なし（表題登記は課税されない。欄を描き足さない）

**一棟の建物の表示**

- 主である建物又は附属建物：空欄

## 第2欄の画像

第1欄とは別に、答案用紙の右下の第2欄（罫線入りの横長の枠）を、問3の説明文を記入した状態で1枚作る（横1200px。枠の上に「第2欄」と印刷、罫線は点線、記入は濃い青）。note記事の第5章、トリ先生が「敷地権がないから、敷地権の表示を書く欄もないの」と言った直後に挿入する。

記入する文（10行に分けて、1行ずつ罫線の間に書く）：

「敷地権とは、区分建物の敷地利用権（専有部分を所有するための建物の敷地に関する権利）のうち、登記されたものであって、区分所有法第22条第1項本文（同条第3項において準用する場合を含む。）の規定により、区分所有者の有する専有部分と分離して処分することができないものをいう。本件の一棟の建物の敷地は120番1と120番2の2筆で、120番1は乙川夏子が、120番2は甲野春男がそれぞれ単独で所有し、相手方の土地は無償で使用する合意があるにすぎない。敷地利用権は数人で有する権利ではなく、専有部分の全部を所有する者の権利でもないから、分離処分は禁止されない。また、無償で使用する権利（使用借権）は登記することができない。したがって、本件の敷地利用権は敷地権に当たらず、敷地権は登記されない。」

キャプション：「平成24年度 土地家屋調査士試験 第22問 問3（第2欄）解答例」

## 仕上がりの確認項目

- 項目の順序が「表題 → 登記の目的 → 添付書類 → 申請日・法務局 → 所有者（被代位者） → 申請人（代位者） → 代位原因 → 代理人（略） → 一棟の建物の表示 → 敷地権の目的である土地の表示 → 区分した建物の表示」になっているか
- 登録免許税の欄を描き足していないか
- 一棟の建物の所在が「120番地１、120番地２」の2筆になっているか（Ⓐがある120番地１だけにしていないか）
- 一棟の建物の床面積が壁心（142.50・120.00）、区分した建物の床面積が内法（68.57・57.69）になっているか
- 区分した建物の構造に屋根の種類（かわらぶき）が入っているか
- 敷地権の目的である土地の表示に斜線があり、何も記入していないか
- 床面積が整数部と小数部に正しく分かれているか（小数点を書いていないか）
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
