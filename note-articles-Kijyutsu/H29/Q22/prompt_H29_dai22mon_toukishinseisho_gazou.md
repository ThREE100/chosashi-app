## 作り方

1. HTMLとCSSで様式を組み立てる（第1欄用・第2欄用の2ファイル、または1ファイルで2枚に書き出す。外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様（2枚共通）

- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない
- 押印・字数の記載は不要なので入れない
- 記入データにない文言を、推測で補わない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 1枚目：①が「建物分割登記」（「建物区分登記」ではない）、②が印刷文字の続きとして「一個の建物」を2回使った文になっているか、③が「添付しなければならない。」か
- 2枚目：項目の順序が「表題 → 登記の目的 → 添付書類 → 申請日・法務局 → 申請人 → 代理人 → 建物の表示」になっているか（登録免許税の項目がないことを確認する）
- 添付書類が5点（建物図面・各階平面図・所有権証明書・登記事項証明書・代理権限証書）そろっているか。住所証明書・登記識別情報が紛れ込んでいないか
- 申請人が「Ａ市Ｃ町二丁目６番２号　社会福祉法人Ｃ福祉会　理事長　人権岩男」で、人権岩男さん個人の住所（Ａ市Ｂ町三丁目３番１号）やＢ町自治会になっていないか
- 所在が「Ａ市Ｂ町三丁目１番地１」だけで、「１番地２」が残っていないか
- 記入行2の原因が「①」で始まり、②③が付いていないか。記入行2の構造・床面積が空欄か
- 丙建物が「符号２」で、「符号１」になっていないか。構造が「発泡ポリスチレン造平家建」（屋根の種類なし）で、床面積が「60｜00」（55.20ではない）か
- 乙建物（倉庫・79.49）の行を書いていないか
- 床面積が整数部と小数部に正しく分かれているか（小数点を書いていないか）
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
