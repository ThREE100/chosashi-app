# 画像作成プロンプト：平成29年度 第21問（土地）登記申請書 解答記入済み

これは共通テンプレート（`../../prompt_toukishinseisho-gazou_kihon-form.md`）の「基本フォーム」に、平成29年度 第21問の解答をあらかじめ埋め込んだ、そのまま実行できる版です。項目の順序と土地の表示の行数は、平成29年度の試験の答案用紙（第3欄）に合わせてあります（登録免許税が添付書類のすぐ下、その次に申請の日付と提出先、申請人、代理人〈（略）の印刷〉。土地の表示は所在の欄が2段、記入行6行と、その下に区切りのない空欄が1段。欄の外の右下に「土地家屋調査士　法務　民子」の印刷）。

あなたは土地家屋調査士試験の教材デザイナーです。平成29年度土地家屋調査士試験 第21問 答案用紙の登記申請書（第3欄）を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP、IPA明朝・IPAゴシックなど）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1750px 程度（A4縦の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない
- 画像の最下部に小さく「平成29年度 土地家屋調査士試験 第21問 登記申請書 解答例」とキャプションを入れる

## フォーム（上から順に。この順序を必ず守る）

各項目は「左に項目名（印刷・黒）、右に横長の記入枠（四角い枠線）」の形です。項目名は枠の左上の高さにそろえます。

**① 表題**
- 中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**
- 項目名「登記の目的」（印刷）
- 記入枠（高さは1行分）に「土地地積更正・分筆登記」（記入・青）

**③ 添付書類**
- 項目名「添　付　書　類」（印刷）
- 記入枠（高さは2〜3行分）に「地積測量図　相続証明書　代理権限証書」（記入・青）。枠の上寄せ

**④ 登録免許税**
- 項目名「登録免許税」（印刷）
- 記入枠（高さは1行分）に「金2,000円」（記入・青）

**⑤ 申請の日付と提出先（枠なしの1行）**
- 「平成29年８月18日　申請　Ａ地方法務局」（印刷・黒）

**⑥ 申請人**
- 項目名「申　　請　　人」（印刷）
- 記入枠（高さは4行分の大きな枠）に、次の3行（記入・青）
  - 1行目：「（被相続人　甲野一郎）」
  - 2行目：「相続人　Ａ市Ｂ町100番地　甲野太郎」
  - 3行目：「　　　　Ａ市Ｄ町210番地　甲野次郎」（「相続人」の4文字分を空けて、住所の頭を2行目にそろえる）

**⑦ 代理人（枠なしの1行）**
- 項目名「代　　理　　人」（印刷）
- 行の中央あたりに「（略）」（印刷・黒）

**⑧ 土地の表示の欄（大きな表）**

表全体を太めの外枠で囲みます。

所在の行（2段）
- 左セル：「所　在」（印刷。2段を縦に結合）
- 右セルの上段：「Ａ市Ｂ町字Ｃ」（記入・青）。下段は空欄

所在の行の下から最後の段までの左端に、縦書きで「土　地　の　表　示」（印刷）と書いた細い列を置きます。この列は、所在の行から最後の段までを縦に結合します。

見出し行（印刷）
- 「①地　　番」「②地　目」「③地　積　（m²）」「登記原因及びその日付」の4列

記入行は6行。③地積の列は、すべての行で縦の点線により整数部と小数部に分けます。各行の内容は次のとおりです。

- **記入行1**
  - ①地番：「100番」
  - ②地目：「宅地」
  - ③地積：「297｜52」
  - 登記原因及びその日付：空欄
- **記入行2**
  - ①地番：「（イ）100番１」
  - ②地目：空欄
  - ③地積：「146｜62」
  - 登記原因及びその日付：1行目「③錯誤」、2行目「①③100番１、100番２に分筆」（セルの中で2行に書く）
- **記入行3**
  - ①地番：「（ロ）100番２」
  - ②地目：「宅地」
  - ③地積：「153｜22」
  - 登記原因及びその日付：「100番から分筆」
- **記入行4〜6**：すべて空欄

記入行6の下に、列の区切りのない空欄の段を1段置く（答案用紙どおり）。

**⑨ 欄の外（右下）**
- 「土地家屋調査士　法　務　民　子」（印刷・黒）

列幅の目安（表全体を100とした場合）

- 縦書き「土地の表示」の列：6
- ①地番：22
- ②地目：11
- ③地積：19（整数部12、小数部7）
- 登記原因及びその日付：42

## 記入時の注意

- 地番の数字の書き方は上記のとおり（「100番１」のように、番のあとの支号は全角）
- 地積は、整数部を点線の左に右寄せ、小数部を点線の右に左寄せで書く（小数点は書かない）
- 記入内容は各枠・各セルの左寄せ（地目だけ中央寄せ）
- 押印・字数の記載は不要（注9）なので入れない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「表題 → 登記の目的 → 添付書類 → 登録免許税 → 申請日・法務局 → 申請人 → 代理人 → 土地の表示」になっているか（平成29年度の答案用紙の順序）
- 申請の日付が「平成29年８月18日」になっているか（予備校の過去問集の再掲にある別の日付ではない）
- 申請人の欄が「（被相続人　甲野一郎）」と相続人2人の3行になっているか
- 記入行1の地積が「297｜52」（合筆前の100番の115.70でも、実測の299.83でもない）になっているか
- 記入行2の登記原因が「③錯誤」「①③100番１、100番２に分筆」の2行、記入行3が「100番から分筆」になっているか（記入行1の登記原因は空欄）
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 縦書きの「土地の表示」が折れ返っていないか
- 日本語がすべて正しく表示されているか
