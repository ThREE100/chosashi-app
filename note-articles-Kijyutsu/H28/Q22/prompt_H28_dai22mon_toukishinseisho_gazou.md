# 画像作成プロンプト：平成28年度 第22問（建物）登記申請書 解答記入済み

これは共通テンプレート（`../../prompt_toukishinseisho-gazou_kihon-form_tatemono.md`）をもとに、本問が**区分建物に関係しない、通常の非区分建物の表題部変更登記（渡り廊下でつながった新館の増築）**であることに合わせて「建物の表示」欄を単純な1段構成のまま使い、次の点を試験の答案用紙（平成28年度 午後の部 第二十二問答案用紙）の印刷どおりに変えた版です。

- 表示に関する登記（表題部変更登記）のため**登録免許税欄が存在しない**（共通テンプレートの⑦を省略する）
- 答案用紙には、申請の日付・提出先「平成28年8月10日　申請　Ａ　地方法務局　Ｂ　出張所」と、代理人の「（略）」が印刷済み。申請人は記入欄
- 建物の表示の表の一番上に「不動産番号」の行があり、右側に「記載省略」が印刷済み
- 所在の行は2段（上段は横いっぱい、下段は左の広いセルと右の狭いセルに分かれる）。本問は上段だけに記入する
- 家屋番号の行は、左に項目名、その右に狭い記入セル、残りは空きのセル
- 見出し行の1列目が「主たる建物又は附属建物」、最後の列が「登記原因及びその日付」（答案用紙の印刷どおり。「主である建物」「原因及びその日付」ではない）
- 記入行は4行（2行目まで記入し、3・4行目は空欄）。その下に横いっぱいの空欄の行が1行ある

あなたは土地家屋調査士試験の教材デザイナーです。平成28年度土地家屋調査士試験 第22問 答案用紙の登記申請書（第1欄）を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1650px 程度
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない
- 画像の最下部に小さく「平成28年度 土地家屋調査士試験 第22問 登記申請書 解答例」とキャプションを入れる

## フォーム（上から順に。この順序を必ず守る。登録免許税の項目はない）

**① 表題**：中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**：項目名「登記の目的」（印刷）＋記入枠（1行分）

**③ 添付書類**：項目名「添　付　書　類」（印刷）＋記入枠（2〜3行分）

**④ 申請の日付と提出先（枠なしの1行）**：「平成28年８月10日　申請　Ａ　地方法務局　Ｂ　出張所」（印刷・黒）

**⑤ 申請人**：項目名「申　請　人」（印刷）＋記入枠（3行分）

**⑥ 代理人（枠なしの1行）**：「代　理　人　（略）」（印刷・黒）

**⑦ 建物の表示（大きな表。⑥の少し下）**

太めの外枠で囲んだ表。

- 不動産番号の行：左セル「不動産番号」（印刷）／右セル（横いっぱい）の中央に「記載省略」（印刷・黒）
- 不動産番号の行の下から最終行までの左端に、縦書きで「建　物　の　表　示」（印刷）と書いた細い列を置く
- 所在の行（2段）：左セル「所在」（印刷。2段分を縦に結合）／上段は横いっぱいの記入セル、下段は左の広いセルと右の狭いセル。上段に所在を記入（青）、下段は空欄
- 家屋番号の行：左セル「家屋番号」（印刷）／その右の狭いセルに記入（青）／残りは空きのセル
- 見出し行（印刷）：「主たる建物又は附属建物」「①種類」「②構造」「③床面積　m²」「登記原因及びその日付」の5列
- 記入行：4行（1・2行目に記入し、3・4行目は空欄）
- 最終行：横いっぱいの空欄のセル1行

**③床面積の列**：すべての記入行で、縦の点線で整数部と小数部に分けたセルにする（小数点は書かない）。整数部は点線の左に右寄せ、小数部は点線の右に左寄せ。

## 記入時の共通ルール

- 記入内容は各枠・各セルの左寄せ（種類・構造だけ中央寄せ）
- 空欄と指定された箇所には何も書かない
- 押印・字数の記載は不要なので入れない
- 記入データにない文言を、推測で補わない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「表題 → 登記の目的 → 添付書類 → 申請日・法務局 → 申請人 → 代理人 → 建物の表示」になっているか（登録免許税の項目がないことを確認する）
- 登記の目的が「建物表題部変更登記」で、「区分建物表題登記」「建物表題登記」になっていないか
- 添付書類が4点（建物図面・各階平面図・所有権証明書・代理権限証書）そろっているか。住所証明書・登記識別情報が紛れ込んでいないか
- 申請人が「乙山和雄」（所有権の登記名義人）で、新館の費用を出した「丙山一郎」になっていないか。住所が「Ａ市Ｂ町二丁目５番10号」で、丙山らの住所（Ｄ市Ｅ町）になっていないか
- 記入行2の構造が「渡廊下付き３階建」で、「２階建」や「渡廊下付き」の抜けた「３階建」になっていないか
- 記入行2の床面積が1階・2階・3階の3行そろっていて、「1階　89｜10」が抜けていないか。2階が「118｜08」、3階が「46｜73」か
- 記入行2の原因が「②③」で始まり、日付が「平成28年７月21日」（申請日の８月10日ではない）か
- 記入行2の①種類が空欄か
- 床面積が整数部と小数部に正しく分かれているか（小数点を書いていないか）
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
