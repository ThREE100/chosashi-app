1. `R8_dai22mon_toukishinseisho_machigai_shinseinin.png`（申請人）
   - 誤答：A市B町四丁目6番3-701号　白石恵／A市C町三丁目5番1号　安田結
   - 添削：安田結を消す。「区分の登記を申請できるのは表題部所有者か所有権の登記名義人だけ（不動産登記法第54条第1項）。安田さんは売買契約をしただけで、まだ登記名義人ではない」
   - 正解：A市B町四丁目6番3-701号　白石恵
2. `R8_dai22mon_toukishinseisho_machigai_tenpu.png`（添付書類）
   - 誤答：建物図面　各階平面図　登記識別情報　印鑑証明書　規約証明書　代理権限証書
   - 添削：登記識別情報・印鑑証明書を消し、抵当権消滅承諾書を足す。「区分は表示に関する登記で、登記識別情報・印鑑証明書は要らない。Eタイプの1番抵当権を消すには、蓮の花銀行の承諾書が要る（法第54条第3項・第40条）」
   - 正解：建物図面　各階平面図　規約証明書　抵当権消滅承諾書　代理権限証書
3. `R8_dai22mon_toukishinseisho_machigai_menkyo.png`（登録免許税）
   - 誤答：不要
   - 添削：「所有権の登記がある建物の区分は課税。区分後の建物の個数×1,000円（登録免許税法別表第一の一（十三）イ）。701と702の2個で2,000円」
   - 正解：金2,000円
4. `R8_dai22mon_toukishinseisho_machigai_genin.png`（区分した建物の表示の原因）
   - 誤答：区分前の行「6番3の701、6番3の702に区分」、（イ）・（ロ）の行「6番3の701から区分」（令和3年度の非区分の建物の区分と同じ書き方）
   - 添削：区分前の行と（イ）の行の原因を消し、（イ）の行に「③6番3の702を区分」。「区分建物を区分すると、701の登記記録は残る（不動産登記規則第129条第3項・第4項）。残る（イ）の行は『③702を区分』、新しくできる（ロ）の行だけが『701から区分』」
   - 正解：区分前の行は空欄、（イ）「③6番3の702を区分」、（ロ）「6番3の701から区分」
5. `R8_dai22mon_toukishinseisho_machigai_shikichiken.png`（敷地権の表示の原因）
   - 誤答：（イ）・（ロ）とも「令和8年10月18日敷地権」
   - 添削：「701は割合が70分の5から70分の3に変わっただけ → ③（割合の欄）の変更。702の70分の2は、新築のときから701に付いていた敷地権を分けたもの → もともとの日付」
   - 正解：（イ）「③令和8年10月18日変更」、（ロ）「平成12年6月17日敷地権」
