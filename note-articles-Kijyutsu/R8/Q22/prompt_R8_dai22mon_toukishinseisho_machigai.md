# 登記申請書の添削画像プロンプト：令和8年度 第22問（建物）

①誤答 → ②赤ペンでの添削 → ③正解の3コマを縦に積んだ縦長（横1200px）。誤答の欄ごとに1枚。
`zu/make_R8_dai22mon_shinseisho_gazou.py` で書き出してある。欄の形は答案用紙の形式が未発表のため仮の形。

1. `R8_dai22mon_toukishinseisho_machigai_shinseinin.png`（申請人）
   - 誤答：A市B町四丁目6番3-701号　白石恵／A市C町三丁目5番1号　安田結
   - 添削：安田結を消す。「区分の登記を申請できるのは表題部所有者か所有権の登記名義人だけ（不動産登記法第54条第1項）。安田さんは売買契約をしただけで、まだ登記名義人ではない」
   - 正解：A市B町四丁目6番3-701号　白石恵
2. `R8_dai22mon_toukishinseisho_machigai_tenpu.png`（添付書類）
   - 誤答：建物図面　各階平面図　登記識別情報　印鑑証明書　規約証明書　代理権限証書
   - 添削：登記識別情報・印鑑証明書を消し、抵当権消滅承諾証明書を足す。「区分は表示に関する登記で、登記識別情報・印鑑証明書は要らない。Eタイプの1番抵当権を消すには、蓮の花銀行の承諾書が要る（法第54条第3項・第40条）」
   - 正解：建物図面　各階平面図　規約証明書　抵当権消滅承諾証明書　代理権限証書
3. `R8_dai22mon_toukishinseisho_machigai_menkyo.png`（登録免許税）
   - 誤答：不要
   - 添削：「所有権の登記がある建物の区分は課税。区分後の建物の個数×1,000円（登録免許税法別表第一の一（十三）イ）。701と702の2個で2,000円」
   - 正解：金2,000円
4. `R8_dai22mon_toukishinseisho_machigai_genin.png`（区分した建物の表示の原因）
   - 誤答：1行目「6番3の701、6番3の702に区分」、2行目・3行目「6番3の701から区分」（令和3年度の非区分の建物の区分と同じ書き方）
   - 添削：1行目と2行目の原因を消し、2行目に「③6番3の701、6番3の702に区分」。「区分建物を区分すると、701の登記記録は残る（不動産登記規則第129条第3項・第4項）。新しくできるのは702だけ。701は床面積が変わるので③を付けて『に区分』」
   - 正解：1行目は空欄、2行目「③6番3の701、6番3の702に区分」、3行目「6番3の701から区分」
5. `R8_dai22mon_toukishinseisho_machigai_shikichiken.png`（敷地権の表示の原因）
   - 誤答：701・702とも「令和8年10月18日敷地権」
   - 添削：「敷地権は区分で生まれたのではなく、新築のときから701に付いていた。702の70分の2も、その一部を分けたもの」
   - 正解：701・702とも「平成12年6月17日敷地権」
