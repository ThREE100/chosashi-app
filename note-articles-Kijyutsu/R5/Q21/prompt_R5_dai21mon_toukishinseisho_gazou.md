あなたは土地家屋調査士試験の教材デザイナーです。令和5年度土地家屋調査士試験 第21問 答案用紙（第4欄）の登記申請書を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1650px 程度（A4縦の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない
- 画像の最下部に小さく「令和5年度 土地家屋調査士試験 第21問 登記申請書 解答例」とキャプションを入れる

## フォーム（上から順に。この順序を必ず守る）

試験の答案用紙では、申請書の各欄（左）と土地の表示の表（右）が横に並んでいますが、この画像では縦に並べます（上が申請書の各欄、下が土地の表示の表）。

各項目は「左に項目名（印刷・黒）、右に横長の記入枠（四角い枠線）」の形です。項目名は枠の左上の高さにそろえます。

**① 表題**
- 中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**
- 項目名「登記の目的」（印刷）
- 記入枠（高さは2行分）に「土地地目変更・分合筆登記」（記入・青）

**③ 添付書類**
- 項目名「添　付　書　類」（印刷）
- 記入枠（高さは3行分の大きな枠）に「地積測量図　登記識別情報　印鑑証明書　代理権限証書」（記入・青）。枠の上寄せで1行目から書き、入りきらなければ2行目へ折り返す

**④ 申請の日付と提出先（枠なしの1行）**
- 「令和５年10月16日　申請　Ａ地方法務局」（印刷・黒）

**⑤ 申請人**
- 項目名「申　　請　　人」（印刷）
- 記入枠（高さは2行分）に「Ａ市Ｂ町二丁目２番地１　河野桂子」（記入・青）

**⑥ 代理人（枠なしの1行）**
- 項目名「代　　理　　人」（印刷）
- 行の中央あたりに「（略）」（印刷・黒）

**⑦ 登録免許税**
- 項目名「登録免許税」（印刷）
- 記入枠（高さは2行分）に「金2,000円」（記入・青）

**⑧ 土地の表示の欄（大きな表）**

表全体を太めの外枠で囲みます。

1行目（所在の行）
- 左セル：「所　在」（印刷）
- 右セル：「Ａ市Ｂ町二丁目」（記入・青）

2行目以降の左端に、縦書きで「土　地　の　表　示」（印刷）と書いた細い列を置きます。この列は、見出し行から最終行までを縦に結合します。

記入行は5行。③地積の列は、すべての行で縦の点線により整数部と小数部に分けます（試験の答案用紙に「（略）」の印刷はない）。

## 記入時の注意

- 地番の数字の書き方は上記のとおり（「１番４」のように、番の前後の数字は全角）
- 地積は、整数部を点線の左に右寄せ、小数部を点線の右に左寄せで書く（小数点は書かない）
- 記入内容は各枠・各セルの左寄せ（地目だけ中央寄せ）
- 押印・字数の記載は不要（問題文の注8）なので入れない
- 地番・見出し・登記原因が折り返していないか、PNGを目で見て確かめる（記入行3と記入行5の登記原因だけは2行にしてよい）

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「表題 → 登記の目的 → 添付書類 → 申請日・法務局 → 申請人 → 代理人 → 登録免許税 → 土地の表示」になっているか
- 登記の目的が「土地地目変更・分合筆登記」、添付書類に「印鑑証明書」が入っているか
- 記入行2の登記原因に「③１番１に一部合併」、記入行3に「１番４から分筆して１番１に合併する部分」、記入行5に「②③令和５年９月20日地目変更」「③１番４から一部合併」が入っているか（記入行1・記入行4の登記原因は空欄）
- 記入行5の地積が「357｜59」（357.09や357.70ではない）になっているか
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
