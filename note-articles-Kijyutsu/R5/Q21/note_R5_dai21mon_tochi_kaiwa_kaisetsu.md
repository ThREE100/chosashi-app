## 第2章：問1 筆界点は金属標のGとIじゃない

**トリ先生**  
「問1の前半は、地積測量図の定義よ。（ア）の土地の地積に関する（イ）の結果を明らかにする図面。藍子、埋めてごらんなさい」

**藍子**  
「不動産登記令第2条第3号ですね。（ア）は『一筆』、（イ）は『測量』です！」

**トリ先生**  
「正解。規則でも、地積測量図には筆界点間の距離を書くことになっている（不動産登記規則第77条第1項第6号）。だから後半は、備え付けの地積測量図の辺長と、今回の座標から出した距離を比べて筆界点を決める、という話になるの」

**藍子**  
「イ地点にはF点とG点、ロ地点にはI点とJ点が並んでいますね。G点とI点は金属標で、本件借地もA・C・G・Iで囲んだ範囲です。ブロック塀もIからGへ通っているので……（ウ）はG点、（エ）はI点！」

**トリ先生**  
「――待ちなさい。境界標は、A・D・E・Jがコンクリート杭、C・F・G・Iが金属標。F点だって金属標よ。境界標の種類でも、借地の範囲でも、塀の位置でも、筆界は決まらないわ。問題文が何と比べろと言っているか、読み直しなさい」

**藍子**  
「……『C点から（ウ）までの点間距離及びA点から（エ）までの点間距離』を、平成15年の地積測量図と比べるんでした」

**トリ先生**  
「そう。C・F・GはY座標が同じ、A・I・JもY座標が同じ。だから距離はX座標の引き算だけよ」

```
C→G ＝ 702.79 − 680.64 ＝ 22.15
C→F ＝ 702.79 − 680.14 ＝ 22.65
A→I ＝ 701.48 − 680.64 ＝ 20.84
A→J ＝ 701.48 − 680.49 ＝ 20.99
```

**藍子**  
「地積測量図のほうは、1番1の西の辺が11.64と11.01、1番2と1番3の西の辺が10.33と10.66です」

**トリ先生**  
「平成25年の合筆で、1番2と1番3の間の筆界は消えた。だから2本を足して比べるのよ」

```
11.64 ＋ 11.01 ＝ 22.65（C→F と一致。C→G の22.15とは0.50違う）
10.33 ＋ 10.66 ＝ 20.99（A→J と一致。A→I の20.84とは0.15違う）
```

**藍子**  
「FとJなら、ぴったりです……！」

**トリ先生**  
「念のため、南の辺も確かめておきなさい。地積測量図の1番3の南の辺は10.87。斜めの辺だから、ここは電卓よ」

式（点名）

```
FJ ＝ Abs(F − J)
```

電卓操作（A＝A点、C＝C点、F＝F点、X＝J点）

```
701.48 [+] 692.76 [i] [SHIFT] [STO] [A]
702.79 [+] 703.62 [i] [SHIFT] [STO] [C]
680.14 [+] 703.62 [i] [SHIFT] [STO] [F]
680.49 [+] 692.76 [i] [SHIFT] [STO] [X]
[Abs] [ALPHA] [F] [−] [ALPHA] [X] [)] [=]
```

表示：10.8656…

**藍子**  
「四捨五入して10.87。地積測量図と同じです。GとIを結ぶとX座標が同じ680.64なので、ちょうど10.86。こっちは合いません」

**トリ先生**  
「そういうこと。面積でも確かめておくわ。C・F・GもA・I・Jも真北向きの線の上だから、乙土地も甲土地も南北の2辺が平行な台形よ」

```
乙土地（A・C・F・J）＝ (20.99 ＋ 22.65) ÷ 2 × 10.86 ＝ 236.9652（登記記録 236.81 との差 0.1552）
G・Iを通した場合（A・C・G・I）＝ (20.84 ＋ 22.15) ÷ 2 × 10.86 ＝ 233.4357（差 3.3743）
甲土地（C・D・E・F）＝ (22.65 ＋ 24.82) ÷ 2 × 14.14 ＝ 335.6129（地積測量図の 335.5096500 との差 0.10）
```

**藍子**  
「F・Jなら乙土地は登記記録とほとんど同じ。G・Iだと3㎡以上も足りません。甲土地も、F点を角にした面積が平成15年の地積測量図とほぼ同じです」

**トリ先生**  
「乙土地の登記記録236.81㎡に対する甲2の公差は約1.37㎡（第4章で計算するわ）。0.16㎡は範囲内、3.37㎡は範囲外。GとIは、筆界点から少し北に入ったところにある、塀と借地の範囲の目印にすぎないの。答えを整理するわ」

- **ア**：一筆
- **イ**：測量
- **ウ**：F点
- **エ**：J点

> 【画像挿入】筆界点の判断の比較図（左：G・Iを結ぶと22.15・20.84で地積測量図と合わない、右：F・Jを結ぶと22.65・20.99で一致）

**藍子**  
「ということは、乙土地の筆界はA→C→F→J。本件借地のA・C・G・Iより、南に細長い部分がはみ出しているんですね」

## 第3章：問2 B点は「CGから西へ1.00m」の線の上

**トリ先生**  
「問2はB点とH点。条件は、BHがCGに平行で、その西側に1.00m離れた直線。BはAC上、HはGI上よ。藍子、B点はどう出す？」

**藍子**  
「任せてください！BはC点から1.00m西なので、C点からA点の方向へ1.00m進めばいいんです。C ＋ (A − C) ÷ Abs(A − C) × 1.00 で……（702.67, 702.63）です！」

**トリ先生**  
「――それはACに沿って1.00m測った点。問題文は『CGに平行で、その西側に1.00m離れた直線』よ。1.00mは、CGから直角に測った幅なの。ACは斜めだから、ACに沿って1.00m進んでも、CGからは0.99mしか離れないわ」

**藍子**  
「あっ……CGは真北向きの線だから、1.00m西の線はY座標が1.00小さい線。Y ＝ 703.62 − 1.00 ＝ 702.62 ですね」

**トリ先生**  
「そう。BはAC上でY座標が702.62になる点。AからCへ進むとY座標は 703.62 − 692.76 ＝ 10.86 増える。702.62にするには 702.62 − 692.76 ＝ 9.86 だけ増やせばいいから、9.86 ÷ 10.86 だけ進んだ点よ」

式（点名）

```
B ＝ A ＋ (C − A) × 9.86 ÷ 10.86
```

電卓操作（A＝A点、C＝C点）

```
[ALPHA] [A] [+] [(] [ALPHA] [C] [−] [ALPHA] [A] [)] [×] 9.86 [÷] 10.86 [=]
```

表示：702.6693… ＋ 702.62i

**トリ先生**  
「座標は問題文の注3で小数第3位を四捨五入。丸めた値を打ち直して記憶しておきなさい」

```
702.67 [+] 702.62 [i] [SHIFT] [STO] [B]
```

**▶ B点（702.67, 702.62）**

**藍子**  
「X座標は同じ702.67なのに、Y座標が702.62と702.63で0.01違うんですね。こわい……」

**トリ先生**  
「座標は0.01違っても不正解よ。それから、あとで地積測量図に書くBCは1.01になる。1.00じゃないのは、ACが斜めだからよ」

**藍子**  
「ほかの解き方もありますか？」

**トリ先生**  
「CGから西へ1.00mの線の上の点を1つ作って、ACとの交点を計算してもいいわ。CGは真北向きだから、その点は C − 1i ＝（702.79, 702.62）。この点を通る南北の線とACの交点を出せば、同じ（702.67, 702.62）になる。でも、線が南北なら、Y座標の差の比で進むほうがキーの数が少ないの」

> 【画像挿入】B点の求め方の図（CGから西へ1.00mのY＝702.62の線とACの交点がB、ACに沿って1.00m測った誤りの点はCGから0.99mしか離れない）

**トリ先生**  
「H点は？」

**藍子**  
「HはGとIを結ぶ直線の上です。GもIもX座標が680.64なので、GIは真東向きの線。BHの線はY＝702.62なので、交わる点は X＝680.64、Y＝702.62。計算は要りません！」

**▶ H点（680.64, 702.62）**

**トリ先生**
