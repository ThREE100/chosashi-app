# 図の作成プロンプト：令和5年度 第22問（建物）解説用の図4枚

以下をそのまま貼り付けて使ってください。note記事「令和5年度のわなを見抜け！〜区分合併と床面積の恐怖〜」に入れる、計算過程を理解するための図を4枚作ります。

※画像生成AI（Midjourney、DALL·E など）では座標・辺長どおりの正確な図は描けません。このプロンプトは「座標値・辺長からプログラムで作図し、PNGに書き出す」方式です。Claude（ファイル作成とコード実行ができる環境）、またはChatGPT／Google AIのコード実行機能（Python・matplotlibを実行できるモード）で使ってください。単なる画像生成（プロンプトだけで絵を描かせる機能）には投げないこと。

---

あなたは土地家屋調査士試験の教材デザイナーです。下の座標値・辺長に基づいて、note記事「令和5年度のわなを見抜け！」に挿入する解説用の図を4枚作成してください。

- 図1：本件土地（敷地）の辺長確認図（第2章用）
- 図2：1階の床面積求積図（第3章用）
- 図3：2階の床面積求積図（第3章用）
- 図4：藍子の誤り比較図「✕全体から引く／○分割して足す」（第3章用）

## 作り方

1. Python（matplotlib）で、座標値・辺長から作図する。手で位置を調整してはいけない
2. 各図をPNGで書き出す
3. 書き出したPNGを自分で開いて確認する（下の「確認項目」）
4. 問題があれば直して再出力し、最後に4枚のPNGと作図に使ったPythonファイルを渡す

## 全図に共通するルール

- **サイズ**：横1600px × 縦1200px 程度、背景は白
- **フォント**：日本語が表示できるもの（Noto Sans CJK JP など）。なければインストールする。□や豆腐文字が1つでも出たら、フォントを見直す
- 縦横の縮尺を必ず同じにする（matplotlib なら `ax.set_aspect('equal')`）。形がゆがむと図の意味がなくなる
- 座標軸・目盛り・グリッドは表示しない（図面らしく見せるため）
- 辺の長さの数値ラベルは、対応する辺のすぐそばに大きめのフォントで配置する（記事の数値と一字一句一致させる）
- 数値ラベル以外の文字（部屋名など）は入れない。シンプルな図面線＋寸法線＋強調色だけにする
- 強調したい面積は、半透明の色（赤系またはオレンジ系）で塗る。塗り分けた2つの領域は、はっきり違う色にする
- 「本記事の数値と一字一句一致しているか」を作成後に必ず自分で確認する（下の確認項目）

## 図1：本件土地（敷地）の辺長確認図

第2章「複素数計算で敷地の辺長を瞬殺するわよ」の直後（トリ先生が「これで建物図面の敷地枠はノーミスで描けるわ」と言った後）に挿入する図。

### 座標（〔座標値一覧表〕そのまま。X＝北、Y＝東）

- A（50.00, 75.00）
- B（68.00, 75.00）
- C（68.00, 89.50）
- D（52.00, 88.00）

### 作図内容

- 4点A・B・C・Dを結んだ四角形（本件土地の敷地形状）を描く。**横軸にY座標、縦軸にX座標**をとる（測量座標系はX＝北・Y＝東なので、数学のグラフとは軸の向きが逆であることに注意する）
- 各頂点に点名（A・B・C・D）をラベルする
- 各辺のそばに、記事の値どおりの辺長ラベルを置く
  - 辺AB：「18.0m」
  - 辺BC：「14.5m」
  - 辺CD：「16.1m」
  - 辺DA：「13.2m」
- 右上に方位マーク（真上を向いた矢印＋「N」の文字）を、図の大きさに対して目立ちすぎない大きさ（図の高さの1/8程度）で入れる
- 敷地の内側に「本件土地」という文字を小さく入れてもよい
- 強調色は使わなくてよい（辺長の確認だけが目的の図のため）

## 図2：1階の床面積求積図

第3章「■ 1階の床面積　西側の長方形と、東側の出っ張り（和室・LDK側）に分ける！」の直後、「＜1階 求積表＞」の直前に挿入する図。

### 形状（原点は図の左上、右方向をY、下方向をXとする。単位はメートル）

1階の外形は、次の頂点を順に結んだ多角形（L字形）。

```
(Y, X) = (0, 0) → (6.4, 0) → (6.4, 2.8) → (7.3, 2.8) → (7.3, 11.8) → (0, 11.8) → (0, 0)
```

- 上部（X：0〜2.8）は幅6.4m（東側0.9mぶんが欠けている＝西側だけの狭い部分）
- 下部（X：2.8〜11.8、高さ9.0m）は幅7.3m（欠けずに東側までフルに広がる部分）

### 塗り分け

- **西側の長方形**（Y：0〜6.4、X：0〜11.8。面積6.40×11.80）を1色（例：薄い青）で塗る
- **東側の出っ張り**（Y：6.4〜7.3、X：2.8〜11.8。面積0.90×9.00）を別の色（例：半透明の赤かオレンジ）で塗り、「和室・LDK側」と小さく添える

### 数値ラベル（記事の数値と一字一句一致させる）

- 西側の長方形：横「6.40m」、縦「11.80m」
- 東側の出っ張り：横「0.90m」、縦「9.00m」
- 図の下に小さく「1階 床面積：83.62㎡」と入れる

## 図3：2階の床面積求積図

第3章「■ 2階の床面積　西側の長方形と、東側のリビング拡張部分に分ける！」の直後、「＜2階 求積表＞」の直前に挿入する図（本文中の【※ここで画像生成AIで作成した図解（画像）を挿入】の指示に対応する）。

### 形状（原点・軸の向きは図2と同じ）

```
(Y, X) = (0, 0) → (7.3, 0) → (7.3, 12.7) → (4.6, 12.7) → (4.6, 11.8) → (0, 11.8) → (0, 0)
```

- 西側（Y：0〜4.6）は深さ11.8mまで
- 東側（Y：4.6〜7.3）は深さ12.7mまで（西側より0.9m深く飛び出している＝リビング拡張部分）

### 塗り分け

- **西側の長方形**（Y：0〜4.6、X：0〜11.8。面積4.60×11.80）を1色（例：薄い青）で塗る
- **東側の飛び出し部分**（Y：4.6〜7.3、X：0〜12.7 のうち、X：11.8〜12.7 の帯。リビング拡張部分）を目立つ半透明の赤で塗り、赤い矢印と「リビング拡張部分」のラベルを添える（元の画像プロンプトを踏襲する）

### 数値ラベル

- 西側の長方形：横「4.60m」、縦「11.80m」
- 東側の長方形：横「2.70m」、縦「12.70m」
- 図の下に小さく「2階 床面積：88.57㎡」と入れる

## 図4：藍子の誤り比較図「✕全体から引く／○分割して足す」

第3章、トリ先生が「全体から引く計算なんて図面を書く時にミスを誘発するだけよ！」と言った直後（【トリ先生直伝！正しい求積の分割法】の見出しの前）に挿入する図。2階を題材にする。

### 左右2枚を1枚の画像に並べる

**左：「✕ 藍子の考え方（誤り）」**

- 横7.30m×縦11.80mの長方形を実線で描く
- その南東（右下）の角から、横2.70m×縦4.50mの小さな長方形を「引く」ように、点線で欠けさせて描く（藍子が言った「バルコニー部分（2.70かける4.50）を引く」という誤った発想を表す）
- 欠けさせた部分の上に、大きな赤い「✕」を重ねて描く
- 図の下に赤字で「✕ 全体の枠が7.30×11.80だと思い込んでいる」と入れる

**右：「○ 正しい考え方」**

- 図3と同じ2階の正しいL字形（西側4.60×11.80＋東側2.70×12.70）を描く
- 東側の飛び出し部分（X：11.80〜12.70の帯）を目立つ緑またはオレンジで塗り、緑のチェックマーク「✓」を添える
- 「実際は11.80mより0.90m飛び出している」という趣旨の短い注記を入れる

**中央**：左右を区別する縦の仕切り線を1本入れる。左右で「同じ7.30m幅・同じ11.80mの高さ」を使っているのに結論が違う、という対比が一目でわかるようにする

## 確認項目（4枚共通）

PNGを渡す前に、次の点を自分で確認してください。

- 記事本文に書かれている数値（辺長・床面積）と、図中のラベルが一字一句一致しているか
- 図2・図3の形状が、それぞれ本文の求積表の分割（1階＝西側6.40×11.80＋東側0.90×9.00、2階＝西側4.60×11.80＋東側2.70×12.70）と矛盾していないか
- 図1の辺長（AB18.0／BC14.5／CD16.1／DA13.2）が、本文の値と一致しているか
- 図4で「✕」側と「○」側の見分けがつきやすいか（色・記号だけで判断できるか）
- 日本語ラベルが正しく表示されているか（文字化けがないか）
