# 画像作成プロンプト：令和5年度 第22問（建物）登記申請書 解答記入済み

これは共通テンプレート（`../../prompt_toukishinseisho-gazou_kihon-form_tatemono.md`）の考え方をもとに、本問が**区分建物の合併登記**であることに合わせて「建物の表示」欄を「一棟の建物の表示」と「区分した建物の表示」の2段に分けた、そのまま実行できる版です（区分建物が関わる問題ではこの2段構成になる。区分建物が最初から関係しない問題では共通テンプレートの単純な1段構成のままでよい）。

あなたは土地家屋調査士試験の教材デザイナーです。令和5年度土地家屋調査士試験 第22問 答案用紙の登記申請書を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1800px 程度
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 画像の最下部に小さく「令和5年度 土地家屋調査士試験 第22問 登記申請書 解答例」とキャプションを入れる

## フォーム（上から順に。この順序を必ず守る）

**① 表題**
- 中央に「登　記　申　請　書」（印刷。字間を空ける）

**② 登記の目的**
- 記入枠に「区分建物表題部変更・合併登記」（記入・青）

**③ 添付書類**
- 記入枠（3〜4行分）に「建物図面　各階平面図　登記識別情報　印鑑証明書」（1行目）、「所有権証明書　代理権限証書」（2行目）（記入・青）

**④ 申請の日付と提出先（枠なしの1行）**
- 「令和５年10月12日　申請　Ａ地方法務局」（印刷・黒）

**⑤ 申請人**
- 記入枠に「Ａ市Ｂ町一丁目３番地９　甲田栄一」（記入・青）

**⑥ 代理人（枠なしの1行）**
- 「代　　理　　人」（印刷）、行の中央あたりに「（略）」（印刷・黒）

**⑦ 登録免許税**
- 記入枠に「金1,000円」（記入・青）

**⑧ 一棟の建物の表示（表。①〜⑦の下に置く）**

太めの外枠で囲んだ表。左端に縦書きで「一　棟　の　建　物　の　表　示」と書いた細い列を置く（見出し行から最終行までを縦に結合）。

- 1行目：左セル「所　在」（印刷）／右セル「Ａ市Ｂ町一丁目３番地９」（記入・青）
- 2行目：左セル「建物の名称」（印刷）／右セル：空欄
- 見出し行（印刷）：「①構　造」「②床面積　m²」（2列に分ける：整数部｜小数部）「原因及びその日付」
- 記入行（1行のみ）：①構造「軽量鉄骨造陸屋根２階建」（記入・青）／②床面積「1階　83｜62」「2階　73｜99」（記入・青、それぞれ整数部と小数部を縦の点線で分ける）／原因及びその日付：空欄

**⑨ 区分した建物の表示（表。⑧のすぐ下に続けて置く。⑧と同じ外枠内でよい）**

左端に縦書きで「区　分　し　た　建　物　の　表　示」と書いた細い列を置く（3行分を縦に結合）。

見出し行（印刷）：「家屋番号」「建物の名称」「主である建物又は附属建物」「①種　類」「②構　造」「③床面積　m²」「原因及びその日付」

- **記入行1**（Ｂ町一丁目3番9の1）
  - 家屋番号：「Ｂ町一丁目３番９の１」（記入・青）
  - 建物の名称・主である建物又は附属建物：空欄
  - ①種類：「居宅」（記入・青）
  - ②構造：「軽量鉄骨造２階建」（記入・青）
  - ③床面積：「1階部分　4｜61」「2階部分　70｜21」（記入・青）
  - 原因及びその日付：空欄
- **記入行2**（合併後の非区分建物。この行だけ家屋番号欄の代わりに「所在（省略）」、建物の名称欄に「（省略）」と印刷）
  - 家屋番号の位置に「所在（省略）」（印刷・黒、点線の枠で囲む）
  - 建物の名称の位置に「（省略）」（印刷・黒）
  - ①種類：「居宅」（記入・青）
  - ②構造：「軽量鉄骨造スレートぶき２階建」（記入・青）
  - ③床面積：「1階　83｜62」「2階　88｜57」（記入・青）
  - 原因及びその日付：「②③令和５年10月６日構造変更、増築、３番９の２を合併」（記入・青）
- **記入行3**（Ｂ町一丁目3番9の2。合併により消滅する建物）
  - 家屋番号：「Ｂ町一丁目３番９の２」（記入・青）
  - 建物の名称・主である建物又は附属建物：空欄
  - ①種類：「居宅」（記入・青）
  - ②構造：「軽量鉄骨造１階建」（記入・青）
  - ③床面積：「1階部分　74｜72」（記入・青）
  - 原因及びその日付：「３番９の１に合併」（記入・青）

**⑩ 敷地権の目的である土地の表示／敷地権の表示（⑨のさらに下）**

どちらも列見出しだけ印刷し、値の欄はすべて空欄。原因及びその日付の欄にそれぞれ「記載不要」（記入・青）とだけ書く。

## 記入時の共通ルール

- 家屋番号・地番は「３番９の１」のように、番のあとの数字を全角で書く
- 床面積はすべて整数部と小数部を縦の点線で分けたセルにする（小数点は書かない）
- 記入内容は各枠・各セルの左寄せ（種類・構造だけ中央寄せ）
- 押印・字数の記載は不要なので入れない
- 記入データにない文言を、推測で補わない

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「表題 → 登記の目的 → 添付書類 → 申請日・法務局 → 申請人 → 代理人 → 登録免許税 → 一棟の建物の表示 → 区分した建物の表示 → 敷地権の目的である土地の表示 → 敷地権の表示」になっているか
- 記入行2（合併後の建物）の原因及びその日付に「構造変更、増築、３番９の２を合併」がすべて入っているか（「構造変更」の書き忘れが典型的な誤り）
- 記入行2の床面積が「1階83.62　2階88.57」になっているか（一棟の建物の表示の「1階83.62　2階73.99」＝合併前の値と混同していないか）
- 記入行2の家屋番号欄が「所在（省略）」になっており、家屋番号を書いていないか
- 敷地権関連の欄がすべて「記載不要」になっているか
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか

## 出力

- PNG画像（1枚）
- 画像の元になったHTMLファイル（後で修正できるように）
