# 依頼文：新しい年度の第21問（土地）会話形式記事を別チャットで作成するとき

新しい年度の第21問（土地）の会話形式note記事を、別のチャット（Claude Code のセッション）で作らせるときに貼り付ける依頼文です。第22問（建物）用の `irai-bun_tatemono_shinki-nendo.md` と同じ使い方です。

## 使い方

- 下のコードブロックの中身をそのままチャットに貼る
- 書き換えるのは冒頭の【対象年度】の1行だけ（年度と、フォルダ名）
- 問題PDF・答案用紙PDF・予備校の解答例PDFの3つを一緒に添付する
- フォルダ名は、令和は `R1`〜`R7`、平成は `H30` のように書く（第21問で使用済み：`H25`〈会話形式〉、`H26`〈会話形式〉、`H27`〈会話形式〉、`H28`〈会話形式〉、`H29`〈会話形式〉、`H30`〈会話形式〉、`R1`〈会話形式〉、`R2`〈会話形式〉、`R3`〈会話形式〉、`R4`〈会話形式〉、`R5`〈会話形式〉、`R6`〈プロース形式・会話形式〉、`R7`〈プロース形式・会話形式〉）
- 解説図・登記申請書の完成形・添削画像をリポジトリの中で実際に書き出させるので、Python（matplotlib・playwright）と Chromium が使える環境（Claude Code のセッション）で依頼する

## 保守のルール

- 執筆プロンプト（`prompt_note-kijutsu_tochi_kaiwa_kyoutsu.md`）、ダブルチェック指示書（`qa-checklist-kijutsu.md`）、解説図の基本フォーム（`prompt_kaisetsuzu-gazou_kihon-form_tochi.md`）に、依頼文にも関わる新しいルールが加わったら、この依頼文も合わせて更新する
- 参考例（年度ごとの問題の型）の一覧は、新しい年度の記事ができるたびに追記する

---

```
【対象年度】令和6年度（フォルダ名：R6）

GitHubリポジトリ ThREE100/chosashi-app の main ブランチで、上記年度の土地家屋調査士試験 第21問（土地）について、トリ先生と藍子の会話形式のnote解説記事と付属ファイル一式を作ってください。完成したら main に直接コミット・pushしてください。

■ 特に守ること
- 解答例を見る前に、まず自分で解く。迷ったこと・一度間違えたことをメモし、藍子の誤答とダブルチェック事項の候補にする
- タイトルは「【土地家屋調査士受験生向け】{年度}問題21（土地）〜見出し〜」の形にする。見出しは25文字以内。見出し画像の文字もタイトルと同じ文言にそろえる
- 計算は省略しない。座標・面積・長さの計算は「式（点名）・電卓操作（変数の対応）・表示」の3点セットをセリフの間に置く。変数の割り当ては第1章で示し、使い回すときはその場で言う
- 設問一覧表を作り、問1〜問Nのすべての答え（点ごと・空欄ごと・申請書の欄ごと）に会話の中で答える
- 藍子の誤答やトリ先生の「AじゃなくてB」の対比には、正解と対になる誤りを使う（例：時計回り⇔反時計回り、実測の面積⇔登記記録の地積、地域で決まる精度区分⇔土地の呼び名につられた精度区分、台形⇔平行四辺形）
- 座標は小数第3位を四捨五入し、丸めた座標で以降を計算する。地積は切り捨て（宅地は小数第2位未満、それ以外は1㎡未満）
- 筆界点を認定する年度は、求めた点で隣の土地の面積（または隣の土地の地積測量図の辺長・三斜の高さ）を計算し、登記記録・地積測量図との一致で裏付ける。「公差の範囲内」の杭をそのまま筆界点にしない。誤った筆界（関係者の説明、合意で置いた構造物など）で計算した面積が合わないことも数値で見せる
- 観測角の向きの注がない年度は、時計回りとして扱い、求めた点が調査図素図の位置に出るかで確かめる。後視点の観測角（読み）が0°00′00″でない年度は、求点の読みから後視の読みを引く
- 「ほぼ真北」「ほぼ真南」に見える線は、座標の差（E − H など）を表示させて軸に平行かを確かめてから使う（H30：H→E〈南向き〉は西へ0.70m傾いていて、真南に下ろすとI点がJ点とほぼ重なる）
- 売買・工事・利用の変化があるたびに、分ける土地の一部の地目が変わっていないか確かめる。変わっていれば一部地目変更を分筆と一の申請情報で申請し、日付は契約日ではなく利用が変わった日にする（H30：ブロック塀と増築で売った細い部分が宅地に）
- 座標が大きな値（世界測地系の −5万台など）の年度は、マイナスの座標を「0 [−] … [−] … [i]」と引き算で入れ、面積は1つの頂点を原点にずらした差、または全点から同じ丸い数を引いた座標で計算して表示を読みやすくする（H30）
- 申請書は時系列（申請日と完了日の前後）で申請人の住所・地番を確かめる
- 相続を証する情報の要否も時系列で決める。申請日より前に相続による所有権の登記が済んでいれば付けない（R7：10月の分筆）
- まとめの時間配分は一般論にしない。いちばん時間を食う計算と、それがなくても書ける欄を具体的に示し、本番で解く順番を言わせる（R7：L点のX座標は最後。問5の申請書は地積が「（略）」なのでL点がなくても書ける）
- 予備校の解説（解説文・動画の書き起こし）があれば、答えだけでなく解く順番・時間配分・別解も記事と見比べ、足りない観点を自分の言葉で足す（言い回しは流用しない）
- 依頼が「分筆だけ」に見えても、分筆後の地積の合計と登記記録の地積の差を、地域で決まる精度区分の公差と必ず比べる（R1/Q21は差1.31㎡・公差1.28㎡で、0.03㎡だけ超えて地積更正が要った）。日付付きの利用状況（家庭菜園など）があっても、すぐに一部地目変更にしない（柵や囲いのない庭の菜園は建物の敷地と一体の宅地）
- 登記申請書の画像の欄の順序は、その年度の試験の答案用紙どおりにする（R1/Q21・R3/Q21は登録免許税・申請人が申請の日付より前）
- 「表示：」の値や、丸める前の辺長を書くときは、小数第5位以下を切り捨てる（10.68535…は10.6853…。四捨五入の10.6854にしない）
- 水路・道路の「幅」や「〜m離れた直線」は、基準の線に直角に測った距離として扱う。角の内側の点を外側の点の真横にとらない。斜めの線を南北・東西に横切る長さは幅より長い（幅 ÷ sin）
- 申請書の申請人は、登記記録の下線（抹消の印）と付記登記（本店移転・住所変更）を確かめて、今の住所で書く。法人は代表者の氏名も書く
- 問題文に書かれた情報（申請人以外の相続人の住所など）を、申請書のどこかで使っているか確かめる。登記名義人の相続人の1人だけが申請する分筆は、ほかの相続人に代位する申請（申請人兼代位者・被代位者・代位原因）になる
- 藍子の誤答の点が「北に」「南に」ずれると書くときは、作図して座標で向きを確かめる
- 問題文の注と調査素図（調査図素図）の注は番号が別々にある。記事では「問題文の注3」「調査素図の注2」のように、どちらの注かを書き分ける
- 理由を文章で説明させる問（第2欄など）は、答案に書く文章を記事の中に箇条書きで示し、何をそろえれば採点者に伝わるかを会話で整理する
- 試験の問題文・法令に漢字で出てくる用語（杭、梁、桁、庇、鋲など）は、常用外でも問題文どおりの漢字で書く。問題文がひらがなの用語はひらがなのまま
- 解説図は画像生成AIに描かせず、座標からPythonで作図する。座標値・辺長を図形に重ねない。座標を求める点ごとに1枚（同じ器械点からの放射でも分ける）。座標を使わない法令の穴埋めの問は、条文の構造を並べた整理図を1枚作る。表示範囲は tools/zu_helpers.py の fit(..., pad_aspect=True) で決める（図形の端が切れないように）。問題文に座標がない点は、調査素図から読み取って確定値のように描かず、模式の位置に置いて「位置は模式」と書く
- 記号「✕」「✓」と実務の略語（「名変」など）は本文に使わない
- 条文を示すときは原典で確認したものだけにする。確認していない先例は書かない
- 穴埋めの語は、意味が合うかだけでなく、空欄の前後の言葉と文としてつながるかで選ぶ（H30：「所有者の（エ）によって」には、複数の当事者の間で成り立つ「合意」ではなく「意思」）
```
