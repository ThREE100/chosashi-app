あなたは土地家屋調査士試験の教材デザイナーです。令和2年度土地家屋調査士試験 第21問 答案用紙の登記申請書を、解答をすべて記入した状態で、画像（PNG）として作成してください。

## 作り方

1. HTMLとCSSで申請書の様式を組み立てる（1ファイル、外部ファイルなし）
2. ヘッドレスブラウザ（Playwrightなど）でPNGに書き出す
3. 書き出したPNGを自分で開いて確認し、文字化け・はみ出し・罫線のずれがないか点検する
4. 問題があれば直して再出力し、最後にPNGを渡す

日本語フォントはシステムにあるものを使う（Noto Sans CJK JP / Noto Serif CJK JP など）。なければインストールしてから作業する。□や豆腐文字が1つでも出たら、フォントを見直すこと。

## 画像の仕様

- **サイズ**：縦長。横1200px × 縦1750px 程度（A4縦の答案用紙に近い比率）
- **背景**：白
- **様式の罫線と印刷文字**：黒。印刷文字は明朝体
- **記入した解答**：濃い青（#1a3a8f 程度）。読みやすいゴシック体
- 様式（印刷部分）と解答（記入部分）が一目で区別できること
- 「第○欄」という欄の名前は画像に入れない
- 画像の最下部に小さく「令和2年度 土地家屋調査士試験 第21問 登記申請書 解答例」とキャプションを入れる

## フォーム（上から順に。この順序を必ず守る）

各項目は「左に項目名（印刷・黒）、右に横長の記入枠（四角い枠線）」の形です。項目名は枠の左上の高さにそろえます。

**② 登記の目的**

**③ 添付書類**

**④ 登録免許税**
- 項目名「登録免許税」（印刷）
- 記入枠（高さは1行分）に「金2,000円」（記入・青）

**⑤ 申請人**

## 記入時の注意

- 地番・地積の数字の書き方は上記のとおり（「32番５」「32番地４」のように、番・番地のあとの数字は全角）
- 地積は、整数部を点線の左に右寄せ、小数部を点線の右に左寄せで書く（小数点は書かない）
- 記入内容は各枠・各セルの左寄せ（地目だけ中央寄せ）
- 押印・字数の記載は不要（問2の注意）なので入れない
- 表の下に、小さな字（グレー）で次の注を入れる（記事の本文の注と同じ内容。2026-10-02追加）：「※相続証明書は、今は法定相続情報一覧図の写しか法定相続情報番号の提供で代えることもできる（不動産登記規則第37条の3第1項）。出題当時は法定相続情報番号の制度がなかった」

## 仕上がりの確認項目

PNGを渡す前に、次の点を自分で確認してください。

- 項目の順序が「表題 → 登記の目的 → 添付書類 → 登録免許税 → 申請人 → 代理人 → 申請日・法務局 → 土地の表示」になっているか（令和2年度の答案用紙の順序）
- 申請人の欄が「（被相続人　山川一郎）」と相続人2人の3行になっているか
- 記入行2の地積が「107｜73」（107.68ではない）、記入行5の地積が「156｜12」（156.53ではない）になっているか
- 記入行2の登記原因が「③32番４に一部合併」、記入行5が「③32番５から一部合併」、記入行3が「32番５から分割して32番４に合併する部分」になっているか（記入行1・4の登記原因は空欄）
- 印刷部分（黒）と記入部分（青）が正しく塗り分けられているか
- 日本語がすべて正しく表示されているか
