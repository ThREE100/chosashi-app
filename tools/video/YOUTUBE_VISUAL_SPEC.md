# YouTube 用の画面の基準と、図を動画用にする手順

2026-10-21 に、令和8年 第21問（`note-articles-Kijyutsu/R8/Q21/zu/`）の解説図21枚を分析して決めた。
note 用の図（4:3、文字14〜22px、1枚に情報を詰める）は、そのままでは動画で読めないため、動画用の画面と手順を分けた。

## 1. 動画のサイズ・形式（YouTube の公式の推奨）

| 項目 | 値 | 根拠・理由 |
|---|---|---|
| 縦横比 | **16:9** | YouTube の動画ヘルプ「Video resolution & aspect ratios」（パソコンの標準）。黒帯・余白を動画の中に焼き込まない（プレーヤーが自動で合わせるため） |
| 解像度 | **1920×1080**（フルHD）。高画質にしたいときは 3840×2160（4K） | 同上。4Kは書き出しが約4倍重いので、まず1080p |
| コマ数 | 30fps（静止画中心なので十分） | |
| 形式 | MP4（H.264 High + AAC-LC 48kHz）、色は BT.709 | 公式の推奨形式。色の指定がないと再生側で色がずれる |
| サムネイル | 16:9・1280×720・2MB以下（JPG） | `render.py` が `thumbnail.jpg` を書き出す |

文字の大きさの公式基準は見つからなかったので、次は私たちの基準（根拠: フルHDの動画を、スマホを横にして全画面（幅約800px）で見ると縮尺は約0.42倍。実寸36px の文字は約15px で読める下限）。

## 2. 画面の配置（1920×1080）

```
 y   0〜 64  ヘッダー（シリーズ名・章の名前）  文字28〜34px
 y  72〜882  図の枠 x240〜1680（1440×810 = 16:9）  白いカード
 y 890〜930  話者の名札
 y 912〜1060 字幕 x240〜1680  2行・44px
 左(x0〜250)  藍子   右(x1670〜1920)  トリ先生  （字幕の下端にそろえる。聞き手は薄く）
```
以前の配置（図の枠 1260×660、字幕3行・42px）より、図の枠は面積で約1.3倍、字幕は2行で大きくなった。

## 3. 文字の大きさの基準（実寸 px）

| 文字 | 下限 | 備考 |
|---|---|---|
| 字幕 | 44 | 1ページ56文字（2行）まで。1行に約31文字 |
| 図の中の注釈（callout） | 40（既定42） | 強調したい値・結論だけを入れる。1つ12〜20文字 |
| カードの見出し / 本文 | 38〜40 / 34 | |
| 縦の表（rows） | 36〜38 | |
| 図（画像）の中の文字 | **28（これ未満は不可）／32未満は注意** | `check_shots.py` が機械で確かめる |
| 何があっても使わない | 28未満 | |

## 4. R8 第21問の図の分析（21枚）

- 元の図は幅1600px。文字は 14〜22px。動画の図の枠（1260×660）に入れると縮尺0.35〜0.69倍 → **画面で5〜15px**（基準の3分の1以下）。
- 21枚のうち、座標を描いた図形（全体図・K点・L点・C点・地積測量図など）と、文字が主役の整理図（時系列・注の仕分け・書類の表など）に分かれる。

| 種類 | 枚数（R8/Q21） | 動画での扱い |
|---|---|---|
| 座標図形の図 | zu02, 06, 07, 10, 12, 13, 16〜20 | **高解像度（2倍）・大きな文字で描き直し**、場面ごとにズーム |
| 文字が主役の整理図 | zu01, 03, 04, 05, 08, 09, 11, 14, 15, 21 | **動画用の画面（縦の表・カード・箇条書き）で作り直し**。1項目ずつ出す |
| 答案の欄の画像 | dai1ran などのPNG | 縦の表（rows）に作り直して答えを1行ずつ出す |

文字を一律に大きくして描き直すと、座標図形の図は文字どうしが重ならないが、整理図は枠から文字があふれた（実験済み）。そのため **図ごとに、重なりの出ない最大の倍率を自動で選ぶ**（`prep_figures.py`）。R8/Q21 では 1.2〜1.5倍が通ったのは zu02(1.35)・06・07・16〜19(1.5)・10(1.2) の8枚。

## 5. 図を動画用にする手順

1. **高解像度・大きな文字で描き直す**（描画スクリプトは書き換えない）:
   `python3 prep_figures.py <描画スクリプト> --scale 2 --out out/zu_hires/<名前>`
   図ごとの文字の倍率は `_font_scales.json`、図の中の文字の位置と大きさは `<図>.json`。
   台本の `figures` に書いておけば、`render.py` が足りないときに自動で実行する。
2. **場面（ショット）を決める**。1つの図を、話の区切りごとに 3〜5 の見せ方に分ける:
   - 全体（overview）：図の形を見せる。最初の1回だけ。文字は小さくてもよい（`"overview": true`）。
   - ズーム：話している部分だけを拡大する（`view`）。文字は 32px 以上になるまで拡大する。
   - 強調：赤い枠（`focus`）と、結論の注釈（`callout`）。
3. **点検する**: `python3 check_shots.py episodes/<id>.json --png`
   - 文字が小さい（28px未満）・途中で切れている場面を一覧にする（NGがあれば終了コード1）。
   - `out/<id>/shotcheck/NN.png` に、文字の枠を緑（十分）・橙（注意）・赤（小さい）・青（切れ）で描いた確認画像。
4. **書き出す**: `python3 render.py episodes/<id>.json` → 最後に `pacing.txt`（話す速さ・図の動く間隔・画面のはみ出し）が出る。

### 台本（KaisetsuScript v2）に足した書き方

```jsonc
{"speaker": "tori", "image": "zu02.png", "view": [0.08, 0.11, 0.96, 0.77], "overview": true, "text": "…"},      // 図を出す（view は図の幅・高さに対する0〜1の割合）
{"speaker": "aiko", "view": [0.50, 0.07, 0.96, 0.415], "callout": {"text": "D・J・C：X＝510.78", "pos": "br", "color": "red"}, "text": "…"},  // ズーム＋注釈
{"speaker": "tori", "focus": [[0.46, 0.125, 0.645, 0.765]], "text": "…"},                                      // 赤い枠（図の割合）
{"speaker": "tori", "rows":  {"title": "…", "rows":  [{"k": "日付", "v": "出来事", "color": "red"}]}, "reveal": 2, "text": "…"},   // 縦の表。reveal=見せる行数
{"speaker": "tori", "cards": {"title": "…", "cols": 2, "cards": [{"head": "…", "color": "blue", "items": ["…"], "span": true}]}, "reveal": 1, "focus_item": [0], "text": "…"},
{"speaker": "tori", "bullets": {"heading": "…", "items": ["…"]}, "focus_item": [3, 4], "text": "…"}            // focus_item=強調する番号（ほかは薄くなる）
```
- `view` は縦横比 16:9 になるように決める（`幅の割合 × 0.75 = 高さの割合`、図が4:3のとき）。16:9でない範囲を指定すると、足りない方向は広く見える。
- `view_px` / `focus_px` で、図のピクセルの座標でも指定できる。
- `callout` の位置: `tl` `tr` `bl` `br` `tc` `bc`。図の大事な文字に重ならない位置を選ぶ。
- 動き: 同じ図で `view` が変わるとなめらかに拡大・移動（0.55秒）、別の図・別の画面に変わると重ねて入れ替え（0.4秒）。**動いている間は話さず、先に図を見せてから話し始める**。注釈・強調・カードの追加だけのときは、動かさず0.22秒おいて話す。

## 6. 会話のリズムと話すタイミング

| 項目 | 基準 | 実装 |
|---|---|---|
| 1つのセリフ | 1〜2文、60文字以内（字幕2行に収まる） | 長いセリフは文の区切りで字幕を分ける（56文字） |
| 話者 | 同じ話者が3回続かない。解説が続くときは藍子の相づち・質問を挟む | 台本で調整 |
| 図の出る順 | **図を出す → 0.15秒 → 話す**。図が動き終わる前に話し始めない | `render.py`（LEAD、T_ZOOM） |
| 図を切り替える場所 | 話の区切り（文の頭）。1つの文の途中で切り替えない | 台本は **1文＝1 beat** を基本にする |
| 図が動かない時間 | 25秒以内（視聴者が飽きる目安） | `pacing.txt` が警告 |
| 話す速さ | 平均 約6文字/秒、最速でも8.5文字/秒まで | `pacing.txt` が警告 |
| 読み上げない | 数値・座標は注釈（callout）で見せ、声では要点だけ言う。電卓のキー列は読まない | 台本 |
