# キャラクター画像の置き場所

ここに置いた絵が、すべての台本の動画に自動で使われる（絵のないキャラクターは仮のSVGのまま）。

## ファイル名
`<キャラ>_<ポーズ番号>_closed.png`（口を閉じた絵）と `<キャラ>_<ポーズ番号>_open.png`（口を開いた絵）の組。
キャラは台本の characters のキー（`aiko`・`tori`）。大文字小文字は問わない（`Aiko_01_closed.png` でよい）。
番号のない `aiko_closed.png`・`aiko_open.png` はポーズ1として扱う。.webp でもよい。

## 絵の条件
- 背景は透明（PNGのアルファ）。1枚に1体。
- 口を閉じた絵と開いた絵は、口以外をできるだけ同じにする。大きさや位置が少しずれていても、`chars_prep.py` が自動で合わせる
  （開いた絵を閉じた絵に重なるよう拡大縮小・移動する。重なり具合は `python3 chars_prep.py` で表示）。
- 切り出しで残った小さな破片（本体から離れた本体の5%未満の塊、絵の端に接する15%未満の塊）も自動で消す。
- 元の画像は書き換えない。整えた写しは `out/_chars/`（コミットしない）にでき、元の画像を差し替えると作り直される。
- ポーズを足すときは、番号を増やして置き、`poses.json` に名前を足す。
