# キャラクター画像の置き場所

ここに次の名前で画像を置くと、すべての台本の動画に自動で反映される（置いていないキャラクターは仮のSVGのまま）。

| ファイル名 | 中身 |
|---|---|
| `aiko_closed.png` | 藍子・口を閉じた絵 |
| `aiko_open.png` | 藍子・口を開いた絵 |
| `tori_closed.png` | トリ先生・くちばしを閉じた絵 |
| `tori_open.png` | トリ先生・くちばしを開いた絵 |

- 1枚に1ポーズ（キャラクターシートの全体ではなく、1体だけを切り出したもの）。上半身〜全身、正面かやや内向き（藍子は右向き＝画面の中央向き、トリ先生は左向き）。
- 背景は透明（PNGのアルファ）。縦長で、横:縦がおよそ 300:346（例 600×692px）。余白は少なめに。
- 閉じた絵と開いた絵は、口以外（大きさ・位置・ポーズ・色）を完全に同じにする。違うと口パクのたびに体が揺れて見える。
- .webp でもよい。特定の台本だけ別の絵にしたいときは、台本の characters.<key>.images に {"closed": "...", "open": "..."} を書く（そちらが優先）。
