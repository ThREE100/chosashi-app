# 学習まんがの共通部品（`tools/gakushu_manga/`）

ひっかけ診断ノートの学習まんが（`note-unei/hikkake-shindan/kaiwa/`、2026-11-28 ユーザー評価「とても良好」）のプロンプトの書き方を、
ほかのコンテンツでも使えるように切り出したもの。kaiwa/ のファイルは書き換えていない（向こうは別スレッドが記事を作成中）。

| ファイル | 中身 |
|---|---|
| `manga_core.py` | 1ページのプロンプト（5段：画風とキャラクター・コマ割り・コマごと・文字の決まり・品質の確認）、見出し画像、プロンプトのmdの組み立て。**図の差し込み枠（FIGURE SLOT）**を足した |
| `manga_kata.py` | 定番のページ：扉・つまずき・図解の大ゴマ（図の枠つきも可）・確かめクイズ・まとめ（○×のはんこあり／なし） |
| `manga_instr.py` | Codex用・ChatGPT（GitHub接続）用の貼り付け文。図があるページは、図のURLと「添付する」印を自動で入れる |
| `manga_check.py` | 共通の機械チェック：名前・役割名、個人の演習結果の語、吹き出し30字・ナレーション28字・1ページ220字、同じ話し手の連続、既存作品の名前、図の枠と縦横比、元データにない数、元データの根拠にない条 |
| `paste_fig.py` | 生成したページに、Claudeが作った正確な図を枠どおりに貼り直す（ChatGPTが図を崩したときの直し方） |

## 使っている仕組み

- 一枚まとめ：`note-articles/ichimai-matome/manga/`（型は `KATA.md`）
- 毎日ドリル 朝・夜：`daily-drill/manga/`（型は `KATA.md`。夜は図を Claude が作って `pm/fig/` に置く）

## 台本の形

```
page  = dict(caption, aim, layout, panels=[panel, …])
panel = dict(size, art, chars?, narration?, talk=[('S'|'T', 文), …]?, words=[…]?, fig=dict(name, rect=(x, y, 幅, 高さ), …)?)
```
S＝生徒（左）、T＝先生（右）。名前・役割名は台本の文字にも書かない。`fig` は、ページ（1024×1536）の中の枠に、
プロンプトのmdと同じフォルダの `fig/<name>.png` をそのまま置かせる指定。

## 図の差し込みの仕組み（FIGURE SLOT）

1. 図は Claude が元データ（座標など）から SVG で描き、PNG に書き出してリポジトリに置く（画像生成AIに描かせない）。
2. プロンプトには、図のファイル名・raw.githubusercontent.com のURL・枠の位置と大きさ（px）を書き、「この図をそのまま置き、描き直さない。枠に人物・吹き出しを重ねない」と指示する。
3. ChatGPTには、6枚のキャラクターシートに加えて、そのページの図のPNGを添付する。
4. 生成された画像で図が崩れていたら（数字・線が変わるなど）、`python3 tools/gakushu_manga/paste_fig.py <生成した画像> <プロンプトのmd> <ページ番号>` で正確な図を枠に貼り直す（画像を 1024×1536 にそろえてから貼る）。Codex には必ず貼り直させる。
