# 択一式 一問一答ドリル

R7〜H17の択一式420問（問1〜3 民法／問4〜19 不動産登記法／問20 土地家屋調査士法）を肢ごとに分解し、
〇・×・？の3択で解いて、正誤を記録し、苦手論点をあぶり出す。Claude Codeのスマホアプリ（クラウドセッション）で使う。

## 構成
- `data/items.json` 問題バンク（2,095肢。重複41肢を統合。`status`: verified 1,949／provisional 112（根拠がやや弱い）／hold 34（出題しない）。対比ペア（似ているが結論が逆）は `pair`）
- `drill.py` 出題・採点・記録・集計のエンジン（標準ライブラリのみ）
- `extract_notes.py` → `derive_truth.py` → （LLMで確定）→ `build_bank.py` がバンクの作り方。`work/` は中間ファイル（git管理外）
- `REVIEW_HOLD.md` 保留にした問題（公式正答と解説が食い違うもの）
- 学習記録は専用ブランチ `drill-log`（`log.jsonl`、1回答1行）。`.drill-log/` はそのworktree

## 使い方（セッションで「ドリル」と言うか `/drill`）
`start` → `next -n 10` → 1問ずつ `answer <ID> <o|x|?>` → 10問ごとに `save` → `report`。

## 判定と復習
- 〇/×が正解＝定着、〇/×が不正解＝誤解（逆に覚えている）、？＝未習得。誤解は未習得より重く扱う。
- 誤答・？は連続正解数0に戻り、**日付をまたいだ翌日（日本時間0時）以降**に復習に戻る（同じ日には再出題しない）。その後は1・3・7・21・60日の間隔。初見で正解した肢は21日後に確認し、連続6回で卒業。
- 新規の肢は、まだ解いていない論点を先に、次に弱い論点・出題頻度の高い肢を優先する。

## 正誤の基準
**現行法令を正とする。** 正誤は `note-articles/` の解説記事（執筆ルールに従い現行法令で書かれ、法改正後は設問を改題している）の結論に従う。
出題当時の公式正答は、記事と一致するかの突き合わせにだけ使い、食い違うときは記事（現行法）を採る。

## 正誤データの確かさ
- 標準形式313問は、公式正答番号から逆算した正誤が、記事の「ア（正）」表記と全肢一致したもの（公式正答と現行法の記事が同じ結論の問題）。
- 残り107問（対話・個数・空欄補充など）は、解説記事からエージェントが確定した（確信度は high／medium／low）。
- 公式正答と記事が食い違う11問（法改正後の改題）は、記事（現行法）基準で確定し直した（`work/batch_out_fix.json`）。
- 記事自身が不確実と注記している肢、記事の結論と解説が矛盾する肢は保留（hold）にする（`REVIEW_HOLD.md`）。

## 解説の方針（2026-10-03）
- 解説は **note-articles（main）の該当肢の解説をそのまま引用**する（`answer`・`explain` の出力）。ドリルを動かすClaudeが独自の解答・解説を作ることは禁止。
- 引用した解説に誤りがある（正解との食い違い、`note-articles/laws/` の原文との不一致、記事内の矛盾）と気づいたら、引用を出した時点で指摘し、訂正案を添える。`drill.py issue` で記録できる（`drill-log` の `issues.jsonl`）。記事の書き換えは別作業。
- 2,100肢すべてで、記事の該当肢の解説を取り出せることを確認した（ラベルの取り違え0件）。
