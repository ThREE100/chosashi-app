# 条文を主役にした4コマ（joubun/）

条文別『苦手克服』シリーズ（`note-articles/joubun-nigate/`、main ブランチ）の各フォルダ `prompt_4koma_01_*.md` と同じ内容の控えです（2026-10-10）。
一問一答で繰り返し誤答している肢の根拠になっている条文そのものを主役にして、条文の中身が1枚で言えるように組んだ4コマです。同じ肢を「肢」中心で作った版は、1つ上のフォルダの `<ID>_prompt.md` にあります。

- D1596-D1728-D2023：不動産登記規則 第28条・第28条の2（保存期間）
- D1659：不動産登記事務取扱手続準則 第79条第3号（家屋番号の定め方）
- D1762：不動産登記規則 別表二・別表三（所在欄・構造欄）
- D1712：土地家屋調査士法 第22条・第41条第1項（依頼に応ずる義務と法人への準用）
- D1633：不動産登記令 第13条と調査士報告方式の取扱い
- D2016：民法 第921条第1号（法定単純承認）

各 `<fid>_spec.py` が設計データです。再生成は `python3 tools/drill/manga/render_spec.py tools/drill/manga/joubun/<fid>_spec.py`。
