## 1. 使用目的

土地家屋調査士試験の note 見出し画像、解説図、4コマ解説図解、記述式解説漫画（長編）で使う案内役のキャラクター。親しみやすさと専門性を両立させ、**すべての画像で同一人物・同一キャラクターに見えること**を最優先とする。

登場してよいキャラクターは、**女性キャラクター（藍子）と、鳥のトリ先生の2人だけ**。事例の当事者（Ａ・Ｂ・Ｃなど）はキャラクターにせず、顔なしの単純なピクトグラム＋文字ラベルで描く（キャラの増加による見た目のブレを防ぐ）。

### 用途ごとの役割

| 用途 | 登場 | 藍子の役割 |
| --- | --- | --- |
| note 見出し画像 | 藍子（＋トリ先生） | 学習を落ち着いて導く案内役（第1版の設定。落ち着いた所作を優先） |
| 4コマ解説図解（一問一答ドリル） | 藍子＋トリ先生 | 生徒役（誤解・誤答を言う側） |
| 記述式の会話形式note記事・記述式解説漫画 | 藍子＋トリ先生 | 生徒役（まじめで素直、ワナに引っかかる猪突猛進） |

どの用途でも、**顔・髪型・服装・画風は同じ**。変わるのは役割に応じた表情・所作だけ。

### 3-3. 位置のルール
- 4コマ・学習漫画の本体：**藍子は常に左側、トリ先生は常に右側**。吹き出しは話者と同じ側に置き、尾は話者の口（顔）に向ける。相手側に向けない。
- 見出し画像（苦手分析シリーズ踏襲）：トリ先生が中央より左下、藍子が右下。
- 読む順は、上から下。同じ区画では藍子（質問・誤答）が先、トリ先生（訂正・理由）が後。

### 3-4. 人体構造（藍子・厳守）
- 頭1つ・胴体1つ・腕2本（左右1本ずつ）・手2本。各手の指は5本。
- 余分な腕・手・指、浮いた手、重複した手、肩から生えていない腕、手の融合を描かない。肩・肘・手首が自然につながること。
- **手の割り当て**：藍子を描く場面ごとに、両手の役割を決める（例：片手で指さし、もう片手は下ろすかクリップボードを持つ／片手をあごに、もう片手でクリップボード／両手で小さくガッツポーズ）。**指さすときは片腕だけ**。胸の前で手を組むなど、指さしと同時に3本目の手に見える動作をしない（「二人でそろって指さす」場面で手が3本になった不具合の再発防止）。
- ポーズは場面ごとに変える（立つ、座る、前かがみ、頬づえなど）。生成のたびに変える。

## 4. 禁止事項

- 髪色・髪型・顔の骨格・目の色を変えない。
- 藍子に、アクセサリー、眼鏡、帽子、派手なメイク、ネイル、スマートフォン、イヤホンを追加しない（トリ先生の丸い赤い眼鏡は固定設定）。
- 幼く見せない、別人のような美形化・デフォルメをしない。
- 露出の多い服、私服調の派手な衣装、制服風衣装にしない。
- 電話をするポーズを使わない（藍子。トリ先生のシートにある「電話（対応）」カットも、学習漫画では使わない）。
- 見出し画像では、吹き出しに長文を入れない。
- 実在の人物・既存キャラクターに寄せない。
- 登場してよいのは藍子とトリ先生だけ。第3のキャラクターを足さない。
- **ピンク・緑・オレンジを面・図・ラベルに使わない。意味のない色で塗り分けない**（効果線の色は§5）（§9の色の規則）。
- 電卓のキー操作（キー列）を画像に描かない（記述式漫画）。

## 6. 表情カタログ（2026-10-08・長編漫画で確定）

表情で「今どこで引っかかるか」を伝える。画像生成では**表情・視線・手・姿勢だけ**を変え、髪型・服・顔の作りは固定する。章（4コマ）の感情の流れの標準：A1自信満々 → T1呆れ → A2固まる → T2指し示す → A3ひらめき → A4確かめる → T3感心 → A5安堵。

| ID | 名前 | 使う場面 | 描き方 |
| --- | --- | --- | --- |
| A1 | 自信満々 | 誤答を言うとき | 胸を張る、口角が上がる、片手を腰か胸 |
| A2 | 固まる・青ざめ | 誤答の結果が図に出たとき | 目が点、汗、片手が口元 |
| A3 | ひらめき | 訂正を受けて気づく | 目が大きく、指を立てる、小さな電球の輝き |
| A4 | 確かめる・考える | 式を立てる、検算する | あごに手、ペンを持つ |
| A5 | 安堵・達成 | 答えが合ったとき、章末 | 笑顔、小さなガッツポーズ（両手は2本） |
| T1 | 呆れ・叱る（愛あり） | 誤答を受けて | 眼鏡を押し上げる、目を細める。手本：シート1/3「あきれ・ため息」「激怒（ツッコミ）」 |
| T2 | 指し示す | 根拠を示すとき | 翼で図やカードの注目点を指す。手本：シート2/3「案内」、3/3「紹介（プレゼン）」 |
| T3 | 感心 | 藍子が正しく答えたとき | 頷く、目が丸い。手本：シート2/3「納得」、3/3「グッジョブ」 |
| T4 | どや・念押し | 「これがこの年度のわなよ」と言うとき | 胸を張る、翼を広げる。手本：シート1/3「ドヤ顔（自慢）」 |

## 7. キャラクターの出し方（2026-10-08・4コマの検品から確定）

注目してほしい情報が大きいほど、キャラクターは小さくする。1ページ（1コマ）に両方を必ず出す必要はない。**大きさは数値（px）で指定する**（「小さく」だけだと大きく描かれて図が狭くなる）。数値は 1080×1920px のページの場合。

| モード | 大きさ | 使う場面 |
| --- | --- | --- |
| FULL | 全身または上半身で高さ約440〜520px | 章扉、誤答の寸劇、章末、感情を見せたい場面。結論のコマ（4コマの4コマ目）は原則これ |
| MID | 上半身で高さ約300px | 図の横で会話するとき |
| SMALL | 全身で約110px。藍子は左下、トリ先生は右下 | フローチャート・表を大きく見せたいとき |
| FACES | 顔アイコンだけ。直径約80px（体・手は描かない） | 会話ラリー。吹き出しの尾が顔に向く。左端＝藍子、右端＝トリ先生。1往復20字前後で4〜8往復。長い説明を、図を大きくしたまま入れられる |
| NONE | 描かない（吹き出しもなし） | 全面図、答案用紙の完成形、制度の対比図など、図が主役のコマ。1コマ目・4コマ目には使わない |
| リアクション窓（長編） | 直径約120px の丸窓を図や吹き出しの角に重ねる | 図の説明中の「えっ」「なるほど」。吹き出しは1〜6字。図の文字・数値を隠さない |
| 指し棒（長編） | トリ先生の翼だけ、または指し棒だけが図の端から出る | 図の注目点を指す。キャラを大きく出さずに視線を誘導 |

- 隣り合うコマ（ページ）で同じ出し方を続けない。同じテンプレートを3ページ連続させない。
- **無言の反応（silent）**：その場面でセリフがない（記事で話していない）人物は、表情だけで反応させてよい。言葉・吹き出しは足さない。
- 登場しないキャラクターの吹き出しは書かない。

## 8. 吹き出しと文字

- 吹き出し：白地＋濃紺の細い枠＋濃紺の文字。大きく読みやすい日本語（文字の高さ40px以上）。**尾は必ず自分の話者へ**向ける。
- **セリフは正本の文字列を一字一句そのまま**入れる（言い換え・短縮・追加をしない）。1つの吹き出しは25字以内（FACESは20字前後）、1行15字以内で、改行は与えたとおりに保つ。強調語は黄色マーカー。
- 文字は常用漢字・ひらがな・カタカナ・算用数字。簡体字・繁体字・不要な英字・擬似文字を入れない。人物の記号は全角（Ａ・Ｂ・Ｃ）。数字・小数点・度分秒の記号は正確に。
- **崩れやすい語**は、プロンプトの最終確認で綴りを確認させる（過去の例：「原則」が「思則」、「まとめて」が「まとかて」と描かれた）。新しく崩れた語が出たら、`tools/drill/manga/check_prompt.py` の `GARBLED` に登録する（以後、プロンプトに自動で確認文が入る）。
- （第1版との違い）note見出し画像では、吹き出しに長文を入れない。**4コマ・記述式漫画では、吹き出しの文字はChatGPTが正本のとおり描き**、生成後に一字一句照合する。

## 9. 色と図の扱い（2026-10-08）

### 色の規則
- 基調：ネイビー（枠・タグ・帯）、ウォームグレー／薄い灰色（カード）、淡いクリームの背景、黄色マーカー（強調語だけ）。
- 青・赤を使ってよいのは次だけ。
  - 4コマ：青＝○・✓・はい、赤＝×・✕・いいえ（フローチャートの枝、対比カードの印）。
  - 記述式漫画：赤は**誤り・訂正の箇所だけ**（誤答の座標、「誤り」カード。登記申請書の図と同じ使い方）。青✓は正しい整理の印だけ。答えの帯は濃紺。
  - 図（座標から作図したPNG）の中の赤は制限しない（そのまま使う）。
- 図の部品（人物ピクトグラム、領域、バー、タグ、ボックス）の**色は必ず指定する**。指定がないと意味のない青・赤・緑・ピンクで塗られ、○×・はい／いいえに見える。標準：ピクトグラム＝同じ薄い灰青（比較用だけ濃い灰）＋濃紺のタグ／領域・カード＝同じ薄い灰色＋濃紺の枠／結果の箱・バー＝白地＋濃紺の枠／壁・点線の矢印・帯＝濃紺。
- ○×の印は、1つのカードに1つだけ。同じ箱に✓と✕を重ねない。印はカード本文の下の空きに置き、文字に触れさせない。疑問バッジには印を付けない。

### 図・カードの扱い
- **添付図版は縮小・拡大のみ。トリミング、色変更、線・数字・文字の描き直し、図版へのキャラクターや吹き出しの重ね置きをしない。**
- 記述式漫画（方式A′）：図・計算カード・答えバナーは**ChatGPTに描かせない**。ChatGPTには「何も書かれていない薄い灰色（#E6E6E6）の長方形（仮枠）」だけを描かせ、あとから `tools/drill/manga/kijutsu_pilot/compose_pages.py` が画像から仮枠を自動で見つけて、図（`zu/` のPNG）やカードを貼る。図をChatGPTに添付する必要はない。仮枠には何も重ねず、枠線の飾り・影・文字を入れない。

## 10. note 見出し画像用の構成ルール

- キャンバス：**1280×670px、横長**。
- safe zone：表示時に中央帯だけが見えることを前提に、**タイトルと主題の図解を中央付近**に置く。
- 基本配置：左側にタイトル・図解、右側に女性キャラクター。ただし内容に合わせて左右反転は可。
- 女性は画面の約 1/3 を目安にし、全身を無理に入れない。バストアップ〜腰上を基本とする。
- ポーズは毎回変える。指差し、資料を持つ、考える、手のひらで示す、机に座る等を使い分ける。
- 背景は白〜淡色（苦手分析シリーズ踏襲の水彩の空に統一する場合あり）。文字は濃紺を基本に、アクセントはシリーズの色に合わせる。
- 日本語は常用漢字・ひらがな・カタカナを用い、簡体字・文字化け・不要な英語を入れない。
- 4コマ解説図解の見出し画像の文言・構成は `tools/drill/manga/MANGA_RULES.md` の「見出し画像」に従う。

## 11. 学習漫画・4コマの構成ルール

- 4コマ解説図解・記述式漫画のページ：**1080×1920px 縦長（9:16）**。完全に不透明な淡いクリーム背景。薄い枠線と余白（第1版の「縦長2:3」は、ページの大きさが決まるまでの代替案）。
- 4コマの構成：タイトル帯（約190px）、4コマ（各約395px）、結論帯（約110px）。長編はページを区画（ゾーン）に分け、各区画の y と高さ（px）を構成表に書く。
- キャラクターは全ページで同一人物。髪型・衣装・年齢印象を変えない。
- 各コマ（ページ）で、**問いの事案・出題者のねらい・ひっかけ・勘違い・正しい整理（＋なぜそうなるかの理由）**を図や文言として示す。
- 落ち着いた所作を優先し、過度な驚きや大きすぎる感情表現は避ける（藍子の「固まる」「安堵」は§6の範囲で）。
- 詳細は `tools/drill/manga/MANGA_RULES.md`（4コマ）、`tools/drill/manga/kijutsu_manga_prompt_elements.json`（記述式漫画の要素）、`tools/drill/manga/kijutsu_pilot/`（パイロット）。

### 漫画用プロンプトの作り方
プロンプトは手書きせず、構成表（設計データ）から生成する。
- 4コマ：`tools/drill/manga/gen_prompts.py` → `check_prompt.py`（NG 0件）
- 記述式漫画：`tools/drill/manga/kijutsu_pilot/r7_q21_ch02.py` → `check_pages.py` → `gen_pages.py`（`prompts/`）→ ChatGPT → `compose_pages.py`

共通部分の要点（生成器が自動で入れる）：参照画像を固定参照として読み込む／顔・髪・服装・画風を全コマで統一／人体構造と手の割り当て／キャラの出し方と大きさ（px）／吹き出しは正本の文字列／仮枠は空の灰色の長方形／ピンク・緑・オレンジ・電卓キーは使わない／最終確認（綴り、仮枠の空、キャラの大きさ、背景の不透明）。

## 12. 最終チェックリスト（生成後に目視）

- [ ] 画像が**実際に表示されているか**（「作成しました」と言うだけで出ていないことがある）。
- [ ] 参照資料と同じ人物に見えるか（藍子・トリ先生とも）。
- [ ] 髪色、前髪（ぱっつんでない）、巻き髪、目の色、シャツのストライプが維持されているか。藍子の髪型が全ページで同じか。
- [ ] 藍子の腕2本・手2本・指5本。指さしのとき3本目の手がない。
- [ ] 藍子が左・トリ先生が右で、吹き出しの尾が話者に向き、読む順が正しいか。
- [ ] 全台詞・ラベルが正本と一字一句同じか（崩れた字・脱落・数字の誤りがない）。
- [ ] キャラの大きさが指定どおりか（FACESやSMALLが大きく描かれて図を狭めていない）。NONEのページにキャラ・吹き出しがない。
- [ ] 仮枠が、何も描かれていない空の灰色の長方形で、位置・大きさが構成表どおりか。
- [ ] 色：意味のない青・赤・緑・ピンクがない。青・赤が○×・はい／いいえ・誤りの箇所だけか。人物の頭の上などに余計な印がない。
- [ ] 顔向き・ポーズが直前の画像と重複しすぎていないか。同じ出し方（キャラのモード）が連続していないか。
- [ ] 文字・図解・キャラクターが用途の安全領域に収まっているか。
- [ ] 禁止事項（電話、アクセサリー、別衣装、第3のキャラ、電卓キー、文字化け等）が入っていないか。
- [ ] 法的内容が記事の範囲内で正確か（記事にない説明を足していない）。
