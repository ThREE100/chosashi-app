# 女性キャラクター 統一仕様書

## 1. 使用目的

土地家屋調査士試験の note 見出し画像、解説図、学習漫画で使う案内役の女性キャラクター。親しみやすさと専門性を両立させ、すべての画像で同一人物に見えることを最優先とする。

## 2. 最初に読み込ませる参照素材

作成前に、以下を必ず参照画像として読み込ませる。

- マスター画像：`マスター1(20260829-231217).PNG`
- 顔向き・角度シート 01：`女性キャラクター_顔向き8カット_基本.png`
- 顔向き・角度シート 02：`女性キャラクター_顔向き8カット_差分.png`

参照画像は「構図の再現」ではなく、**同一人物の顔・髪型・服装・画風を固定するための資料**として扱う。

## 3. キャラクターの固定設定

| 項目 | 固定仕様 |
| --- | --- |
| 役割 | 学習を落ち着いて導く、知的で親しみやすい女性の先輩・解説者 |
| 年齢印象 | 成人。落ち着いた若手〜中堅の専門職らしい印象 |
| 顔立ち | やや卵形。自然な肌色。アーモンド形の温かいブラウンの瞳。やさしい表情 |
| 髪 | ダークチェスナットブラウン。肩より少し長いロングヘア。ゆるい巻き髪。自然に下ろした前髪。分け目は中央寄り |
| 基本服 | 薄い青と白の細いピンストライプのシャツ。襟あり。袖は軽くまくる。濃紺のスカートまたはパンツスーツは用途に応じて使用可 |
| 表情 | 基本は穏やかな微笑み。説明時は真剣、考える場面は落ち着いた思案顔、注意喚起は驚きすぎない集中表情 |
| 画風 | 繊細な濃色の線画、淡い水彩風の陰影、清潔感のある日本の教育・解説イラスト。リアル寄りだが柔らかい漫画調 |
| 背景 | 原則、白またはごく淡い暖色の白。必要時のみ、内容を妨げない薄い室内・机・本棚等 |

## 4. 禁止事項

- 髪色・髪型・顔の骨格・目の色を変えない。
- 幼く見せない、別人のような美形化・デフォルメをしない。
- アクセサリー、眼鏡、帽子、派手なメイク、ネイル、スマートフォン、イヤホンを追加しない。
- 露出の多い服、私服調の派手な衣装、制服風衣装にしない。
- 電話をするポーズを使わない。
- 見出し画像では、吹き出しに長文を入れない。漫画の吹き出しは、後から文字を入れるため原則空白。
- 実在の人物・既存キャラクターに寄せない。

## 5. 顔向きカットの使い分け

### シート 01：基本方向

正面、左右の斜め向き、左右の横顔、見上げ、見下ろし、振り返り。説明の相手・図版・タイトルの位置に応じて、視線の向きを選ぶ。

### シート 02：実用差分

左右の視線外し、首の傾き、横向きからの視線戻し、上から見た角度、下から見た角度。連続するページで単調にならないよう、同じ正面顔を連続使用しない。

## 6. note 見出し画像用の構成ルール

- キャンバス：**1280×670px、横長**。
- safe zone：表示時に中央帯だけが見えることを前提に、**タイトルと主題の図解を中央付近**に置く。
- 基本配置：左側にタイトル・図解、右側に女性キャラクター。ただし内容に合わせて左右反転は可。
- 女性は画面の約 1/3 を目安にし、全身を無理に入れない。バストアップ〜腰上を基本とする。
- ポーズは毎回変える。指差し、資料を持つ、考える、手のひらで示す、机に座る等を使い分ける。
- 背景は白〜淡色。文字は濃紺を基本に、アクセントはシリーズの色に合わせる。
- 日本語は常用漢字・ひらがな・カタカナを用い、簡体字・文字化け・不要な英語を入れない。

```text
タイトルと主要な図解は画面中央の安全領域に配置する。女性は［右／左］に［バストアップ／腰上］で配置し、［ポーズ］、顔は［顔向きシートの該当方向］。
アクセサリー、眼鏡、電話、派手な私服、長い吹き出し、簡体字、文字化けは入れない。
```

## 7. 学習漫画用の構成ルール

- 基本は縦長 2:3。白背景、黒の細いコマ枠、薄いトーンを使用する。
- 使用色はネイビー、ウォームグレー、赤の3色を主軸とする。
- キャラクターは全ページで同一人物。髪型・衣装・年齢印象を変えない。
- 吹き出しは後工程で文字を入れるため、原則として中身を空白にする。
- 添付図版は縮小・拡大のみ。トリミング、色変更、線・数字・文字の描き直し、図版へのキャラクターや吹き出しの重ね置きはしない。
- 説明役らしい落ち着いた所作を優先し、過度な驚きや大きすぎる感情表現は避ける。

### 漫画用プロンプト雛形

```text
添付のマスター画像と顔向きカットシートを、同一人物の固定参照として読み込む。
女性キャラクターの顔・髪・服装・画風を全コマで完全に統一する。ダークチェスナットブラウンのゆるいロングヘア、自然な前髪、温かいブラウンの瞳、薄い青白の細いピンストライプシャツ（必要に応じて濃紺スーツ）を維持する。

縦長2:3の学習漫画。白背景、黒の細いコマ枠、薄いトーン、ネイビー／ウォームグレー／赤の3色を基調にする。
女性は［コマごとのポーズ・表情・顔向き］。吹き出しは［空白／なし］。添付図版は指定の枠にそのまま配置し、トリミング・改変・文字の描き直しをしない。
アクセサリー、眼鏡、電話、派手な私服、別人化、過度なデフォルメ、不要な文字は入れない。
```
