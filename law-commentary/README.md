# 法令の全文解説（law-commentary）

条文を、条ごとに、かみ砕いて説明するためのフォルダです。リポジトリ直下に置いています（`note-articles/`の中ではありません）。`note-articles/laws/`（条文の原文のデータベース）に収録した法令を対象に、受験生が「条文を読み解く」ための補助として作ります。年度別の過去問解説記事（`h17-mondai/`〜`r7-mondai/`）や、苦手分析（`column/`）とは別の、条文そのものの解説です。

## 構成

- `fudousan-touki-hou/`：不動産登記法（平成16年法律第123号）。章ごとに1ファイル。
- 今後、他の法令（不動産登記令、不動産登記規則、準則、民法の関連部分など）を追加する場合は、同じ形で法令ごとにフォルダを作ります。

## 1条ごとの書き方

1. **原文**：`laws/`の条文を、一字一句そのまま引用します（要約・言い換えなし）。
2. **ひとことで**：その条文が何を定めているかを、一文で。
3. **かみ砕き**：項・号ごとに、平易な言葉で説明します。長い条文は、項・号の単位に分けます。
4. **つまずきポイント**：混同しやすい点、読み違えやすい点。
5. **たとえば**：具体例（人物はA・B・Cなどの記号か、役割で書く）。
6. **試験での押さえどころ**：穴埋めや正誤問題で問われやすい点。確認できた関連記事・一問一答だけを書く。
7. **関連条文**：条番号の参照先。

## 守るルール

- 条文の文言から確実に言えること（原文）と、一般的な理解・実務上の説明（条文に直接の文言がないもの）を、書き分けます。後者は、その旨を「確認事項」に書きます。
- 判例・先例の番号は書きません（内容の言及は可）。判例・先例の原文を確認できていない点は、「確認事項」に書きます。
- `laws/`に収録されていない法令（採石法など）の説明は、一般的な説明にとどめ、その旨を書きます。
- 表（Markdownのテーブル）は使いません（箇条書きで書く）。です・ます調、全角のかっこ。
- 原文の引用は、生成スクリプトで`laws/`から転記し、人が手で打ち直しません。
- 法改正があったときは、`laws/`の更新に合わせて、該当する条の解説を見直します。
