## 論点ごとの整理

### T01 敷地権・敷地利用権・分離処分可能規約
- **つまずきの原因**：(1) 「分離処分の禁止」（区分所有法22条）と「敷地権になる要件」（不動産登記法44条1項9号）を一続きの話として捉えられず、権利の種類（共有・単独・分有・準共有の賃借権・使用貸借・仮登記）ごとの結論が混ざる。(2) 敷地権の割合が、専有部分を数個持つ場合（床面積の割合）と、1個ずつ持つ場合（土地の持分の割合）で別の決まり方になる点。(3) 敷地権に変動があったとき、どの登記を、いつまでに、どこ（建物の表題部／土地の権利部）に記録するか。
- **理解に必要なこと**：敷地権は「区分建物の敷地」「敷地利用権」「分離して処分できない」「登記された」の4つがそろったものだけ。分離処分の禁止は「数人で有する権利」と「専有部分の全部を持つ人の単独所有」にかかり、分有は対象外。規約で別段の定めをすれば分離処分できて、敷地権にならない。変動の登記は建物の表題部の変更（1月以内）で、敷地権である旨の登記は土地の権利部にある。
- **図解**：T01-1 敷地権になる条件／T01-2 権利別の早見表／T01-3 敷地権の割合／T01-4 敷地権が変わるとき

### T02 共用部分・団地共用部分の登記
- **つまずきの原因**：(1) 共用部分である旨の登記に申請義務がない（対抗要件）のに、期限があるものと混ぜてしまう。(2) 「1月以内」の起算日が、場面ごとに「廃止の日」「所有権の取得の日」「共用部分である旨の登記がされた日」と違う。(3) 団地共用部分の申請情報（区分建物は家屋番号ではない）や、建物の区分の登記ができるか。
- **理解に必要なこと**：申請できるのは表題部所有者か所有権の登記名義人だけで、所有者を証する情報は要らず、新築の表題登記の一括申請とは同時にできない。新しい所有者は、所有権の取得の日から数える。団地共用部分に一部共用はない。
- **図解**：T02-1 登記のしくみ／T02-2 期限の起算日／T02-3 団地共用部分

### T03 区分建物の成立・合併・合体・分割・建物の表示
- **つまずきの原因**：(1) 「接続していれば区分合併」と決めつけ、主従の関係があれば附属合併もできる点を落とす。(2) 一の申請情報にできる組合せを、規則35条の列挙と照らさずに推測する。(3) 分割は任意の登記なのに、義務と取り違える。分割で職権により所有権の登記がされた建物には登記識別情報がない。(4) 建物の種類（幼稚園＝校舎、料亭＝料理店）や冠記の細かい決まり。
- **理解に必要なこと**：合併の制限（準則86条）は「区分合併は接続、附属合併は主従」。一の申請情報にできる組合せは規則35条の列挙だけ。新築の表題登記は変更ではないので冠記を付けない。
- **図解**：T03-1 建物かどうかの見分け／T03-2 区分建物になったとき／T03-3 合併の種類／T03-4 一の申請情報の組合せ／T03-5 合体と分割の書類／T03-6 表示の書き方

### T04 移記・転写
- **つまずきの原因**：移記と転写の言葉を、場面ごとに暗記しようとして入れ替える。
- **理解に必要なこと**：見分け方は一つだけ。元の登記記録が閉鎖されるなら移記、閉鎖されずに残るなら転写。敷地権でなくなったときは建物の登記記録が残るので、土地へは転写。建物のみの抵当権は、特定登記ではないので土地へ転写されない。
- **図解**：T04-1 移記と転写の見分け方

### T05 代位申請・申請人・通知・代理権
- **つまずきの原因**：(1) 区分建物の代位が双方向（新築した人から既存の人へ、既存の人から新築した人へ）であることと、代位原因の書き方。(2) 相続人・合併後の法人は代位ではなく承継人として申請する。(3) 申請の代理権が消える場合と消えない場合（死亡・法定代理人側の事情は消えず、本人の破産は消える）。(4) 登記識別情報の通知先（申請人だけ。法定代理人が申請すれば法定代理人）と完了の通知。(5) 持分の更正に増える人の承諾も要る。
- **理解に必要なこと**：条文ごとに「だれが・だれに代わって」を表にして覚える。民法423条の代位は、自分の登記請求権を守るために必要なときだけ。
- **図解**：T05-1 代理権の消滅／T05-2 区分建物の代位／T05-3 民法による代位／T05-4 更正の登記／T05-5 通知

### T06 申請情報・添付情報・図面・登記原因・原本還付
- **つまずきの原因**：(1) 図面の要否（地番の誤りだけなら不要、地番変更は建物図面だけ、床面積の変更は各階平面図）。(2) 地役権図面は承役地のもので、範囲が一部になるかで決まる。(3) 登記原因の日付の取り方（埋立地は竣功認可の告示の日、国有地の払い下げは不詳）。(4) 縮尺と兼用の条件、原本還付できないもの。
- **理解に必要なこと**：「何が変わったか」と図面の対応を表で押さえる。原本還付できないのは、申請書・委任状・承諾書に押印した人の印鑑証明書。
- **図解**：T06-1 図面が要るとき／T06-2 地役権図面／T06-3 登記原因の書き方／T06-4 縮尺と兼用／T06-5 原本還付

### T07 土地の登記（分筆・地番・区画整理・登録免許税）
- **つまずきの原因**：(1) 職権の分筆が「しなければならない」場合（地目・地番区域）と「できる」場合（地図作成。異議がないとき）を混ぜる。(2) 分筆に伴う権利の消滅の記録（甲土地は付記登記と抹消の記号、乙土地には転写しない）と、地番の例外。(3) 地番の重複は閉鎖ではなく変更。(4) 区画整理の特例（ブロック地番は任意など）。(5) 登録免許税の対象と端数。
- **理解に必要なこと**：「だれが申請するか」「登記官が職権でする場合」「どの記録に何を付記するか」を分けて整理する。登録免許税は、所有権の登記がある土地の分筆が1個1000円で、表題部所有者の申請や一部地目変更には課されない。
- **図解**：T07-1 分筆の申請と職権／T07-2 権利の消滅の記録／T07-3 地番の定め方／T07-4 区画整理の登記／T07-5 登録免許税

### T08 筆界特定・法定相続情報・保存期間・証明書
- **つまずきの原因**：(1) 保存期間の数字（3年・5年・30年）が、帳簿の名前と対応していない。(2) 登記事項証明書と登記事項要約書の違い。(3) 筆界特定の申請（署名・押印不要、管轄がまたがる場合は指定前でも申請できる、却下の場面）。(4) 法定相続情報の申出先（被相続人の本籍地は含まれ、申出人の本籍地は含まれない）。
- **理解に必要なこと**：保存期間は表にして、事件簿（5年）とつづり込み帳の書類（30年）の違いまで押さえる。要約書は、書面で請求し、認証文も職印もない。
- **図解**：T08-1 保存期間／T08-2 証明書と要約書／T08-3 筆界特定の申請／T08-4 法定相続情報

### T09 民法（登記と第三者・共有・相続・意思表示・相隣関係）
- **つまずきの原因**：条文の要件（善意だけか、無過失もか。登記が要るか）と、期間・承諾の要否を、似た制度と取り違える。配偶者居住権は、成立しない場合（配偶者以外の者との共有）と、承諾があってもできないこと（譲渡）の区別。
- **理解に必要なこと**：制度ごとに「要件」「期間」「承諾の要否」の三点を表にして押さえる。判例による結論は、条文と分けて覚える。
- **図解**：T09-1 登記と第三者／T09-2 共有と相続／T09-3 意思表示／T09-4 配偶者居住権／T09-5 相隣関係

### T10 土地家屋調査士法・業務
- **つまずきの原因**：届出先（調査士会を経由するのか、両方に直接か）と、同意が要る場面の例外（書類作成として受任している事件）。領収証の正本に押す印は職印。
- **理解に必要なこと**：調査士法人の成立の届出は、調査士会と連合会の両方へ（経由ではない）。受任している事件の相手方から別の事件を依頼されたときの同意は、書類作成の受任なら要らない。
- **図解**：T10-1 領収証と届出／T10-2 同意が要る場面
