# 土地家屋調査士試験 note解説記事

土地家屋調査士試験の過去問（択一式、ア〜オの5肢問題）を、note投稿用に初学者向けに解説した記事一式です。Claude Codeとの対話の中で、法務省公表の試験問題原本・正答資料、条文、実務解説サイトを都度確認しながら作成しています。

**この`note-articles/`フォルダ（`main`ブランチ）が、土地家屋調査士に関するnote記事の保存・更新の正本です。** 過去に他のブランチ（`claude/surveyor-exam-afternoon-q1-20-5lehv0`および年度別・テーマ別の各作業ブランチ）で並行して作業されていた記事は、すべてこのフォルダに統合済みです。今後のnote記事に関する更新は`main`に一本化し、他のブランチは更新しません（アーカイブ済み）。

## 分野別・総合解説記事（bunya-kaisetsu）について

`bunya-kaisetsu/` は、年度別フォルダ（`r4-mondai/`等）のような「1問1答」形式ではなく、特定の法律分野・テーマを年度横断で扱う記事を格納するフォルダです。執筆フォーマットは `bunya-kaisetsu/format-template.md` を参照してください。

第1弾として、民法の制限行為能力者（未成年者・成年被後見人・被保佐人・被補助人）を扱いました。

- 4類型それぞれを解説する個別記事（`01`〜`04`）と、4類型を横断して比較する総合記事（`00`）で構成しています。
- 情報ソースは、年度別記事と同じく `src/data/takuitsu.json`（条文根拠つきexplanation）・`src/data/kaisetsu_plus.json`（補足解説）を一次情報源とし、複数の法律情報サイトに掲載された条文の引用を相互に照合して条文番号を確認しています（本作業環境ではe-Gov法令検索への直接アクセスがブロックされたため、複数の独立したサイトの引用を突き合わせる方法で確認しました）。この過程で、当初の記事案にあった民法14条（保佐開始の審判の取消しの請求権者）・13条2項の請求権者の記載誤りを発見し、修正しました。詳細は各記事の確認事項ブロックを参照してください。
- 過去の出題実績（年度・問題番号）は、`takuitsu.json`を令和・平成の全年度にわたって検索し、この分野が中心的に問われた年度（令和6年度・令和4年度・平成30年度・平成26年度・平成25年度、いずれも午後の部第1問）と、代理・遺言・対抗要件など他分野の問題の中の1肢として登場した年度（令和5年度・令和3年度・令和元年度・平成29年度・平成24年度・平成22年度・平成18年度）を区別して整理しました。
- インフォグラフィック・図解は画像を生成せず、各記事内に「インフォグラフィック設計メモ」として構成案を文章で指定する形にとどめています（画像化はユーザー側で行う想定）。
- note.comはMarkdownの表組みを描画できないため、記事本文中（4類型比較・暗記すべき事項のまとめ等）ではMarkdown表を使わず、比較対象ごとに見出しを立てた箇条書きブロックで整理しています（総合記事`00`で当初表を使っていた箇所を修正済み）。
- 各記事の末尾には、本文中の図解用の「見出し画像用フレーズ」（5つ・20字前後）に加えて、記事冒頭・一覧表示に出るアイキャッチ画像1枚に載せる「アイキャッチ用ワンフレーズ」（候補5つ・10字前後）を追加しています。note全体の一般的なアイキャッチ作成のコツ（文字は10字以内が目安、タイトルをそのまま入れず一言に絞る）を踏まえた文字数です。
- 平成26年度午後第1問の1肢（成年後見人の代理権の範囲に関する記述）について、データベース上の表記に誤字が疑われる箇所を発見したため、条文（民法859条1項）と公式正解に整合する内容で解説し、その旨を確認事項ブロックに明記しました。

第2弾として、不動産登記規則の「登記識別情報に関する証明の請求」（`05-touki-shikibetsu-shoumei.md`）を扱いました。この記事は4類型のような並列構造を持たない単独テーマのため、個別記事＋総合記事の組ではなく1本の記事にまとめています。資格者代理人（土地家屋調査士等）が代理請求する場合に委任状（代理権限証明情報）が不要になる特例（不動産登記規則68条14項）を中心に、令和4年度午後第5問・平成21年度第6問の出題実績を整理しました。あわせて、法務省公式サイトの当該論点専用ページ（「資格者代理人による登記識別情報に関する証明の代理請求について」）で条文根拠を確認し、データベース上の表記に不正確さが疑われた箇所（職印証明書の名義人）を条文・公式ページと整合する内容に補正しています。

第3弾として、不動産登記規則の「区分建物の附属建物の所在の記録」（`06-fuzoku-tatemono-shozai.md`）を扱いました。区分建物（専有部分）には所在欄そのものが存在しないため、非区分の附属建物がある場合はその所在を構造欄に記録する（規則4条3項別表3）という点を中心に、附属建物が区分建物である場合の発展的な記録内容（法44条1項5号・7号・8号・9号、令和4年度午後第14問で既出）との違いを整理しました。

第4弾として、土地区画整理法に関する「従前地・底地・仮換地」（`07-jyuzenchi-sokochi-karikanchi.md`）を扱いました。似た言葉が並んで混同しやすい3つの用語（従前地＝もともと持っていた土地、仮換地＝これから使ってよい土地、底地＝仮換地の場所にいま登記記録上存在している土地）を整理したうえで、換地処分（103条・104条）による登記記録の引継ぎ、施行者による代位申請・嘱託（107条）が問われる出題実績（令和5年度午後第5問・第7問、令和元年度午後第14問、平成23年度午後第11問、平成18年度午後第8問、平成17年度午後第11問）を整理しました。

第5弾として、添付書類の有効期限に関する「印鑑証明書は全部3か月以内」という思い込みを整理した記事（`tenpu-jouhou-yuukoukigen.md`）を扱いました。3か月ルールの有無は「印鑑証明書かどうか」ではなく「何のために添付されるのか」で決まる（申請書・委任状への記名押印の真正性を担保するものは3か月以内、第三者の承諾・本人確認のためだけの書類は無期限）という対比を軸に、不動産登記令16条3項・18条3項などの根拠条文を横断的に整理しました。

## topics・column・link-map フォルダについて

`bunya-kaisetsu/`と同時並行で、他のブランチが以下の3種類のフォルダを整備しました。いずれも1問1答形式ではなく、テーマ横断の解説・整理を目的としています。

- **`topics/`**：`bunya-kaisetsu/`と同種のテーマ別解説記事です（地目23種類・調査士届出先マトリクス・代位申請・合筆合併の制限・筆界特定制度・表示登記義務一覧・申請資格・建物種類一覧・建物図面提供要否・添付情報早見表・取消権の期間制限・登記識別情報総整理・登録免許税早見表・床面積算入・原本還付、計15本）に加え、複数回にわたる連続記事シリーズを1本収録しています（調査士法人の業務制限：総論＋第1回〜第5回の全6本、`chousashi-houjin-gyoumu-seigen-00`〜`-05`）。合計21本。通常は記事ごとに独立したテーマを1本にまとめる形式ですが、1テーマの分量が大きい場合は、`{テーマslug}-{00〜}-{各回のslug}.md`という命名で連番の連続記事に分割し、各記事の冒頭にシリーズ全回への相互リンクを置きます（`bunya-kaisetsu/`のようなフォルダ全体の連番構成とは異なり、シリーズ単位の連番です）。noteへの一括インポート用ファイルは `tools/topics_to_mt.py` で生成し、`exports/topics.mt.txt` に出力済みです。
- **`column/`**：複数年度にまたがって繰り返し出題される頻出テーマを、条文の数字・区分ごとに総まとめするコラム記事です（保存期間の5段階まとめ・表示登記の申請義務と現実の運用の違い・表題部所有者と登記名義人の違い・建物認定の3要件、計4本）。
- **`link-map/`**：年度別記事どうしの関連性を整理したリンクマップです。`{年度}-related-articles.md`（年度別、全19年度分）は、その年度の各問と、同じ論点・似た論点を扱う他年度の過去問記事・個別テーマ記事（`topics/`・`column/`・`bunya-kaisetsu/`）を★の重要度つきで対応づけ、note記事に相互リンクを埋め込む際の設計図として使います。`topic-priority.md`は、出題頻度・未カバー度・ハブ性の3軸で、今後どのテーマ記事から優先的に作成すべきかをまとめたロードマップです。

## laws（ローカル法令データベース）について

`laws/` は、不動産登記法・令・規則・準則、民法（全5編）、区分所有法、会社法（全編）、農地法、土地家屋調査士法・同施行規則、登録免許税法（登記関連部分）の全文をe-Gov法令API等から取得して保存したものです。条文を根拠として引用する際は、まずこのフォルダをGrep/Readで確認し、Web検索より速く確実に条文の正確な文言を確認できるようにしています。収録法令一覧・使い方・既知の制限事項は `laws/README.md` を参照してください。

## tools・exportsについて

`tools/` には、Markdown記事をnote.comの一括インポート機能が読み込めるMT(Movable Type)形式のテキストファイルに変換するスクリプトがあります。

- `md_to_mt.py`：`{年度}-mondai/`のような1問1答形式(出典行・問題文引用・まとめ・正解という固定構造)の記事フォルダを変換します。
- `topics_to_mt.py`：`topics/`のような、固定構造を持たない任意の見出し構成の記事フォルダを変換します（表組みは自動的に箇条書きに変換）。
- `table_to_bullets.py`：`### まとめ表`のMarkdown表を箇条書きに一括変換する補助スクリプトです。

`exports/` には、上記スクリプトで生成した変換済みファイル（`.mt.txt`）を年度・フォルダ単位で保存しています。noteのインポート機能にそのままアップロードすると、下書き状態で記事が作成されます。

- `takuitsu.json`（問題文・肢・正解・explanationフィールドの詳細な条文根拠解説）を各記事の法的根拠の一次情報源とした。

## 令和4年度分の情報ソースについて

令和4年度分（r4-mondai）は、ユーザーが過去に構築した土地家屋調査士試験対策アプリのデータベース（`src/data/takuitsu.json`・`src/data/kaisetsu_plus.json`）を主要な一次情報源として作成しました。

- `takuitsu.json`（問題文・肢・法務省公式正答を反映したcorrectAnswer・各肢の○×判定と条文根拠を記したexplanationフィールド）を各記事の法的根拠の一次情報源とした。

- ローカルに保存されているアガルートの過去問テキストPDF等は、ユーザーの手元環境にあるファイルであり、本作業を行ったクラウド上の実行環境（リポジトリのクローン）には含まれていなかったため、直接は参照できなかった。根拠は上記データベースに拠っている。
- 作成後、次の独立したダブルチェックを実施済み: (1) 全20問の正解番号・組合せがtakuitsu.jsonのcorrectAnswer/combosと一致すること、(2) まとめ表の各肢の判定（正/誤）がexplanationの○×と完全一致すること、(3) 各肢の見出しが「正しい結論」を述べており、誤りの肢の設問内容をそのまま肯定していないこと、をスクリプトで機械的に照合し、加えて各問の条文根拠・具体例の整合性を独立レビューで確認した。
- なお、第10問（建物の認定）はtakuitsu.jsonのexplanationが空欄であったため、kaisetsu_plus.json（建物認定の3要件・準則77条の考え方）を根拠とした。第8問・第9問・第18問はkaisetsu_plus.jsonのapproach/pitfalls欄に一部矛盾する記述があったため、法務省公式正答と整合するexplanation欄に従い、その旨を各記事の確認事項ブロックに明記した。土地家屋調査士法（第20問）の条数は、法改正による表記差があるため、その旨を確認事項ブロックに明記している。

## 令和3年度分の情報ソースについて

令和3年度分（r3-mondai）は、ユーザーが過去に構築した土地家屋調査士試験対策アプリのデータベース（`src/data/takuitsu.json`・`src/data/kaisetsu_plus.json`）を主要な一次情報源として作成しました。

## 各記事の構成

各記事は `format-template.md` の型に沿って以下の要素で統一されています。

1. タイトル（【土地家屋調査士受験生向け】＋一言キャッチ、25文字以内）
2. 出典（出題年度・午前/午後・問題番号）
3. 問題文の引用（ア〜オの肢＋選択肢の組合せを含む全文）
4. 各肢の解説（見出しは正しい結論を表すフレーズ、条文根拠、「たとえば」で始まる具体例）
5. まとめ（肢・判定・ポイントの箇条書き。Markdown表は使わない）
6. 正解（本文の最後に明記。冒頭での先出しはしない）
7. 「このまま使える点／使う前に確認したい点」の確認事項ブロック（出典・根拠の確認状況を正直に記載）
8. 見出し画像用フレーズ（語り口調のキャッチフレーズ、通常5つ）

## 正確性についての方針

- 出題年度・問題番号・正解番号は、法務省公表の試験問題原本(https://www.moj.go.jp/MINJI/minji05_00732.html 等)と正答資料(https://www.moj.go.jp/content/001450015.pdf 等)を直接確認したものです。
- 各肢の法的根拠は、まず `laws/` のローカル法令データベースで確認し、収録がない場合や改正の疑いがある場合のみ条文(e-Gov法令検索等)・実務解説サイト・予備校教材を検索して確認しています。確認できた根拠の確度は記事ごと・肢ごとに異なります。各記事末尾の確認事項ブロックに、根拠が条文レベルで確認済みか、一般原則からの推論にとどまるかを明記しています。
- 今後、内容の誤りが判明した場合は、該当ファイルを修正し、コミットメッセージに修正内容を明記してください。
