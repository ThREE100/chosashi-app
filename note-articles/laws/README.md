## 使い方（執筆・品質管理での参照ルール）

`format-template.md` の「適用法令の確認ルール」に従い、条文を根拠として引用する際は、まずこのフォルダ内の該当ファイルをGrep/Readで確認してください。

1. 条文番号・項・号の正確な文言は、まずこのフォルダ内の該当ファイルを確認する。
2. このフォルダに収録されていない法令・条文（判例、先例、通達、都道府県条例等）や、収録後に法改正があった疑いがある場合のみ、e-Gov法令検索やWeb検索で追加確認する。
3. このフォルダの内容とWeb検索結果が食い違う場合は、取得日以降に法改正があった可能性を疑い、必ずe-Gov法令検索で現在の最新版を確認する（この一覧表の「取得日」を参照）。

## 既知の制限事項

- **見出し記法の不統一**: `kaishahou-1-*`（第一編・第二編）は条見出しを`### 第一条`（漢数字、独立行にキャプション）で表記していますが、`kaishahou-2-*`（第三編以降）は`###### 第575条`（算用数字、編=`##`〜条=`######`の固定6階層）で表記しています。異なるエージェントが個別に変換したための表記差であり、条文内容自体は両方とも完全です。条文番号でGrep検索する分には支障ありません。
- **別記様式・図面**: 不動産登記規則の別記様式（申請書ひな形）、不動産登記事務取扱手続準則第52条・53条の図面内の寸法ラベルの一部は、PDF/画像内の要素であり完全にはテキスト化できていません（該当箇所に`［要確認］`等の注記あり）。
- **今後の法改正**: 会社法には2026年8月以降に施行予定の改正（金融商品取引法関連の技術的改正など）が複数予定されていますが、取得時点で未施行のため反映していません。
- **附則**: 制定時からの全改正附則を収録していますが、実務上の参照頻度は低いため、条文本体ほど厳密な検証はしていません。

## 更新方法

法改正を確認した場合、該当ファイルをe-Gov法令API（`https://laws.e-gov.go.jp/api/2/law_data/{law_id}`）から再取得し、この一覧表の「取得日」列を更新してください。
