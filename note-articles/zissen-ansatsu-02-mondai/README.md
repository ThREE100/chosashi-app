## 各記事の構成

タイトル → 出典行（`**出題年度：実践答練　第2回　択一式　第n問**`）→ 問題文の引用 → 区切り線 → 導入文 → ア〜オの解説（見出し・本文・「たとえば」）→ まとめ → 正解 → 確認事項 → 見出し画像用フレーズ（5つ）→ **見出し画像 プロンプト** → **インフォグラフィック プロンプト（問題全体）**。

- 解説文は、教材の解説の文章を流用せず、条文（`note-articles/laws/`）と自分の言葉で書いています。教材は、各肢の正誤と考え方の確認にだけ使いました。
- 判例・先例・通達の番号は、記事の本文には書かず、各記事の「確認事項」だけに書いています。原文を本環境で確認できなかったものは、そのように書いてあります。
- 図解のプロンプトは、どの記事も5枚のカード（2列）で、誤りの肢は本来正しいルールに直して図解しています。肯定（○）は緑、否定（✕）は赤に統一し、列の色は緑とオレンジです。見出し画像は、淡いパステルカラーのアイソメトリック・フラットデザインで、人物キャラクターは入れていません（キャラクター入りの見出し画像に変える場合は、`tools/drill/manga/gen_prompts.py` の `header_prompt` を参照してください）。

## 作り方と機械チェック（`src/`）

- `src/body/qNN.md`：記事の本文（導入文〜見出し画像用フレーズ）。手書きです。
- `src/specs_a.py` 〜 `specs_d.py`：問題文・正解・図解のカード・見出し画像の指定。
- `src/build.py`：上の2つから `qNN-xxx.md` を作ります（`python3 build.py`、または `python3 build.py 3 7`）。本文を直すときは、`src/body` を直してから実行してください。
- `src/check_all.py`：記事の構成・見出し・まとめの正誤と正解の整合・書式（敬体、全角括弧、「肢ア」の禁止、判例番号の禁止、段落の長さ）・プロンプトの必須文言・カードの文字数を機械的に確かめます。現在、NG 0件です（WARN は、1つのカードに別の箱で ✓ と ✕ を置いたカードの確認用で、意図どおりです）。

## 教材の記述と食い違った点（記事では原文に合わせて直した箇所）

提供された教材の説明には、本環境の条文データ（`note-articles/laws/`）と食い違う箇所がありました。記事は、条文の原文に合わせています（各記事の「確認事項」にも書いてあります）。

- 第8問：補正の連絡事項の根拠は、教材の「規則36条2項」ではなく、**不動産登記事務取扱手続準則36条**（不動産登記規則36条は会社法人等番号の定め）。
- 第12問オ：要役地の地役権の定めは、教材の「規則104条4項」ではなく、**規則104条6項**（準則67条1項5号が引用する規定）。
- 第17問ウ：合併の制限は、教材の「法56条5項」ではなく、**法56条5号**（56条は項に分かれていない）。
- 第20問オ：調査の委嘱は、教材の「法39条の2第1項」ではなく、**土地家屋調査士法施行規則39条の2第1項**（法39条の2は調査士法人の清算人の規定）。
- 第16問オ：一点鎖線の定めは、準則52条**3項**（2項は点線）。
- 第10問イ：一括申請と代位の条文は、区分建物の所有者が代位する場面では、**法48条3項・4項**で説明できる（教材は52条1項を挙げている）。
- 第7問ウ：教材は「建物図面として備え付ける」と書いていたが、規則11条2項の原文は「**建物所在図**として備え付ける」。
- 第5問ウ：支配人に通知される根拠は、「支配人は法人の法定代理人だから」ではなく、**規則62条1項1号の括弧書き**（支配人その他の法令の規定により代理できる者を含む）。
- 第4問エ：教材は、法定代理人の破産で法定代理人の代理権が消えると説明しているが、結論は不動産登記法17条4号だけで出せるため、記事はその点に立ち入っていない。

教材の誤植として直したもの：第6問・第15問の設問文冒頭の「次の1から5まで」（正しくは「アからオまで」）、第14問・第16問ほかの「減失」（正しくは「滅失」）。
