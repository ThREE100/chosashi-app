# 「間違いノート」補足解説を追加するためのプロンプトテンプレート

すでに公開済みの記事について、「まとめの正誤判定・正解には納得したが、なぜそうなるのか自力ではたどり着けなかった」という特定の肢がある場合に、その肢だけを深掘りする補足解説と、理解を助ける個別インフォグラフィックを追加するためのプロンプトです。令和7年度第1問ア・オで実施した作業（`note-articles/r7-mondai/q01-ishihyouji.md`）を、他の年度・問題・肢にも再現できるよう一般化したものです。

このリポジトリ（`ThREE100/chosashi-app`）を開いた状態、または `note-articles/format-template.md` と `note-articles/infographic-prompt-template.md` の内容をあらかじめ読み込ませた状態で実行するとスムーズです。

---

## プロンプト例

```
{令和◯年度} {午前/午後}の部 第{n}問の肢{ア/イ/ウ/エ/オ等、複数可}について、
この肢が{正しい/誤りである}という結論に自力でたどり着けませんでした。
どのように理解すればわかるようになるか、note-articles/{年度}-mondai/q{n}-*.md
の現在の解説に、分かりにくいポイントの解説を追加してください。
説明に必要な個別のインフォグラフィックのプロンプトも用意してください。

この作業で追加する図解は「間違いノート型」（infographic-prompt-template.md
の「④ 間違いノート型」）とし、②の俯瞰ポスター型のような文字数・条文引用の
制限は設けません。理解度を高めることを最優先し、フローチャート・対比図・
説明文の多い図解など、内容に応じて自由に構成してください。1肢あたりの
画像枚数の制限も設けません。
```

## 手順

1. **対象記事・対象の肢を特定する**：`note-articles/{年度}-mondai/q{n}-*.md` を読み、指定された肢の既存の解説（本文・「たとえば」の具体例）と、まとめの正誤判定を確認する。**正誤判定・正解の組合せ自体は変更しない**（今回の作業は理解を助ける補足の追加であり、内容の訂正ではない）。
2. **なぜ分かりにくいのか、つまずきの構造を特定する**：一般的に、初学者がこの肢の結論に自力でたどり着けない理由は、次のようなパターンに分類できることが多い。
   - **原則と例外の多段構造**：「原則はこう。しかし、条件◯◯を満たせば例外的にこうなる」という条文構造で、原則の部分だけを読んで思考を止めてしまう（例：R7第1問ア＝表意者の重過失で判断を止め、相手方の落ち度という例外条件を見落とす）。
   - **主観要件（善意・悪意・過失の有無）の混同**：「誰の」善意・悪意・過失が、「どの場面」の話なのかを取り違える。特に、似た制度（心裡留保・詐欺・強迫・虚偽表示等）で第三者保護に必要な主観の程度（善意のみで足りるか、無過失まで必要か）が異なる場合に混同しやすい（例：R7第1問オ＝相手方の悪意と第三者の過失を混同する）。
   - **直感に反する結論**：条文の文言どおりに読めば導ける結論だが、常識的な感覚（「悪いことをした側に近い人は保護されないはず」等）と逆に感じられるため、読み流すと誤った方向に納得してしまう。
   - **類似の肢・類似の制度との混同**：同じ記事内の別の肢、または他の年度の類似論点と、要件や結論を取り違えやすい。
   どのパターンに当てはまるかを見極めたうえで、次のステップで解説を組み立てる。
3. **「ここが分かりにくいポイント」を本文に追加する**：対象の肢の既存の「たとえば」の具体例の直後（次の肢の見出しの前）に、`**ここが分かりにくいポイント**：` の段落を追加する。
   - **書式（重要・厳守）**：`**ここが分かりにくいポイント**：` の直後で必ず改行し、説明文はその次の行から書き始める（コロンの後ろに続けて文章を書かない）。
   - まず、読者が陥りやすい誤った思考のルートを具体的に言語化する（「〜と読んだ時点で、〜と考えて、そこで思考を止めてしまいがちです」等）。
   - 次に、正しい判断のステップを明示する。条件が複数段階ある場合は、番号付きの箇条書きで手順化する。
   - 他の肢・他の制度との対比が有効な場合は、箇条書きで要件を並べて比較する（Markdown表は使わない。`note.com`は表を描画できないため）。
   - 結論として、対象の肢がどちらに該当するかを明示的に述べる。
   - です・ます調で統一し、判例・先例の具体的な番号は本文に書かない（`format-template.md`の既存ルールと同じ）。条文番号は書いてよい。
4. **タイトルのキャッチフレーズを見直す**：`## 【土地家屋調査士受験生向け】{年度} 第{n}問〜{キャッチフレーズ}〜` のキャッチフレーズが、今回「分かりにくい」と分かった肢とは別の肢（または論点）を指している場合は、キャッチフレーズの見直しを検討する。読者が実際につまずいた肢は、`format-template.md` が定める「受験者が誤答しやすい傾向にある論点」の何よりも確実な実例であるため、既存のキャッチフレーズより優先して差し替えることが多い。差し替える場合も、25文字以内・他資格名を混ぜない等、`format-template.md` の文字数ルールはそのまま適用する。複数の肢を扱う場合は、それらに共通する論点（例：「誰の主観・落ち度が問題になるかを見誤ると結論が逆転する」）を一言でまとめられないか検討するとよい。
5. **確認事項ブロックに追記する**：`このまま使える点／使う前に確認したい点` ブロックに、「読者から◯肢の結論に自力でたどり着けなかったというフィードバックを受け、分かりにくいポイントの解説を追加した」旨と、追加した解説の要点（何と何を対比したか等）を1〜2文で追記する。タイトルを変更した場合はその旨も一言添える。
6. **個別インフォグラフィックのプロンプトを作成する**：`note-articles/infographic-prompt-template.md` の「④ 間違いノート型」の雛形を使い、対象の肢1つにつき1枚（内容が複雑なら複数枚）のプロンプトを作成する。
   - つまずきの構造に応じて型を選ぶ：多段階の条件判定なら「2段階（多段階）フローチャート型」、他制度との混同なら「対比型」。
   - ②の俯瞰ポスター型と異なり、フローチャートの分岐条件・比較パネルの説明文・条文の引用を、要約せず文章のまま配置してよい。「誤りやすいポイント」のコールアウトボックスに1〜3文程度の説明文を書いてよい。
   - 文字化け・簡体字対策（CRITICAL TEXT REQUIREMENT・Final checkの二重明記、使用する漢字の列挙）は他の型と同様に必ず適用する。
   - 記事ファイルの末尾（既存のインフォグラフィックプロンプトの後）に `## インフォグラフィック プロンプト（{肢}肢・間違いノート）` の見出しを立てて追記する。
7. **保存前の機械チェック**：以下をコマンドで確認してから保存する。
   - コードフェンス（`` ``` ``）の数が偶数であること（開き・閉じの対応が崩れていないか）。
   - コードブロック外に半角括弧 `()` が残っていないこと（`note-articles/format-template.md` の全角括弧ルール。URLとコード表記のみ例外）。
   - Markdown表（`| ... |`）が本文中に残っていないこと。
   - 「ここが分かりにくいポイント：」の直後に改行が入っており、コロンの後ろに文章が続けて書かれていないこと。
8. **mainブランチに直接コミット・push する**：`CLAUDE.md` の運用ルールにより、note-articles配下の更新はmainに一本化されている。作業前に `git pull origin main` で最新化し、コミットメッセージには対象の年度・問題番号・肢と、追加した補足解説の要点（タイトルを変更した場合はその旨も）を明記する。

## 注意点（令和7年度第1問での実施経験から）

- この作業は**内容の訂正ではなく理解の補助**である。既存の解説が事実として誤っていた場合は、この手順ではなく通常の誤り修正として対応し、`qa-checklist.md` に基づく再検証の枠組みで扱う。
- 「分かりにくいポイント」の解説は、条文解釈のプロセス自体を長々と説明するもの（`format-template.md` が禁止する「条文の読み方の解説」）にならないよう注意する。あくまで「読者がどこで判断を誤りやすいか」という**読み手の思考のクセ**に焦点を当てる。
- 同じ記事内の別の肢との対比が使える場合（例：R7第1問オとウの対比）は、積極的に活用する。読者はすでにその肢を読んでいるため、比較の負荷が小さく理解の助けになりやすい。
- 間違いノート型インフォグラフィックは、②の問題全体インフォグラフィックとは別物であり、②の内容やスタイル（俯瞰ポスター・短い結論タグ）を書き換えるものではない。既存の②のセクションはそのまま残し、新しいセクションとして追記する。
- R7第1問では、当初のタイトルのキャッチフレーズがウ（詐欺の第三者保護）を指していたが、読者が実際につまずいたのはア・オだったため、両肢に共通する論点（「誰の落ち度か」を見誤ると結論が逆転する）を捉えたキャッチフレーズに差し替えた。このように、当初のキャッチフレーズ選定時の想定と、実際の読者のつまずきどころが食い違うことは起こりうるため、手順4を必ず確認する。
