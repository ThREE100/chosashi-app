## 【土地家屋調査士】不動産登記法の「数字の図鑑」〜一月・二年・三年・十年…期限と数字は、「何の登記か」と「いつから数えるか」で整理すると覚えやすい〜

**関連：不動産登記法（令和8年6月24日施行分）第3条・第10条・第36条・第37条・第42条・第47条・第49条・第51条・第57条・第58条・第69条の2・第70条・第70条の2・第71条・第76条の2〜第76条の5・第127条・第157条・第159条〜第164条／不動産登記規則第28条・第28条の2**

不動産登記法には、「一月以内」「三年以内」「十万円以下」「三十年間」など、数字がたくさん出てきます。

数字だけを順番に暗記しようとすると、すぐに混ざってしまいます。この記事では、数字を**引き出し**に分けて整理します。どの数字も、次の2つをセットで覚えるのがコツです。

- **何の登記（何の手続）の数字か**
- **いつから数えるか（起算点）**

この記事の目的は、数字を全部覚えることではなく、**不動産登記法にどんな種類の数字があるのか、全体の見取り図をつかむ**ことです。法律の全体の構成は、別の記事「建て付けマップ」で確かめられます。

### まず結論：数字の7つの引き出し

| 引き出し | 代表的な数字 | 一言 |
|---|---|---|
| 表示の登記の申請期限 | 一月以内 | 土地・建物の状況が変わったら一月以内 |
| 権利の登記の申請期限 | 三年以内・二年以内 | 相続は三年、氏名・住所の変更は二年 |
| 過料 | 十万円以下・五万円以下 | 申請を怠ったときの金額 |
| 罰則（刑罰） | 二年以下の拘禁刑・百万円以下の罰金など | 登記識別情報などに関する罪 |
| 時の経過で単独申請できる登記の抹消 | 十年・二十年・三十年 | 年月が経つと、登記権利者が単独で申請できる |
| 保存期間 | 永久〜一年 | 登記所の情報をいつまで保存するか |
| その他の数字 | 四親等内・十個・三日など | 一つずつ別の条文にある |

### 1. 表示の登記は「一月以内」

土地・建物の**表示に関する登記**は、多くが**一月以内**に申請しなければならないと定められています。

ここで大切なのは、「一月」は同じでも、**起算点（いつから数えるか）が登記ごとに違う**ことです。

| 登記 | 土地 | 建物 |
|---|---|---|
| 表題登記 | 第36条：所有権の取得の日から | 第47条第1項：所有権の取得の日から |
| 変更の登記 | 第37条第1項（地目・地積）：変更があった日から | 第51条第1項：変更があった日から |
| 滅失の登記 | 第42条：滅失の日から | 第57条：滅失の日から |
| 合体による登記等 | — | 第49条第1項：合体の日から |
| 共用部分の規約を廃止したとき | — | 第58条第6項：規約の廃止の日から |

**起算点が変わるパターン**

- 変更があった後に表題部所有者や所有権の登記名義人になった人は、**更正の登記または所有権の登記があった日**から一月以内です（土地：第37条第2項、建物：第51条第2項）。
- 共用部分の規約を廃止した後に所有権を取得した人は、**その所有権の取得の日**から一月以内です（第58条第7項）。
- 合体による登記等には、「合体の日」以外にも、持分を取得した日などから数える場合があります（第49条第3項・第4項）。

### 2. 権利の登記の期限は「三年」と「二年」

権利に関する登記には、原則として申請期限の定めはありません。ただし、例外として、期限のある登記が2つあります。

**相続による所有権の移転の登記は、三年以内**（第76条の2）

- 相続により所有権を取得した人は、**自己のために相続の開始があったことを知り、かつ、所有権を取得したことを知った日**から三年以内です（第1項）。相続人に対する遺贈により取得した人も同じです。
- 遺産の分割があったとき、相続分を超えて所有権を取得した人は、**遺産の分割の日**から三年以内です（第2項）。
- 相続人である旨を登記官に申し出た人は（第76条の3第1項）、その期間内に申し出ると、第76条の2第1項の申請義務を履行したものとみなされます（第76条の3第2項）。その後に遺産の分割で所有権を取得したときは、**遺産の分割の日**から三年以内に登記を申請します（同条第4項）。

**所有権の登記名義人の氏名・住所の変更の登記は、二年以内**（第76条の5）

- 氏名若しくは名称または住所について**変更があった日**から二年以内です。

「三年」と「二年」は、**相続は三年、氏名・住所の変更は二年**とセットで覚えると、混ざりにくくなります。

### 3. 怠ったときの金額：過料と罰則

**過料（第164条）**

申請義務のある登記を、正当な理由がないのに怠ったときの金額です。

- 十万円以下の過料：第36条、第37条、第42条、第47条第1項、第49条、第51条、第57条、第58条第6項・第7項、第76条の2、第76条の3第4項などの申請を怠ったとき（第1項）。
- 五万円以下の過料：第76条の5の申請を怠ったとき（第2項）。

つまり、**氏名・住所の変更の登記（第76条の5）だけ、金額が半分の五万円以下**です。

**刑罰（第159条〜第162条）**

過料とは別に、次のような刑罰が定められています。

| 条文 | 行為 | 刑罰 |
|---|---|---|
| 第159条 | 登記識別情報の作成・管理に関する秘密を漏らした | 二年以下の拘禁刑または百万円以下の罰金 |
| 第160条 | 虚偽の登記名義人確認情報を提供した | 二年以下の拘禁刑または五十万円以下の罰金 |
| 第161条 | 不実の記録をさせる目的で登記識別情報を不正に取得した | 二年以下の拘禁刑または五十万円以下の罰金 |
| 第162条 | 登記官の検査などを拒み、妨げた | 三十万円以下の罰金 |

### 4. 年月が経つと、単独で申請できる登記の抹消

権利に関する登記の抹消は、原則として共同申請です。しかし、**一定の年月が経った場合**には、登記権利者が単独で申請できる特則があります。

| 条文 | 場面 | 経過した年月 |
|---|---|---|
| 第69条の2 | 買戻しの特約に関する登記 | 契約の日から**十年**を経過したとき |
| 第70条第4項後段 | 所在不明の相手方がいる場合の先取特権・質権・抵当権の登記 | 被担保債権の弁済期から**二十年**を経過し、その後に被担保債権などの全額に相当する金銭が供託されたとき |
| 第70条の2 | 解散した法人の先取特権・質権・抵当権の登記 | 被担保債権の弁済期から**三十年**を経過し、かつ、法人の解散の日から**三十年**を経過したとき |

「十・二十・三十」と段階があり、それぞれ**条件が違う**ところに注意してください。

### 5. 登記所の保存期間（不動産登記規則第28条・第28条の2）

登記所に保存される情報は、種類によって保存期間が違います。ここでは、主なものを段階別に並べます（全部ではありません）。

| 期間 | 主なもの |
|---|---|
| 永久 | 登記記録（閉鎖登記記録を除く）、地図・地図に準ずる図面、建物所在図（いずれも閉鎖したものを含む）、土地所在図・地積測量図・建物図面・各階平面図（閉鎖していないもの） |
| 五十年 | 土地に関する閉鎖登記記録（閉鎖した日から） |
| 三十年 | 建物に関する閉鎖登記記録（閉鎖した日から）、表示・権利に関する登記の申請情報・添付情報（受付の日から）、閉鎖した土地所在図・地積測量図・建物図面・各階平面図（閉鎖した日から）、地役権図面（閉鎖した日から） |
| 二十年 | 信託目録（信託の登記の抹消をした日から） |
| 十年 | 共同担保目録（記録されているすべての事項を抹消した日から）、受付帳に記録された情報（受付の年の翌年から。登記識別情報に関する証明の請求に係るものは一年）、登記識別情報の失効の申出に関する情報（受付の日から） |
| 五年 | 職権表示登記等事件簿（立件の日から）、法定相続情報一覧図つづり込み帳（作成の年の翌年から） |
| 三年 | 不正登記防止申出書類つづり込み帳、土地価格通知書つづり込み帳など（作成の年の翌年から） |
| 一年 | 登記識別情報通知書交付簿、登記事務日記帳など（作成の年の翌年から） |

**混ざりやすいポイント**：図面は、閉鎖していなければ永久ですが、**閉鎖すると閉鎖した日から三十年**になります。ただし、建物所在図だけは、閉鎖したものも永久です。

条文に散らばっている数字のうち、押さえておきたいものです。

| 数字 | 条文 | 内容 |
|---|---|---|
| 十個 | 第3条 | 登記することができる権利（所有権、地上権、永小作権、地役権、先取特権、質権、抵当権、賃借権、配偶者居住権、採石権） |
| 四親等内 | 第10条 | 登記官の配偶者または四親等内の親族が申請人であるとき、その登記官は当該登記をすることができない |
| 一月以内の期間 | 第71条第1項 | 登記官が職権で登記を抹消する前に、異議を述べる期間として定める |
| 三日以内 | 第157条第2項 | 登記官が審査請求の日から三日以内に、意見を付して事件を送付する |
| 二年 | 第127条第3項 | 筆界調査委員の任期 |

### まとめ：数字の見取り図

- 不動産登記法の数字は、**表示の申請期限・権利の申請期限・過料・罰則・時の経過・保存期間・その他**の7つの引き出しに分けられる。
- 表示の登記は、多くが**一月以内**。ただし**起算点が登記ごとに違う**（取得の日、変更の日、滅失の日、合体の日、規約廃止の日など）。
- 権利の登記は、原則として期限なし。例外が、**相続は三年**、**氏名・住所の変更は二年**。
- 怠ったときは、**十万円以下の過料**。ただし**第76条の5だけは五万円以下**。
- 時の経過で単独申請できる抹消は、**十年（買戻し）・二十年・三十年**で条件が違う。
- 保存期間は、**永久・五十年・三十年・二十年・十年・五年・三年・一年**の階段。図面は閉鎖すると三十年になる。

**学習のすすめ方**

- 数字を単独で覚えず、「何の登記か」「いつから数えるか」とセットにする。
- まず「表示は一月、権利の例外は三年と二年」の軸を固める。保存期間などは、その後で十分です。
