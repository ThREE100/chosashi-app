# 直前復習カード：論点ごとのデータ（parts/<slug>.py）の書き方

復習・チェック扱いの肢を論点ごとに並べ、「誤答の原因」「正しく理解するために必要なこと」「図解カード（インフォグラフィックのプロンプト）」をまとめる作業の手引きです。
データは `parts/<slug>.py` の `P` に書き、`src/build.py <slug>` で記事（`<slug>.md`）と図解プロンプト（`<slug>_prompts.md`）を作り、`src/check_all.py <slug>` で機械チェック（NG 0件）をします。
見本は `parts/f12-tourokumenkyozei.py`（pairs型とtable型を1枚ずつ使っている）。

## 入力

- `work/<slug>_items.json`：その論点の復習対象の肢。各肢に `id`、`statement`（肢の文）、`truth`（バンクの正誤。**これが正**）、`cls`（must＝要復習／check＝チェック）、`history`（○正解・✗誤解・？わからない の履歴）、`wrong_dir`（間違いの向き：正しい記述を×／誤った記述を〇／不明）、`sources`（出典の年度・問と、解説記事 `note_path`）。
- 解説記事 `note_path`（`note-articles/…`）：その肢の結論と理由が書いてある。**結論はこの記事とバンクの `truth` に従う。独自の判断で変えない。**
- 条文の原文は `note-articles/laws/`。条番号・項番号を書くときは、原文で確かめたものだけにする。確かめられない根拠（通達・先例・実務の取扱い）は、そう分かる書き方にする（『先例による』『実務の取扱い』）。

## P の形

```python
P = dict(
    slug="…", title="論点名", law="主な根拠（短く）",
    clusters=[ dict(
        title="グループ名（28字以内）",
        ids=["D0001", …],            # その論点の全肢が、どれか1つのグループに1回だけ入る
        cause="誤答の原因（100〜420字）",
        understand=["正しく理解するために必要なこと（3〜7項目、各130字以内）", …],
        verdicts={"D0001": "その肢の正しい結論（90字以内）", …},   # idsの全肢
        law="根拠条文（短く）",
        cards=[ card, … ],           # 1グループにつき1〜2枚が目安（最大3枚）
    ), …])
```

### 誤答の原因の書き方

- 肢の文・`wrong_dir`・`history` から、**何と何を取り違えているか／どこで疑ったか／知らなかったのか**を、グループ全体としてまとめる。『正しい記述を×にした』は、例外や落とし穴を疑いすぎている傾向、『誤った記述を〇にした』は、もっともらしい文に引かれている傾向、『わからない』は知識の欠落、として読める。
- 個人の回数・肢の番号（Dxxxx）・年度は、原因の文にも理解のポイントにも書かない（肢の番号は `ids` と `verdicts` のキーだけ）。
- 憶測で書かない。肢が複数あるとき、全部に当てはまらない傾向を『どちらも』と書かない。

### カード（図解インフォグラフィックのプロンプトの元データ）

2種類から選ぶ。**画像はプロンプトの文字を描くだけ**なので、文の説明を絵に載せず、短いラベルと絵で伝える。

1. `kind="pairs"`（状況の絵 → 正しいイメージ（青）だけを描く。2026-10-17に、区分建物シリーズに合わせて『正解だけを描く形』に改めた。誤ったイメージの絵は描かない。間違えやすい点は、正しい絵の下に短い文字で添える）。登場人物・土地・建物・手続の流れなど、場面で見せられる論点向き。
```python
dict(kind="pairs", memo="何を見せるカードか（日本語1文）",
     t1="タイトル1行目", t2="タイトル2行目", sub="サブタイトル",   # 各16字以内、サブは28字以内
     state=dict(draw="English description of the situation scene", labels=["短いラベル", …]),
     pairs=[dict(ids=["D…"],
                 claim="この図で示す『正しい内容』を言い切る1文（36字以内。疑問形にしない。『誤』を書かない）",
                 right=dict(draw="English description of the CORRECT picture only", labels=["…"], tag="結論タグ（14字以内、文にしない。『誤』を書かない）"),
                 pitfall="間違えやすい点の短い文（52字以内）。『〜と思いがちですが、実際は〜』の形")])
```
   - 1枚のpairは1〜3組。`wrong` と `stmt` は書かない。1組の `ids` には、同じ内容を確かめる肢を入れる（正しい肢と誤った肢が混ざってもよい。誤った肢のときも、描くのは『正しい内容』）。
   - `draw` は英語。顔のある人は描かず、顔なしのピクトグラムにする。等角図（isometric）のやさしい絵にする。誤りの絵・赤い×は描かない。
2. `kind="table"`（比較表・早見表）。数字・期間・書類・できる／できないの一覧など、並べると分かる論点向き。
```python
dict(kind="table", ids=["D…", …], memo="…", t1="…", t2="…", sub="…",
     cols=["列名", …],                       # 2〜4列
     rows=[["セル", "セル", "@yes"], …],     # 2〜8行。セルは24字以内。"@yes"＝青い丸のマーク、"@no"＝赤い×のマーク（文字なし）
     takeaway="最後の一言（文にしない、20字以内）")
```

### 画像に載せてはいけないもの（機械チェックあり）

- 肢の番号（Dxxxx）、年度、問題番号、『誤答』『復習』『演習』などの個人の演習結果。
- 『決定木』『判定木』『ツリー』（『判定の流れ』と書く）、緑色（肯定は青、否定は赤）。
- 文章の説明。ラベルとタグは名詞・短いフレーズにする。条文の引用や長い文は載せない。

## 作業の進め方

1. `work/<slug>_items.json` を全部読み、肢が使っている概念で、グループに分ける（1グループ2〜10肢が目安）。
2. 各肢の `note_path` の解説記事を読み、正しい結論と理由を確かめる。条番号は `note-articles/laws/` で確かめる。
3. グループごとに、原因・理解のポイント・肢ごとの正しい結論・カードを書く。
4. `python3 note-articles/chokuzen-fukushuu-card/src/build.py <slug>` → `python3 note-articles/chokuzen-fukushuu-card/src/check_all.py <slug>` でNG 0件にする。
5. 生成された `<slug>.md` を読み返し、結論がバンクの truth と一致していること、原因の記述が肢の履歴と矛盾しないことを確かめる。
