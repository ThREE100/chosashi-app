# 直前復習カード（復習・チェック扱いの肢の論点別整理）

一問一答ドリルで『要復習』『チェック』になっている肢（414肢、2026-10-17時点）を論点ごとに並べ直し、論点ごとに **誤答の原因** と **正しく理解するために必要なこと** を整理して、理解を助ける **図解インフォグラフィックのプロンプト** を付けた、直前期の復習資料です。

**個人用の資料です。** 演習の履歴（回数・間違いの向き）を含むので、公開用の記事には使いません。図解のプロンプトの中身（画像に載る文言）には、個人の演習結果・肢の番号・年度は入っていません。画像は生成していません（ChatGPTで生成し、目視で確かめるのはこれからです）。

## 入口

- [00-fukushuu-list.md](00-fukushuu-list.md)：全論点の復習リスト（論点別の一覧。要復習は誤解・未習得の回数が多い順、そのあとにチェック）

## 既存の教材を使う論点

- **区分建物・敷地権・共用部分（54肢）**：全肢が『苦手克服〜区分建物の範囲』シリーズ（`note-articles/joubun-nigate/kubun-tatemono-hani/`、全9回・図解60枚）に入っているため、新しい図解は作らず、肢ごとに既存の回を案内しています。
- **調査士法（3肢）**：総合記事③の図解・4コマ（`note-articles/sokatsu-zukai/03-chousashi-hou/`）と、条文別『苦手克服』（依頼応諾義務）に入っているため、既存教材を案内しています。
- 肢ごとに、すでにある4コマ（`tools/drill/manga/D*_prompt.md`）があれば、各ファイルの復習リストに載せています。

## 図解カードの型

- **pairs型**：『状況の絵 → 正しいイメージ（青）だけ』。誤りの絵は描かず、間違えやすい点を絵の下に短い文字で添えます（区分建物シリーズと同じ形。2026-10-17）。場面で見せられる論点向き。
- **table型**：比較表・早見表。数字・期間・書類・できる／できないの一覧向き。

プロンプトの共通部品（日本語のみ・簡体字禁止・背景の不透明化・青／赤の配色）は、条文別『苦手克服』シリーズの `common/infographic_parts.py` と同じものです。

## 根拠について

結論は、バンクの正誤（`tools/drill/data/items.json` の `truth`）と各肢の解説記事（`note-articles/`）に従っています。条番号は `note-articles/laws/` の原文で確かめたものだけを書き、通達・先例・実務の取扱いなど原文で確かめられないものは、そう分かる書き方にしています（各ファイルの『根拠』『正しい結論』）。解説記事の理由づけが弱い肢や、前提が足りない肢は、結論に注記しています。

## 作り方

- `src/extract.py`：ドリルの記録から復習・チェックの肢を論点ごとに抽出（`work/*_items.json`。個人の演習記録を含む作業用データ）
- `parts/<slug>.py`：論点ごとの元データ（書き方は [AUTHORING.md](AUTHORING.md)）
- `src/build.py <slug>`：論点別の資料（`<slug>.md`）と図解プロンプト（`<slug>_prompts.md`）を生成
- `src/make_list.py`：全論点の復習リスト（`00-fukushuu-list.md`）と、既存教材を案内する論点の資料を生成
- `src/check_all.py`：機械チェック（肢の過不足、正誤の整合、画像に載せてはいけない語、Final checkの漢字リストなど）。現在 NG 0件

復習対象は日々変わります。最新の状態に直すときは、`extract.py` を再実行し、増えた肢を `parts/` のグループに足して `build.py` と `check_all.py` を実行します。
