## 記事の構成

各記事は、タイトル → 出題行 → 問題文の引用 → 導入 → 各肢の解説（ア〜オ。結論・根拠・「たとえば」）→ まとめ → 正解 → 確認事項 → 見出し画像用フレーズ → 総論インフォグラフィックのプロンプト → 見出し画像のプロンプト、の順です。
民法（第1〜3問）は、法律用語を初学者向けに言い換えています。

## 作り方

記事は手で直さず、`src/`のデータを直して再生成します。

- `src/q01.py`〜`q20.py`：各問のデータ（問題文、各肢の解説、まとめ、確認事項、図解のカード、見出し画像の文言）
- `src/build.py`：データから記事を組み立てる（`python3 note-articles/chokuzen-yosou-moshi/src/build.py`）。インフォグラフィックと見出し画像のプロンプトの定型文もここにある
- `src/check_all.py`：機械チェック（タイトル25字以内、敬体、段落の長さ、判例・先例番号が本文にないこと、全角括弧、表の不使用、正解とまとめの整合、正解番号と採点基準の照合、プロンプトの必須文言、見出し画像に数字を入れないこと、など）。現在 NG 0件

## 出題元の記述と現行法の食い違い（要確認）

- **第4問オ（改題）**：出題元は、法定相続情報一覧図の作成者が「署名し、又は記名押印しなければならない」を正しい記述としています。しかし、令和3年4月1日施行の省令改正で、現行の不動産登記規則247条3項1号は作成者について「記名」だけを求めており、署名・押印は要件ではありません。そのままでは、現行法で誤りの記述がイ・ウ・オの3つになり、選択肢に対応する組合せがなくなります。そこで、オを「…記名しなければならない」に改め、正解（3番）を維持しました。タイトルと出題行に「（改）」を付け、記事に改題の注記を入れています。
- **第13問イ**：地下鉄の駅のホームを床面積に算入しない、という結論は、準則82条4号の文言（常時一般に開放されている「通路及び階段」を除く）にホームの記載がないため、条文だけからは導けません。平成17年度第4問（同型の過去問）の整理に合わせて書いています。
- **第5問ア**：「持分の価格の過半数で申請した分筆では、申請人にならなかった共有者の全員に通知する」は、通達（令和5年3月28日民二533号）に基づく結論です。規則183条2項の文言だけを見ると「1人に通知すれば足りる」とも読めるため、通達本文で確認したかったのですが、本作業環境から法務省のサイトに接続できず、未確認です。公開前に通達本文で確かめてください。
