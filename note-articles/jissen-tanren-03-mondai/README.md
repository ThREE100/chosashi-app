## 作業用スクリプト（`src/`）

- `cards.py`：20問分の総論インフォグラフィック（2列・5枚のカード）と見出し画像のデータ。
- `build.py`：各記事の末尾（`## インフォグラフィック プロンプト（問題全体）`以降）を、`cards.py`から作り直します。記事本文は変更しません。`python3 build.py`（全問）／`python3 build.py 3 7`（第3問・第7問のみ）。
- `check.py`：記事20本の機械チェック（タイトル・出典行・引用ブロックの体裁、肢の見出し、「たとえば」の段落、まとめと正解の整合、文体、判例・先例番号の混入、半角括弧、段落の長さ、プロンプトの雛形文言・文字数・漢字リストなど）。`python3 check.py`で「NG 0件」になることを確かめてから使います。

## 使うときの注意

- 問題文は法務省の試験問題ではなく、答練（民間の教材）の出題です。問題文の引用を公開してよいかは、教材の利用条件に照らしてご自身で確認してください。
- 判例・先例（通達）の結論は、提供された教材の記述に基づく肢があります（第2・7・9・10・11・15・19問）。原文をこの環境では確認できていないため、各記事の確認事項ブロックに「未確認」と明記しています。
- `tools/md_to_mt.py`（note用の書き出し）は、法務省の出題年度の行（`**出題年度：…**`）を前提にしているため、この記事群（`**出題：実践答練　第3回　択一式　第n問**`）にはまだ対応していません。書き出しが必要になったら、ツール側を直してから使ってください。
- 図解プロンプトの本文・文言を直したときは、画像の再生成が必要です（`../infographic-prompt-template.md`「図解プロンプトと記事本文の整合チェック」）。
