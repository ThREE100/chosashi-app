## 作り方（再生成の手順）

道具は `tools/drill/sokatsu/` にある（作業フォルダは `/tmp/sokatsu_work/`。`dos/`・`out/` を作る）。

1. `build_dossier.py` … `drill-log` の記録から、要復習・チェックの肢の資料（`dos/all.json`）を作る。
2. `cluster.py` → `mktxt.py`（どちらも `/tmp/sokatsu_work/dos/` で実行）… 担当グループ（章）ごとの資料（`dos/bundle_*.json`・`.txt`）を作る。
3. 章ごとに執筆（`BRIEF.md` の指示で、担当を分けて並列に書かせた）。出力は `out/<章>.md` と `out/<章>_tags.json`（原因の型）。
4. `check_cov.py <章>` … 全肢の網羅・重複・正誤の一致・体裁（表・番号系・半角括弧）を確認する。
5. `assemble.py` … 導入・型の集計・串刺し・付録を足して3本に組み立てる。
6. `postprocess.py` … 読みやすさを整える（見出し・ラベル・段落の間に空行を入れる、`**結論**：…` のようなラベルを単独の行にする、長い段落を文の区切りで125字以内に分ける、`1)` の並びを番号つきリストにする）。あわせて民法編を章ごとに分けた3本（`sokatsu-01-minpou-ch1〜3.md`）を作る。文字の増減がないことを内部で確かめる。
7. `split_fudousan.py` … 不動産登記法編を章ごとの9本に分割し、総合記事を入り口とまとめに再構成する（2026-10-13に1回だけ実行。入力は分割前の総合記事で、分割後の総合記事には章の本文がないので再実行はできない）。これ以後に `assemble.py` を再実行すると分割前の1本で上書きされるので、再生成するときは出力を別の場所に出し、章の本文だけを差し替えること。
