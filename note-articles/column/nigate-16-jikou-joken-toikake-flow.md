## 【土地家屋調査士受験生向け】何度も同じところで間違える人へ〜苦手分析シリーズ⑯取得時効は「いつ見るか」、時効の猶予・更新と条件を問いの型で解く〜

**対象条文：民法127条（条件成就の効果）・130条（条件成就の妨害）・131条（既成条件）・132条（不法条件）・134条（随意条件）・145条（時効の援用）・147条（裁判上の請求等）・150条（催告）・152条（承認）・162条（所有権の取得時効）・163条（所有権以外の財産権の取得時効）・177条（不動産の対抗要件）・186条（占有の推定）・187条（占有の承継）**

この記事は、これまでの解答結果を分野別に振り返ったときに「同じ論点で何度も間違えている」と判明した分野を整理し直す苦手分析シリーズの第16回です。今回は、時効と条件を取り上げます。時効については、⑧（時効の援用）と⑨（時効の成立と進行）で扱い済みの内容を、「いつの時点で何を見るか」という切り口で補強します。条件は、このシリーズで初めて扱います。

きっかけは、一問一答ドリルの1問です。「Bは、甲土地を無権利者から買い受け、自己の所有物であると過失なく信じ、平穏かつ公然に占有を始めたが、10年が経過する前に、甲土地がAの所有物であることを知った。この場合、占有の開始から10年間占有を継続しても、時効によって取得することはできない」という記述が、平成25年度 第2問 ウで出題されています。

答えは誤りです。10年の短期の取得時効に必要な善意・無過失は、占有を開始した時に備わっていれば足ります。途中で悪意になっても、10年で取得できます。ところが、同じ問の5肢をすべて、逆に答えてしまいました。

ドリルの答え合わせでは、時効と条件の35肢のうち、定着が50%、誤解（逆に覚えている）が38%、未習得が12%でした。誤解は、取得時効の要件、取得時効と登記、時効の完成猶予・更新に集中していました。共通するのは、「どの時点の事情を見るのか」と「相手は誰か」を決めずに、感覚で答えを出していることです。

この記事では、条文の細かい説明よりも、**問題文を読んだあとに何を、どの順番で確認するか**に絞って整理します。令和2年4月1日施行の民法（債権関係）改正のあとの、現行の条文で書いています。

### 最初の一手：問いの最後の一文で「型」を決める

- **型A「取得時効が成立するのは、いつの時点の事情までか」と聞かれている**：手順1で判定します。
- **型B「取得時効を主張するのに、登記は要るか」と聞かれている**：手順2で判定します。
- **型C「時効は完成するか、援用できるか」と聞かれている**：手順3で判定します。
- **型D「条件が付いた契約は、どうなるか」と聞かれている**：手順4で判定します。

時効の問題では、問題文に出てくる日付や人物が多く、どこを見ればよいのか分からなくなります。そこで、次の2つを先に決めます。

1. **時間軸を1本引く**：占有の開始、承継、第三者の登場、時効の完成、援用の順に、点を打ちます。
2. **点ごとに、見るものを決める**：善意・無過失は開始の点だけ、平穏・公然は線全体、登記は完成の前か後か、という具合に分けます。

### 手順1：取得時効は、「開始時の一点」と「期間を通じて」を分けて見る

取得時効が成立するかを聞かれたら、次の順に確認します。

1. **途中で、所有の意思・平穏・公然のどれかが欠けたか**：欠けた占有では成立しません。たとえば、10年の途中で、占有が隠匿のものになったときは、占有の開始から10年間占有を継続しても、取得できません（平成25年度 イ）。
2. **20年以上続いたか**：善意・悪意や、過失の有無を問わず、成立します（162条1項）。他人の物だと知って買い受けた人も、20年占有すれば取得できます（令和2年度 イ）。
3. **10年以上で、開始時に善意かつ無過失だったか**：成立します（162条2項）。**途中で悪意になっても、成立します**（平成25年度 ウ）。無過失は推定されないので、時効を主張する側が示す必要があります（186条。令和2年度 エ）。
4. **占有を承継したか**：承継人は、自己の占有のみを主張することも、前の占有者の占有を併せて主張することもできます（187条1項）。併せて主張するときは、善意・無過失を**最初の占有者**で判断します（同条2項。平成25年度 エ・オ）。相続人は、被相続人が所有の意思なく占有していたときでも、新たに所有の意思をもって占有を始めれば、自己の占有のみを主張して取得できます（令和2年度 ア）。

**たとえば**、善意無過失のBが3年占有し、事情を知っているCに売って、Cがさらに7年占有したとします。Cが前の占有を併せて主張すれば、最初のBが善意無過失なので、10年で成立します（平成25年度 エ）。逆に、悪意のBが4年占有し、善意無過失のCが6年占有したとき、併せて主張しても、最初のBが悪意なので、10年の短期では成立しません（平成25年度 オ）。

賃借権のように、所有権以外の財産権も、20年（善意無過失なら10年）の取得時効にかかります（163条）。無権利者から借りた場合でも、賃借の意思で平穏かつ公然に使い続ければ、取得できます（平成25年度 ア）。ただし、賃借権が対抗要件を備える前に、土地に抵当権が登記されたときは、その後に時効の期間が経過しても、抵当権の実行による買受人には対抗できません（令和2年度 ウ）。

### 手順2：取得時効と登記は、「相手」と「完成の前か後か」で見る

時効取得を主張する相手に、登記が要るかを聞かれたら、次の順に確認します。

1. **相手は、元の所有者（当事者）か**：登記なしで主張できます（平成21年度 ウ）。
2. **相手は、時効の完成前に現れた第三者か**：登記なしで主張できます（平成21年度 ア）。
3. **相手は、時効の完成後に現れた第三者か**：登記がなければ、対抗できません（平成21年度 イ）。二重譲渡と同じ対抗関係になるからです。
4. **起算点を選んでいないか**：起算点は、占有を開始した時に固定されます。時効を主張する人が、起算点を任意に選んで、完成の時期を早めたり遅らせたりすることはできません（平成21年度 エ、令和2年度 オ）。

善意無過失で占有を始めた人が、20年の取得時効を主張することもできます（平成21年度 オ）。

**たとえば**、Aが平成2年1月1日に、過失なく自分の土地だと信じて占有を始めたとします。10年で時効が完成するのは、平成12年1月1日です。平成10年にCが元の所有者から買ったなら、完成前の第三者なので、Aは登記なしで主張できます。平成13年にCが買ったなら、完成後の第三者なので、先に登記をしたほうが勝ちます。

### 手順3：時効の猶予・更新・援用は、「事由ごとに待つか、やり直すか」を見る

時効の完成や援用を聞かれたら、次の順に確認します。

1. **時効の完成後に、債務を承認したか**：完成を知らなくても、援用できなくなります（平成23年度 オ、平成28年度 オ）。
2. **確定判決で権利が確定したか**：事由が終了した時から、新たに進行します（更新。147条2項。平成28年度 イ）。
3. **訴えが、権利が確定せずに取り下げられたか**：終了の時から6か月を経過するまで、時効は完成しません（完成猶予。147条1項かっこ書。平成28年度 ウ）。
4. **承認（一部弁済を含む）があったか**：その時から、新たに進行します（更新。152条1項）。一部弁済は、残りの債務についても承認にあたります（平成28年度 エ）。
5. **催告があったか**：その時から6か月は完成しません。猶予されている間にした再度の催告には、猶予の効力はありません（150条。平成28年度 ア）。

援用できる人も、問われます（平成23年度）。保証人は、主債務の時効を援用できます（145条）。自分の保証債務を、時効の完成前に承認していても同じです（ア）。後順位の抵当権者は、先順位の抵当権の被担保債権の時効を援用できません（イ）。建物の賃借人は、土地の取得時効を援用できません（ウ）。共同相続人の一人は、自己の相続分の範囲でのみ援用できます（エ）。

**たとえば**、貸金の返済が遅れている債務者が、時効の完成前に5万円だけ返したとします。一部弁済は承認にあたるので、その時から時効は新たに進行します。時効の完成の後に承認したときは、完成を知らなくても援用できなくなります。

### 手順4：条件は、「条文を順に当てはめて」見る

条件を付けた法律行為を聞かれたら、次の順に確認します。

1. **成就した時以前にさかのぼらせる合意があるか**：その合意に従います（127条3項）。たとえば、「優勝したら、4月分からさかのぼって奨学金を給付する」と合意したなら、優勝後に4月分から請求できます（平成19年度 ア）。
2. **停止条件が、契約の時に既に成就していたか**：無条件で有効です（131条1項。平成19年度 イ）。
3. **条件自体が不法か**：契約全体が無効です。条件だけを外して有効になることはありません（132条。平成19年度 ウ）。
4. **停止条件が、債務者の意思のみに係るか**：無効です（134条）。解除条件は、無効になりません（平成19年度 エ）。
5. **解除条件が成就したか**：成就した時から効力を失います。当事者が成就を知らなくても同じです（127条2項。平成24年度 オ）。
6. **成就で不利益を受ける者が、故意に成就を妨げたか**：相手方は、成就したものとみなせます（130条1項。平成19年度 オ）。ただし、農地の売買の農業委員会の許可のように、行政庁の処分は、みなす規定で作り出せません（平成24年度 ア）。

周辺の論点も、出題されています。条件付きの贈与契約でも、条件付所有権移転の仮登記ができます（不動産登記法105条2号。平成24年度 ウ）。「2週間以内に払わなければ解除する」という催告と一体の条件付き解除は、有効です（平成24年度 イ）。条件の成就前は、確定した損害賠償請求権までは生じません（平成24年度 エ）。

**たとえば**、「Aが大学で進級できなかったら、Bは奨学金を、その後は払わない」と約束したとします。Aが進級できなかった時点で、Bがその事実をまだ知らなくても、Bの支払義務は、その時から消えます。

### まとめ

- **型A（取得時効の要件）**：善意無過失は開始時だけ。所有の意思・平穏・公然は期間を通じて。承継を併せて主張するなら、善意無過失は最初の占有者で見る。無過失は推定されない。
- **型B（取得時効と登記）**：元の所有者と完成前の第三者には登記なし。完成後の第三者には登記が必要。起算点は動かせない。
- **型C（猶予・更新・援用）**：完成後の承認は援用できない。確定判決と承認は更新。催告と取下げは完成猶予。保証人は援用できる。
- **型D（条件）**：遡及の合意は合意どおり。既成の停止条件は無条件。不法条件は全体が無効。解除条件の成就は知らなくても効力を生じる。故意の妨害は成就したものとみなせる。

迷ったら、この順に確認してください。①時間軸を1本引く。②点ごとに、見るものを決める（善意無過失は開始時、平穏・公然は期間中、登記は完成の前か後か）。③事由ごとに、待つか、やり直すかを決める。④条件は、遡及の合意、既成、不法、随意、成就の順に条文を当てはめる。

途中で他人の土地だと知っても、10年の時効は成り立つの。始めた時にまじめだったなら、あとで知ったからって、台無しにはならないの」

### 型D：条件は、「条文を順に当てはめる」

**藍子**  
「条件って、停止条件と解除条件があって、何が何だか分かりません。『優勝したら、4月分からさかのぼって奨学金』と約束したとき、停止条件は成就した時から効力が生じるから、4月分は請求できないですよね？」

**トリ先生**  
「原則だけ覚えて、例外を見落とす病。停止条件は、成就した時から効力が生じる（127条1項）。でも、当事者が、成就する前までさかのぼらせると約束したなら、その約束が優先するの（同条3項）。この問題は、『4月分からさかのぼって』と書いてあるでしょ。約束そのものよ。だから、4月分から請求できる」

**藍子**  
「解除条件はどうですか？ たとえば、進級できなかったら奨学金を払わない、という約束で、進級できなかったことを、払う側がまだ知らなかったら、払い続けるんじゃないですか？」

**トリ先生**  
「知らなくても、成就した時から効力を失うの（127条2項）。条件が成就したかどうかは、当事者が知っているかどうかとは関係なく、客観的な事実で決まるのよ。進級できなかった日から、払う義務は消える。知らなくて払い続けてしまったお金の扱いは、別の話」

**藍子**  
「ほかの条文も、混ざります。既成条件とか、不法条件とか」

**トリ先生**  
「順に当てはめなさい。契約の時に、停止条件の事実が、もう起きていた。既成の停止条件は、無条件。有効（131条1項）。

条件が不法、たとえば『境界標を、隣地の人に黙って動かしたら50万円あげる』。これは、不法な条件を付けた法律行為だから、契約全体が無効（132条）。条件だけ外して有効、にはならない。

あと、停止条件が、債務者の気持ち次第だけの場合は、無効（134条）。ただし、解除条件なら無効にならない。『気が変わったら効力を失う』という贈与は、有効なのよ」

**藍子**  
「条件の成就を、わざと妨げた人は？」

**トリ先生**  
「7日以内に修理が終わったら割増料金、という契約で、払いたくない側が、相手の道具をわざと壊した。成就で不利益を受ける人が、故意に成就を妨げた。相手は、成就したものとみなせるの（130条1項）。

ただ、農地の売買で、農業委員会の許可が条件のとき、売主が妨害して許可が出なかったとしても、買主は、許可が出たことにはできないわ。許可は行政の処分だから、みなす規定でも作り出せないのよ」
