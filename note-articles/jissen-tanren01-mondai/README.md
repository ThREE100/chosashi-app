# 実践答練 第1回（択一式 第1問〜第20問）解説記事

アガルートアカデミー土地家屋調査士講座「実践答練 第1回」の択一式（問1〜問20）を、`format-template.md` の型で、初学者向けに具体例つきで解説した記事です。1問1ファイル（`q01-*.md`〜`q20-*.md`）で、ほかの年度（`r7-mondai/` など）の記事と同じ構成です。

## 情報源と作り方

- **問題文・正解番号**：ユーザーから提供された答練のPDF（92ページ。タブレット画面の撮影画像）を目で読んで転記しました。正解番号は採点基準（PDF3ページ）の正解表と照合しています（問1:3、問2:3、問3:5、問4:5、問5:4、問6:4、問7:3、問8:3、問9:1、問10:3、問11:2、問12:3、問13:5、問14:4、問15:3、問16:5、問17:4、問18:3、問19:5、問20:2）。
- **解説文**：PDFの解答解説の結論（各肢の○×）は参考にしましたが、文章はそのまま使わず、自分の言葉で書いています。
- **条文の確認**：`note-articles/laws/` のローカル法令データベース（令和8年5月21日施行の不動産登記規則など現行版）の原文と、肢ごとに突き合わせました。同データベースに収録がない通達・先例・土地区画整理登記令／規則は、e-Gov法令検索にも接続できなかったため、原文を確認できていません。各記事の「確認事項」ブロックに、確認できた根拠とできなかった根拠を分けて書いています。
- **判例・先例・通達の番号**：本文には書かず、確認事項ブロックにだけ記載しています（`format-template.md` のルール）。
- **過去問との照合**：`tools/drill/data/items.json`（過去問2,100肢の一問一答バンク）で、各肢と似た過去問の肢を検索し、○×の結論が矛盾しないことを確かめました。

## 注意点（PDFの記載と本記事の違い）

- 問14の設問文は、PDFでは「次の1から5までの記述」と印刷されていますが、選択肢の記号がア〜オなので誤植と判断し、「次のアからオまでの記述」として引用しています。
- 問18の学生の発言アは、PDFでは「筆界を必要とする理由が」と印刷されていますが、「筆界特定を必要とする理由が」の誤植と判断しています。
- 解答解説PDFが示す条文の項・号が、現行条文と違う箇所があります（問2オの「251条1項」→過半数で決めるのは252条1項、問4オの「28条9項」→9号、問14ウの「35条3項」→3号、問20ウ・オの「15条1項3号」→現行は4号）。本記事は現行条文で書いています。
- 問8ウは、規則183条1項1号の「更正前の表題部所有者」に持分が変わらない共有者が含まれるかが条文の文言だけでは明確でなく、解答解説の考え方（持分が更正される共有者が対象）に従っています。

## 著作権についての注意

問題文は予備校（アガルートアカデミー）の答練問題を、PDFから転記して引用しています。noteなどで公開する場合は、問題文の引用が権利者の許諾の範囲に収まるかを、公開前にご確認ください。解説文は自分の言葉で書き直していますが、問題文そのものを載せない形（出題の趣旨だけを書くなど）に直すこともできます。

## 生成・点検の仕組み（`src/`）

- `src/prompts_data.py`：見出し画像とインフォグラフィックのカード（見出し・図解・結論タグ）の元データ。記事のまとめ・各肢の解説（正しい結論）に合わせてあります。
- `src/gen_prompts.py`：元データから、各記事の末尾（「## 見出し画像プロンプト」以降）を作り直します（`python3 -I src/gen_prompts.py`）。Final checkの注意漢字は、そのプロンプトに実際に出てくる漢字から自動で選びます。
- `src/check_articles.py`：形式の機械チェック（タイトル25字以内、引用ブロックの形式、見出し構造、まとめの正誤と正解表の整合、正解の先出し禁止、半角括弧、先例番号の混入、プロンプトの必須文言など）。`python3 -I src/check_articles.py` でNG 0件を確認します。
