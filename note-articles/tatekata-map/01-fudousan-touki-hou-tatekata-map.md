## 【土地家屋調査士】不動産登記法の「建て付け」マップ〜164条を8つの棚で眺めると、全体像と押さえどころが見えてくる〜

**関連：不動産登記法 第1条〜第164条（令和8年6月24日施行分）／本則は枝番号を含めて175条**

不動産登記法は、本則だけで164条（枝番号を含めて175条）あります。第1条から順に読み始めると、「いま、全体のどこを読んでいるのか」が分からなくなり、途中で嫌になってしまう人も多いはずです。

でも、この法律は、**8つの棚**に分けて眺めることができます。

この記事の目的は、条文を覚えることではありません。

- 不動産登記法が、**どんな構成**になっているのか
- 学習で**押さえるべきポイント**はどこか

この2つを先に知って、学習へのハードルを下げることです。初めて不動産登記法に触れる方は、まずこの記事で全体像をつかんでから、各条文に進んでください。

### まず結論：8つの棚

| 棚の名前 | 条文 | 一言 |
|---|---|---|
| 土台 | 第1条〜第5条 | 目的・言葉の定義・登記できる権利・順位・第三者 |
| 担い手 | 第6条〜第10条 | 登記所と登記官 |
| 記録 | 第11条〜第15条 | 登記簿・登記記録（表題部と権利部）・地図 |
| 共通手続 | 第16条〜第26条 | 申請と嘱託・受付・順序・識別情報・却下 |
| 表示 | 第27条〜第58条 | 土地と建物の状況の登記 |
| 権利 | 第59条〜第118条 | 所有権・抵当権などの権利の登記 |
| 確かめる | 第119条〜第150条 | 証明書の交付、筆界特定 |
| 周辺 | 第151条〜第164条 | 雑則と罰則（過料） |

このうち、条文の数が多いのは**表示**（第27条〜第58条）と**権利**（第59条〜第118条）の2つの棚です。この2つの違いが分かれば、法律全体の見通しがかなりよくなります。

### 土台の言葉：登記は2種類、帳簿は1冊

地図を読むために、最初に覚える言葉は3つです（第2条）。

- **表示に関する登記**：不動産の表示に関する登記（第2条第3号）。土地や建物が「どこにあって、どんな状況か」を記録する。
- **権利に関する登記**：不動産についての所有権・抵当権などの権利に関する登記（第2条第4号）。
- **登記記録**：表示に関する登記または権利に関する登記について、**一筆の土地または一個の建物ごと**に作成される電磁的記録（第2条第5号、第12条）。

登記記録は**表題部**と**権利部**に区分して作成します（第12条）。表題部には表示に関する登記が、権利部には権利に関する登記が記録されます（第2条第7号・第8号）。登記は、登記官が登記簿に登記事項を記録することによって行います（第11条）。

つまり、**表示に関する登記は表題部に、権利に関する登記は権利部に**入る、という対応です。

> 📷 **画像挿入：図2（登記簿・登記記録・表題部と権利部）**

登記できる権利は、第3条が10個を列挙しています。所有権、地上権、永小作権、地役権、先取特権、質権、抵当権、賃借権、配偶者居住権、採石権です。同じ不動産について登記した権利の順位は、法令に別段の定めがある場合を除き、**登記の前後**で決まります（第4条第1項）。

### 登記ができあがるまで：共通手続の棚

表示でも権利でも通る、共通の手続が第16条〜第26条にまとまっています。流れを追うと次のとおりです。

1. **申請または嘱託**：登記は、法令に別段の定めがある場合を除き、当事者の申請または官庁若しくは公署の嘱託がなければ、することができません（第16条第1項）。申請は、電子情報処理組織を使う方法か、書面を提出する方法のどちらかで行います（第18条）。
2. **受付**：登記官は、申請情報が提供されたら受付をします（第19条第1項）。
3. **審査**：登記官は、申請を却下すべき場合には、理由を付した決定で却下します（第25条）。表示に関する登記では、必要があるときに登記官が調査をします（第29条）。
4. **登記**：登記官が登記簿に記録します（第11条）。権利に関する登記は、同一の不動産の申請が二以上あるときは、受付番号の順序に従って登記します（第20条）。
5. **通知**：申請人自らが登記名義人となる場合は、登記完了後に登記識別情報を通知します（第21条）。

### 表示の棚の中身：土地と建物

表示の棚（第27条〜第58条）は、3つに分かれています。

- 通則（第27条〜第33条）
- 土地の表示に関する登記（第34条〜第43条）
- 建物の表示に関する登記（第44条〜第58条）

土地には、地番・地目・地積（第34条第1項）、建物には、家屋番号・種類・構造・床面積など（第44条第1項）が登記事項として定められています。

代表的な登記を、土地と建物で並べます。

| 登記 | 土地 | 建物 |
|---|---|---|
| 表題登記 | 第36条 | 第47条 |
| 変更の登記 | 第37条（地目・地積） | 第51条 |
| 更正の登記 | 第38条 | 第53条 |
| 分筆・合筆／分割・区分・合併 | 第39条（分筆・合筆） | 第54条（分割・区分・合併） |
| 合筆・合併の制限 | 第41条 | 第56条 |
| 滅失の登記 | 第42条 | 第57条 |

> 📷 **画像挿入：図4（表示の棚の中身）**

ここで見逃せないのが、**期限**です。土地の表題登記（第36条）、地目・地積の変更の登記（第37条第1項）、土地の滅失の登記（第42条）、建物の表題登記（第47条第1項）、建物の表題部の変更の登記（第51条第1項）、建物の滅失の登記（第57条）は、いずれも**一月以内**に申請しなければならないと定められています。

正当な理由がないのに怠ると、第164条により**十万円以下の過料**に処せられます。

もう一つの特徴は、**職権**です。表示に関する登記は、登記官が職権ですることができます（第28条）。

### 権利の棚の中身：8つの款

権利の棚（第59条〜第118条）は、「款」で分かれています。

| 款 | 条文 |
|---|---|
| 通則 | 第59条〜第73条 |
| 所有権に関する登記 | 第73条の2〜第77条 |
| 用益権に関する登記 | 第78条〜第82条 |
| 担保権等に関する登記 | 第83条〜第96条 |
| 信託に関する登記 | 第97条〜第104条の2 |
| 仮登記 | 第105条〜第110条 |
| 仮処分に関する登記 | 第111条〜第114条 |
| 官庁又は公署が関与する登記等 | 第115条〜第118条 |

通則では、権利に関する登記の登記事項（第59条）、**共同申請**（第60条）、登記原因を証する情報の提供（第61条）が定められています。所有権の登記は、「所有権に関する登記」の款で、保存の登記（第74条）などが定められています。

### 表示と権利の違い

2つの棚の違いを、対比してみます。

| 項目 | 表示に関する登記 | 権利に関する登記 |
|---|---|---|
| 記録される場所 | 表題部 | 権利部 |
| 何を登記するか | 不動産の物理的な状況 | 不動産についての権利 |
| 申請の仕方 | 申請人は、表題部所有者または所有権の登記名義人など | 原則として**共同申請**（登記権利者と登記義務者。第60条） |
| 職権 | 登記官が職権でできる（第28条） | 原則として当事者の申請または嘱託が必要（第16条第1項） |
| 期限 | 多くが**一月以内**（第36条、第37条、第42条、第47条、第51条、第57条など） | 原則として定めなし。ただし相続による所有権移転の登記（第76条の2）は3年以内、所有権の登記名義人の氏名等の変更の登記（第76条の5）は2年以内 |
| 順位 | 順位の条文（第4条）は「権利の順位」であり、表示の登記には当てはまらない | **登記の前後**で決まる（第4条第1項） |

> 📷 **画像挿入：図6（表示と権利の対比）**

「期限」の行は、権利にも期限のある登記があることに注意してください。相続による所有権の移転の登記は、自己のために相続の開始があったことを知り、かつ、所有権を取得したことを知った日から**3年以内**（第76条の2第1項）。所有権の登記名義人の氏名若しくは名称または住所の変更の登記は、変更があった日から**2年以内**（第76条の5）に申請しなければなりません。

### 確かめる棚と周辺の棚

最後の2つの棚です。

**確かめる棚（第119条〜第150条）**には、2つのまとまりがあります。

- **証明・図面の交付**（第五章、第119条〜第122条）：何人も、手数料を納付して、登記事項証明書の交付を請求できます（第119条第1項）。地図、建物所在図、地図に準ずる図面の写しの交付も請求できます（第120条）。
- **筆界特定**（第六章、第123条〜第150条）：筆界の現地における位置を特定する制度です（第123条第2号）。筆界とは、表題登記がある一筆の土地とこれに隣接する他の土地との間において、その一筆の土地が登記された時にその境を構成するものとされた線をいいます（第123条第1号）。

**周辺の棚（第151条〜第164条）**は、雑則（第七章、第151条〜第158条）と罰則（第八章、第159条〜第164条）です。第164条の過料は、申請義務のある登記を怠ったときの制裁です。

### まとめ：全体像と、押さえるべきポイント

**全体像**

- 不動産登記法は、**土台・担い手・記録・共通手続・表示・権利・確かめる・周辺**の8つの棚でできている。
- 前半の「土台・担い手・記録」は、法律の前提（言葉の定義、登記所と登記官、登記簿のつくり）。
- 本体は、**表示**（第27条〜第58条）と**権利**（第59条〜第118条）の2つの棚。条文の数も、この2つに集中している。
- 登記は2種類。**表示に関する登記は表題部に、権利に関する登記は権利部に**記録される。これがすべての出発点。

**押さえるべきポイント**

1. **表示と権利の2本柱を区別する。** 何を登記するのか（状況か、権利か）、記録される場所（表題部か、権利部か）が違う。
2. **申請の入口は共通。** 申請または嘱託→受付→審査→登記→通知の流れは、表示でも権利でも同じ（共通手続の棚）。
3. **表示の登記は、期限と職権に注意。** 多くが**一月以内**の申請義務で、怠ると**十万円以下の過料**（第164条）。登記官が**職権**でもできる。
4. **権利の登記は、共同申請と順位に注意。** 原則として**共同申請**、順位は**登記の前後**で決まる。ただし、相続（3年以内）と氏名・住所の変更（2年以内）には期限がある。

**学習のすすめ方**

- 迷ったら、「いま読んでいるのは、どの棚か」に戻る。
- 順番は、まず全体像（この記事）→**表示**の棚→**権利**の棚。細かい条文は、その後でよい。
