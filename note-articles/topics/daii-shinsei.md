## 【土地家屋調査士受験生向け】代位申請、できる場合とできない場合を全部整理する

**対象条文：民法第423条・第423条の7、不動産登記法第59条7号・第99条・第43条4項、不動産登記令第7条1項3号・別表、登録免許税法第4条・第5条1号**

表示に関する登記の分野では、ほぼ毎年のように「登記の代位申請」というテーマで、複数の場面を並べて代位の可否を問う組合せ問題が出題されます（令和6年度第11問、令和元年度第14問、平成27年度第11問、平成23年度第11問など）。この分野は場面ごとの丸暗記になりがちですが、「代位しなければ自分の権利が実現・保全されないか」という一点に立ち返って考えると、初見の事案でも判断がぶれにくくなります。

### 代位とはそもそも何か（民法423条）

民法423条1項は、代位の基本要件を次のように定めています。

> 債権者は、自己の債権を保全するため必要があるときは、債務者に属する権利（以下「被代位権利」という。）を行使することができる。ただし、債務者の一身に専属する権利及び差押えを禁じられた権利は、この限りでない。

2項では期限未到来の権利は原則行使できないこと（保存行為は例外）、3項では強制執行により実現できない債権では行使できないことが定められています。表示に関する登記の代位では「その登記をしないと自分の登記申請権・登記請求権が実現できない関係にあるか」（保全の必要性）が判断の中心になります。

さらに、2020年施行の民法改正で新設された423条の7は、登記請求権の保全のための代位を正面から定めています。

> 登記又は登録をしなければ権利の得喪及び変更を第三者に対抗することができない財産を譲り受けた者は、その譲渡人が第三者に対して有する登記手続又は登録手続をすべきことを請求する権利を行使しないときは、その権利を行使することができる。この場合においては、前三条の規定を準用する。

これは、たとえば土地・建物を買い受けた者が、その前主（さらに前の所有者）に代わって表題登記を申請する、といった典型場面をまさに想定した条文です。

**なお**、金銭債権の保全を目的とする代位（いわゆる本来型）では債務者の無資力が要件とされますが、登記請求権のような特定物債権の保全を目的とする代位（いわゆる転用型）では、判例・通説上、債務者の無資力は要件とされないと理解されています。この無資力不要の点は民法423条の条文自体には明記されておらず、判例の積み重ねによる解釈です（後掲の確認ブロックで詳しく述べます）。

### 不動産登記の手続で「代位」が具体的にどう現れるか

不動産登記法・令・規則のうち、「代位」という語を用いて具体的な手続を定めている条文は、確認できた範囲で次のとおりです。

- **不動産登記法第59条7号**：権利に関する登記の登記事項として「民法第四百二十三条その他の法令の規定により他人に代わって登記を申請した者（以下「代位者」という。）があるときは、当該代位者の氏名又は名称及び住所並びに代位原因」を挙げています。代位申請があったこと自体が登記記録に残る仕組みです。
- **不動産登記令第7条1項3号**：「民法第四百二十三条その他の法令の規定により他人に代わって登記を申請するときは、代位原因を証する情報」を提供しなければならないと定めています。
- **不動産登記法第99条**：信託の登記について「受益者又は委託者は、受託者に代わって信託の登記を申請することができる」と定め、代位による信託登記の申請を明文で認めています。
- **不動産登記法第43条4項**：河川区域内の土地となった旨（またはそうでなくなった旨）の登記を河川管理者が嘱託する場合において、「土地の一部について前二項の規定により登記の嘱託をするときは、河川管理者は、当該土地の表題部所有者若しくは所有権の登記名義人又はこれらの者の相続人その他の一般承継人に代わって、当該土地の分筆の登記を登記所に嘱託することができる」と定めています。これも実質的に代位型の嘱託です。

これら以外の場面（買主が売主に代位して表題登記を申請する、共有者の一人が他の共有者に代位して分筆登記を申請する等）は、民法423条（および423条の7）を直接の根拠として認められているもので、不動産登記法側に個別の授権規定があるわけではありません。

### たとえば、こんな場面で代位が使われる

**たとえば**、土地を買い受けたものの、まだ表題登記がされていない場合、売主（前の所有者）が表題登記を申請してくれないと、買主は自分名義の登記に進めません。このとき買主は、民法423条の7に基づき、売主に代位して表題登記を申請することができます。

**たとえば**、マンションの分譲会社（原始取得者）が表題登記をしないまま部屋を転々売却し、最終的に購入した人が困っているとします。この場合、その転得者は、分譲会社に代位して、分譲会社を表題部所有者とする区分建物の表題登記を申請することができます。区分建物の転得者には表題登記の申請義務自体がないため、原始取得者に代位する形をとる必要があります。

**たとえば**、田中さんが所有する建物の附属建物（物置）だけを鈴木さんが買い受けたのに、田中さんが建物の分割登記に協力してくれないとします。この場合、鈴木さんは田中さんに代位して、まず物置部分を独立した建物として分割する登記を申請することができます。

**たとえば**、共有物分割の確定判決や裁判上の和解が成立したのに、共有者の一人が分筆登記の申請に協力しないとします。この場合、もう一方の共有者は、確定判決の正本（または和解調書）を代位原因を証する情報として提供し、非協力の共有者に代位して分筆登記を単独で申請することができます。

**たとえば**、洪水で川の流れが変わり、これまで畑だった土地の一部が新しく河川区域に組み込まれてしまった場合、その土地の持ち主が何もしなくても、河川管理者が代わりに分筆登記の嘱託手続を進めることができます（不動産登記法43条4項）。

このほか、過去問で扱われた代位の場面としては、遺産分割調停が成立した後に相続人の一人が他の相続人に代位して分筆登記を申請する場面（代位原因証明情報として調停調書正本を用いる）、処分禁止の仮処分を得た債権者が仮処分登記の前提として所有者に代位して分筆登記を申請する場面、農地法所定の許可前に農地の一部を買い受けた者が条件付所有権移転仮登記の前提として代位で分筆登記を申請する場面、土地区画整理事業の施行者が所有者に代位して分筆・合筆・表題登記を申請する場面（土地区画整理法の特則）、抵当権者が担保目的物を特定するために設定者に代位して分筆登記を申請する場面などが繰り返し出題されています。

### 代位できない・不要な場面

一方で、次のような場面では代位申請は認められません。「代位しなくても自分で単独申請できる」「代位しても自分の権利保全につながらない」のいずれかに当てはまるのが共通点です。

**たとえば**、甲土地の一部に地役権の設定を受けた地役権者は、承役地の所有者に代位して分筆登記を申請することはできません。地役権は一筆の土地の一部だけを対象にしても設定できるため、わざわざ分筆をしなくても地役権設定登記請求権は保全されるからです。

**たとえば**、隣り合う2筆の土地をまとめて1つにしてから買う約束をしていても、買主が「合筆してくれないと困る」と売主に代位して合筆登記を申請することは認められません。合筆をしなくても、所有権移転登記請求権そのものは保全されているからです。

**たとえば**、共有の建物が増築されて床面積が変わった場合、共有者の一人が変更登記に応じなくても、もう一人の共有者は、その者に代位するのではなく、保存行為として自分ひとりの申請で変更登記をすることができます（民法252条5項）。地目の変更登記も同様に、共有者の一人が保存行為として単独で申請できるため、他の共有者に代位する構成は不要です。

**たとえば**、区分建物の一棟の建物の表示に関する表題部の記録事項に誤りがあった場合、ある区分建物の所有権の登記名義人が更正の登記を申請すれば、その効力は同じ一棟に属する他の区分建物にも及び、登記官が職権で更正します。したがって、他の区分建物の所有権の登記名義人に代位して更正登記を申請する必要も余地もありません。

### 代位申請できる場合・できない場合の早見表

| 場面 | 代位の可否 | 理由 |
|---|---|---|
| 買主が、表題登記をしない売主に代位して表題登記を申請する | できる | 登記請求権保全のための代位（民法423条の7） |
| 区分建物の転得者が、表題登記をしない原始取得者に代位して表題登記を申請する | できる | 転得者には申請義務がなく、原始取得者への代位による |
| 附属建物のみの買主が、分割登記をしない売主に代位して建物の分割登記を申請する | できる | 所有権移転登記請求権の保全に必要 |
| 共有物分割の確定判決・裁判上の和解を得た共有者が、非協力の共有者に代位して分筆登記を申請する | できる | 確定判決・和解調書を代位原因証明情報として提供 |
| 遺産分割調停成立後、相続人の一人が他の相続人に代位して分筆登記を申請する | できる | 調停調書正本を代位原因証明情報として提供 |
| 処分禁止の仮処分を得た債権者が、所有者に代位して分筆登記を申請する（仮処分登記の前提） | できる | 仮処分命令正本を代位原因証明情報として提供 |
| 河川管理者が、土地所有者等に代わって分筆登記を嘱託する | できる | 不動産登記法43条4項の明文の授権 |
| 受益者・委託者が、受託者に代わって信託の登記を申請する | できる | 不動産登記法99条の明文の授権 |
| 地役権者が、承役地の所有者に代位して分筆登記を申請する | できない | 地役権は土地の一部にも設定でき、分筆を要しない |
| 合筆後の売却を前提に、買主が売主に代位して合筆登記を申請する | できない | 合筆をしなくても所有権移転登記請求権は保全される |
| 共有者の一人が、保存行為として自ら単独申請できる登記（地目変更・床面積変更等）について他の共有者に代位する | できない（不要） | 代位を持ち出すまでもなく単独申請できる |
| 一棟の表題部の更正登記について、他の区分建物の所有者に代位して申請する | できない | 職権で他の区分建物にも更正の効力が及ぶため |
| 転借人が、賃貸人（所有者）に直接代位して分筆登記を申請する | できない（原則） | 転借人と所有者の間に直接の権利義務関係がない |

### 代位原因を証する情報の要否

代位により登記を申請するときは、不動産登記令7条1項3号により、申請情報と併せて「代位原因を証する情報」を提供しなければなりません。前述の共有物分割確定判決の正本、遺産分割調停調書の正本、処分禁止の仮処分命令の正本などは、いずれもこの代位原因を証する情報に当たります。

ここで注意したいのは、この情報は「代位できる理由」を証明するものであって、「本当にその不動産の権利者は誰か」を証明する情報（所有権を証する情報など）とは別物だという点です。たとえば、同じ一棟のマンションで自分の区分建物の表題登記をした際に使った所有権証明情報を、隣の区分建物についての代位申請にそのまま流用（援用）することは認められません。代位原因を証する情報は、代位ごとに個別に用意する必要があります。

また、代位による申請だからといって、被代位者側の証明が省略されるわけでもありません。たとえば市町村が私人の土地について代位による土地の表題登記を嘱託する場合でも、表題部所有者となるべき者（被代位者）が所有権を有することを証する情報は、不動産登記令別表「四」の項添付情報欄ハにより、通常どおり必要です。代位はあくまで「誰が申請するか」の話であり、「本当にその人の土地であること」の証明までは免除されません。

### 代位による登記の登録免許税の扱い

登録免許税の扱いを整理するときは、「代位だから非課税」という単純な理解ではなく、条文の構造を正確に踏まえる必要があります。

登録免許税法2条は「登録免許税は、**別表第一に掲げる**登記…について課する」と定めています。つまり、そもそも別表第一に列挙されていない登記は、非課税規定（5条）を持ち出すまでもなく、最初から課税の対象になりません。表示に関する登記の大半（表題登記そのもの、地目又は地積の変更・更正の登記、建物の表題部の変更の登記、滅失の登記など）はこの別表第一に登場せず、非課税ではなく「そもそも課税範囲外」です。別表第一「一」の中で明示的に課税対象として掲げられている表示に関する登記は、所有権の登記のある不動産についての分筆・分割・区分及び合筆・合併（不動産1個につき1,000円）程度に限られます。

この構造を踏まえたうえで、代位に特有の非課税規定は登録免許税法5条1号です。

> 一　国又は別表第二に掲げる者がこれらの者以外の者に代位してする登記又は登録

これは「国又は別表第二に掲げる者（地方公共団体等）」が代位者となって行う登記・登録を非課税とする規定であり、代位という手続の性質そのものが非課税事由になっているわけではありません。あくまで「誰が代位して申請・嘱託するか」が問われており、代位者が地方公共団体等（別表第二該当者）である場合に限って、この非課税規定が適用されます。

なお、これとは別に、登録免許税法4条は「国及び別表第二に掲げる者が**自己のために**受ける登記等については、登録免許税を課さない」と定めています。4条は自己のための登記の非課税、5条1号は他人に代位してする登記の非課税であり、両者は場面が異なります。

**たとえば**、市が道路用地として私人の土地の一部を買い受けた際、地権者に代わって代位で分筆登記を嘱託しても、代位者が地方公共団体（別表第二該当者）であるため、登録免許税法5条1号により登録免許税はかかりません。一方、私人である買主が、表題登記をしない私人の売主に代位して表題登記を申請する場合は、代位者が国・別表第二の者に当たらないため5条1号は適用されませんが、表題登記そのものが別表第一に列挙されていない登記であるため、いずれにせよ課税対象にはなりません。このように、非課税なのか、そもそも課税対象外なのかを区別して理解しておくことが重要です。

### まとめ

- 代位申請の可否は、「代位しなければ自分の権利（登記請求権・登記申請権）が実現・保全されないか」（保全の必要性）を軸に判断する。
- 民法423条が代位の一般規定、423条の7が登記請求権保全のための代位を明文化した規定。不動産登記法側では59条7号（登記事項）・99条（信託の代位申請）・43条4項（河川管理者の分筆嘱託）が個別の授権・裏付け規定として確認できる。
- 地役権者の承役地分筆代位、合筆前提の代位、保存行為で単独申請できる登記への代位、一棟表題部更正の他区分建物への代位など、「代位しなくても権利が保全されている」「代位しなくても自分で申請できる」場面は代位できない。
- 代位原因を証する情報（令7条1項3号）は代位ごとに個別に必要で、他の申請の添付情報の援用では足りない。また代位申請でも被代位者側の証明（所有権証明情報等）は別途必要。
- 登録免許税は「別表第一に載っていない登記はそもそも課税対象外」という構造を押さえたうえで、代位固有の非課税規定（5条1号）は代位者が国・別表第二の者である場合に限られることを正確に理解する。
