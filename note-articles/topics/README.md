# 個別テーマ記事（topics）の分類

2026-11-04、`note-articles/tatekata-map/` の8つの棚に合わせて、KA〜KHの8種類に分類し、ファイル名と見出しに `KA_01` の形の番号を付けた。

- ファイル名：`KA_01_<slug>.md`、見出し：`## 【KA_01】【土地家屋調査士受験生向け】…`
- 新しい記事を足すときは、棚を選んで棚内の最後の番号の次を付ける（途中の番号は詰め直さない）。
