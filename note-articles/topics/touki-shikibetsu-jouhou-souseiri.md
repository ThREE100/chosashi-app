## 【土地家屋調査士受験生向け】登記識別情報、総整理〜通知される場合・されない場合と、提供できないときの3つの手当て〜

**対象条文：不動産登記法21条(登記識別情報の通知)、22条(登記識別情報の提供)、23条(事前通知等)、不動産登記法施行令8条、不動産登記規則62条〜65条・70条・72条**

登記識別情報は、かつての「権利証」に代わる12桁の符号です。以前の記事([調査士の代理請求、委任状はいらないんです〜登記識別情報に関する証明の請求を解説〜](../bunya-kaisetsu/05-touki-shikibetsu-shoumei.md))では、「この符号が有効かどうかを確認する」証明の請求だけを扱いました。今回は、登記識別情報そのもの——**いつ通知され、いつ通知されないのか**、**提供できないときにどう手当てするのか**——という制度全体を整理します。

### たとえば

**たとえば**、Aさんが所有する土地に、新しく建物を新築して表題登記をした場合を考えてみます。この表題登記によってAさんは「表題部所有者」にはなりますが、「登記名義人」にはなりません(不動産登記法2条10号・11号)。登記識別情報は「申請人自らが登記名義人となる場合」に通知されるものなので(法21条本文)、この表題登記では登記識別情報は通知されません。

一方、**たとえば**、Aさんが所有権の登記がある甲土地と乙土地を合筆する登記を申請した場合はどうでしょうか。合筆の登記も表示に関する登記の一種ですが、この場合は例外的に、Aさんに登記識別情報が通知されます。同じ「表示に関する登記」でも、通知される場合とされない場合があるのです。

### 基本の原則：登記識別情報が通知されるのは「申請人自らが登記名義人となる場合」

登記官は、その登記をすることによって**申請人自らが登記名義人となる場合**において、登記を完了したときは、速やかに、当該申請人に対し登記識別情報を通知しなければなりません(法21条本文)。ただし、申請人があらかじめ通知を希望しない旨の申出をした場合その他法務省令で定める場合は、この限りではありません(法21条ただし書)。

ここでポイントになるのが、「登記名義人」の定義です。不動産登記法上、「登記名義人」とは登記記録の**権利部**に権利者として記録されている者をいい(法2条11号)、登記記録の**表題部**に所有者として記録されている「表題部所有者」(法2条10号)とは、条文上区別された別の概念です。つまり、表示に関する登記(表題登記・地目や地積の変更登記など)によって表題部所有者になるだけでは、法21条本文の「登記名義人となる場合」には当たらず、原則として登記識別情報は通知されません。

### 例外：合筆・合体・建物の合併では、表示に関する登記でも通知される

もっとも、表示に関する登記のうち、次の3つは例外的に登記識別情報の通知の対象になります。

- 所有権の登記がある**土地の合筆の登記**
- 所有権の登記がある**建物の合体による登記等**
- 所有権の登記がある**建物の合併の登記**

これらは、不動産登記法施行令8条1項1号〜3号において、法22条(登記識別情報の提供)の「政令で定める登記」として明示されており、既存の所有権の登記名義人が申請人となるときは、登記識別情報を申請情報と併せて**提供**しなければならないとされています。合筆に係る土地・合体に係る建物・合併に係る建物が複数あるときは、そのうちいずれか一つの所有権の登記名義人の登記識別情報を提供すれば足ります(令8条2項)。

この3類型では、既存の所有権の登記名義人が、合筆・合体・合併後の(存続する)登記記録の権利部にあらためて登記名義人として記録されることになるため、法21条本文の「申請人自らが登記名義人となる場合」に該当するものとして扱われ、登記識別情報が通知されます。この点は、過去問での出題(後掲)でも繰り返し確認されている実務上確立した取扱いです。

一方、地目の変更登記や地積の更正登記のような、単純な表示の変更・更正にとどまる登記では、申請人はすでに表題部所有者または所有権の登記名義人であり、その登記によって新たに「登記名義人となる」わけではないため、登記識別情報は通知されません。

### 通知の要否・早見表

| 場面 | 通知の有無 | 根拠 |
|---|---|---|
| 権利に関する登記で、申請人自らが登記名義人となる場合(原則) | 通知される | 法21条本文 |
| あらかじめ通知を希望しない旨の申出をした場合 | 通知されない | 法21条ただし書、規則64条1項1号 |
| 表示に関する登記(地目変更・地積更正など、原則) | 通知されない | 表題部所有者は「登記名義人」に当たらない(法2条10号・11号) |
| 所有権の登記がある土地の合筆の登記 | 通知される(例外) | 令8条1項1号 |
| 所有権の登記がある建物の合体による登記等 | 通知される(例外) | 令8条1項2号 |
| 所有権の登記がある建物の合併の登記 | 通知される(例外) | 令8条1項3号 |
| 電子申請で、送信可能になってから30日以内に受信しない場合 | 通知されない扱い | 規則64条1項2号 |
| 書面申請で、登記完了から3か月以内に受領しない場合 | 通知されない扱い | 規則64条1項3号 |
| 通知を受けるべき者が官庁又は公署(あらかじめ通知を希望する申出がない限り) | 通知されない | 規則64条1項4号 |

### 誰が通知を受けるか

登記識別情報の通知を受けるのは、原則として申請人本人ですが、次の場合には代わりに次の者に通知されます。

- **法定代理人によって申請している場合**(支配人その他の法令上の代理人を含む)：当該法定代理人(規則62条1項1号)
- **申請人が法人である場合**(前号を除く)：当該法人の代表者(規則62条1項2号)
- **通知を受けるための特別の委任を受けた代理人がある場合**：当該代理人(規則62条2項)

**たとえば**、成年被後見人の代わりに成年後見人が合筆の登記を申請して完了した場合、登記識別情報は本人(成年被後見人)ではなく、申請した成年後見人に通知されます。また、土地家屋調査士が依頼者から「登記識別情報の受け取りもお願いします」と特別に委任を受けていれば、その調査士に通知されます。

通知の方法は、電子申請の場合は電子情報処理組織を使用してファイルに記録する方法、書面申請の場合は登記識別情報を記載した書面を交付する方法によります(規則63条1項)。

### 提供できないとき(失念・紛失)の3つの対応方法

登記識別情報を提供しなければならない登記であっても、これを提供することができないことにつき正当な理由がある場合は、提供しなくても申請できます(法22条ただし書)。**登記識別情報には再発行の制度がありません**。紛失・失念しても、同じ符号が改めて発行されることはなく、代わりに次の3つの方法のいずれかで本人であることを確認する仕組みが用意されています。

| 方法 | 根拠条文 | 概要 |
|---|---|---|
| **事前通知** | 法23条1項、規則70条 | 登記官が登記義務者に対し、書留郵便等で「申請があった旨」を通知し、通知を発送した日から**2週間以内**(登記義務者が外国に住所を有する場合は**4週間以内**)に、申請の内容が真実である旨の申出をすべきことを求める方法(規則70条8項)。期間内に申出がなければ、登記官はその登記をすることができない。 |
| **資格者代理人による本人確認情報の提供** | 法23条4項1号、規則72条 | 登記の申請の代理を業とすることができる代理人(土地家屋調査士など)が、申請人と面談するなどして本人確認を行い、その内容を記した本人確認情報を登記官に提供し、登記官がその内容を相当と認めるときは、事前通知が省略される方法。 |
| **公証人の認証** | 法23条4項2号 | 申請情報(委任による代理人によって申請する場合は、その権限を証する情報)を記載・記録した書面又は電磁的記録について、公証人(公証人法8条により公証人の職務を行う法務事務官を含む)の認証を受け、登記官がその内容を相当と認めるときは、事前通知が省略される方法。 |

**たとえば**、依頼者が過去に通知された登記識別情報の書面を紛失してしまった場合、依頼を受けた土地家屋調査士が依頼者本人と面談して運転免許証等の提示を受け、本人確認情報を作成して登記所に提供すれば、登記官がその内容を相当と認める限り、事前通知の手続を経ずに登記を進めることができます。

なお、資格者代理人が本人確認情報を提供するときは、あわせて自らが登記の申請の代理を業とすることができる者であることを証する情報も提供しなければなりません(規則72条3項)。

### 登記識別情報の失効の申出

登記名義人又はその相続人その他の一般承継人は、登記官に対し、通知を受けた登記識別情報について**失効の申出**をすることができます(規則65条1項)。この申出は義務ではなく、あくまで任意の手続です。したがって、たとえば登記識別情報の通知を受けた登記名義人が死亡しても、その相続人が必ず失効の申出をしなければならないわけではありません。

失効の申出は、電子情報処理組織を使用する方法、または申出情報を記載した書面を登記所に提出する方法のいずれかによります(規則65条3項)。相続人その他の一般承継人が申出をするときは、相続その他の一般承継があったことを証する情報の提供も必要です(規則65条5項)。

### まとめ

- 登記識別情報が通知されるのは、原則として「申請人自らが登記名義人となる場合」(法21条本文)。表題部所有者になるだけの表示に関する登記(地目変更等)では、原則として通知されない。
- 例外として、所有権の登記がある土地の合筆の登記・建物の合体による登記等・建物の合併の登記では、表示に関する登記でありながら例外的に登記識別情報が通知される(令8条1項1号〜3号)。
- 通知を受けるのは原則として申請人本人だが、法定代理人、法人代表者、特別の委任を受けた代理人がいる場合はその者に通知される(規則62条)。
- あらかじめ通知を希望しない申出をした場合、電子申請で30日以内に受信しない場合、書面申請で3か月以内に受領しない場合、通知先が官公署で希望の申出がない場合は、通知されない(規則64条1項)。
- 登記識別情報を提供できないときの対応は、事前通知(法23条1項)、資格者代理人による本人確認情報の提供(法23条4項1号)、公証人の認証(法23条4項2号)の3つ。登記識別情報そのものに再発行制度はない。
- 失効の申出(規則65条)は任意の手続であり、登記名義人本人だけでなく、その相続人その他の一般承継人もすることができる。

- 不動産登記法施行令8条1項1号〜3号(合筆・合体・合併が22条の政令で定める登記に当たること)・2項、令3条12号(提供できない理由の申請情報への記載)は、`note-articles/laws/fudousan-touki-rei.md` の条文原文で確認済みです。
- 不動産登記規則62条(通知の相手方)・63条(通知の方法)・64条(通知を要しない場合)・65条(失効の申出)・70条(事前通知、2週間・外国4週間)・72条(資格者代理人による本人確認情報)は、`note-articles/laws/fudousan-touki-kisoku-1.md` の条文原文で確認済みです。
- 合筆・合体・建物の合併で登記識別情報が「通知」される(単に「提供」が必要というだけでなく)という結論そのものは、令8条には明記されておらず、法21条本文の「申請人自らが登記名義人となる場合」に該当するという解釈を介した整理です。この解釈は、土地家屋調査士試験対策アプリの検証済みデータベース(takuitsu.json)に基づく過去問解説記事(平成22年度第19問・平成23年度第4問・平成29年度第5問・令和4年度第5問。いずれも合筆の登記を題材に「登記識別情報が通知される」ことを前提とした出題・解説)で繰り返し確認できるものの、条文上に「合筆・合体・合併は通知の例外」と直接書かれた一文があるわけではない点は、正直に申し添えます。
- 表示に関する登記(地目変更等)で登記識別情報が通知されないという原則は、`src/data/kaisetsu_plus.json` 内の解説(「表示に関する登記（地目変更等）では登記識別情報は通知されない（登記識別情報は権利の登記の際に通知）」)で裏取りしています。
- 事前通知の申出方法(規則70条5項)、前の住所地への通知(法23条2項、規則71条)、失効の申出の詳細な添付情報(規則65条2項〜11項)など、手続の細部まではこの記事では取り上げていません。より詳しく確認したい場合は、上記の条文原文を直接ご参照ください。
- 資格者代理人による本人確認情報の提供の際に確認する本人確認書類の種類(運転免許証・個人番号カード等、規則72条2項各号)は条文で確認済みですが、記事本文では紙幅の都合上、具体的な列挙は省略しています。

- 表示登記では、識別情報は原則出ないんです
