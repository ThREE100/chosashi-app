## 【土地家屋調査士受験生向け】合筆の登記の制限(不登法41条)と建物の合併の登記の制限(不登法56条)、まとめて対比整理

**対象条文：不動産登記法41条(合筆の登記の制限)、54条(建物の分割、区分又は合併の登記)、56条(建物の合併の登記の制限)、不動産登記規則105条・131条(制限の特例)**

土地の合筆と建物の合併は、どちらも「複数の不動産をひとつにまとめる」という点でよく似た手続きです。そのため、「合筆はできるのに合併はできない(またはその逆)」というひっかけが、午後の部の択一で繰り返し出題されます。似ているからこそ混同しやすい両者を、条文の号数レベルで対比しながら整理します。

### たとえば

**たとえば**、所有者Aが単独で所有する甲土地・乙土地を合筆したいとき、乙土地にBのための抵当権の登記があると、原則として合筆の登記はできません(不登法41条6号)。ただし、その抵当権が甲土地にも登記の目的・受付年月日及び受付番号・登記原因及びその日付が同一の内容で登記されていれば、例外的に合筆できます(不登規則105条2号)。

**たとえば**、甲建物を存続させ、乙建物(いずれも所有者A)をその附属建物とする合併登記をしたいとき、乙建物にAを登記名義人とする所有権の移転請求権の仮登記があると、所有権以外の権利に関する登記があるものとして合併の登記はできません(不登法56条5号、令和6年度午後の部第16問イ肢)。

このように、「所有者が同じでも他の権利の登記があると原則NG、ただし内容が同一なら例外的にOK」という構造は土地の合筆・建物の合併に共通しています。一方で、細部の制限事由には違いもあるため、以下で号数ごとに整理します。

### 土地の合筆の登記の制限(不登法41条)

不登法41条は、次に掲げる合筆の登記は「することができない」と規定しています。

- 一　相互に接続していない土地の合筆の登記
- 二　地目又は地番区域が相互に異なる土地の合筆の登記
- 三　表題部所有者又は所有権の登記名義人が相互に異なる土地の合筆の登記
- 四　表題部所有者又は所有権の登記名義人が相互に持分を異にする土地の合筆の登記
- 五　所有権の登記がない土地と所有権の登記がある土地との合筆の登記
- 六　所有権の登記以外の権利に関する登記がある土地(権利に関する登記であって、合筆後の土地の登記記録に登記することができるものとして法務省令で定めるものがある土地を除く。)の合筆の登記

過去問データベースでは、「持分がAは5分の3・5分の2、Bは5分の2・5分の3」というように持分の内訳が逆転している場合も41条4号の「持分を異にする」に該当し合筆できない、という肢(令和6年度午後の部第9問)や、登記記録上の地目が同一であれば現況地目が異なっていても合筆できる(41条2号は登記記録上の地目を基準とする)という肢が確認できています。

### 建物の分割・区分・合併の登記(不登法54条)

まず、建物側の3つの登記類型を条文どおりに押さえておきます(54条1項各号)。

- 一　**建物の分割の登記**：表題登記がある建物の附属建物を、当該表題登記がある建物の登記記録から分割して登記記録上別の一個の建物とする登記
- 二　**建物の区分の登記**：表題登記がある建物又は附属建物の部分であって区分建物に該当するものを登記記録上区分建物とする登記
- 三　**建物の合併の登記**：表題登記がある建物を登記記録上他の表題登記がある建物の附属建物とする登記、又は表題登記がある区分建物を登記記録上これと接続する他の区分建物である表題登記がある建物若しくは附属建物に合併して一個の建物とする登記

いずれも「表題部所有者又は所有権の登記名義人以外の者は、申請することができない」(54条1項柱書)点、共用部分である旨・団地共用部分である旨の登記がある建物についての分割・区分の登記は所有者以外の者は申請できない(54条2項)点、所有権等の登記以外の権利に関する登記がある建物についての分割・区分の登記には40条(分筆に伴う権利消滅の登記)が準用される(54条3項)点も条文上の重要ポイントです。

### 建物の合併の登記の制限(不登法56条)

不登法56条は、次に掲げる建物の合併の登記は「することができない」と規定しています。

- 一　共用部分である旨の登記又は団地共用部分である旨の登記がある建物の合併の登記
- 二　表題部所有者又は所有権の登記名義人が相互に異なる建物の合併の登記
- 三　表題部所有者又は所有権の登記名義人が相互に持分を異にする建物の合併の登記
- 四　所有権の登記がない建物と所有権の登記がある建物との建物の合併の登記
- 五　所有権等の登記以外の権利に関する登記がある建物(権利に関する登記であって、合併後の建物の登記記録に登記することができるものとして法務省令で定めるものがある建物を除く。)の建物の合併の登記

過去問データベースでは、甲・乙いずれの建物にも共用部分である旨の登記がある場合は合併の登記を申請できない(56条1号、令和6年度午後の部第16問ウ肢)、甲・乙いずれにも同一名義人Aを登記名義人とする所有権の移転請求権の仮登記がある場合は所有権以外の権利の登記があるとして合併できない(56条5号、同問イ肢)といった肢が確認できています。

### 対比表

| 観点 | 土地の合筆(41条) | 建物の合併(56条) |
|---|---|---|
| 根拠条文 | 不登法41条(全6号) | 不登法56条(全5号) |
| 接続(隣接)要件 | **あり**(1号：相互に接続していない土地は不可) | 条文上の独立要件としては明記なし(区分合併は54条1項3号の定義自体に「接続する」区分建物である旨が組み込まれている) |
| 用途・種類の同一性 | **あり**(2号：地目が相互に異なる土地は不可) | 条文上の独立要件としては明記なし(建物の種類が異なることを理由とする制限は56条に規定なし) |
| 地番区域・所在の同一性 | **あり**(2号：地番区域が相互に異なる土地は不可) | 該当なし |
| 表題部所有者・登記名義人の同一性 | **あり**(3号) | **あり**(2号) |
| 持分の同一性 | **あり**(4号) | **あり**(3号) |
| 所有権の登記の有無の一致 | **あり**(5号：所有権登記の有無が異なる土地は不可) | **あり**(4号：所有権登記の有無が異なる建物は不可) |
| 所有権以外の権利の登記 | **原則不可、例外あり**(6号) | **原則不可、例外あり**(5号) |
| 共用部分・団地共用部分の登記 | 条文上の規定なし(土地に共用部分の概念はない) | **あり**(1号：共用部分・団地共用部分の登記がある建物は不可) |
| 制限の例外(特例)を定める規則 | 不登規則105条(全4号) | 不登規則131条(全2号) |

### 例外が認められる場合(所有権以外の権利の登記があっても合筆・合併できるケース)

41条6号・56条5号は、いずれも「所有権以外の権利に関する登記があるものを除く」という原則を掲げつつ、「合筆後(合併後)の登記記録に登記することができるものとして法務省令で定めるものがある土地(建物)」を例外としています。この「法務省令で定めるもの」の中身は、不登規則105条(合筆)と131条(建物の合併)で個別に定められており、**両者の範囲は完全には一致しません**。

**不登規則105条(合筆の登記の制限の特例、全4号)**

- 一　承役地についてする地役権の登記
- 二　担保権の登記であって、登記の目的、申請の受付の年月日及び受付番号並びに登記原因及びその日付が同一のもの
- 三　信託の登記であって、法97条1項各号に掲げる登記事項が同一のもの
- 四　鉱害賠償登録令26条に規定する鉱害賠償登録に関する登記であって、鉱害賠償登録規則2条に規定する登録番号が同一のもの

**不登規則131条(建物の合併の登記の制限の特例、全2号)**

- 一　担保権の登記であって、登記の目的、申請の受付の年月日及び受付番号並びに登記原因及びその日付が同一のもの
- 二　信託の登記であって、法97条1項各号に掲げる登記事項が同一のもの

見てのとおり、**「担保権の登記(内容同一)」「信託の登記(登記事項同一)」の2つは土地・建物どちらの例外にも共通**していますが、**「承役地についてする地役権の登記」と「鉱害賠償登録に関する登記」は土地の合筆にしか例外として規定されていません**。地役権は土地(承役地)を対象とする権利のため、建物の合併の場面ではそもそも想定されていないと考えられます。「土地の合筆では地役権があっても合筆できる場合があるから、建物の合併でも地役権と同様に考えてよい」と類推してしまうと誤りになる点に注意してください。

### まとめ

土地の合筆(41条)と建物の合併(56条)は、**「所有者が同じ」「持分が同じ」「所有権登記の有無が一致」「他の権利の登記がない(または内容が同一)」という骨格が共通**しています。一方で、**土地には「接続していないこと」「地目・地番区域が異なること」という土地特有の制限があり、建物には「共用部分・団地共用部分の登記があること」という建物特有の制限がある**点が最大の違いです。さらに例外(特例)の範囲も、地役権・鉱害賠償登録は土地の合筆にしか認められていません。号数と「土地特有か・建物特有か・共通か」をセットで覚えると、初見の肢でも「この制限は土地専用のはずなのに建物の話で使っている」といったひっかけを見抜けるようになります。

## 見出し画像用フレーズ

- 合筆と合併、似てるようで制限が違うんです
- 土地には「地目」、建物には「共用部分」、それぞれの弱点があるんです
- 地役権があっても合筆できる、でも建物の合併では話が別なんです
- 持分がひとつでも違えば、合筆も合併もできないんです
- 号数で覚えるより、土地専用か建物専用かで覚えるのがコツなんです
