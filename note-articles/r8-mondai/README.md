# 令和8年度 土地家屋調査士試験 択一式（第1問〜第20問）解説記事

令和8年度の午後の部・択一式の第1問〜第20問を、`format-template.md` の型で、初学者向けに具体例つきで解説した記事です。1問1ファイル（`q01-*.md`〜`q20-*.md`）で、令和7年度（`r7-mondai/`）などと同じ構成です。

## 情報源と作り方

- **問題文**：受験者が持ち帰った問題用紙の写真から文字起こしした `exam-data/R08/takuitsu_R08_questions.json` を、そのまま引用しています（記事の引用ブロックと機械的に照合しています）。転記は、公式の問題冊子との1肢ずつの再照合が未実施です。
- **正解番号**：予備校の解答速報（2026年10月18日公開）によるもので、**暫定**です。法務省の公式の正答が公表されたら、照合してください（`src/lib.py` の `ANSWER` と、`exam-data/R08/` の `correctAnswer`）。
- **解説文**：条文は `note-articles/laws/` の原文で確認し、確認できなかった根拠（判例・通達・先例に基づく扱い）は、各記事の確認事項ブロックに「原文は未確認」と分けて書いています。判例・先例の番号は本文に書いていません。
- **過去問との照合**：`tools/drill/data/items.json`（過去問2,100肢の一問一答バンク）で、各肢と同型の肢を探し、結論が矛盾しないことを確かめました。
- **欄外メモ**：各肢の解説の後ろに、過去に作成した関連記事のファイル名（`note-articles/…`）を載せています。noteに投稿するときは、「※欄外メモ」の行を削除してください。関連記事は、バンクの出典と、論点別に整理した一覧（`src/rel.py`）から拾っています。

## 各記事に入っているもの

タイトル／出題行／問題文の引用／導入文／各肢の解説（具体例と欄外メモつき）／まとめ／結論文／正解／確認事項ブロック／見出し画像用フレーズ（5つ）／**見出し画像プロンプト**（トリ先生・藍子、1280×670px）／**インフォグラフィック プロンプト（問題全体）**（総論。1080×1920px、5枚のカード）。画像そのものは生成していません。

**解答を誤った6問（第3・4・13・14・17・18問）**には、肢ごとに、正しいルールの側から理解するための「インフォグラフィック プロンプト（ア〜オ肢・間違いノート）」を、各5枚ずつ追加しています（④間違いノート型）。画像の中には、個人の演習結果や問題番号は入れていません。

## 個人用の分析（`personal/`）

誤答した6問について、**あなたの解答結果をもとにした、肢ごとの分析**（判断の印・実際との照合・間違えた理由・次に確認すること）を `personal/qNN-analysis.md` に書いています。個人の演習結果なので、**noteには載せません**（`CLAUDE.md` の方針どおり、記事の本文と画像には入れていません）。

印は、答案の写真から読み取ったもので、読み取りに自信がない箇所は「迷いの印」「読み取りに自信なし」と書いています。

## 注意点

- 第4問ウ・エ、第13問エ・オ、第17問オの根拠は、法令データベースに直接の定めが見つからず、通達・先例に基づく扱いか、条文の文言からの整理です。解答速報の正解と整合するように整理しています。公式の正答・解説が出たら、見直してください。
- 第4問イの問題文は「特段の事情」ですが、不動産登記規則10条1項ただし書は「特段の事由」です（意味は同じ）。
- 問題文は法務省の試験問題です。noteなどで公開するときの引用の範囲は、公開前にご確認ください。

## 生成・点検の仕組み（`src/`）

- `src/d01.py`〜`d07.py`：各問のデータ（本文・まとめ・確認事項・図解のカード・間違いノート・個人分析）。
- `src/build.py`：データから、記事と個人用の分析を書き出します（`python3 src/build.py`、または `python3 src/build.py 3 14` で指定した問だけ）。
- `src/lib.py`：問題文の引用、見出し画像・総論・間違いノートのプロンプトの組み立て、正解番号。
- `src/rel.py`・`src/relkw.py`：欄外メモ（関連記事）の元データ。
- `src/check_articles.py`：形式の機械チェック（`python3 src/check_articles.py` でNG 0件）。
