## 独立照合の記録（2026-11-16）
書いた担当とは別の担当が、全40枚の主張を原文（`note-articles/laws/`）と1文ずつ照合した。直した点は次の15か所（答えが変わる誤りと、言い過ぎ・読み違えやすい書き方の両方）。
- A-01：規則第35条の第1・6・7号を使うのは「土地の表示の登記」に限る（第8〜10号は土地にも使える）。
- A-06：準則第67条第1項第5号・第7号の例外（適宜の地番）を表の注に足した。
- B-03：再築は「その材料を用いて建てる」場合（準則第83条）。「屋根の葺き替え」を「屋根の種類」の変化に直した（規則第114条）。
- B-06：建物の合併の制限の例外は規則第131条の担保権・信託の2つだけ。地役権を並べていた表を直した。
- C-03：「建物のみに関する旨」を付記する対象は、担保権等の登記（所有権の登記を除く。規則第123条第1項）。
- C-04：団地共用部分の添付情報は令別表19の項（18の項と併記）。
- C-05：団地共用部分の規約（区分所有法第67条第2項）に「最初に」の要件はない。
- D-01：過料は法第164条第1項だけでなく第2項（第76条の5）もある。
- D-05：図面をスキャンして添付情報にすることはできない、と書く（令第13条第1項）。「電子で作成して送る」とは断定しない。
- E-02：各階平面図の「1階の位置を点線で示す」は区分建物に限らない（準則第53条第1項）。
- F-01：筆界特定は地方公共団体も申請できる（法第131条第2項）。関係人の根拠は法第133条第1項第2号。閲覧の制限（法第149条第2項ただし書）を足した。
- G-04：準共有の準用から第262条の2・第262条の3が除かれる（民法第264条）。
- H-02：登記識別情報・印鑑証明書が要るのは「所有権の登記がある土地の合筆」に限る（令第8条第1項第1号）。
- H-03：主である建物の滅失で「何年何月何日主たる建物に変更」を、主たる建物と附属建物の両方の欄に記録する（準則第102条）。
直さずに残した点（誤りとまでは言えない書き方の幅）：結論の言い切りと原文の「要しない」の差（B-02・B-04）、追認の遡及効の「別段の意思表示」の省略（G-01）、令和5年4月1日施行の日付（G-04。施行期日を定めた政令が `laws/` にない）。

### その2の独立照合（2026-11-16）で直した点（18枚のうち11か所）
- A-07：離れた建物を乙建物の附属建物にするなら規則第35条第2号・第4号の組合せになる（接続が要るのは区分合併だけ）。
- A-08：準則第69条第4号は「牧畜のために使用する建物の敷地」。
- C-06：承諾で権利が消えても、土地へ転写しないのは土地について承諾したときだけ（規則第125条第2項・第3項）。
- C-07：20の項（変更・更正）の申請人は法第58条第5項で決まる。
- F-05：立入りに占有者の承諾が要るのは宅地や囲まれた土地（法第137条第3項・第4項）。
- F-07：業務を行い得ない事件の第3項は、第2号なら依頼者の同意でできる（法第22条の2第3項ただし書）。表題を「筆界特定手続代理関係業務」に直した。
- G-06：第112条第1項は、善意は本文の要件、ただし書は過失だけ。
- G-07：取消しを家庭裁判所に申述するのは限定承認・放棄の取消しだけ（民法第919条第4項）。
- G-08：第256条は分割の請求。第258条の2の10年の例外は、持分が相続財産のときに限る。
- G-09：強制執行などの終了による更新を足し、権利の承認の限定（処分につき。民法第152条第2項）を書いた。
- H-04：表題登記・合体の申請書では専有部分の家屋番号を書かない（令第3条第8号ロ）。
- H-05：遺産分割の後は取得した相続人が申請人になる、という扱いは民法第909条からの解釈で、原文に直接の文言はないため確認事項に移した。
