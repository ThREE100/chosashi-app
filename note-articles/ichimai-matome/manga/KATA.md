# 一枚まとめ 学習まんが版の型

一枚まとめ（`note-articles/ichimai-matome/`）の1枚を、学習まんがで読めるようにする型。ひっかけ診断ノートで検証済みの型
（`note-unei/hikkake-shindan/kaiwa/02-gakushu-manga-no-kata.md`）の決まり（1ページ＝1枚 1024×1536、文字は全部プロンプトに、名前・役割名なし、
生徒＝左・先生＝右、個人の演習結果なし）はそのまま。共通部品は `tools/gakushu_manga/`。

一枚まとめは「表で並べて違いをつかむ」コンテンツなので、漫画版は**表の1行ずつを場面に置きかえ、最後に一枚の画像へ戻す**流れにする。

| 段 | ページ | 中身（シートのどこから） |
|---|---|---|
| 1 | 扉 | 題名を問いにする（catalog の題名） |
| 2 | 場面 | 比べる2つを並べた場面（blocks の最初の表の1行目） |
| 3 | つまずき | 間違えやすい点（traps）の1つで生徒が引っかかる |
| 4 | なぜ | そのつまずきの理由（traps の根拠の条） |
| 5 | 図解の大ゴマ | 表全体を1枚の地図に（blocks） |
| 6〜 | 1つずつ | 表の行・ブロックを1ページずつ。残りの traps もここで |
| 末の前 | 確かめクイズ | 3問 |
| 末 | まとめ | 見出し「この一枚で言えること」。結論（conclusion）を短く言い直す。先生が一枚の画像で確かめるよう促す |

## 決まり
- 中身はシート（`src/sheets/<ID>.py`）の範囲だけ。シートのデータは読むだけで書き換えない。シートにない条・数を描かない。
- シートの結論・間違えやすい点の**太字の語**は、漫画のどこかに必ず出す（落とすと機械チェックでNG）。
- 記事（`<ID>_manga.md`）は、漫画の画像のあとに、シートの結論・間違えやすい点・根拠を自動で載せ、一枚まとめの記事へ案内する。
- タイトル：`【土地家屋調査士試験】一枚まとめ（漫画版）_<題名>～<副題>～`（一枚まとめのタイトルに「（漫画版）」を足した。2026-11-28 ユーザー確定）。

## 作り方
`manga/src/<ID>.py`（台本）→ `python3 note-articles/ichimai-matome/manga/src/build_manga.py [ID]` → `python3 note-articles/ichimai-matome/manga/src/check_manga.py`（NG 0件）。
生成物（`<ID>_manga.md`・`<ID>_prompts.md`・`<ID>-codex-instructions.md`・`<ID>-chatgpt-github-instructions.md`）は手で直さない。

機械チェック：共通（名前・個人の結果の語・文字数・話し手の連続・既存作品）＋ 漫画の「第N条」がシートの basis・articles の条だけ、シートの太字の語が漫画にある、漫画の数がシートにある、生成物が最新。
