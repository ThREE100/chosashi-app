# ChatGPTに貼る指示文（GitHubから直接読み込ませる形・一枚まとめ E-01 学習まんが）

使い方：GitHubと接続したChatGPTに、キャラクターシート_トリ先生_01〜03 と キャラクターシート_I-01〜03 の6枚を添付し、「ここから」〜「ここまで」を貼る。1回の返事で1ページだけ作らせ、2ページ目からは同じチャットで下の1行を送る（全11ページ＋見出し画像2枚）。
ChatGPTがリポジトリを読めなかったときは、`note-articles/ichimai-matome/manga/E-01_prompts.md` の該当ページのコードブロックの中身を、そのまま全文貼る（6枚の添付と一言はそのまま）。

---ここから---

接続しているGitHubのリポジトリ ThREE100/chosashi-app（ブランチ main）から、次のファイルを読んでください。
https://github.com/ThREE100/chosashi-app/blob/main/note-articles/ichimai-matome/manga/E-01_prompts.md

このファイルの見出し「## 1ページ目：扉：地積測量図に何を書く？」の下にある ``` で囲まれたプロンプトを、1文字も変えずに（要約・翻訳・言い換えをせずに）使って、画像を1枚作ってください。コードブロックの外の説明文と、ほかの見出しのプロンプトは使いません。

- 添付した6枚のうち、鳥の3枚（キャラクターシート_トリ先生_01〜03）が先生、女性の3枚（キャラクターシート_I-01〜03）が生徒です。
- 名前・役割名は画像のどこにも書かないでください。話し手は、絵と吹き出しのしっぽで見分けます。
- 大きさは 1024×1536（縦長）。作るのはこの1ページだけです。
- 作る前に、読み込んだプロンプトの最初の1行（「Draw page 1 of 11 …」で始まる行）をそのまま返事に書いて、正しいプロンプトを読めたことを示してから画像を作ってください。読めなかったときは、画像を作らずに「読めなかった」と答えてください。

---ここまで---

2ページ目以降は、同じチャットで次の1行だけを送る（○に数字）。図のあるページは、その図のPNGを添付してから送る。
「同じファイルの『## ○ページ目：…』の見出しの下のプロンプトで、同じやり方で次の1枚を作ってください。最初の1行を書いてから作ってください。」

途中のページから作り直すとき（例：4ページ目から）は、上の「ここから」〜「ここまで」の『## 1ページ目：扉：地積測量図に何を書く？』をそのページの見出しに、「Draw page 1 of 11」をそのページの番号に替えて貼る。

見出し画像は、次の1行を送る（大きさはプロンプトのとおり）。
「同じファイルの『## 見出し画像（note用 1280×670）』の見出しの下のプロンプトで、同じやり方で1枚作ってください。最初の1行を書いてから作ってください。」（Instagram用は見出しを『## 見出し画像（Instagram用 1080×1440）』に替える）
