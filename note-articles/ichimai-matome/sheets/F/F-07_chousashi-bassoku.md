## 【土地家屋調査士試験】一枚まとめ_調査士の義務違反と罰則～秘密保持・業務を行い得ない事件・研修～

**一枚まとめ　筆界・調査士法　｜　対象条文：土地家屋調査士法第22条〜第25条・第42条・第69条〜第71条の2・第75条**

> 【画像挿入】F-07_chousashi-bassoku.png　（この一枚の画像。保存しておけば、通信なしで見返せます）

### この一枚で言えること

- 罰則があるのは、依頼に応ずる義務（**罰金のみ**）・虚偽の調査測量・**秘密の漏示**など。秘密の漏示は**告訴がなければ**公訴を提起できない（法第71条の2第2項）。
- 業務を行い得ない事件（法第22条の2）の違反に罰則の条文はなく、懲戒の対象になる（法第42条）。研修（法第25条）は努力義務。
- 筆界特定・ADRの代理は、相手方から協議を受けた事件などでは行えない。**依頼者の同意**で行えるのは限られた号だけ。

### 義務違反と罰則

| 違反 | 罰則 |
|---|---|
| 依頼に応ずる義務（法第22条・第70条第1項） | 百万円以下の罰金 |
| 虚偽の調査・測量（法第23条・第71条） | 一年以下の拘禁刑又は百万円以下の罰金 |
| 秘密の漏示（法第24条の2・第71条の2） | 六月以下の拘禁刑又は五十万円以下の罰金。告訴が必要 |
| 業務を行い得ない事件（法第22条の2） | 罰則の条文なし。違反は懲戒の対象（法第42条） |

### 筆界特定手続代理関係業務を行えない事件（法第22条の2第2項）

| 事件 | 依頼者の同意 |
|---|---|
| 相手方の協議を受けて賛助・依頼を承諾した（第1号） | あってもできない |
| 相手方の協議を受け、信頼関係に基づくもの（第2号） | あってもできない |
| 受任中の事件の相手方からの他の事件（第3号） | あればできる |
| 法人にいた間に法人が賛助等し、自ら関与（第4号・第5号） | あってもできない |
| 使用人として、法人が相手方から受任（第6号） | あってもできない |
| 使用人として、法人の受任事件の相手方からの他の事件（第7号） | あればできる |

ADR代理は、これらに加え、社員として法人が相手方から筆界特定の代理を受任している事件も行えない（同条第3項第1号）。法人の受任事件の相手方からの他の事件（同項第2号）は、依頼者が同意すればできる。

### 書き方の例：同意があればできるか

- 調査士Aは、甲の依頼で乙との筆界特定の代理を受任中。乙から別の事件の依頼を受けた → 甲が同意すればできる（法第22条の2第2項第3号）。
- 調査士Aが、以前に乙から同じ筆界について協議を受けて賛助していた → 甲が同意してもできない（同項第1号）。

### 間違えやすい点

1. 秘密の漏示は**告訴が必要**（法第71条の2第2項）。虚偽の調査・測量（法第71条）には告訴の定めはない。
2. 依頼に応ずる義務の違反は**罰金だけ**で、拘禁刑はない（法第70条第1項）。
3. 研修を受けること（法第25条第1項）も、地域の筆界の慣習の知識を深めること（第2項）も**努力義務**。罰則はない。
