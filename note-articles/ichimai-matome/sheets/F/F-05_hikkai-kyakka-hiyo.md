## 【土地家屋調査士試験】一枚まとめ_筆界特定の却下と費用～却下事由と費用の負担～

**一枚まとめ　筆界・調査士法　｜　対象条文：不動産登記法第127条・第128条・第132条・第134条・第137条・第146条・第162条、不動産登記規則第242条**

### この一枚で言えること

- 却下事由は法第132条第1項の9つ。補正できる不備は**期間内に補正**すれば却下されない。
- 手続費用は**申請人の負担**。複数なら、土地の側と**持分**で割り振る（法第146条）。
- 立入調査は、正当な理由がなければ**拒めない**（法第137条第5項）。拒むと三十万円以下の罰金（法第162条第3号）。

### 却下になる場合（法第132条第1項）

| 場合 | 号 |
|---|---|
| 管轄外の土地 | 第1号 |
| 申請の権限がない者の申請 | 第2号 |
| 法第131条第3項の事項を明らかにしていない | 第3号 |
| 申請情報の提供の方法が方式に合わない | 第4号 |
| 所有権の境界の特定など筆界特定以外が目的 | 第5号 |
| 筆界確定の判決が確定済み | 第6号 |
| 筆界特定が済み | 第7号 |
| 手数料を納付しない | 第8号 |
| 手続費用の予納がない | 第9号 |

### 手続費用の負担（法第146条）

| 申請人 | 負担 |
|---|---|
| 1人（第1項） | 全部 |
| 両側に1人ずつ（第2項） | 等しい割合 |
| 全員が一方の側（第3項） | 持分の割合 |
| 3人以上で両側（第4項） | 各側で2分の1。2人以上の側は持分の割合 |

測量・鑑定などの報酬と費用（不動産登記規則第242条）。概算額を予納させる（第5項）。

### 筆界調査委員と立入調査

| 項目 | 内容 |
|---|---|
| 欠格（法第128条） | 刑の執行終了等から五年、除名・業務の禁止・懲戒免職から三年を経過しない者 |
| 指定できない（法第134条第2項） | 対象土地・関係土地の権利者、その親族・代理人（であった者を含む） |
| 立入り（法第137条） | あらかじめ占有者に通知。日出前・日没後、囲まれた土地へは占有者の承諾が要る |

### 計算例：手続費用600,000円を3人で負担（法第146条第4項）

- 甲土地の側はA1人、乙土地の側はB・C（持分3分の2・3分の1）。A：600,000円 × 1/2 ＝ 300,000円。
- B：600,000円 × 1/2 × 2/3 ＝ 200,000円、C：600,000円 × 1/2 × 1/3 ＝ 100,000円。
- 両側に1人ずつの2人なら 300,000円 ずつ（第2項）。

### 間違えやすい点

1. 筆界特定済みでも、**更に特定する特段の必要**があれば却下されない（法第132条第1項第7号）。判決は不適法却下を除く（第6号）。
2. 3人以上で両側にいるとき、頭数で割らない。まず**土地の側ごとに2分の1**にする（法第146条第4項）。
