## 【土地家屋調査士試験】一枚まとめ_土地家屋調査士の業務の範囲～できること、できないこと～

**一枚まとめ　筆界・調査士法　｜　対象条文：土地家屋調査士法第3条・第68条、土地家屋調査士法施行規則第21条**

> 【画像挿入】F-02_chousashi-gyomu.png　（この一枚の画像。保存しておけば、通信なしで見返せます）

### この一枚で言えること

- 調査士の業務は法第3条第1項の**8つの事務**（下の表）。権利に関する登記の申請代理は入らない。
- ADR代理（民間紛争解決手続代理関係業務）は、**研修の修了・法務大臣の認定・調査士会の会員**の3つがそろう調査士だけ。代理は**弁護士が同一の依頼者から受任している事件**に限る（法第3条第2項）。
- 調査士会に入会している調査士・調査士法人でない者は、第1号〜第5号の事務などを**業とすることができない**（法第68条第1項）。

### 法第3条第1項の業務

| 号 | 業務 | ポイント |
|---|---|---|
| 第1号 | 表示に関する登記に必要な土地・家屋の調査・測量 |  |
| 第2号・第3号 | 表示に関する登記の申請・審査請求の代理と書類作成 |  |
| 第4号・第5号 | 筆界特定の手続の代理と書類作成 | 却下への審査請求も含む |
| 第6号 | 第1号〜第5号の相談 |  |
| 第7号・第8号 | 筆界が現地で明らかでない民事紛争のADR代理と相談 | 法第3条第2項の要件 |

### 場合分け：できるか

| 場面 | できるか | 根拠 |
|---|---|---|
| 筆界特定の申請の代理（認定なし） | できる。認定が要るのはADRだけ | 法第3条第1項第4号 |
| ADR代理（認定あり、弁護士の受任なし） | できない | 法第3条第2項 |
| 調査士会に入会していない調査士が業として測量 | できない | 法第68条第1項 |
| 弁護士が筆界特定の手続を代理 | できる | 法第68条第1項ただし書 |
| 弁護士が表示登記のための調査・測量を業とする | できない（ただし書は第1号を含まない） | 法第68条第1項 |
| 受任の前に報酬の基準を示す | しなければならない | 土地家屋調査士法施行規則第21条 |

### 書き方の例：ADR代理ができるか（順に確かめる）

- 筆界が現地で明らかでないことによる民事紛争で、法務大臣が指定した団体の手続か（法第3条第1項第7号）。研修の修了・認定・会員の3つがそろうか（同条第2項）。
- 代理なら、弁護士が同じ依頼者から受任している事件か（法第3条第2項後段）。相談（第8号）にはこの限定がない。

### 間違えやすい点

1. 筆界特定の代理（第4号）は**認定がなくても**全ての調査士ができる。認定が要るのはADR（第7号・第8号）だけ。
2. ADR代理は単独では受けられない。**弁護士が同一の依頼者から受任している事件**に限る（法第3条第2項）。
3. 資格があっても、**調査士会に入会していない**と業として調査・測量はできない（法第68条第1項）。

### 根拠とくわしい記事

- 根拠：土地家屋調査士法第3条・第68条、土地家屋調査士法施行規則第21条

**確認事項（原文を確かめられなかった根拠）**

- 認定司法書士も、司法書士法に定める筆界特定の手続に係る範囲で第4号・第5号の事務ができる（法第68条第1項ただし書）。その範囲（対象土地の価額の上限など）は司法書士法の原文が手元になく未確認のため、表に入れていない。
