### この一枚で言えること

- 建物の合併ができないのは、法第56条の**5つ**（共用部分の登記・名義人の違い・持分の違い・所有権の登記の有無・ほかの権利の登記）。
- ほかの権利の登記があっても、**担保権**（登記の目的・受付・原因が同一）と**信託**（登記事項が同一）なら合併できる（規則第131条）。
- さらに、附属合併は**主従の関係**、区分合併は**接続**していることが要る（準則第86条）。

### 合併できるか

| 場面 | 可否 | 根拠 |
|---|---|---|
| 共用部分・団地共用部分である旨の登記がある | できない | 法第56条第1号 |
| 表題部所有者・所有権の登記名義人が違う | できない | 法第56条第2号 |
| 名義人の持分が違う | できない | 法第56条第3号 |
| 所有権の登記がない建物とある建物 | できない | 法第56条第4号 |
| 所有権等以外の権利の登記がある | 原則できない | 法第56条第5号 |
| 担保権の登記で、目的・受付・原因が同一 | できる | 規則第131条第1号 |
| 信託の登記で、登記事項が同一 | できる | 規則第131条第2号 |
| 附属合併で、主従の関係にない | できない | 準則第86条第1号 |
| 区分合併で、互いに接続していない | できない | 準則第86条第2号 |

### 土地の合筆との違い

| 項目 | 土地の合筆 | 建物の合併 |
|---|---|---|
| 名義人・持分・所有権の登記の有無 | 同じでないとできない（法第41条） | 同じでないとできない（法第56条） |
| ほかの権利の登記の例外 | 承役地の地役権・担保権・信託・鉱害賠償登録（規則第105条） | 担保権・信託の2つだけ（規則第131条） |
| 地目・地番区域 | 違えばできない（法第41条第2号） | 種類が違うことの制限はない |

### 書き方の例：合併の登記のあと

- 附属合併の原因：合併される甲建物に「何番に合併」、残る乙建物に「何番を合併」（準則第98条）。
- 合併後の家屋番号：合併前の家屋番号のうち上位のものを使う（準則第79条第9号）。

### 間違えやすい点

1. 法第56条は**合併**の制限。合体による登記等にはこの制限はなく、権利の扱いは法第50条などで決まる。
2. 例外の数が違う。土地は規則第105条の4つ、建物は規則第131条の**担保権と信託の2つだけ**。
3. 名義人が同じでも、**持分が違えば**合併できない（法第56条第3号）。

- 根拠：不動産登記法第41条・第54条・第56条、不動産登記規則第105条・第131条、準則第79条・第86条・第98条
