## 【土地家屋調査士試験】B_07_一枚まとめ_合体による登記等～法第49条・第50条～

**一枚まとめ　建物の表示の登記　｜　対象条文：不動産登記法第49条・第50条、不動産登記令第5条・第8条、令別表13の項、不動産登記規則第120条**

> 【画像挿入】B-07_gattai.png　（この一枚の画像。保存しておけば、通信なしで見返せます）

### この一枚で言えること

- 合体後の建物の**表題登記**と合体前の建物の**表題部の抹消**を、合体の日から**1月以内**に**一の申請情報**で申請する（法第49条第1項、令第5条）。
- 申請できる人は、合体前の建物の登記の状態で決まる。所有権の登記のない側があれば、その人の**所有権の登記も併せて**申請する場合がある。
- 抵当権などは合体後の建物の持分に**存続登記**として残る。権利者が**消滅を承諾**すれば、消滅した旨を登記する（法第50条）。

### 誰が申請し、所有権の登記を併せるか（法第49条第1項）

| 合体前の建物 | 申請できる人／併せる所有権の登記 |
|---|---|
| 第1号：表題登記なし＋表題登記あり | 所有者か表題部所有者／併せない |
| 第2号：表題登記なし＋所有権の登記あり | 所有者か登記名義人／表題登記なしの建物の所有者の分 |
| 第3号：いずれも表題登記あり | 表題部所有者／併せない |
| 第4号：表題登記あり＋所有権の登記あり | 表題部所有者か登記名義人／表題部所有者の分 |
| 第5号：いずれも所有権の登記あり | 登記名義人／併せない |
| 第6号：3つの状態の建物がそろう | いずれか／所有者と表題部所有者の分 |

「表題登記あり」は所有権の登記がない建物。いずれも表題登記がない建物の合体は、表題登記の申請になる（法第49条第2項）。

### 権利と添付・手続

| 項目 | 扱い | 根拠 |
|---|---|---|
| 存続登記 | 家屋番号・登記の目的・受付・順位・名義人と、目的となる権利を書く | 令別表13の項申請情報欄ハ |
| 同じ人が両方の所有者 | 同一の者でないとみなした持分を書く | 同欄ニ |
| 権利を消滅させる | 消滅の承諾の情報→消滅した旨を付記。移記しない | 法第50条、規則第120条第5項・第6項 |
| 登記識別情報 | 名義人が同一ならいずれか一個分 | 令第8条第1項第2号・第2項第2号 |

### 書き方の例：抵当権のある甲建物と、ない乙建物が合体（名義人は同じA）

- 第5号。Aが一の申請情報で申請し、登記識別情報は一個分でよい。
- 甲建物の抵当権の存続登記の事項と、Aを同一の者でないとみなした持分を書く。抵当権者の消滅の承諾があれば、存続させず消滅した旨を登記する。

### 間違えやすい点

1. 合体は**合併の制限（法第56条）を受けない**。抵当権があっても合体による登記等はでき、存続登記か法第50条の承諾で処理する。
2. 所有権の登記がある建物どうし（第5号）では、所有権の登記を**併せない**。併せるのは第2号・第4号・第6号の、所有権の登記のない側の分。
3. 登記識別情報が**一個分で足りる**のは、登記名義人が同一のときだけ（令第8条第2項第2号）。名義人が違えば、それぞれの分が要る。

### 根拠とくわしい記事

- 根拠：不動産登記法第49条・第50条、不動産登記令第5条・第8条、令別表13の項、不動産登記規則第120条
- くわしく読める記事：`joubun-nigate/kubun-tatemono-hani/08-setsuzoku-gattai.md`、`ichimai-matome/sheets/B/B-01_gappei-gattai-bunkatsu-kubun.md`

**確認事項（原文を確かめられなかった根拠）**

- 登記名義人が違う所有権の登記がある建物の合体で、各名義人の登記識別情報が要るという点は、令第8条第2項第2号（名義人が同一のときの特則）の反対解釈。これを述べた先例の原文は未確認。
- 「同一の者でないとみなした持分」の割合の決め方（建物の価格の割合など）は、原文に定めが見当たらないため、このシートでは書いていない。
