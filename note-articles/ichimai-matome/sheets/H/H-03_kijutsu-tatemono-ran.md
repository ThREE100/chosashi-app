### この一枚で言えること

- 建物の表示は**所在・家屋番号・種類・構造・床面積**。表題登記では家屋番号を書かない。
- 床面積は各階ごとに**壁心**（区分建物は**内法**）で、百分の一未満を切り捨てる。
- 原因は変わる欄の番号を冠記する。分割・区分・合併だけが**後の個数×千円**の登録免許税。

### 建物の表示の欄

| 欄 | 書き方 |
|---|---|
| 所在 | 床面積の多い部分の地番が先。「6番地、4番地」 |
| 家屋番号 | 表題登記では書かない |
| 種類 | 主な用途。2つなら「居宅・店舗」 |
| 構造 | 構成材料・屋根・階数（階層的な区分は屋根なし） |
| 床面積 | 各階ごと。合計は書かない |
| 附属建物 | 主である建物と分け、符号を付ける |

準則第88条、令第3条第8号、規則第112条〜第114条、準則第80条・第81条・第91条。

### 原因及びその日付

| 場面 | 書き方 |
|---|---|
| 附属建物の増築 | 「③何年何月何日増築」 |
| 附属建物の合体 | 「③何年何月何日附属建物合体」 |
| 分割 | 「何番から分割」 |
| 附属合併 | 「何番を合併」 |
| 主である建物の滅失 | 附属建物の行に「主たる建物に変更」 |
| 解体移転・再築 | 滅失と新築として扱う |

準則第83条・第85条・第94条〜第96条・第98条・第102条（登記記録の書き方。申請書もこれに合わせる）。

### 添付情報と登録免許税

| 登記 | 添付情報 | 登録免許税 |
|---|---|---|
| 表題登記 | 建物図面・各階平面図・所有権証明情報・住所証明情報 | なし |
| 床面積の変更 | 建物図面・各階平面図（増加は所有権証明情報も） | なし |
| 分割・区分・合併 | 建物図面・各階平面図（合併は登記識別情報・印鑑証明書も） | 後の個数×千円 |
| 滅失 | 個別の定めなし | なし |

令別表12・14・16の項、令第8条、規則第47条。代理権限証明情報は別。税は所有権の登記がある建物だけ（登録免許税法別表第一の一（十三））。

### 書き方の例：構造と床面積

- 構造：「木造かわらぶき2階建」。屋根が2種なら「かわら・亜鉛メッキ鋼板ぶき」（準則第81条第2項）。
- 床面積：各階ごとに書き、端数がなくても「00」を書く（準則第91条）。

### 間違えやすい点

1. 天井の高さ1.5メートル未満の地階・屋階は階数にも床面積にも入れない。ただし**1室の一部**が低いだけなら算入する（準則第81条第4項・第82条）。
2. 2筆にまたがる建物の所在は、**床面積の多い部分**の地番が先（準則第88条第2項）。「6、4番地」と略さない。
3. 合併の登記識別情報は**いずれか一個**の建物の分で足りる（令第8条第2項第3号）。表題登記・表題部の変更は登録免許税がかからない。
