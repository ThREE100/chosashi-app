## 【土地家屋調査士試験】一枚まとめ_建物の申請書の欄の書き方～建物の表示・原因・添付情報～

**一枚まとめ　記述式の型　｜　対象条文：不動産登記規則第47条・第112条〜第115条、不動産登記令第3条・第8条・別表、準則第80条〜第102条**

> 【画像挿入】H-03_kijutsu-tatemono-ran.png　（この一枚の画像。保存しておけば、通信なしで見返せます）

### この一枚で言えること

- 建物の表示は**所在・家屋番号・種類・構造・床面積**。表題登記では家屋番号を書かない。
- 床面積は各階ごとに**壁心**（区分建物は**内法**）で、百分の一未満を切り捨てる。
- 原因は変わる欄の番号を冠記。登録免許税は分割・区分・合併の**後の個数×千円**だけ。

### 建物の表示の欄

| 欄 | 書き方 |
|---|---|
| 所在 | 床面積の多い部分の地番が先。「6番地、4番地」 |
| 家屋番号 | 表題登記では書かない |
| 種類 | 主な用途。2つなら「居宅・店舗」 |
| 構造 | 構成材料・屋根・階数（階層的な区分は屋根なし） |
| 床面積 | 各階ごと。合計は書かない |
| 附属建物 | 主である建物と分け、符号を付ける |

準則第80条・第81条・第88条・第91条、令第3条第8号。

### 原因及びその日付

| 場面 | 書き方 |
|---|---|
| 附属建物の増築 | 「③何年何月何日増築」 |
| 分割 | 「何番から分割」 |
| 附属合併 | 「何番を合併」 |
| 主である建物の滅失 | 「何年何月何日主たる建物に変更」（主たる建物の欄と附属建物の欄の両方） |

準則第94条〜第102条の登記記録の書き方に合わせる。

### 添付情報と登録免許税

| 登記 | 添付情報（図面＝建物図面・各階平面図） | 税 |
|---|---|---|
| 表題登記 | 図面・所有権証明・住所証明 | なし |
| 床面積の変更 | 図面（増加は所有権証明も） | なし |
| 分割・区分 | 図面 | 個数×千円 |
| 合併 | 図面・登記識別情報・印鑑証明書 | 個数×千円 |
| 滅失 | 個別の定めなし | なし |

令別表12・14・16の項、令第8条、規則第47条。税は所有権の登記がある建物だけ（登録免許税法別表第一の一（十三））。

### 書き方の例：構造と床面積

- 構造：「木造かわらぶき2階建」。屋根が2種なら「かわら・亜鉛メッキ鋼板ぶき」（準則第81条第2項）。
- 床面積：各階ごとに書き、端数がなくても「00」を書く（準則第91条）。

### 間違えやすい点

1. 天井1.5メートル未満の地階・屋階は数えない。**1室の一部**が低いだけなら算入（準則第82条第1号）。
2. 所在は**床面積の多い部分**の地番が先（準則第88条第2項）。「6、4番地」と略さない。
3. 合併の登記識別情報は**いずれか一個**の建物の分で足りる（令第8条第2項第3号）。

### 根拠とくわしい記事

- 根拠：不動産登記規則第47条・第112条〜第115条、不動産登記令第3条・第8条・別表12・14・16の項、準則第80条〜第82条・第88条・第91条・第94条・第96条・第98条・第102条、登録免許税法別表第一の一（十三）
