### この一枚で言えること

- 登録免許税は、**別表第一に掲げる登記**にだけかかる（登録免許税法第2条）。表題登記・地目や地積の変更・建物の表題部の変更・滅失は、別表第一に掲げられていないので**かからない**。
- 表示の登記でかかるのは、**所有権の登記がある**不動産の、分筆・建物の分割・区分と、合筆・建物の合併だけ（別表第一第一号（十三））。
- 金額は、**登記後の個数×千円**。分筆・分割・区分は分けた後の個数、合筆・合併は合わせた後の個数で数える。

### 表示に関する登記と登録免許税

| 登記 | 税 | 決まり方 |
|---|---|---|
| 土地・建物の表題登記 | かからない | 別表第一に掲げられていない |
| 地目・地積の変更、建物の表題部の変更 | かからない | 別表第一に掲げられていない |
| 土地・建物の滅失 | かからない | 別表第一に掲げられていない |
| 表示に関する更正・変更（表題部所有者の住所など） | かからない | （十四）は表示に関するものを除く |
| 表題部の登記の抹消 | かからない | （十五）は表題部の登記の抹消を除く |
| 分筆、建物の分割・区分（所有権の登記あり） | かかる | 分けた後の個数×千円（（十三）イ） |
| 合筆、建物の合併（所有権の登記あり） | かかる | 合わせた後の個数×千円（（十三）ロ） |

### 課税されない登記（第5条の主なもの）

| 場面 | 根拠 |
|---|---|
| 住居表示の実施・変更に伴う変更の登記（証する書類を添付） | 第5条第4号 |
| 行政区画・町・字やその名称の変更に伴う変更の登記（地番の変更を含む。証する書類を添付） | 第5条第5号 |
| 墳墓地に関する登記 | 第5条第10号 |
| 登記機関の過誤による登記の抹消・更正 | 第5条第12号 |

### 計算例：登記後の個数×千円

- 所有権の登記がある1筆を3筆に分筆：3個 → **金3,000円**
- 所有権の登記がある3筆を1筆に合筆：1個 → **金1,000円**
- 所有権の登記がある建物を区分して2個に：2個 → **金2,000円**
- 表題登記だけの土地を2筆に分筆：2個 → **かからない**（（十三）は所有権の登記がある不動産だけ）

### 間違えやすい点

1. 分筆は「分筆**前**の1筆」ではなく「分筆**後**の個数」で数える。1筆を3筆にすれば3,000円である。
2. 所有権の登記がない土地（表題登記だけ）の分筆・合筆には、（十三）があたらないので**かからない**。
3. 分筆と地目の変更を一の申請情報で申請しても、税がかかるのは分筆の部分だけである（地目の変更は別表第一に掲げられていない）。

### 根拠とくわしい記事

- 根拠：登録免許税法第2条・第3条・第5条、登録免許税法別表第一第一号（十三）〜（十五）

**確認事項（原文を確かめられなかった根拠）**

- 分合筆（一部合併）の税額を「分合筆後の個数×千円」とする扱いは、別表第一の文言からの読み。先例の原文は未確認なので、本文には入れていない。
- 合体による登記等と併せてする所有権の登記の課税（所有権の保存の登記としての扱い・課税標準）は、先例の原文が未確認なので、本文には入れていない。
