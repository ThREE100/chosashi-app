**一枚まとめ　申請手続の共通ルール　｜　対象条文：不動産登記令第7条・第9条、令別表4の項〜21の項、不動産登記規則第36条**

### この一枚で言えること

- 添付情報は、**令第7条の共通のもの**（代理・代位・相続・法人）と、**令別表の項ごとのもの**の2段で決まる。
- 図面が要るのは、表題登記・地積の変更更正・分筆（地積測量図）と、建物の表題登記・床面積の変更・分割区分合併（建物図面・各階平面図）。**地目の変更と合筆には図面が要らない**。
- 表題登記は**所有権証明情報と住所証明情報**も要る。区分建物は、敷地権について規約を証する情報などが加わる。

### 登記ごとの添付情報（令別表）

| 登記 | 主な添付情報 | 別表の項 |
|---|---|---|
| 土地の表題登記 | 土地所在図・地積測量図・所有権証明情報・住所証明情報 | 4の項 |
| 地積の変更・更正 | 地積測量図 | 6の項 |
| 分筆 | 分筆後の土地の地積測量図 | 8の項 |
| 合筆 | 図面は不要（地役権の範囲が一部になるときだけ地役権図面など） | 9の項 |
| 建物の表題登記 | 建物図面・各階平面図・所有権証明情報・住所証明情報 | 12の項 |
| 建物の表題部の変更・更正 | 床面積の変更：建物図面・各階平面図／所在の変更：建物図面 | 14の項 |
| 建物の分割・区分・合併 | 分割後・区分後・合併後の建物図面・各階平面図 | 16の項 |

### どの登記にも共通のもの（令第7条第1項）

| 場面 | 添付する情報 | 根拠 |
|---|---|---|
| 申請人が会社などの法人 | 会社法人等番号 | 第1号 |
| 代理人が申請する | 代理人の権限を証する情報 | 第2号 |
| 代位して申請する | 代位原因を証する情報 | 第3号 |
| 相続人が申請（不動産登記法第30条） | 相続などを証する情報 | 第4号 |

### 区分建物の表題登記で加わるもの（12の項）

| 場面 | 添付する情報 |
|---|---|
| 規約敷地・規約で定めた割合 | その規約を設定したことを証する情報 |
| 敷地が他の登記所の管轄 | その土地の登記事項証明書 |
| 分離処分可能規約などで敷地権にならない | その事由を証する情報 |

### 書き方の例：会社が新築した建物の表題登記（代理人が申請）

- 建物図面、各階平面図、所有権証明情報、住所証明情報、会社法人等番号、代理権限証明情報。
- 住所証明情報は、会社法人等番号（個人なら住民票コード）を申請情報の内容にすれば省略できる（令第9条、不動産登記規則第36条第4項）。

### 間違えやすい点

1. 地目の変更には**地積測量図が要らない**（5の項に定めがない）。地積の変更・更正には要る（6の項）。
2. 合筆には地積測量図が要らない。分筆で出すのは「**分筆後の土地の**」地積測量図である（8の項）。
3. 建物の種類だけの変更には図面が要らない。14の項の図面は、所在・床面積の変更と附属建物の新築のときである。
