## 【土地家屋調査士試験】一枚まとめ_申請人と代位申請の早見～誰が申請できるか～

**一枚まとめ　申請手続の共通ルール　｜　対象条文：不動産登記法第30条・第31条・第36条〜第39条・第47条・第48条・第51条〜第54条・第57条・第58条、民法第423条、不動産登記令第3条・第7条**

> 【画像挿入】D-03_shinseinin-daii.png　（この一枚の画像。保存しておけば、通信なしで見返せます）

### この一枚で言えること

- 表題登記は「**所有権を取得した者**」、それ以外の表示の登記は「**表題部所有者または所有権の登記名義人**」が申請する。
- 分筆・合筆、建物の分割・区分・合併、表題部の更正は、表題部所有者または所有権の登記名義人**以外は申請できない**。名義人が死亡したら相続人が申請できる（法第30条）。
- 他人に代わる申請（**代位**）は、区分建物の法第48条・第52条と、民法第423条の債権者代位。申請情報に代位原因を書き、それを証する情報を付ける。

### 登記ごとの申請人

| 登記 | 申請できる人 | 根拠 |
|---|---|---|
| 土地・建物の表題登記 | 所有権を取得した者 | 法第36条・第47条第1項 |
| 区分建物の表題登記 | 新築したときの所有者（買った人は申請人にならない） | 法第47条第1項 |
| 変更・滅失の登記 | 名義人 | 法第37条・第42条・第51条・第57条 |
| 分筆・合筆 | 名義人だけ | 法第39条第1項 |
| 建物の分割・区分・合併 | 名義人だけ | 法第54条第1項 |
| 表題部の更正 | 名義人だけ | 法第38条・第53条第1項 |
| 表題部所有者の氏名・住所の変更 | 表題部所有者だけ | 法第31条 |
| 名義人が死亡した | 相続人その他の一般承継人 | 法第30条 |

名義人＝表題部所有者または所有権の登記名義人。

### 他人に代わって申請する（代位）

| 場面 | 誰が、誰に代わって | 根拠 |
|---|---|---|
| 一棟の建物を新築（区分建物） | 区分建物の所有者が、他の区分建物の所有者に代わる | 法第48条第2項 |
| 非区分の建物に接続して区分建物を新築 | 新築した区分建物の所有者と既存の建物の名義人が、互いに相手に代わる | 法第48条第4項・第52条第2項 |
| 二以上の建物が接続して区分建物に | 一の建物の名義人が、他の建物の名義人に代わる | 法第52条第4項 |
| 土地の一部を買った | 買主（債権者）が、売主（債務者）に代わり分筆 | 民法第423条 |

### 書き方の例：代位で申請するときに足すもの

- 申請情報：申請人が代位者である旨、代わられる人（被代位者）の氏名・住所、代位原因（令第3条第4号）。
- 添付情報：代位原因を証する情報（令第7条第1項第3号）。売買契約書などがあたる。
- 相続人が申請するとき：申請人が相続人である旨（令第3条第10号）と、相続を証する情報（令第7条第1項第4号）。

### 間違えやすい点

1. 土地の一部を買った人は、自分では分筆を申請できない。所有権の登記名義人ではないので、**売主に代位**して申請する。
2. 区分建物を新築者から買った人は、表題登記の申請人にならない。法第47条第1項の取得者は「区分建物以外」の建物の取得者である。
3. 名義人の相続人の申請（法第30条）は代位ではない。付けるのは代位原因を証する情報ではなく、**相続を証する情報**である（令第7条第1項第4号）。
