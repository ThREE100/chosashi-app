### この一枚で言えること

- 地目は、土地の**主な用途**で、規則第99条の**23種類**のどれかに定める。
- 土地の**現況と利用目的**に重点を置き、部分的にわずかな差異があっても**土地全体**の状況で定める（準則第68条）。
- 迷う例は準則第69条にある。**永久的設備と認められる建物**の敷地かどうかで、宅地と雑種地が分かれる例が多い。

### 似た地目の比べ方（準則第68条）

| 地目 | 定める土地 | 比べる相手 |
|---|---|---|
| 田 | 農耕地で用水を利用して耕作する土地 | 畑は用水を利用しない |
| 宅地 | 建物の敷地と、その維持・効用を果たすために必要な土地 | 庭なども含みうる |
| 山林 | 耕作の方法によらないで竹木の生育する土地 | 原野は雑草・かん木類 |
| 池沼 | かんがい用水でない水の貯留池 | ため池は耕地かんがい用 |
| 用悪水路 | かんがい用または悪水はいせつ用の水路 | 井溝は田畝・村落の間の通水路 |
| 公衆用道路 | 一般交通の用に供する道路 | 道路法の道路かどうかを問わない |
| 境内地 | 宗教法人法第3条第2号・第3号の土地 | 宗教法人の所有でないものを含む |
| 雑種地 | 以上のいずれにも当たらない土地 | 最後の受け皿 |

### 迷う例（準則第69条）

| 土地 | 地目 | 号 |
|---|---|---|
| 牧草栽培地 | 畑 | 第1号 |
| 耕作地の中の農具小屋等の敷地（永久的設備の建物） | 宅地 | 第3号 |
| 水力発電のための水路・排水路 | 雑種地 | 第5号 |
| テニスコート・プール | 宅地に接続→宅地、その他→雑種地 | 第9号 |
| ガスタンク・石油タンクの敷地 | 宅地 | 第10号 |
| 高圧線の下で他の目的に使えない区域 | 雑種地 | 第13号 |
| 鉄塔・変電所の敷地 | 雑種地 | 第14号 |

### 書き方の例：一筆の一部だけ用途が変わったとき

- 一筆の土地の一部だけが建物の敷地になった：その部分を分けて「土地一部地目変更・分筆登記」（規則第35条第7号）。
- 申請がなくても、一筆の一部が別の地目になったときは、登記官が職権で分筆する（不動産登記法第39条第2項）。
- 地目が変わったら、所有権の登記名義人などは一月以内に地目の変更の登記を申請する（不動産登記法第37条第1項）。

### 間違えやすい点

1. 地目は**主な用途**で決める。部分的なわずかな差異だけで地目を分けない。
2. 道路は道路法の道路でなくても、一般交通の用に供していれば**公衆用道路**。
3. 鉄塔・変電所の敷地は宅地ではなく**雑種地**。ガスタンク・石油タンクの敷地は**宅地**。
