# 一枚まとめ シートの書き方（執筆者向け）

1枚＝`src/sheets/<ID>.py` 1ファイル。見本は `src/sheets/E-01.py`（必ず読む）。このファイルのデータから、記事(.md)・画像(.png/.html)・ChatGPT用プロンプトが自動で作られる。

## 作業の手順
1. 対象の法令を原文で読む：`python3 -c "import sys;sys.path.insert(0,'note-articles/ichimai-matome/src');import lawlib;print(lawlib.text('不動産登記法','41'))"`（法令名は 不動産登記法／不動産登記令／不動産登記規則／準則／区分所有法／民法／土地家屋調査士法／土地家屋調査士法施行規則／登録免許税法。条は '41'、枝番は '76の2'）。令別表は `note-articles/laws/fudousan-touki-rei-betsuhyou.md`、通達は `note-articles/laws/tsutatsu-*.md`。既存の長編記事（`note-articles/topics/`、`note-articles-Kijyutsu/`）は素材として読んでよいが、**結論は必ず原文で確かめ直す**（記事に誤りがありうる）。
2. `src/sheets/<ID>.py` を書く。
3. `python3 note-articles/ichimai-matome/src/build.py <ID>` → 画像を目で確かめる（Readでpngを開く）。
4. `python3 note-articles/ichimai-matome/src/check_all.py <ID>` が **NG 0件** になるまで直す。
5. gitは触らない（commit/pushしない）。ほかのシートのファイルは編集しない。共通ファイル（render.py など）も直さず、困ったら報告する。

## データの形（キーはすべて必須。zukai だけ任意）
```
SHEET = dict(
  id='E-01', law='不動産登記規則',          # 「第N条」だけの引用は、この法令として原文を確かめる
  articles='不動産登記規則第77条ほか',       # 「対象条文」の行
  conclusion=[3行],                          # この一枚で言えること。**太字**は ** で囲む
  blocks=[...1〜4個...],                     # 本体
  example=dict(kind='計算例'|'書き方の例', title='…', lines=[…]),
  traps=[2〜3個],                            # 間違えやすい点
  basis=['不動産登記規則第77条', …],         # 根拠（法令名つき）
  more=['topics/KD_05_…md'],                 # 任意：くわしく読める既存記事（note-articles/ からの相対パス。実在するもの）
  claims=[('不動産登記規則','77','原文の文言そのまま'), …],   # 4つ以上。原文にその文言が（空白を除いて）あるか機械で確かめる
  unverified=['…'],                          # 任意：原文を確かめられなかった根拠（通達・先例など）。あれば必ず書く
  note_law='…',                              # 任意：法改正の時点（改正があった論点だけ）
  header=dict(l1, l2, hl, left, right),      # 見出し画像（下記）
  zukai=dict(title, topics, cards=[...]),    # 任意：イラスト図解（下記）
)
```
**ブロックの種類**（本体 `blocks`）
- `dict(kind='table', title=, head=[…], rows=[[…],…], note=)`：**4列まで・10行まで**。セルは短く（80字以内、できれば30字前後）。1列目は項目名。
- `dict(kind='check', title=, yes_label=, yes=[…], no_label=, no=[…], cols_yes=2, cols_no=2)`：2つの箱（緑○／赤×）。項目が短い（14字以内）ときだけ `cols_*=2`（2列）。
- `dict(kind='steps', title=, items=[…])`：番号つき手順（8つまで）。
- `dict(kind='defs', title=, items=[('語','定義'),…])`：用語カード。
- `dict(kind='text', title=, text=)`：短い説明。

## 守ること
- **スマホで読む**ことが最優先。1枚の画像は幅1080pxで、**高さ3,400px以下を目標**（4,000pxを超えるとNG）。内容が多ければ削る（詰め込まない）。論点が大きすぎるときは、データに入れず「その2に分ける」と報告する。
- 文体はである調。1文を短く。絵文字・顔文字は使わない。**太字**は結論の決め手の語だけ。
- 条文は番号だけ書く（原文の長い引用は載せない）。「第N条」は必ず法令名とセットで書く（例：不動産登記規則第77条、法第41条、令第7条、準則第72条）。ブロックの中で省略するときは `law` の法令として扱われる。
- **数値の入った例は、式から文字列を作る**（f文字列）。計算が出るシートは、ファイル内に `def verify():` を書いて `assert` で検算する（check_all.py が呼ぶ）。端数は切り捨て・四捨五入の別を原文で確かめてから書く。
- **確かめていないことは書かない**。通達・先例・判例で `note-articles/laws/` に原文がない根拠は、本文では断定せず、`unverified` に「原文は未確認」と分けて書く。「頻出」「必ず出る」は書かない。
- 禁止：個人の演習結果・誤答の回数・問題番号・年度（令和◯年度など）・「アガルート」等の教材名・図番・樹形図を意味する「木」「ツリー」の語（『判定の流れ』『流れ図』と書く）。
- 現行法令を正とする（試験当時の法令ではない）。改正があった論点は `note_law` に時点を書く。
- 年度別の解説の結論と食い違う場合は、原文を正とし、報告に書く。

## 見出し画像（header）
女性のMCキャラクター1人の見出し画像（ChatGPT用）の素材。
- `l1`：1行目（14字以内）、`l2`：2行目（14字以内）、`hl`：`l2` の中の強調する語（赤橙になる）。**数字・英字を入れない**（漢数字は可）。
- `left` / `right`：左右の背景の絵（**英語**で書く。文字・数字は一切描かせない：「a …, all without any text」）。このシートの論点が分かる小物（天秤、図面、建物、土地、書類、カレンダー等）。

## イラスト図解（zukai）：絵にして分かりやすい論点だけ
`zukai=dict(title=（14字前後）, topics=（論点の列挙）, cards=[dict(h=見出し22字以内, illust=英語の絵の説明, words=['絵に入れてよい語'], tag=結論タグ（3〜16字）), …4〜6枚])`
- 図形・位置関係・流れ・構造のあるシート（図面、敷地権、合併合体、手順など）は入れる。表だけで足りるシートは省略してよい。
- `illust` は英語。絵の中に入れる文字は `words` の語だけ（絵の中の文字は少なく、なくてもよい）。`h`・`tag` に英字は不可（半角数字は可）。
- 絵はフラット・アイソメトリックで、文章を描かせない。1カード＝1つの結論。

## 報告に書くこと（最後に短く）
- できたID、画像の高さ、`unverified` にした点、年度別解説や既存記事と食い違った点、その2に分けた方がよい論点。
