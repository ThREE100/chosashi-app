# 平成24年度 午後の部 択一 ─ 関連記事リンクマップ（第1問〜第20問）

平成24年度の各問について、**同じ論点・似た論点を扱う他年度の過去問記事**と、**理解を助ける個別テーマ記事**を対応づけたものです。
note記事に「埋め込み」でリンクを差し込む際の設計図として使います。リンクは相互に埋め込む（H24側にも他年度側にも入れる）ことを前提としています。

## 凡例

- ★★★ … ほぼ同一論点。最優先で相互リンクすべき
- ★★ … 同じ制度・条文の別角度。リンク効果が高い
- ★ … 隣接論点。余力があればリンク
- 個別テーマ記事 … `topics/` `column/` `bunya-kaisetsu/` にある論点解説記事

## 第2問　条件（法律行為に付された条件）

**論点**：農地法所定の許可は行政処分であり条件成就の擬制は及ばない／単独行為への条件付与は原則不可だが催告解除は例外／停止条件付き贈与契約は条件付所有権移転の仮登記（不登法105条2号）ができる／条件成就前の期待権は確定的な損害賠償請求権を生じさせない／解除条件の効果は不知でも生じる
