# 相互リンクの運用ルール（提案）

1. **択一記事 → テーマ記事**：各肢の解説の直後、または「まとめ」の直前に埋め込む。1記事あたり **1〜2本**まで。多すぎると読み飛ばされる
2. **択一記事 → 択一記事**：「まとめ」の後に「▼この論点の類題」として、★★★のものを **最大3本**。全部並べると note では長すぎる
3. **テーマ記事 → 択一記事**：テーマ記事の末尾に「▼この論点が出た過去問」として年度順に一覧。ここは多くてよい（ハブとして機能させる）
4. **埋め込みの向き**：新しい年度→古い年度だけでなく、古い年度の記事にも「▼この論点の最新出題」を追記して双方向にする
5. **作業単位**：テーマ記事を1本書いたら、そのテーマにぶら下がる択一記事すべてにリンクを差し込むところまでを1セッションとする（CLAUDE.md の運用ルールに合わせて都度コミット）
