# 令和4年度 午後の部 択一 ─ 関連記事リンクマップ（第1問〜第20問）

令和4年度の各問について、**同じ論点・似た論点を扱う過去問記事**と、**理解を助ける個別テーマ記事**を対応づけたものです。
note記事に「埋め込み」でリンクを差し込む際の設計図として使います。リンクは相互に埋め込む（R4側にも過去問側にも入れる）ことを前提としています。

## 凡例

- ★★★ … ほぼ同一論点。最優先で相互リンクすべき
- ★★ … 同じ制度の別角度。リンク効果が高い
- ★ … 隣接論点。余力があればリンク
- 個別テーマ記事 … `topics/` `column/` `bunya-kaisetsu/` にある論点解説記事
