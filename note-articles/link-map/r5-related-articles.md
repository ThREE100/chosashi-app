# 令和5年度 午後の部 択一 ─ 関連記事リンクマップ（第1問〜第20問）

令和5年度の各問について、**同じ論点・似た論点を扱う過去問記事**と、**理解を助ける個別テーマ記事**を対応づけたものです。
note記事に「埋め込み」でリンクを差し込む際の設計図として使います。リンクは相互に埋め込む（R5側にも過去問側にも入れる）ことを前提としています。

## 凡例

- ★★★ … ほぼ同一論点。最優先で相互リンクすべき
- ★★ … 同じ制度の別角度。リンク効果が高い
- ★ … 隣接論点。余力があればリンク
- 個別テーマ記事 … `topics/` `column/` `bunya-kaisetsu/` にある論点解説記事

## 収録済み年度について

現在このリポジトリにあるのは **平成17年度**と**平成20年度〜令和7年度**です（平成18年度・平成19年度は未作成）。

## 第5問　表題部の登記記録

**論点**：換地処分で表題部の登記記録が新たに作成される／先取特権保存登記後の建物完成でも表題部登記記録は新規作成／分合筆でも分筆・合筆先の土地の登記記録は新規作成されない／解体移転建物は元の登記記録に解体移転した旨が記録される／区分建物の中間部分取壊しで非区分建物になると登記記録は新規作成される
