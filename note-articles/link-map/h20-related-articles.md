# 平成20年度 午後の部 択一 ─ 関連記事リンクマップ（第1問〜第20問）

平成20年度の各問について、**同じ論点・似た論点を扱う他年度の記事**と、**理解を助ける個別テーマ記事**を対応づけたものです。
note記事に「埋め込み」でリンクを差し込む際の設計図として使います。リンクは相互に埋め込む（H20側にも他年度側にも入れる）ことを前提としています。

## 凡例

- ★★★ … ほぼ同一論点。最優先で相互リンクすべき
- ★★ … 同じ制度・条文の別角度。リンク効果が高い
- ★ … 隣接論点。余力があればリンク
- 個別テーマ記事 … `topics/` `column/` `bunya-kaisetsu/` にある論点解説記事

## 収録済み年度について

このリポジトリにあるのは **平成17年度**と**平成20年度〜令和7年度**です（平成18年度・平成19年度は未作成）。
平成17年度は第7問・第9問・第20問が欠番のため17問収録です。

## 第1問　不動産質権

**論点**：質権の不可分性（全部の弁済を受けるまで全部に権利行使可）／転質に設定者の承諾は不要（責任転質）／不動産質権者は承諾なしで使用収益できる／数個の質権の順位は登記の前後による／金銭以外の引渡請求権も被担保債権にできる

## 第3問　無効と取消し

**論点**：期間経過で確定的に有効となるのは取消しうる行為の特徴／だれでも主張できるのは無効の特徴／将来に向かってのみ効力を失うのは取消しの特徴ではない（無効・取消しとも遡及効）／既払金の返還請求は無効でも取消しでも生じる／成年被後見人の行為は原則として取消しうる行為
