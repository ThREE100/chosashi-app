BODY:
<p><strong>関連：令和6年度午後の部第8問イ・第9問イ</strong></p>
<p>そもそも「分筆」と「合筆」は逆の登記です。分筆は1筆の土地を複数に分ける登記、合筆は複数の土地を1筆にまとめる登記であり、正反対の操作である点をまず押さえておきましょう。</p>
<p>分筆における一の申請情報でまとめられるかという論点と、合筆の制限に関する論点は、一見似ていますが、「手続き上まとめて申請できるかどうか」の話と、「そもそも登記自体が認められるかどうか」の話という、根本的に別の次元の話です。令和6年度午後の部の第8問イと第9問イを題材に、この2つを整理します。</p>
<h3>分筆の「一括申請」は、手続き上の便宜の話</h3>
<p>令和6年度第8問のイは、「甲土地と乙土地、それぞれ別々に分筆したい場合に、申請書を1通にまとめて出せるか」という手続き上の話です。</p>
<p>ここで問われているのは、「甲土地はまだ表題登記だけ（表題部所有者）、乙土地は所有権登記まで済んでいる（所有権の登記名義人）」という登記の進み具合が違う土地どうしでも、まとめて1通の申請書で出せるか、という点です。</p>
<p>答えは「出せる」です。なぜなら、不動産登記令4条ただし書が定める一括申請の条件は、①同じ登記所の管轄内であること、②登記の目的が同じであること（どちらも「分筆の登記」）、③登記原因及びその日付が同じであること、の3つだけだからです。「土地の登記が表題部だけか、権利部まで進んでいるか」という登記の進捗状況は、一括申請できるかどうかの条件には含まれていません。</p>
<p><strong>たとえば</strong>、Ａさんが持っている甲土地（表題登記だけ）と乙土地（所有権登記済み）を、両方とも分筆したいとき、この2つの登記の「進み具合」が違っていても、それは単なる事務手続き上の話にすぎず、まとめて1通の申請書で処理することを妨げません。</p>
<h3>合筆の「地目の一致」は、登記そのものが成立するかどうかの話</h3>
<p>一方、令和6年度第9問のイは、「甲土地と乙土地をそもそも合筆（1つにまとめる登記）してよいかどうか」という、登記の実体的な成立要件の話です。</p>
<p>不動産登記法41条は、合筆をしてはいけない場合（合筆の制限）をいくつか列挙しており、その1つに「地目又は地番区域が異なる土地は合筆できない」というルールがあります（41条2号）。ここでいう「地目」は、登記簿に書かれている地目ではなく、実際の現況の地目で判断します。登記簿上はどちらも「畑」と書いてあっても、実際には一方がもう宅地として使われているなら、法律上その2筆は「性質の異なる土地」とみなされ、そもそも合筆という登記自体が成立しません。</p>
<p><strong>たとえば</strong>、登記簿上「畑」「畑」となっている隣り合う2筆の土地でも、片方が実際には宅地として使われているなら、書類の書き方をどう工夫しても、合筆の登記そのものを通すことはできません。</p>
<h3>2つの違いのまとめ</h3>
<p><strong>令和6年度第8問イ（分筆の一括申請）</strong></p>
<ul>
<li>問われている次元：手続き上、書類をまとめられるか</li>
<li>比較しているもの：登記の目的・原因・日付が同じか</li>
<li>結論：登記の進捗状況（表題部所有者／所有権登記名義人）が違っても関係なく一括できる</li>
</ul>
<p><strong>令和6年度第9問イ（合筆の地目制限）</strong></p>
<ul>
<li>問われている次元：登記そのものが法律上成立するか</li>
<li>比較しているもの：土地の現況の地目が同じか</li>
<li>結論：現況地目が違えばそもそも合筆できない</li>
</ul>
<p>要するに、第8問イは「書類の出し方」の柔軟性の話、第9問イは「土地の中身」に関する厳格な要件の話という、レベルの異なる論点なので、混同しないように注意しましょう。</p>
<h3>合筆の登記ができる条件（不動産登記法41条の裏返し）</h3>
<p>不動産登記法41条は「合筆ができない場合」を列挙する形の条文なので、逆に言うと、以下のすべての条件を満たしたときに初めて合筆ができる、ということになります。</p>
<ul>
<li><strong>①相互に接続していること（41条1号の裏返し）</strong>：合筆する土地同士が、地図上で隣り合って接していない場合は合筆できません。</li>
<li><strong>②地目・地番区域が同一であること（41条2号）</strong>：登記簿上の地目だけでなく、現況の地目も一致している必要があります（先ほど解説した第9問イの論点です）。</li>
<li><strong>③表題部所有者又は所有権の登記名義人が同一であること（41条3号）</strong>：持ち主が違う土地どうしは合筆できません。</li>
<li><strong>④持分が同一であること（41条4号）</strong>：共有名義の場合、名義人が同じでも持分の割合（例：Ａが5分の3・Ｂが5分の2）が土地ごとに異なると合筆できません。</li>
<li><strong>⑤所有権登記の有無が一致していること（41条5号）</strong>：所有権登記がない土地（表題部所有者のみ）と、所有権登記がある土地は合筆できません。</li>
<li><strong>⑥所有権以外の権利の登記（抵当権など）がないこと（41条6号）</strong>：原則として、抵当権などの権利登記がある土地は合筆できません（ただし、合筆後もそのまま登記できる一定の権利は例外として認められます）。</li>
</ul>
<h3>まとめ</h3>
<ul>
<li>分筆と合筆は正反対の登記であり、混同しないよう注意する</li>
<li>分筆の一括申請（第8問イ）は<strong>手続き上まとめられるかどうか</strong>の話。不動産登記令4条ただし書の3条件（同一管轄・同一目的・同一原因日付）だけで判断でき、登記の進捗状況は関係ない</li>
<li>合筆の地目制限（第9問イ）は<strong>登記そのものが法律上成立するかどうか</strong>の話。不動産登記法41条2号の「地目」は現況の地目で判断する</li>
<li>合筆は、土地の性質（地目・地番区域）、持ち主の状況（名義人・持分・所有権登記の有無）、他の権利の有無という3つの側面すべてで「同じ状態」がそろっていないと認められない、かなり厳格な登記だとイメージすると覚えやすくなります</li>
</ul>
<p>「まとめて申請できるか」という手続レベルの話と、「そもそも登記が成立するか」という実体要件レベルの話を区別できると、初見の組合せ問題にも対応しやすくなります。</p>
<h3>見出し画像用フレーズ</h3>
<ul>
<li>分筆と合筆、実は正反対の登記なんです</li>
<li>一括申請できるかは、進捗状況と関係ないんです</li>
<li>地目は登記簿ではなく、現況で判断するんです</li>
<li>「まとめられるか」と「成立するか」は別次元です</li>
<li>合筆は3つの側面全部そろわないとダメなんです</li>
</ul>

BODY:
<p><strong>関連：不動産登記規則28条・28条の2・235条／過去問（令和7年度午後の部第5問、令和4年度午後の部第4問、平成27年度午後の部第18問など）</strong></p>
<p>土地家屋調査士試験では、「登記所に保存されている情報の保存期間」がほぼ毎年のように出題されます。図面・登記記録・申請書類など、書類の種類ごとに保存期間がバラバラに定められており、「図面だから」「登記記録だから」と大きくくくって覚えると必ず引っかかります。今回は、不動産登記規則28条を中心に、試験で問われやすい主要な期間を5段階に整理してまとめます。ただし、これは規則28条・28条の2に定められた期間の全てではなく、これ以外にも20年・3年・1年などの期間が定められています（詳細は後述）。</p>
<h3>保存期間は5段階</h3>
<p>大きく分けると、登記所に保存される情報の保存期間は次の5段階に分かれます。</p>
<p><strong>永久保存</strong></p>
<ul>
<li>登記記録（規則28条1号）——<strong>閉鎖登記記録を除く</strong>、つまり<strong>現に使用されている（閉鎖されていない）もの</strong>は永久</li>
<li>地図及び地図に準ずる図面（規則28条2号）</li>
<li>建物所在図（規則28条3号）——<strong>閉鎖されたものを含めて</strong>永久</li>
<li>土地所在図・地積測量図・建物図面及び各階平面図（規則28条13号）——<strong>現に使用されている（閉鎖されていない）もの</strong>は永久</li>
<li>筆界特定書に記載され、又は記録された情報（規則235条1項1号）</li>
</ul>
<p><strong>50年保存</strong></p>
<ul>
<li>土地に関する閉鎖登記記録（閉鎖した日から）（規則28条4号）</li>
</ul>
<p><strong>30年保存</strong></p>
<ul>
<li>建物に関する閉鎖登記記録（閉鎖した日から）</li>
<li>閉鎖した土地所在図・地積測量図・建物図面及び各階平面図（閉鎖した日から）（規則28条13号）</li>
<li>表示に関する登記及び権利に関する登記の申請情報・添付情報（受付の日から）（規則28条9号）</li>
<li>筆界特定書以外の筆界特定手続記録に記載・記録された情報（送付を受けた年の翌年から）（規則235条1項2号）</li>
</ul>
<p><strong>10年保存</strong></p>
<ul>
<li>共同担保目録（記録されている全ての事項を抹消した日から）（規則28条6号）</li>
</ul>
<p><strong>5年保存</strong></p>
<ul>
<li>法定相続情報一覧図つづり込み帳（作成の年の翌年から）（規則28条の2第6号）</li>
<li>職権表示登記等事件簿（立件の日から）（規則28条11号）</li>
</ul>
<p><strong>この5段階に含まれない期間</strong></p>
<p>上記5段階は、土地家屋調査士試験で問われやすい主要な期間に絞ったものです。規則28条・28条の2には、このほかにも次のような期間が定められています。</p>
<ul>
<li><strong>20年間</strong>：信託目録（信託の登記の抹消をした日から）（規則28条7号）</li>
<li><strong>1年間</strong>：受付帳のうち登記識別情報に関する証明の請求に係るもの、各種通知簿、請求書類つづり込み帳、申出立件事務日記帳、登記事務日記帳及び登記事項証明書等用紙管理簿（規則28条8号かっこ書き・16号・18号、規則28条の2第一の二号・第二号）</li>
<li><strong>3年間</strong>：不正登記防止申出書類つづり込み帳、土地価格通知書つづり込み帳、建物価格通知書つづり込み帳及び諸表つづり込み帳（規則28条の2第4号）</li>
<li><strong>10年間（共同担保目録とは起算点が異なるもの）</strong>：登記識別情報の失効の申出に関する情報（当該申出の受付の日から）（規則28条17号）</li>
</ul>
<h3>紛らわしいポイントに注意</h3>
<p><strong>同じ「図面」でも、現用か閉鎖後かで扱いが変わる</strong></p>
<p>土地所在図・地積測量図・建物図面・各階平面図は、現に使用されている間は永久保存ですが、新しい図面に置き換えられて閉鎖されると、そこから30年で保存期間が満了します。この「現用なら永久、閉鎖後は30年」という2つの扱いは、いずれも同じ規則28条13号の中で定められています。</p>
<p><strong>たとえば</strong>、分筆によって古い地積測量図が新しいものに置き換えられ「閉鎖」の扱いになると、閉鎖後は30年間保存された後、保存期間の対象から外れます。</p>
<p><strong>建物所在図だけは、閉鎖後も永久保存という例外</strong></p>
<p>同じ「図面」の仲間でも、建物所在図だけは閉鎖された後も引き続き永久に保存されます。閉鎖後は30年になる地積測量図・建物図面・各階平面図とは扱いが異なるため、この違いが本試験で繰り返し狙われています。</p>
<p><strong>登記記録そのものも、現用なら永久、閉鎖後は土地50年・建物30年</strong></p>
<p>図面と同じ構造は、登記記録本体にも当てはまります。現に使用されている登記記録（閉鎖登記記録を除く）は規則28条1号により永久保存ですが、合筆・合併・滅失等によって閉鎖されると、そこから先は閉鎖登記記録として期間限定の保存に切り替わります（土地は50年、建物は30年）。</p>
<p><strong>たとえば</strong>、現に使用されている土地の登記記録は永久保存の対象ですが、合筆によってその登記記録が閉鎖されると、閉鎖した日から50年が経過した時点で保存期間が満了します。</p>
<p><strong>土地の閉鎖登記記録は50年、建物の閉鎖登記記録は30年</strong></p>
<p>同じ「閉鎖登記記録」でも、対象が土地か建物かで保存期間が異なります。土地の閉鎖登記記録は50年、建物の閉鎖登記記録は30年です。</p>
<p><strong>たとえば</strong>、合筆によって消滅した土地の閉鎖登記記録は50年間保存されますが、合併によって消滅した建物の閉鎖登記記録は30年間の保存にとどまります。</p>
<p><strong>筆界特定書とそれ以外の筆界特定手続記録は別扱い</strong></p>
<p>筆界特定の手続に関する記録のうち、「筆界特定書」そのものに記載・記録された情報は永久保存ですが、それ以外の筆界特定手続記録（申請書や資料など）は30年保存にとどまります。</p>
<p><strong>たとえば</strong>、筆界特定の結論を記載した筆界特定書自体は将来にわたって参照できるよう永久に保存されますが、その判断に至る過程で提出された資料等は30年で保存対象から外れます。</p>
<h3>まとめ</h3>
<p>保存期間を覚えるときは、「その登記記録・図面は今も使われているか、それとも役目を終えて閉鎖されたものか」「土地の話か建物の話か」「筆界特定書そのものか、それ以外の記録か」という切り口で整理すると、似たような選択肢が並んでいても迷わずに判断できます。</p>
<h3>見出し画像用フレーズ</h3>
<ul>
<li>保存期間、永久・50年・30年・10年・5年の5段階なんです</li>
<li>図面は「現用」か「閉鎖後」かで、寿命が変わるんです</li>
<li>建物所在図だけ、閉鎖されても一生モノなんです</li>
<li>登記記録も、現用は永久、閉鎖後は期限つきなんです</li>
<li>土地の閉鎖記録は50年、建物は30年、実は違うんです</li>
<li>筆界特定書そのものだけ、ずっと保存されるんです</li>
</ul>

CONVERT BREAKS: 0

BODY:
<p><strong>関連：令和6年度午後の部第18問イ</strong></p>
<p>区分建物の登記の問題を解いていると、「表題登記のない一棟の建物」「まだ表題登記されていない区分建物」という表現によく出会います。しかし、不動産登記法は「建物を新築したら表題登記を申請しなければならない」と定めているはずです。だとすれば、「表題登記のない建物」など存在しないのではないか——そう疑問に思う方も多いはずです。今回は、この疑問を出発点に、表題登記の「義務」と「現実」のズレを整理します。</p>
<h3>表題登記は、たしかに「義務」である</h3>
<p>不動産登記法47条1項は、新築した建物の所有者に対して、<strong>所有権を取得した日から1か月以内に、表題登記を申請しなければならない</strong>と定めています。この義務に違反すると、10万円以下の過料という行政上の制裁が科される可能性もあります(不動産登記法164条)。</p>
<p>条文だけを読むと、「新築した建物は必ず1か月以内に登記される」という運用を想像してしまいます。</p>
<h3>「しなければならない」は、「必ずそうなる」という意味ではない</h3>
<p>ここが最大のポイントです。<strong>「申請しなければならない」という規定は、所有者に課された義務にすぎず、その義務が実際に果たされることを保証するものではありません。</strong></p>
<p><strong>たとえば</strong>、道路交通法は「赤信号では止まらなければならない」と定めていますが、この規定があるからといって、すべての車が必ず赤信号で止まるとは限りません。信号無視をする人が現実にいるのと同じように、表題登記の義務も、実際に果たされるかどうかは所有者次第です。</p>
<p>義務違反への制裁(過料)はありますが、これは「違反したらお金を払う可能性がある」という抑止力にとどまり、<strong>登記所が強制的に登記してくれるわけでも、違反した建物が使えなくなるわけでもありません</strong>。そのため、義務が果たされないまま、表題登記のない建物が現実に存在し続けることになります。</p>
<h3>なぜ「未登記の建物」が生まれるのか</h3>
<p>実務では、次のような事情で表題登記が後回しにされることがあります。</p>
<p><strong>たとえば</strong>、大きな建物を建てたものの、各部屋を売り出す時期がバラバラで、まだ誰にも引き渡されていない部屋がある場合、建物全体の表題登記の手続きがなかなか進まないまま時間が経ってしまう、ということが起こり得ます。あるいは、単に所有者が「登記は面倒だから」と申請を後回しにしているだけ、というケースも珍しくありません。相続した建物の登記がそのまま放置されているケースなども、同様の理由によるものです。</p>
<h3>令和6年度第18問イとの関係</h3>
<p>まさにこの「本来は登記すべきなのに、まだ登記されていない建物」が現実に存在する、という前提で作られているのが、令和6年度午後の部第18問のイです。</p>
<p>同問イは「区分建物の表題登記の申請をする場合において、当該区分建物が属する一棟の建物とは別の表題登記のない一棟の建物に属する区分建物を附属建物とするときは、当該附属建物とする区分建物が属する一棟の建物に属する他の区分建物の表題登記の申請と併せてしなければならない」という記述の正誤を問うものでした。</p>
<p><strong>たとえば</strong>、Ａ棟の1室を持つＸさんが、まだ表題登記されていないＢ棟にある倉庫部分も取得していて、これをＡ棟の自室の附属建物としたいと考えたとします。区分建物として登記する場合、一棟の建物に属する全部の区分建物の表題部を一括して備える必要があるため、Ｂ棟がまだ表題登記されていない以上、Ｘさんの附属建物化の申請にあわせて、Ｂ棟にある他の区分建物の表題登記も一緒に申請しなければなりません。</p>
<p>このルールは、「そもそも表題登記のない建物なんて存在しないはず」という建前ではなく、「現実には登記が後回しにされている建物が存在する」という実態を前提に設計されている、という点が重要です。</p>
<h3>まとめ</h3>
<ul>
<li>表題登記は法律上の<strong>義務</strong>であり、違反すれば過料の対象にもなり得ますが、<strong>義務があること自体が「必ず登記される」ことを保証するわけではありません</strong>。</li>
<li>現実には、部屋の売却時期のばらつきや、所有者の単なる先延ばしなどにより、表題登記のない建物が存在し続けることがあります。</li>
<li>区分建物の登記実務は、こうした「未登記のまま放置された建物」が現実に存在することを前提にルールが組み立てられており、令和6年度第18問イの一括申請ルールもその一例です。</li>
</ul>
<p>法律の条文を読むときは、「〜しなければならない」という規定を見た瞬間に「だから必ずそうなっているはずだ」と早合点せず、<strong>義務と現実は別物である</strong>という視点を持っておくと、実務に即した正確な理解につながります。</p>

<p><strong>関連：令和6年度午後の部第8問イ</strong></p>
<p>土地家屋調査士試験の過去問を解いていると、「表題部所有者である甲土地」「所有権の登記名義人である乙土地」というように、同じ「持ち主」を指すのに違う言葉が使い分けられている場面によく出会います。この2つの違いを正確に理解しているかどうかで、分筆・合筆・表題部の変更登記などの問題の理解度が大きく変わります。今回は、この2つの用語の違いを、登記簿の成り立ちから整理します。</p>
<h3>登記記録は「表題部」と「権利部」でできている</h3>
<p>不動産の登記記録は、大きく2つのパートに分かれています。</p>
<ul>
<li><strong>表題部</strong>：土地・建物の物理的な現況（所在、地積、地目、構造、床面積など）を記録する部分</li>
<li><strong>権利部</strong>：その不動産に対する権利関係（所有権・抵当権など）を記録する部分。さらに所有権を記録する「甲区」と、それ以外の権利を記録する「乙区」に分かれる</li>
</ul>
<p>新しく土地ができた、新しく建物を建てた、というときに最初に行う登記が「表題登記」です。この時点ではまだ権利部そのものが存在せず、表題部にだけ「所有者はこの人らしい」という情報が記録されます。この人を<strong>表題部所有者</strong>といいます（不動産登記法2条10号）。</p>
<p><strong>たとえば</strong>、Ａさんが自宅を新築した直後、土地家屋調査士に依頼して表題登記だけを済ませたとします。この時点でＡさんは、登記簿の表題部に「表題部所有者」として記載されますが、権利部（甲区・乙区）はまだ存在しません。</p>
<h3>所有権の登記名義人になるには、もう一段階の手続きが必要</h3>
<p>表題部所有者としての記載は、あくまで「表題登記を申請した人が、自分が所有者だと申告した」という事実上の記録にすぎません。表示に関する登記（表題部の登記）は不動産の物理的な現況を公示することが目的であり、権利を保護するための対抗力を持たないためです。</p>
<p>権利を法的に第三者へ主張できる効力（対抗力）を得るには、あらためて<strong>所有権保存登記</strong>を申請する必要があります（不動産登記法74条1項）。この登記が完了すると、権利部甲区に「<strong>所有権の登記名義人</strong>」として記載されます。</p>
<p><strong>たとえば</strong>、先ほどのＡさんが、住宅ローンを組むために金融機関から「正式な所有権登記をしてください」と求められ、司法書士に依頼して所有権保存登記をしたとします。この登記が完了すると、Ａさんは権利部甲区に所有権の登記名義人として記載されるようになります。</p>
<h3>実務では、同じ人が両方の立場を持つことがある</h3>
<p>実務上よくあるのが、<strong>同じ所有者が持つ複数の土地のうち、一方は表題部所有者のまま、もう一方は所有権の登記名義人になっている</strong>、という状態です。特に相続で受け継いだ古い土地や、あまり活用されていない土地では、表題登記だけ済ませて所有権保存登記を後回しにしているケースが少なくありません。</p>
<p><strong>たとえば</strong>、Ａさんが甲土地（先祖代々の土地で、表題登記だけ済ませており表題部所有者のまま）と、乙土地（自分の代で新たに取得し、所有権保存登記まで済ませていて所有権の登記名義人）を、それぞれ別の経緯で取得していたとします。この2筆をまとめて分筆の登記をしたいとき、法律上のステータスが異なる甲土地・乙土地を同時に扱うことになります。</p>
<p>これはまさに、令和6年度午後の部第8問イで問われた場面です。同問イは「Ａが表題部所有者である甲土地とＡが所有権の登記名義人である乙土地とが同一の登記所の管轄区域内にある場合であっても、甲土地の分筆の登記と乙土地の分筆の登記とを、一の申請情報によって申請することはできない」という記述の正誤を問うものでした。同一の登記所の管轄区域内にある不動産については、登記の目的・登記原因及びその日付が同一であれば、一の申請情報によって登記を申請することができるため（不動産登記令4条ただし書）、表題部所有者の土地と所有権の登記名義人の土地が混在していても、まとめて申請することができます。</p>
<h3>まとめ</h3>
<ul>
<li><strong>表題部所有者</strong>：表題登記の時点で「所有者らしい」と記録された人。まだ権利部が存在せず、対抗力もない</li>
<li><strong>所有権の登記名義人</strong>：所有権保存登記（または移転登記）を経て、権利部甲区に正式に記録された人。対抗力がある</li>
<li>同じ人物が、土地によって表題部所有者だったり所有権の登記名義人だったりする状態は、実務上よくある</li>
<li>表題部所有者の土地と所有権の登記名義人の土地が混在していても、登記の目的・原因・日付が同一であれば、一の申請情報でまとめて申請できる（令4条ただし書）</li>
</ul>
<p>「持ち主として記載されている」という結果だけを見ると同じに思えますが、その裏にある手続きの段階が違う、という点を押さえておくと、分筆・合筆・変更登記など幅広い問題に応用できます。</p>

<li>表題部所有者の土地でも、まとめて分筆申請できるんです</li>
</ul>

<p><strong>関連：民法20条（制限行為能力者の相手方の催告権）／過去問（令和6年度午後の部第1問、平成25年度午後の部第1問など）</strong></p>
<p>制限行為能力者と契約した相手方は、いつまでも「追認されるかどうか」が確定しない不安定な立場に置かれます。この不安定さを解消するために設けられているのが民法20条の催告権です。20条は1項から4項までの4パターンで構成されており、<strong>「誰に催告したか」によって、無回答（確答なし）の場合の効果が「追認」になるか「取消し」になるかが正反対になる</strong>点が最大のポイントです。土地家屋調査士試験でも繰り返し出題される頻出論点なので、この記事で4パターンをまとめて整理します。</p>
<h3>民法20条の全体構造</h3>
<p>催告は、いずれのパターンでも<strong>必ず「1か月以上の期間」を定めて</strong>行う必要があります（20条1項）。そのうえで、次の4つのパターンに分かれます。</p>
<ul>
<li><strong>①1項</strong>：制限行為能力者が行為能力者となった後、本人に催告 → 無回答は追認</li>
<li><strong>②2項</strong>：制限行為能力者のままの間に、法定代理人・保佐人・補助人に催告 → 無回答は追認</li>
<li><strong>③3項</strong>：①②の催告のうち、特別の方式を要する行為について → 無回答は取消し（原則の逆転）</li>
<li><strong>④4項</strong>：被保佐人、または13条1項の同意権付与の審判（17条1項の審判）を受けた被補助人に、本人へ直接催告 → 無回答は取消し（原則の逆転）</li>
</ul>
<h3>①1項：行為能力者となった後の本人への催告は、無回答なら追認</h3>
<p>制限行為能力者がすでに行為能力者となった後（未成年者が成年に達した後、後見開始の審判が取り消された後など）は、その本人に対して催告することができます。この場合、本人はもはや判断能力の制限を受けていないため、無回答であれば追認したものとみなされます。</p>
<p><strong>たとえば</strong>、未成年者だったAさんが成年に達した後、契約の相手方Bさんが「1か月以内に、あの契約を追認するかどうか確答してください」とA本人に催告した場合、Aさんが期間内に何も答えなければ、その契約は追認されたものとして扱われます。</p>
<h3>②2項：法定代理人・保佐人・補助人への催告は、無回答なら追認（原則どおり）</h3>
<p>制限行為能力者がまだ制限行為能力者のままである間は、相手方はその法定代理人・保佐人・補助人に対して、権限内の行為について催告することができます。この場合も、無回答であれば追認したものとみなされるのが原則です。</p>
<p><strong>たとえば</strong>、被保佐人であるCさんが保佐人の同意を得ずに契約を締結した場合、相手方は保佐人に対して「1か月以内に追認するかどうか確答してください」と催告することができ、保佐人が期間内に何も答えなければ、その契約は追認されたものとして扱われます。</p>
<p>なお、未成年者・成年被後見人の<strong>本人</strong>には、そもそも催告そのものができません。判断能力が著しく不十分なため、意思表示を受け取って理解する能力（受領能力）自体が認められていないからです（98条の2）。相手方は必ず法定代理人・成年後見人に対して催告する必要があり、これがこの②のパターンにあたります。</p>
<p><strong>たとえば</strong>、未成年者Aさんや成年被後見人Bさんと契約した相手方は、A・B本人に「追認しますか？」と催告することはできず、それぞれの親権者や成年後見人に催告する必要があります。</p>
<h3>③3項：特別の方式を要する行為は、無回答なら取消し（1回目の逆転）</h3>
<p>①・②の催告の対象になっている行為が、<strong>追認するために一定の「特別の方式」を具備する必要がある行為</strong>である場合には、期間内にその方式を具備した旨の通知を発しないと、逆に<strong>取り消したもの</strong>とみなされます。</p>
<p>この「特別の方式」の典型例が、後見監督人の同意です。後見監督人がいる場合、後見人が被後見人に代わって営業をし、または13条1項各号に掲げる行為（借財・保証、不動産その他重要な財産に関する権利の得喪、訴訟行為、贈与・和解・仲裁合意、相続の承認・放棄・遺産分割、新築・改築・増築・大修繕、602条所定の期間を超える賃貸借など）をするには、後見監督人の同意を得なければなりません（864条。ただし、元本の領収だけはこの例外で、後見監督人の同意は不要です）。後見人がこの同意を得ずに行った行為は取り消すことができ、この場合には20条の規定が準用されます（865条）。</p>
<p><strong>具体例</strong>：未成年者Aさんの後見人Xさんに、後見監督人Yさんがついているとします。Xさんが、Yさんの同意を得ないまま、Aさん所有の不動産を相手方Zさんに売却する契約を結んでしまいました。不動産の売買は864条・13条1項3号にあたる行為なので、本来はYさんの同意が必要でしたが、それを欠いているため、この契約は取り消すことができる行為になっています。不安に思ったZさんが、Xさんに対して「1か月以上の期間を定めて、この契約を追認するかどうか確答してください」と催告した場合（20条3項の場面）、Xさんが期間内にすべきことは、単に「追認します」と返事をすることではありません。実際にYさんから同意を得たうえで、「後見監督人の同意を得ましたので、この売買契約を追認します」とZさんに通知する必要があります。もしXさんが期間内にこの通知を発しなければ、20条2項の原則（法定代理人への催告→無回答は追認とみなす）とは逆に、この契約は<strong>取り消したもの</strong>とみなされます。</p>
<h3>④4項：被保佐人・被補助人本人への催告は、無回答なら取消し（2回目の逆転）</h3>
<p>被保佐人、または13条1項の行為について同意権付与の審判（17条1項の審判）を受けた被補助人は、未成年者・成年被後見人ほど判断能力が制限されていないため、本人にも意思表示の受領能力が認められ、相手方は保佐人・補助人ではなく<strong>本人に直接</strong>催告することができます。ただし、この場合だけ効果が逆転し、期間内に「保佐人・補助人の追認を得た」旨の通知がなければ、<strong>取り消したもの</strong>とみなされます。</p>
<p><strong>たとえば</strong>、被保佐人であるCさんが保佐人の同意なしに契約した場合、相手方はCさん本人に「保佐人の追認を得てください」と催告することができますが、Cさんが期間内に「追認を得た」と通知しなければ、その契約は取り消されたものとして扱われます。②で紹介した「保佐人に催告した場合は無回答→追認」というパターンと、この「C本人に催告した場合は無回答→取消し」というパターンが正反対になる点が、この分野で最も狙われやすいポイントです（令和6年度午後の部第1問オはまさにこの②のパターンを扱った出題でした）。</p>
<h3>なぜ「追認とみなす」ではなく「取消しとみなす」に逆転するのか</h3>
<p>②の通常のケースでは、法定代理人・保佐人・補助人には、権限の範囲内でその行為を単独で追認する権限が備わっているため、「黙っていたら追認」と扱っても実害がありません。</p>
<p>しかし、③・④のケースはこれと事情が異なります。③（後見監督人の同意を要する行為）では、後見人はそもそも単独で有効に追認する権限を持っていません。もし「無回答＝追認」としてしまうと、後見人が黙っているだけで、本来必要な後見監督人のチェックを経ずに追認が成立してしまい、被後見人保護の趣旨（864条がわざわざ同意を要求している意味）が骨抜きになってしまいます。④（被保佐人・被補助人本人への催告）でも同様に、本人は単独では追認する権限を持たず、保佐人・補助人の追認を得て初めて有効な追認になります。そのため法は、③・④のケースではあえて逆に、「同意・追認を得た旨の通知がなければ取消し」という、制限行為能力者側に有利な方向にデフォルトを設定しています。</p>
<h3>まとめの覚え方</h3>
<ul>
<li>催告は必ず「1か月以上の期間」を定めて行う。</li>
<li>「本人に催告」できるのは、行為能力者となった後の本人（①）、被保佐人・被補助人本人（④）だけ。未成年者・成年被後見人の本人には催告できない。</li>
<li>「本人に催告」した場合の無回答の効果は、①（行為能力者となった後）なら「追認」、④（被保佐人・被補助人、まだ制限行為能力者のまま）なら「取消し」。</li>
<li>「法定代理人・保佐人・補助人に催告」した場合の無回答の効果は「追認」（②、原則どおり）。</li>
<li>例外的に「特別の方式を要する行為」について法定代理人等に催告した場合だけは、②のはずが③で「取消し」に逆転する（典型例：後見監督人の同意を要する行為、864条・865条）。</li>
</ul>
<h3>見出し画像用フレーズ</h3>
<ul>
<li>催告した相手で、結果が正反対になるって知ってた？</li>
<li>未成年者・成年被後見人には、そもそも催告できないんです</li>
<li>被保佐人・被補助人は、本人に直接催告できるんです</li>
<li>無回答なのに「追認」になる場合と「取消し」になる場合があるんです</li>
<li>後見監督人の同意がいる行為、返事だけじゃ追認にならないんです</li>
</ul>

BODY:
<p><strong>関連：不動産登記法上の「建物」の意義／過去問(令和6年度午後の部第12問、令和5年度午後の部第11問、令和4年度午後の部第10問、平成30年度午後の部第10問、平成27年度午後の部第13問、平成21年度午後の部第4問、平成20年度午後の部第16問など)</strong></p>
<p>土地家屋調査士試験では、ほぼ毎年のように「建物の認定」というテーマで、一風変わった構造物(サイロ、石油タンク、桟橋の上の水族館、観音像の本堂…)が建物として登記できるかどうかを問う問題が出題されます。この分野は個別の暗記量が多くなりがちですが、<strong>3つの要件に立ち返って機械的に当てはめる</strong>練習をしておけば、初見の構造物が出てきても対応できるようになります。</p>
<h3>建物の定義(3要件)</h3>
<p>不動産登記法上の「建物」とは、次の3要件をすべて満たすものをいいます(昭24.2.22民事甲240号)。</p>
<p>1. <strong>定着性</strong>：土地に定着した構造物であること 2. <strong>外気分断性</strong>：屋根及び周壁、又はこれに類するものを有すること 3. <strong>用途性</strong>：その目的とする用途に供しうる状態にあること(人間が社会生活上の活動のために利用できる空間であること)</p>
<p>この3要件のうち、<strong>どれか1つでも欠けると建物として登記できません</strong>。過去問を解くときは、「この構造物は3要件のうちどれを満たしていて、どれを欠いているのか」を意識して読むのがコツです。</p>
<h3>建物として登記できるもの(○)</h3>
<p>過去の本試験で「建物として認められる」とされた例を、根拠とあわせて整理します。</p>
<ul>
<li><strong>家畜飼料用のサイロ</strong>(鋼管製の脚柱で土地に定着し、鉄板で外気と分断されているもの)(昭35.4.15民甲928号)</li>
<li><strong>廃車になった鉄道車両</strong>に基礎工事や付帯設備を施し、店舗・居宅として利用しているもの</li>
<li><strong>寺院の山門</strong>のうち、上部が倉庫(宝物庫)として利用され、周壁により外気と分断されている部分(用途性が認められるため、単なる門としては扱われない)</li>
<li><strong>鉄骨を組み立て、屋根及び周壁を永続性のある膜構造の特殊シート(塩化ビニール等)で覆った構造物</strong>(長期使用に耐えるプール施設など)</li>
<li><strong>最上部に屋根及び周壁を有する1層の展望台</strong>で、下部が階段室のみとなっているもの(「高床式平家建」として登記可能)</li>
<li><strong>回転式パーキング機械が設置されたタワー状の立体駐車場</strong>(屋根・外壁があるもの)(昭24.2.22民事甲240号)</li>
<li><strong>観音像の外壁</strong>を持ち、内部に祭壇・参拝者の着席設備があり、寺院の本堂として利用されているもの(昭30.4.9民甲694号)</li>
<li><strong>半永久的な園芸・農耕用の温床施設</strong>(ガラス等で屋根・周壁が造られ、耐久性が認められるもの)(準則77条1号オ、ただし後述の例外に注意)</li>
<li><strong>高架鉄道の高架下(ガード下)を屋根として利用</strong>し、周壁を築造して外気を分断し一体化させた店舗・倉庫</li>
<li><strong>海底からの脚柱で支えられた永久的な構築物(桟橋)の上</strong>に建築された、屋根・周壁を有する建物(水族館、店舗など)</li>
<li><strong>土地に固定している浮船を利用した店舗</strong></li>
<li><strong>貨物運搬用のコンテナボックスを利用した貸倉庫</strong>(基礎工事が施され土地に定着していること)</li>
<li><strong>屋外野球場の観覧席のうち、屋根を有する部分</strong></li>
</ul>
<h3>建物として登記できないもの(×)</h3>
<p>反対に、「建物として認められない」とされた代表例です。</p>
<ul>
<li><strong>駅のホーム内にある売店</strong>(コンクリートで基礎工事が施されていても、停車場〔ホーム〕の一部であり独立性がないため)(昭63.3.24民三1826号)</li>
<li><strong>ガスタンク・石油タンク・給水タンク</strong>(液体等を満たす密閉容器であり、人がその内部空間を利用する用途性を欠くため)(準則77条2号ア)</li>
<li><strong>公衆用道路上に屋根覆いを施しただけのアーケード付街路</strong>(周辺が店舗に囲まれていても、アーケード部分だけでは建物として認められない)(準則77条2号エ)</li>
<li><strong>容易に運搬することができる切符売場・入場券売場</strong>(定着性を欠くため)(準則77条2号オ)</li>
<li><strong>屋根を有しない観覧席</strong>(競馬場・野球場等)(外気分断性を欠くため)</li>
<li><strong>土地に鉄骨柱の土台を置いただけで、容易に移動可能な組立式の事務所</strong>(定着性を欠くため)</li>
<li><strong>機械の上に建設され、地上に基脚や支柱を持たない建造物</strong>(土地そのものに定着していないため)</li>
<li><strong>耐用年数がおおむね1年程度のビニール材質の温室(ビニールハウス)</strong>(半永久性がなく、定着性・耐久性の点で建物として扱われない)(準則77条1号オただし書)</li>
</ul>
<h3>紛らわしいポイントに注意</h3>
<p>同じような構造物でも、<strong>細部の違いで結論が逆転する</strong>組み合わせがよく出題されます。</p>
<ul>
<li><strong>温床施設</strong>：ガラス等で造られ半永久的なもの→○／耐用年数概ね1年程度のビニールハウス→×(耐久性の有無で分かれる)</li>
<li><strong>観覧席</strong>：屋根がある部分→○／屋根がない部分→×(外気分断性の有無で分かれる)</li>
<li><strong>駐車場</strong>：屋根・外壁があり回転式パーキング機械を備えた立体駐車場→○(3要件を満たすため)</li>
<li><strong>切符売場</strong>：容易に運搬できるもの→×／土地に固定した事務所(コンテナボックス利用の貸倉庫等)で基礎工事を施したもの→○(定着性の有無で分かれる)</li>
<li><strong>タンク類</strong>：石油タンク・ガスタンク・給水タンクはいずれも用途性を欠くとして一律に×(サイロと混同しないよう注意)</li>
</ul>
<h3>まとめ</h3>
<p>建物認定の問題は、一見すると「変わった構造物を丸暗記する分野」に見えますが、実際には<strong>定着性・外気分断性・用途性という3つの物差しに当てはめるだけの機械的な作業</strong>です。上記の○×リストを、3要件のどれが決め手になっているかとセットで覚えておくと、初めて見る構造物が出題されても対応できるようになります。</p>
<h3>見出し画像用フレーズ</h3>
<ul>
<li>建物の認定は、たった3つの要件で決まるんです</li>
<li>サイロは○、タンクは×、その違い分かりますか？</li>
<li>屋根があるかないかで、結論が逆転するんです</li>
<li>「動かせるかどうか」が、建物認定のカギなんです</li>
<li>桟橋の上の建物も、ちゃんと登記できるんです</li>
</ul>
