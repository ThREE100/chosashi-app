## 作り方・守ったこと

- **図解**（`src/gen_infographic.py`）：`note-articles/infographic-prompt-template.md` と `joubun-nigate/common/infographic_parts.py` の共通部品（簡体字対策・背景の不透明化・最終確認）で組み立てた。この科目の図解は「拒めるか」「要るか」「義務か裁量か」の分類が中心で、はい／いいえの分岐ではないため、青・赤は使わず、濃紺・薄い灰色・薄い黄色のマーカーで描く指示にした。画像の中には、図の番号・問題番号・個人の演習結果（誤答の回数など）を入れない（`CLAUDE.md` の条文別シリーズのルールと、図番を入れないルールに合わせた）。
- **4コマ**（`src/spec_4koma_C1-*.py` → `src/build_4koma.py`）：`tools/drill/manga/MANGA_RULES.md` の設計メモ（出題者のひっかけ・受験者の勘違い・対比する制度・型の選び方）を書き、生成器 `gen_prompts.py` の `render()` で作って `check_prompt.py` で NG 0件・WARN 0件にした。5本とも型5（整理カード併用。列挙の記憶が肝のため）。単独のnote記事用の節（記事タイトル・冒頭文・見出し画像）は、総合記事に差し込むため外し、保存名を足した（条文別シリーズと同じ体裁）。結論帯の問題番号は載せる。
- **条文**：画像に載せた条文の語は、`note-articles/laws/chousashi-hou.md`・`chousashi-hou-sekourule.md` の原文と照合した（`src/check_all.py`）。
- **記事から外れないこと**：図・セリフは記事の結論・用語の範囲。出題当時の言い方と今の言い方の違い（身体又は精神の衰弱／心身の故障、禁錮／拘禁刑）は、肢を解く決め手にならないので画像に入れていない。
- **対象外にした肢**：D2000はD0902と1本にまとめた。D0610・D1612は1本にまとめた。D0706の逆の結論の肢D0707（法人の社員の競業禁止、法37条1項）は、記事にない論点なので扱っていない。
