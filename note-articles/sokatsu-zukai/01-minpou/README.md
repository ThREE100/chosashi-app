## 使い方・直し方

- 4コマ：ChatGPTにキャラ仕様書の参照画像（`CHATGPT_MANGA_WORKFLOW.md` §3の6枚）を添付し、トリ先生・藍子の区別を一言添えて、プロンプト本体のコードブロックを貼る。直すときは `src/spec_4koma_M?-?.py` を直し、`python3 tools/drill/manga/render_spec.py <spec> <出力フォルダ>` で再生成して、`<fid>_prompt.md` を `prompt_4koma_M?-?_<fid>.md` に名前を変え、`check_prompt.py` で NG 0件・WARN 0件を確かめる（再生成すると冒頭の注記が消えるので、手で戻す）。
- 図解：ChatGPTにプロンプト本体のコードブロックを貼る（キャラクターは描かないので参照画像は不要）。直すときは `src/gen_infographic_M?-?.py` を直して再実行する。
- 画像の中には、図の番号・個人の演習結果・判例番号を入れていない（4コマの結論帯の問題番号は定型どおり入れている）。
- 総合記事の本文には個人の解答履歴に基づく統計が入っているが、これらの画像プロンプトには入れていない。
