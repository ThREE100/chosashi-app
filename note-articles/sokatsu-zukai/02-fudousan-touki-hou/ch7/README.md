## 作り方・守ったこと

- **図解**（`src/gen_infographic.py`）：`note-articles/infographic-prompt-template.md` と `joubun-nigate/common/infographic_parts.py` の共通部品（簡体字対策・背景の不透明化・最終確認）で組み立てた。この章の図解は、分類・早見表・カードが中心なので、青・赤は使わず、濃紺・薄い灰色・薄い黄色のマーカーで描く指示にした。**はい／いいえの分岐がある図解4（判定の流れ）だけ**、はい＝青・いいえ＝赤（共通部品の `COLOR`）。画像の中には、図の番号・問題番号・個人の演習結果（誤答の回数など）を入れていない（`CLAUDE.md` の条文別シリーズのルールと、図番を入れないルールに合わせた）。
- **4コマ**（`src/spec_4koma_PF2-*.py` → `src/build_4koma.py`）：`tools/drill/manga/MANGA_RULES.md` の設計メモ（出題者のひっかけ・受験者の勘違い・対比する制度・型の選び方）を書き、生成器 `gen_prompts.py` の `render()` で作って `check_prompt.py` で NG 0件・WARN 0件にした。型は、4コマ1が型3（理由説明）、4コマ2〜6が型5（整理カード併用。登記原因の並べ方、起算点の3つ、抵当権がからむ添付情報の3つ、存続登記の対象の4つ、同一でなければならない4つ、を右側の整理カードに置いた）。単独のnote記事用の節（記事タイトル・冒頭文・見出し画像・画像ファイル名）は、総合記事に差し込むため外し、保存名を足した（条文別シリーズと同じ体裁）。結論帯の問題番号は載せる。登場人物はトリ先生と藍子だけで、「HTML描画版」は使っていない。
- **条文**：画像に載せた条文の語は、`note-articles/laws/` の原文（不動産登記法49条・50条・60条、不動産登記令別表13の項、不動産登記規則35条、登録免許税法別表第一）と照合した（`src/check_all.py`）。現行法令を正とし、出題当時の言い方との違いで結論が変わる点はない。
- **記事から外れないこと**：図・セリフは記事の結論・用語の範囲。記事が「条文に明記なし」「実務の取扱い」とする点は、画像にもそう書いた（下の確認事項）。

## 確認事項（ユーザーに見てほしい点）

- 画像の生成・目視確認は未実施（この表の全プロンプトが対象）。
- **条文に明記がなく、記事が実務の取扱い・実務の整理としている点**（画像でも断定せず、そのとおり明記した）：
  - 未登記どうしの合体の登記原因が「新築、新築、合体」の形になる点（図解4・4コマ2）。
  - 賃借権が建物の持分の上に登記できず、存続させられない点（図解7・4コマ5）。記事が「先例による」「根拠は確認できていません」としている。
  - 全員が申請人で印鑑証明書を提供したときは、持分の割合を証する情報が別に要らない点（図解9）。
  - 住所に変更があっても先に変更の登記は要らない点（図解10・図解1。既存のD0995・D1888で確認）。
- **記事の本文にはなく、条文（法令DB）から作った整理**：図解4の「所有権の登記がある建物と、ない建物が混じっていれば所有権の登記を併せて申請する」は、法49条1項後段（2号・4号・6号）から作った（記事の本文は2号の場合だけを書いている）。図解5の1号〜6号の表は法49条1項の原文、図解8のイ〜リは令別表13の項の添付情報欄の原文の要約（ヘは「規約を設定したことを証する情報など」と要約した）。
- **載せなかった点**：4コマ1では、「附属建物を先に分割する」という順序は、肢の解説にないので図に入れていない（記事の本文には「まず…分割の登記が要り、次に合体による登記等」とある）。4コマ3では、法49条3項が1号・2号・6号の場合に限られる点は、細かすぎるので図に入れていない。
- 4コマ3の出典表記は「H23-Q18イ・エ」（同じ問のイとエを1本にまとめたため）。
- 見出し画像のサブタイトルは、指定どおり「⑦」の丸数字を含む。画像生成AIが丸数字を別の字にしないか、検品で確かめてください（`gen_midashi.py` は、丸数字⑦だけを許す書き方に直している）。
- 共通ファイル（`tools/drill/manga/` の `MANGA_RULES.md` の「構成の知見ログ」など）は変更していない。今回の知見（合体の肢は、起算点・添付情報・存続の対象のような「並べて覚える列挙」が肝になるため型5が合う。2肢を1本にまとめるときは、コマ1を肢ごとの言い分のカード、コマ2を対比にすると重複しない）を知見ログに足すかどうかは、判断をお願いします。
