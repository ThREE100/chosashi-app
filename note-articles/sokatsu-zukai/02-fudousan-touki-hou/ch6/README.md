## 作り方・守ったこと

- **図解**（`src/gen_infographic.py`）：`note-articles/infographic-prompt-template.md` と `joubun-nigate/common/infographic_parts.py` の共通部品（簡体字対策・背景の不透明化・最終確認）で組み立てた。この章の図解は『できない建物の一覧』『要る・要らない』『原則と例外』の分類が中心なので、見本のとおり青・赤は使わず、濃紺・薄い灰色・薄い黄色のマーカーで描く指示にした。フローチャート（図解4）は、はい／いいえの文字を使わない判定の流れなので、分岐の矢印とラベルを濃紺とし、結果の箱だけを『5号の制限に当たらない＝青』『5号の制限に当たる＝赤』で塗り分けた（緑には触れていない）。画像の中には、図の番号・問題番号・個人の演習結果（誤答の回数など）を入れない。
- **4コマ**（`src/spec_4koma_PF1-*.py` → `src/build_4koma.py`）：`tools/drill/manga/MANGA_RULES.md` の設計メモ（出題者のひっかけ・受験者の勘違い・対比する制度・型の選び方）を肢ごとに書き、生成器 `gen_prompts.py` の `render()` で作って `check_prompt.py` で NG 0件・WARN 0件にした。型は肢ごとに選んだ：4コマ1＝型5（法56条1号〜5号の整理カード）、4コマ2＝型3（原則・例外・付随する登記の理由カード）、4コマ3＝型4（3肢の比較表）＋型5（要る・要らない）、4コマ4＝型4（4肢の比較表）＋型5（分棟の押さえどころ）、4コマ5＝型3（なぜ転写できないか）、4コマ6＝型3（なぜ図面が要るか）。複数の肢をまとめた本は、コマ1を『場面／問われていること』の比較表（または時の順のカード）にした。単独のnote記事用の節（記事タイトル・冒頭文・見出し画像・画像ファイル名）は、総合記事に差し込むため外し、保存名を足した（条文別シリーズ・調査士法編と同じ体裁）。
- **画像の中の問題番号**：4コマの図の中には『肢D○○○○』のタグを置かず、『共用部分の場面』『移転の仮登記の場面』のような場面の名前の短いタグにした（今回の指示。調査士法編の見本は肢IDのタグを入れていた）。結論帯の問題番号だけは載せる（生成器が自動で入れる）。`src/check_all.py` が、結論帯以外の画像の文言に問題番号が入っていないことを確かめる。
- **条文**：画像に載せた条文の語は、`note-articles/laws/` の原文（不動産登記法・令・令別表・規則・準則・登録免許税法）と照合した（`src/check_all.py`）。記事が『条文に明記なし』『実務の取扱い』としている点は、画像でもそう添えて断定していない。
- **記事から外れないこと**：図・セリフは記事の結論・用語の範囲。出題当時と今の言い方の違いは、肢を解く決め手にならないので画像に入れていない。分割の登記の課税など、肢の記事にない内容は4コマに入れていない。

- **git**：操作していない（add・commit・pushなし）。他の章のフォルダと `tools/` の共通ファイルは変更していない。
