## 作り方・守ったこと

- **図解**（`src/gen_infographic.py`）：`note-articles/infographic-prompt-template.md` と `joubun-nigate/common/infographic_parts.py` の共通部品（簡体字対策・背景の不透明化・最終確認）で組み立てた。この章の図解は、分類（早見表・対比カード）と手続の流れ（ステップ・フローチャート）が中心。はい／いいえの分岐を持つ判定の流れ図（図解4・17）だけ、「はい」は青・「いいえ」は赤にし、ある／ないのような中立の分岐（図解7）と、分類の図は、青・赤を使わず、濃紺・薄い灰色・薄い黄色のマーカーで描く指示にした。画像の中には、図の番号・問題番号・個人の演習結果（誤答の回数など）を入れていない。
- **当事者の呼び方**：画像の文字は標準の日本語だけ（ラテン文字を使わない）ので、共有者などの当事者はA・B・Cではなく、甲・乙・丙、または「加わる者」「外れる者」のような役割で書いた（4コマも人型を描かず、文字のカードで示す）。
- **4コマ**（`src/spec_4koma_PA-*.py` → `src/build_4koma.py`）：`tools/drill/manga/MANGA_RULES.md` の設計メモ（出題者のひっかけ・受験者の勘違い・対比する制度・型の選び方）を肢ごとに検討して書き、生成器 `gen_prompts.py` の `render()` で作って `check_prompt.py` で NG 0件・WARN 0件にした。型は、4コマ1＝型5（整理カード併用）、4コマ2＝型3（理由説明）、4コマ3＝型3、4コマ4＝型5、4コマ5＝型3、4コマ6＝型5。単独のnote記事用の節（記事タイトル・冒頭文・見出し画像・画像ファイル名）は、総合記事に差し込むため外し、保存名を足した（調査士法編と同じ体裁）。結論帯の問題番号は載せる。HTML描画版は使っていない。
- **4コマの肢の選び方**：記事の「肢ごとの判定」で誤答の多い肢（★）と付録の最優先肢、結論が逆になりやすい対比の肢を優先した。この章の最優先肢（付録のD0448）は既存の4コマで、★のD1033は4コマ1、D1482は4コマ3でカバーした。似た肢は1本にまとめた（4コマ1：D1033・D0447、4コマ2：D0701・D0702、4コマ3：D1482・D0842、4コマ4：D0661・D0665、4コマ5：D1026・D1027、4コマ6：D0658・D0660・D1463）。
- **条文**：画像に載せた条文の語は、`note-articles/laws/` の原文（法・令・規則・令別表・準則・民法）と照合した（`src/check_all.py`）。4コマの図に出る「民法○条」「不動産登記法○条」は、`check_prompt.py` が肢の元記事にあるか確かめる（この本では「法33条」のように書き、肢の記事にあるものだけを使った）。
- **記事から外れないこと**：図・セリフは記事の結論・用語の範囲。条文に明記のない点は、断定せず「整理」「実務上の取扱い」「条文に明記なし」と書いた（下の確認事項）。出題当時と現在で言い方が違う点は、肢を解く決め手にならないので画像に入れていない。

## 確認事項（ユーザーに見てほしい点）

- 画像の生成・目視確認は未実施（この表の全プロンプトが対象）。
- 条文に明記がなく、記事または条文の文言からの整理として載せた点：
  - 図解9・4コマ3：表示に関する登記を「保存行為」として共有者の一人から単独で申請できるという整理（記事が「条文に明記はなく、解釈による」と書いている。民法252条5項の保存行為の語は図に入れた）。
  - 図解10・4コマ4：抵当権者が代位して分筆を申請できる、地役権者は保全の必要性がなく代位できないという整理（記事が「民法423条による代位の整理」「条文に直接の定めはない」と書いている。図に注記を入れた）。共有地の分筆を持分の価格の過半数で申請できるという整理は、条文で確認できていないので図に入れていない。
  - 図解11：補正のための取下げに特別の委任が要らないという点（条文に明記なし、実務上の整理と図に注記）。
  - 図解14：一部取壊しの後に増築して一の申請情報でするときは、全体で床面積が減っても増築部分の所有権証明が要るという点（実務上の取扱いと図に注記）。
  - 図解8：原始取得者が一部を売却した場合に「代位の形をとるのは転得者の側」という点（記事の整理）。
  - 図解15：「調査士報告方式」の対象外（調査報告情報、地役権者作成の情報）の整理は記事の整理。図の左のカードは令13条1項・2項の文言。右のカードは、1つ目・3つ目が同条1項の括弧書、2つ目は1つ目の具体例（代理人の作成）、4つ目は記事の整理。
  - 図解18：「申請前3月以内の住所変更の登記は準則33条1項の列挙にない」という点は記事の整理。準則33条1項には、列挙のほかに「登記官が職務上知り得た事実により、客観的かつ合理的な理由があると認められるとき」の号（7号）もあるので、図では「この列挙にない」「それだけでは調査義務は生じない」にとどめた。
- 図解4（加わる者の有無で分かれる更正の添付情報）では、記録から外れる者がいない場合（D0447の「AからA及びBへ」）の承諾の要否は断定せず、「外れる者がいれば、その承諾」とした。記事も、新たに加わる者について所有権・住所の証明、外れる者について承諾、と整理している。令別表は、記事では「2項」と書かれているが、法令DB（令別表）では「二」の項に当たる。画像には項番号を入れていない。
