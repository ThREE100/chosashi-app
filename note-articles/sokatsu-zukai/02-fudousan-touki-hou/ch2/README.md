## 作り方・守ったこと

- **図解**（`src/gen_infographic.py`）：`note-articles/infographic-prompt-template.md` と `joubun-nigate/common/infographic_parts.py` の共通部品（簡体字対策・背景の不透明化・最終確認）で組み立てた。型は、早見表（3列）・対比カード（2列）・カードポスター・ステップ・判定の流れの5つ。分類や対比が中心の図は、青・赤は使わず、濃紺・薄い灰色・薄い黄色のマーカーで描く指示にした。判定の流れ図（図解12）だけ、はい＝青・いいえ＝赤で描く（緑には触れない）。画像の中には、図の番号・問題番号・個人の演習結果（誤答の回数など）を入れない。
- **4コマ**（`src/spec_4koma_PB-*.py` → `src/build_4koma.py`）：`tools/drill/manga/MANGA_RULES.md` の設計メモ（出題者のひっかけ・受験者の勘違い・対比する制度・型の選び方）を書き、生成器 `gen_prompts.py` の `render()` で作って `check_prompt.py` で NG 0件・WARN 0件にした。型は、4コマ2＝型3（理由説明）、4コマ3・4＝型4（複数肢の対比。コマ1は比較表）、4コマ7・5・6＝型5（整理カード併用）。単独のnote記事用の節（記事タイトル・冒頭文・見出し画像・画像ファイル名）は、総合記事に差し込むため外し、保存名を足した（見本と同じ体裁）。結論帯の問題番号は載せる。HTML描画版は使っていない。
