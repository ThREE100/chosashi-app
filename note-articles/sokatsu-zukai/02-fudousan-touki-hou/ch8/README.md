## 作り方・守ったこと

- **図解**（`src/gen_infographic.py`）：`note-articles/infographic-prompt-template.md` と `joubun-nigate/common/infographic_parts.py` の共通部品（簡体字対策・背景の不透明化・最終確認）で組み立てた。分類・列挙が中心の図（カードポスター・表・ステップ）は青・赤を使わず、濃紺・薄い灰色・薄い黄色のマーカーで描く指示にした。**判定の流れ図（図解3・図解8）だけ、はい＝青・いいえ＝赤**（緑には触れない）。画像の中には、図の番号・問題番号・個人の演習結果（誤答の回数など）を入れない。
- **4コマ**（`src/spec_4koma_PG1-*.py` → `src/build_4koma.py`）：`tools/drill/manga/MANGA_RULES.md` の設計メモ（出題者のひっかけ・受験者の勘違い・対比する制度・型の選び方）を書き、生成器 `gen_prompts.py` の `render()` で作って `check_prompt.py` で NG 0件・WARN 0件にした。型は、4コマ1・6が型5（整理カード併用）、4コマ2・3・4は型4（共通の問い・場面を並べる）＋型5、4コマ5は型3（理由説明）＋型5。単独のnote記事用の節（記事タイトル・冒頭文・見出し画像・画像ファイル名）は、総合記事に差し込むため外し、保存名を足した（見本の `03-chousashi-hou` と同じ体裁）。**結論帯の問題番号は載せるが、カードやチェック欄の文言には肢のIDを入れていない**（`src/check_all.py` が確かめる）。
- **条文**：画像に載せた条文の語は、`note-articles/laws/` の原文（不動産登記法・区分所有法・不動産登記令別表・不動産登記規則）と照合した（`src/check_all.py`）。
- **記事から外れないこと**：図・セリフは記事の結論・用語の範囲。「条文に明記なし」「登記実務の取扱い」とされた項目（図解6・7・8、4コマ2・3・5）は、画像でも断定せず、そう書いたリボンやタグを添えた。出題当時と今の言い方の違いは、肢を解く決め手にならないので画像に入れていない。
- **対象外にした肢**：D1364（用途に使えるのは「利用上」の独立性）は、構造上⇔利用上の対比を既存のD1356の4コマが扱うので新作にしていない。D1584（登記記録に地上権が記録されることがある）は図解3の注記、D1792（敷地権付きでなくても一棟の全部を併せて申請）は図解5、D1290（区分合併で非区分建物になるときの敷地権の抹消は職権）は図解10の補足カードで扱い、4コマにはしていない。D1367は既存のD1368の裏の肢。D1082（合体で割合を合算するだけなら規約証明は要らない）は、裏の肢D1579を扱う条文別シリーズの4コマと図解11でカバーした。
