## 作り方・守ったこと

- **図解**（`src/gen_infographic.py`）：`note-articles/infographic-prompt-template.md` と `joubun-nigate/common/infographic_parts.py` の共通部品（簡体字対策・背景の不透明化・最終確認）で組み立てた。**判定の流れ図**（図解3・7・9・12・17）は、はい＝青・いいえ＝赤（緑には触れない）。「同じ一棟／別の一棟」のように「はい／いいえ」でない分かれ道は、矢印とラベルを濃紺にして、青・赤を使わない。**分類・早見表・比較カード**の図は、はい／いいえの意味がないので、濃紺・薄い灰色・薄い黄色のマーカーで描く指示にした。画像の中には、図の番号・問題番号・個人の演習結果（誤答の回数など）を入れていない。
- **4コマ**（`src/spec_4koma_PE-*.py` → `src/build_4koma.py`）：`tools/drill/manga/MANGA_RULES.md` の設計メモ（出題者のひっかけ・受験者の勘違い・対比する制度・型の選び方）を、肢ごとに検討して書き、生成器 `gen_prompts.py` の `render()` で作って `check_prompt.py` で NG 0件・WARN 0件にした。型は、4コマ2・2・4が型5（整理カード併用。型1と組み合わせ）、4コマ4・5・6が型3（理由説明。型1の対比と組み合わせ）。単独のnote記事用の節（記事タイトル・冒頭文・見出し画像・画像ファイル名）は、総合記事に差し込むため外し、保存名を足した（条文別シリーズ・調査士法編と同じ体裁）。結論帯の問題番号は載せる。
