## 作り方・守ったこと

- **図解**（`src/gen_infographic.py`）：`note-articles/infographic-prompt-template.md` と `joubun-nigate/common/infographic_parts.py` の共通部品（簡体字対策・背景の不透明化・最終確認）で組み立てた。分類・早見表・時間の流れが中心の図は、青・赤・チェック・バツを使わず、濃紺・薄い灰色・薄い黄色のマーカーで描く指示にした。はい／いいえの判定の流れ図（図解11・図解17）だけ、はい＝青・いいえ＝赤の配色にした。画像の中には、図の番号・問題番号・個人の演習結果（誤答の回数など）を入れていない。
- **4コマ**（`src/spec_4koma_PC-*.py` → `src/build_4koma.py`）：`tools/drill/manga/MANGA_RULES.md` の設計メモ（出題者のひっかけ・受験者の勘違い・対比する制度・型の選び方）を書き、生成器 `gen_prompts.py` の `render()` で作って `check_prompt.py` で NG 0件・WARN 0件にした。型は肢ごとに選んだ：4コマ1・3・5＝型5（整理カード併用。列挙の記憶が肝）、4コマ2＝型4（同じ事例から枝分かれする3肢の対比。コマ3の右に型5の整理カード）、4コマ8＝型2（押さえどころ・読み方3ステップ。切り分けが肝）、4コマ12＝型3（理由説明。なぜ審査請求できるのか）。単独のnote記事用の節（記事タイトル・冒頭文・見出し画像）は、総合記事に差し込むため外し、保存名を足した（総合記事③と同じ体裁）。結論帯の問題番号は載せる。共通の図の指示文は `src/fig_parts.py` に部品としてまとめた。「HTML描画版」は使っていない。
- **条文**：画像に載せた条文の語は、`note-articles/laws/` の原文（不動産登記法・令・規則・準則）と照合した（`src/check_all.py`）。記事が「条文に明記なし」「実務の取扱い」とする点は、画像でも断定せず、そう書いた（下の確認事項）。
- **記事から外れないこと**：図・セリフは記事の結論・用語の範囲。出題当時の言い方と今の言い方の違いは、肢を解く決め手にならないので画像に入れていない。

- **共通ファイルは変更していない**：`tools/drill/manga/` の `MANGA_RULES.md`・`gen_prompts.py`・`check_prompt.py` や、他の章のフォルダ（`ch1`・`ch2`・`ch4`〜）は触れていない。
